# 页的变换与量化

## 负责

一张源页的字节进来，一张**量化图**出去：像素已经转成灰度、裁掉白边、拆过跨页、缩到目标尺寸、
纸色提过白，并且已经按**某一个候选**落到那一档的格点上（连它那一档一起交出去）。
它只管这一页——不认卷、不认盘、不印字、不往报告里填数。

## 顺序

解码 → 彩页识别（在转灰之前，转过之后就没有颜色可看）→ 转灰，或走彩色分支 → 裁白边 →
跨页判定与拆分 → 两半各再裁一次 → 适配 → 缩放（预缩 + 残差段）→ 纸色提白 → 构造参照 → 按候选量化。

## 定点

- **尺寸贴合检查逐页判**，问的是「目标尺寸有一条边贴住面板」。判定范围是灰度路径上的每一页：
  彩页走彩色分支，它既不量化也不抖动，门撑的两件事与它无关（ADR 0010）；坏页连几何都没有；
  残缺页在范围内——它的尺寸是文件头里的真尺寸。门之下「不再被下游缩放」要阅读器做什么，
  两种缩放方式不一样，门够不着这个差别。
- **缩放分两级**：整数倍等权 box 预缩只在总缩放比 ≥ 2 时存在；残差段是主重采样器，恒为 Lanczos3。
  等权平均当主重采样器只剩模糊，因此它固定只作用于预缩那一级（ADR 0001）。
- **裁白边按行列墨量占比**，不取内容外接框——外接框边缘沾一个墨点就退回整页，而扫描件的白边里
  本来就有噪点。逐页各裁各的，**不取卷级裁切框**（卷级框会被留白最多的那一页拖住）。
- **拆分跨页是两级判定**：宽高比挑候选，中缝定切点。**找不到中缝即不切**——那是硬约束，不是兜底：
  切不切由中缝决定，不只是切在哪。中缝与裁白边是同一类扫描，没有第二套墨量依据。
- **纸色提白落在灰度路径上、缩放之后、构造参照之前**：参照与其后一切量化用的都是对齐过的像素，
  画质分两侧因此同源，量化仍然是唯一被隔离出来的变量。彩色分支不经它（ADR 0010）。
- **解码的界线画在「救不救得回像素」上**，不在「解不解得出尺寸」上——尺寸买不到像素。三种结局：
  完好页 / 残缺页（照常写出、缺的那一段留纸白、不参与整卷统一灰阶）/ 坏页。

## 边界

- **不认卷**：卷、成员、到达顺序在[处理范围](scope.md)与[读写](io.md)那一侧。
- **不认盘**：进来的是字节，出去的是像素；这一层一个字节都不读、不写。
- 这一层唯一对外的判据是尺寸贴合检查——抖动、灰阶硬上界、落格都拿它当条件。

决定出处：ADR 0001、ADR 0007、ADR 0008。数值一律以[实测数字](../../docs/measurements.md)为准。
