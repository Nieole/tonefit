# 处理范围与清点

## 负责

三件事，都在**开工之前**：

1. **发现**：用户点名的一个路径展开成一批卷；
2. **收编**：互相嵌套或重复点名的路径按卷根合成一份，镜像路径以最外层那条为准；
3. **计数**：把每一卷枚举一遍，算出这一趟的**全局总步数**。

外加一把尺子——**同一处**：两条路径指不指着盘上同一个地方。收编、借住、撞名、逐层补全都用它。

## 定点

- **点名的是在哪里找，不是找到什么。** 处理范围是用户点名的子集：不做全库扫描、不维护全库索引，
  源库只读（ADR 0009 决定第 1 条）。
- **两条规则就是这条边界**：路径是归档 → 一个卷，内部结构照收；路径是目录 → 直接躺着页就**同时**是
  一个卷（只收直接那一层），并且**继续往下发现**。一个目录可以既是卷又装着卷，而**一页都不许被
  处理两遍**是这条规则的硬边界（ADR 0014）。
- **发现的是候选，不是卷**：它按盘上的形状列出来，一个内容字节都不解，也不知道哪一卷做不做得成。
- **清点只列成员、不碰像素**：目录卷列一层目录，归档卷读归档头。它算出来的是**上界，不是承诺**——
  两遍枚举之间源变了，开工报的步数与报告里的成员数会分家，那时静默按上界处理（词汇表《尚未确立》）。
- **同一处**：先字面规整——相对路径**先接上当前目录**（只接，不做别的规整），再去掉 `.` 分量与尾分隔符，
  **不解析 `..`**——再按**那一侧**的大小写敏感性决定折不折。探不出时两侧取相反的一边（源那一侧按认，
  输出那一侧按不认）。**软链不解析**：两个名字就是两个地方。
- **一种地方两种处置**：**自动跳过的目录默默跳过**——不进退出码、不进任何一栏、报告上一个字都没有；
  **无法访问的地方**逐条报出来，并且进退出码。分得开它们的是「换一趟会不会好」。
- 点名的路径点不开是**拒绝开始**；发现出来的归档点不开是**非漫画文件**，其余卷照做。

## 边界

- 不碰像素、不判画质、不写盘。
- 那把尺子只拿来比，不拿来印：报告里印的仍是用户点的那一条写法。

决定出处：ADR 0009、ADR 0011（决定第 3 条）、ADR 0014。
