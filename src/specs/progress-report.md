# 进度与报告

## 负责

- **进度**：库把一条**事件**交给观察者，观察者收下它、回一个**指令**。
- **报告**：一趟跑完的那份结构化数据，也是每条卷级事件带出去的那一片。

## 定点

- **事件流就是报告的增量**：一卷跑完的那条事件带着那一卷的 `VolumeReport`，调用方边跑边把整份报告
  攒出来。命令行攒完一次性渲染，会话攒到哪儿画到哪儿——同一份数据，不是两套（ADR 0011）。
- **观察者是双向的**：取消不必另开一条信号通路，「写出环节之前停下来问一句」与「按停止」走同一个
  机制。库只管在该问的地方问，等不等人由调用方定（ADR 0012 决定第 3 条）。
- **观察者可能很久不返回**——会话就要在确认点上等人拿主意，那是它正常的样子。因此有一条硬规矩：
  **任何持锁的地方都不许调它**；持锁哨兵守的是最要命的那一把（卷缓存那把锁）。
- **指令只升不降**：库记的是至今为止收到过的最强那一个——按停止是个闩，手指离开键盘之后下一条事件
  答「继续」，不该把已经按下的那一下抹掉。**闩不止一份，编码只有一份**：库记观察者答过什么、
  界面层各记用户按过什么，「三级怎么编成一个字节」是库的公共 API。
- **步数是上界**：全局总步数就是各卷步数之和。幂等命中的卷提前收摊，画全局进度的那一层因此要在
  一卷跑完时结清那一卷预告剩下的步——不结清就在条上留下一段永远走不完的距离。
- **四种结局各占一个退出码**：`0` 全部成功 · `1` 这一趟没做成（拒绝开始）· `2` 做完了但有卷被隔离 ·
  `3` 有卷没做成**或有地方无法访问**。`2` 与 `3` 同时成立取 `3`——「有卷带着坏页」与「有卷根本没做成」
  是两个不同的决定。
- **报告分列**：做成了的卷、没做成的卷、非漫画文件、无法访问的地方。跨两列的先后**一处都没记**
  （卷报告只有时长，没有起止时刻），命令行因此只能先摆一列再摆另一列（词汇表《尚未确立》）；
  会话的卷列表按发现出来的先后排，不复原它。
- **拒绝开始的单子只有一份**（词条《拒绝开始》）：实现文档一律指过去，不各列一遍。

## 边界

- 库这一侧只报到：**印在哪、印不印、长什么样、要不要在确认点上等人由调用方定**。往库里塞一个终端
  组件，等于让它替界面决定输出的样子，而用例也没法在不开终端的情况下问「它到底报到了吗」。
- 措辞不在报告里：报告出数据，文字在[界面层](cli.md)。

决定出处：ADR 0011、ADR 0013。
