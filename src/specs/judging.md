# 判定

## 负责

拿一张量化图算**画质分**，与 profile 里的**画质门槛**比，定下这一页的候选；`--envelope` 时再把逐页
判定收成卷级的一个统一档位。它答「这一页用几位、抖不抖」，不答这一页长什么样——那是[变换](page-transform.md)的事。

## 定点

- **候选是 (灰阶档位, 抖动模式) 的组合。** 候选集进来之前已经裁过两道：灰阶档位按屏幕灰阶数裁
  （ADR 0003），抖动按尺寸贴合检查裁（ADR 0007）。`--bit-depth` / `--dither` 够不着这两道界。
- **画质分是两项之和**：整体走样项（低通后的局部均值误差，量灰调塌陷与色带）与抖动颗粒项
  （候选比参照多出来的高频里，超出颗粒可见下限的那一部分）。只留整体走样项时，同一页内的序会排反——
  误差扩散的定义就是把量化误差摊进邻域、保住局部均值，于是结构性地偏袒抖动、看不见颗粒（ADR 0002）。
  **任何逐像素度量都不得单独作为候选之间的选择依据。**
- **分块聚合**取上分位与「第 K 差的那一块」之间更严的那个。
- **选的是界以内最低的一档**，不是误差最小的那一档——误差最小的恒是候选上界，那样判定就白做了。
- **默认路径上一页的档只取决于它自己**，不做迟滞、不回看邻居（ADR 0018）。整卷齐整是 `--envelope`
  的显式选择，那一层建在逐页这一层之上（ADR 0006），而「整卷统一灰阶」不等于「整卷一个档」：
  差异大的页单独定档、迟滞升档都会在卷内造成差，两个数原样摆进报告。
- **画质分跟着面板走**，不同面板之间不可比较；同一面板上标定出来的档位属于 profile、不属于面板。
  报告印出数值时一并印标定来源。未标定的数（分位、迟滞页数、差异大的页的倍数、聚合的 K、
  颗粒可见下限的上界）在数值旁边写「暂定值」——它们与画质门槛同一批该被复核。

## 边界

- 只出量、只选档。像素怎么变是[变换](page-transform.md)那一侧，字节怎么写出是[编码](encoding.md)那一侧。
- 面板与型号那张表在这里，但**设备的别名关系不是这一层的规矩**：设备只是面板的别名，多对一，
  面板相同的型号输出完全一致。

决定出处：ADR 0002、ADR 0003、ADR 0006、ADR 0018。数值一律以[实测数字](../../docs/measurements.md)为准。
