# 界面层

## 负责

命令行那一侧的全部：

- 把命令行参数拼成 `Request`，分派到库那三件事上，把进度画出来；
- 把 `Report` 渲染成文字；
- 按显示宽度折行、认字形、按「只列前几条」收口；
- 预设文件的读写；
- 按停止的两条规矩。

## 定点

- **无参数即会话，带参数即直接跑**，分岔排在 clap 之前：带参数那一路因此一字不变，连必填项的判定
  都没有被松动过。
- **措辞一处，排版两处**（ADR 0016）。报告的正文分成四段——抬头一次、卷级与逐页逐卷出、末尾小结收口——
  纯文本与表两副排版共用同一套措辞。一句话的出处只有一个；排版说的是它落在哪一列、缩几格、
  格与格之间怎么隔。
- **折行只在这一层**：按显示宽度（宽字符两格），在挨着空格或宽字符处断，禁则与行首缩进跟着走。
  `--help`、命令行报告、会话的详情栏、说明卡与预设栏共用这一套，只是折到的宽度不同——
  **屏上没有第二套折行规矩**。
- **字形约定与只列前几条是库的公共 API**，不是这一层的事：库会把自己造的字直接送进一条对齐的列里，
  也会把一条要用户照着抄的命令写进拒绝里。折法（折到多宽、断在哪儿）仍在这一层——两者量的
  不是同一块地方。
- **停止的两条规矩只此一份**：按一下升到哪一级、一条事件回哪个字。命令行的 `Ctrl-C` 与会话的 `s`
  都调它。它们住在 bin 里而非库里，因为「拿什么字来答」是调用方的策略；闩本身仍在三处各记各的。
- **预设只收两层**：设备设置与处理选项。路径与输出每趟都不同，不进预设；命令行上显式点到的那一项赢；
  不点名 `--preset` 的那一趟，命令行仍是全部输入。存出去的是**说了的那几项**——「没说」与「说了一个
  恰好等于默认值的值」是两件事。
- **`--brief` 只折正文**：抬头与末尾那几小结一个字不少——没做成的那几卷、进了隔离的那几卷只有末尾
  那几小结点得出是哪几个。它**不改产物**，不收预设、也不进参数哈希。
- **不带参数那一路之外，这一层不认会话**：会话是同一个层级的另一个薄壳。

## 边界

- 库不印字；这一层不判定、不碰像素、不开管线。
- 互锁那几句是唯一的例外：措辞在库内，这一层只做呈现——话落在哪一段、前面挂什么标签。
  同一句要从三张嘴里出来（报告抬头、`--help`、那条拒绝的错误），而最后一张嘴在库内。

决定出处：ADR 0016；停止的两条规矩见 ADR 0013。
