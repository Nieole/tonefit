# tonefit

把漫画页适配到电子墨水阅读设备：在尽量不影响阅读效果的前提下，**为每一页**选择缩放、几何裁切与输出位深。

一块 e-ink 面板分得开的灰阶只有十几级。把一本 8 位灰度的漫画原样拷进去，阅读器会自己降一遍——
降成什么样你说了不算，而**平缓的渐变会裂成一道道色带**。手工整批转又要在两头之间猜：
位深压低了出色带，压高了白付体积、翻页还更慢。

tonefit 的做法是**逐页判**：解一遍页、算一个判据值，拿它与那块面板上盲测出来的界比，
再决定这一页用几位、抖不抖动。判据跟着面板走，不同面板之间不可比较。

> **状态：0.1.0，仍在开发中。** 判据的阈值出自一块面板上的真机盲测，尚未逐面板复核——
> 换一块面板时请拿 `calibrate` 自己标一遍。

## 它能做什么

- **点名一个库，不是点名一个卷。** 给它一个目录，底下的归档与子目录各自成卷，一趟转完，
  产物按源的结构镜像出来。一个目录可以既是卷又装着卷（封面图与整套 cbz 混在一起也认得），
  而一页都不会被处理两遍。
- **四种归档进，`.cbz` 出**：`.cbz` / `.zip` / `.rar` / `.7z`，外加平铺的目录。
  输出扩展名一律归一成 `.cbz`——那是阅读器认的名字。
- **34 个内置型号**，覆盖 Kobo、BOOX、Kindle 的主力机型。表里没有你那台，
  可以按面板挑一个替身，或者用 `--gray-levels` / `--threshold` 自己填。
- **几何**：以高为准（默认）或整页装进面板、自动裁掉扫描白边、跨页自动拆分（认装订沟与阅读方向）。
- **幂等**：源与参数都没变的卷整卷跳过，一遍都不做。
- **一趟跑完有报告**：每一卷判成了哪一档、哪一页把整卷拉下来、哪一卷进了隔离、什么没被转换。
- **不带参数直接跑就进交互会话**：调参数、试算、看报告、满意了接着做第二遍，不必来回敲命令行。

**源库只读。** tonefit 不移动、不改名、不删除任何源文件。

## 构建

```
cargo build --release
```

需要：

| | |
|---|---|
| **Rust** | 1.98 或更高（edition 2024） |
| **C++ 工具链** | **必需**——`.rar` 的解码要编译 UnRAR 的 C++ 源码。Windows 上装了 MSVC 生成工具即可（`cc` 自己会找），Linux/macOS 上是 `g++` 或 `clang++`。约多花 40 秒，不必预装 libunrar |

可选特性：

- `--no-default-features` 去掉交互会话（不再依赖 ratatui），只留命令行。
- `--features profiling` 打开分阶段耗时剖面，只印到 stderr。

## 用法

```
tonefit --profile kobo-libra-2 --out D:\转好的 D:\漫画库\某作品
```

不带参数直接跑进交互会话：

```
tonefit
```

### 常用的几项

| | |
|---|---|
| `-p, --profile <型号>` | 目标设备。型号名不区分大小写与分隔符 |
| `-o, --out <目录>` | 输出根目录。产物镜像到它下面，点名路径自己的名字打头 |
| `--dry-run` | 只判不写。逐页读得出各档的判据值——自己标阈值时要的就是它 |
| `--fit <方式>` | `height`（默认，以高为准，宽允许超出面板、靠阅读器横向平移）或 `inside`（整页装进面板） |
| `--no-crop` / `--no-split` | 关掉裁边 / 关掉跨页拆分 |
| `--bit-depth` / `--dither` | 顶掉逐页判定，整卷按你说的来 |
| `--per-page` | 每页各判各的，不取卷级上包络 |
| `--preset <名字>` | 套一份存在盘上的预设。命令行上显式点到的那一项赢 |

`--help` 上每一项都有一段说明它为什么在那儿。

### 标定自己的设备

```
tonefit calibrate --profile kobo-libra-2 --out 标定图.png
```

把生成的图拷进设备、**以原尺寸打开**（关掉缩放、适配屏幕与白边裁切）。它一次答两件事：

1. **阅读器有没有把像素原样贴上**——抖动块与同均值实心块并置，分得开就说明没被重采样。
   这一件不过就别数灰阶，抖动在那种阅读器上做了等于没做。
2. **还分得开几级灰**——并排的位深阶梯，数出来的是**感知可分辨级数**，
   不等于规格表上的物理灰阶数。

判读说明中英两份都印在图里，不必对着文档看。

## 退出码

| | |
|---|---|
| `0` | 全部成功 |
| `1` | 拒绝执行——这一趟的参数或点名的路径有问题，一个字节都没写 |
| `2` | 有卷被隔离（有页失败，那一卷写进了隔离目录） |
| `3` | 有卷没做成，其余卷照常跑完 |

## 它是怎么工作的

一个卷走**两遍**，中间夹一次汇总：

```
幂等这一道 ──► 第一遍 ──► 汇总 ──► 第二遍
（算指纹，     解码、彩页识别、  （要看完整卷    只量化、编码、
  对得上就整     几何、缩放、      才做得了的      写出，不再碰
  卷跳过）       算判据并缓存      统计）          源页
```

判定默认取**卷级上包络**：整卷用同一档，免得翻页时深浅跳动；带迟滞，避免一两页把整卷拉高。
离群的那几页单独记进报告，不让它们自己当尺子。
