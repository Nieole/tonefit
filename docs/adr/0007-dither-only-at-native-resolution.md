# ADR 0007：抖动仅在目标尺寸未被下游缩放时启用

状态：已采纳（2026-08-25）

## 背景

抖动用高频误差换低频保真：误差被推到高频，而高频只有在输出像素与面板像素一一对应时，才落在看不见的尺度上。在低通判据下，抖动在各位深上都改善保真，体积代价随位深升高而降低（见《抖动》）。

目标尺寸一旦与阅读器实际显示的尺寸不一致，阅读器会再重采样一次，把高频噪声折回低频，抖动的收益随之退化。同一个前提还撑着 ADR 0003：面板灰阶数是位深的硬上界——插值会在 16 级灰阶之间重新造出中间灰度，上界当场失效。

所以这不是某一处的局部优化，而是一条被多处依赖的不变量：目标尺寸 = fit-inside(面板分辨率)，且输出不再被下游缩放。它需要一个显式的落点，否则迟早被一次读起来很合理的体积优化换掉。

1:1 说的是像素对应关系，不是填满屏幕。漫画页比面板更瘦，fit-inside 之后宽度小于面板宽，阅读器在两侧填背景、不重采样，1:1 仍然成立。

## 决定

**抖动仅在「目标尺寸 = fit-inside(面板分辨率)，且输出不再被下游缩放」成立时启用。**

- 它是 profile 级的**几何门**，取决于几何、不取决于页的内容，因此**不参与卷级统计**：位深按卷取上包络（见 ADR 0006：位深按卷取上包络并加迟滞），几何门先判。
- 条件不成立时抖动**整体关闭**，不降级成更温和的抖动模式。
- 几何门通过时，抖不抖跟着位深一起按卷决定：候选是 (位深, 抖动模式)，上包络取的是这个组合，不设页级抖动开关。离群页随它自己那个候选走（见 ADR 0006）。
- 判定它的开关与 ADR 0003 用的是同一个，不是两个。
- 目标尺寸只有一个来源：面板分辨率的 fit-inside 结果，不得为别的收益改动。

## 后果

**好的：**

- 抖动的前提成为 profile 里可判定的条件，而不是一条口头纪律。
- 「目标尺寸 = fit-inside(面板分辨率)，且输出不再被下游缩放」升格为显式不变量，同时被本文与 ADR 0003 依赖。
- 目标尺寸不再是可以拿来换体积的自由度，判据的参照因此唯一。
- ADR 0006 外包出来的「抖动那一栏」有了归属：几何门在 profile 上，内容侧跟着位深按卷走。

**要认的代价：**

- **留边。** 漫画页比面板更瘦，目标尺寸的宽小于面板宽，画面两侧留边。本文拒绝用改动目标尺寸来消除它。
- **B 类里有一批页源比目标还小，占比随面板差异很大**（见《B 类素材普查》），按不放大原样输出，几何门不成立，这批页没有抖动可谈。
- 用户在阅读器里放大或裁边时，1:1 前提在使用侧被打破，抖动收益退化。tonefit 只产出文件，无从感知，也无法在输出时补救。
- **任何改动目标尺寸的改动，都要同时对 ADR 0003 的硬上界负责**——两条约束的破裂条件是同一个，只算自己那一条的账，等于把另一条静默关掉。profile 里的几何门，以及「目标尺寸 == fit-inside(面板分辨率)」这条断言，都要在测试里覆盖。
- 抖动多一个必须在 profile 里维护、在测试里覆盖的条件分支。

## 备选方案

- **抖动无条件开启**：省掉开关，代价是在任何非 1:1 的显示路径上收益退化，ADR 0003 的硬上界一并失效。
- **抖动无条件关闭**：同样省掉开关，代价是丢掉低位深上那部分保真（见《抖动》）。
- **抖动做成页级开关**：判据确实能回答该不该抖，但页级开关会重新制造 ADR 0006 要消灭的翻页跳变。
- **把缩放比吸附到最近的整数**：收益只有个位数到十几个百分点，且符号不处处确定（见《缩放比与熵》），这笔账的细账在 ADR 0001；不值得拿 1:1 显示去换。
- **输出高于面板分辨率**，为阅读器内的放大平移留余量：破坏 1:1，且判据的参照定义在目标尺寸上，评估基准会跟着被改掉。
- **探测阅读器的实际显示缩放**：tonefit 看不到阅读器的显示管线，没有可用的探测手段。

## 不要做的「简化」

**「把目标尺寸往最近的整数缩放比上凑一凑，几何上那点偏差人眼看不出来」**——几何偏差确实看不出来；看得出来的是重采样把抖动噪声折回低频的后果，而抖动恰恰开在最吃保真的低位深页上。同一次微调还顺手废掉 ADR 0003 的硬上界：插值会重新造出中间灰度。换来的只是个位数到十几个百分点。
