# ADR 0005：解码一次，缓存缩放后的图

状态：已采纳（2026-08-25）

## 背景

三个特性要求先看完整卷：跨页拆分的判定（用卷内尺寸众数定单页基准）、固定元素检测（各页对齐后逐像素取中位数）、
位深的卷级上包络（见 ADR 0006：位深按卷取上包络并加迟滞）。三者的成本相差三个数量级：
跨页判定只要图片尺寸，读 PNG 的 IHDR 或 JPEG 的 SOF 即可，零解码；固定元素只要 1/16 降采样图；
**只有位深上包络需要全尺寸的缩放后图像**。

这一项无法靠廉价预扫绕开。JPEG 可以在 DCT 域直接解成 1/8 尺寸（`scale_denom`），PNG 没有这个能力，必须完整解码——
「轻量第一遍」在 PNG 源上会退化成完整第一遍，两遍解码就是实打实的两遍。
所以要决定的不是「要不要先看一遍全卷」，而是「那一遍看过的像素留不留」。

## 决定

1. **第一遍**：读 → 解码 → 彩页识别 → 拆分/裁边 → 单次仿射（deskew + 预缩 + 残差重采样）→ 算判据曲线；
   同时缓存缩放到目标尺寸的 8 位灰度图，即判据用的那份**参照**。LZ4 压缩，内存优先，
   超出 `--cache-budget` 溢写临时文件。
2. **汇总**：卷级 p95 上包络 + 迟滞 + 固定元素定位。**特例页识别排在上包络聚合之前。**
3. **第二遍**：从缓存读 → 量化（含可选抖动）→ 编码 → 写出，**不再碰源页**。
4. **彩色 profile 下彩页走彩色分支，不进灰度缓存。** 黑白 profile 下彩页先转灰，再走与其它页相同的灰度路径。
   彩色分支的形态——彩色 profile 由什么定、彩页怎么识别出来、编好的字节何时写出——
   见 ADR 0010：彩页按 profile 分流。
5. 非图片文件（`ComicInfo.xml` 之类）由源层原样透传，既不进缓存，也与本 ADR 无关。
6. **缓存只活在一次运行之内。** 进程结束即释放内存、清理临时文件，不提供跨运行的持久缓存。

缓存体积按面板分辨率 1264×1680、每像素 1 字节估算为 2.1 MB/页。**这个数是 fit-inside 那条路上的上界**：
目标尺寸是 fit-inside 的结果，漫画页更瘦，实际必然更小。以高为准（ADR 0007 决定第 7 条）下宽可以溢出面板，
跨页因此越得过它——最宽的一页有多宽，见《适配方式：fit-inside 与以高为准》。
参照按目标像素数走，这个上界因此跟着**适配方式**变；越过 `--cache-budget` 的页照旧溢写（决定第 1 条），
预算那道闸不因此被绕开。LZ4 压缩与解压的开销相对解码接近于零。

**预算撑不住时的退路是 32 页滞后窗口，不是把卷切块。** 窗口恒定内存、恒定滞后、不产生临时文件；切块会同时削弱
三项卷级统计，且合并不完全等价。这是本 ADR 明确的例外，不与 ADR 0006 冲突：那里禁止的是拿滑动窗口**替代**卷级上包络当常规路径。

## 后果

**好的：**

- PNG 源上不必付第二遍解码。
- 第二遍的输入是确定的像素缓冲：同一次运行内换阈值档位、开关抖动重跑不必重新解码。
- 三项卷级统计各按自己的真实成本取数据，不会因为「都是卷级」就一起按最贵的那项算。

**要认的代价：**

- **卷成为不可分割的处理单元。** 峰值内存与临时空间随卷大小线性增长。
- **缓存体积估算依赖尚未测量的压缩率。** 灰度图能压到多少，真实片源上**尚未测量**；2.1 MB/页 本身也是上界而非实测。
- 超大卷落到退化路径，卷级统计的作用域从全卷降到窗口，影响**尚未测量**。
- 多出一条溢写路径要维护：临时文件的位置、清理、中断后的残留。
- 参照的工作精度定死在 8 位灰度，8 位以上的源在进入判据前已被量化一次。

## 备选方案

- **真两遍、不缓存像素**：内存最低，但 PNG 源上接近两倍总耗时。
- **纯流式、放弃卷级统计**：吞吐最优、内存恒定，但同时推翻上述三个特性。
- **缓存未缩放的原始解码图**：保留汇总后重选缩放参数的自由度，但体积高出数倍，为无人要的自由度付这个价不划算。
- **把超大卷切块**：见决定第 6 条之后——切块削弱统计且合并不等价，退路取滞后窗口。

## 不要做的「简化」

**「第一遍只读尺寸和缩略图，第二遍再完整解码」**——三项统计里确实有两项只要尺寸和 1/16 降采样图，
内存立刻掉到几 MB，临时文件与 `--cache-budget` 一起消失。它漏掉第三项：位深上包络要全尺寸缩放后图像，
PNG 拿不到便宜的预扫，第二遍于是变成第二次完整解码——本 ADR 关掉的正是它。要重开这个口子，先证明手上的源不是 PNG。
