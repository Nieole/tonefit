# ADR 0008：两类源由总缩放比自然分流，不设类型检测器

状态：已采纳（2026-08-25）

## 背景

进来的片源有两种来路。A 类是原始高分辨率扫描，页高远大于任何目标高，且可能真的是 1bit 网点——
灰调要靠降采样解析出来。B 类是网络发布版，上传者已经降采样并做过有损转码，内容到手时已是连续灰调。

B 类有完整刻画：格式、尺寸分布、灰调级数、三块面板下的总缩放比，见 measurements 的《B 类素材普查》；
位深与体积、误差的关系见《B 类位深实测》。A 类没有：目前只有一个合成代理基底
（截图拼接后人工二值化），真实样本尚未取得，**关于 A 类的一切数值均尚未测量**。

管线里已经有一个按总缩放比分岔的路口：预缩只在比值 ≥ 2 时存在（见 ADR 0001
《重采样滤波器的选择比位深更能决定输出体积》）。问题是要不要在它之外再加一个显式的源类型判断。

## 决定

1. **不设源类型检测器。** 没有 `SourceClass` 枚举，没有探测源灰调级数、位深或压缩痕迹的前置步骤。
2. **分流由总缩放比完成。** 比值 ≥ 2 → 整数预缩摘走整数部分，残差段走 Lanczos3；box 的完整窗口平均
   顺带把网点解析成可数灰调，去网点不是额外一步。比值 < 2 → 无整数部分可摘，退化为单次重采样。
3. **A 类 / B 类只是文档词汇**，用来描述两端的素材特征与各自的证据覆盖度，不是运行期的分支条件。
4. **凡引用 A 类相关数值的地方一律标注「尚未测量」**，包括合成基底给出的字节数。

## 后果

**好的：**
- 分支数不增加。已有的「比值 ≥ 2 才预缩」这一个条件同时承担了去网点的开关职责。
- 不存在误判风险——总缩放比是算出来的确定量，不是猜出来的判断。
- 介于两端之间的素材不必被硬塞进某一类，它按自己的比值落在该落的路径上。

**要认的代价：**
- **高分辨率但内容已是连续调的源会走 A 类路径**，白付预缩带来的模糊，还要靠边缘自适应 unsharp 找补。
  这种源占多大比例、代价有多大，**尚未测量**。
- 现有实测在三块目标面板上，B 类的 ≥2.0 占比全为 0.0%（见《B 类素材普查》），
  即预缩路径在手头素材上一次都没触发过——**它是未经真实样本验证的路径**。
- 两类素材的证据覆盖极不对称，本决定成立的依据在 A 类一侧是结构性的，不是实测的。

## 备选方案

- **显式源类型检测器 + 两条独立管线**：多一套需要维护和标定的分支，且检测本身不可靠（见下节）。
- **让用户用命令行开关点名源类型**：把不可靠的判断转嫁给用户，且卷内混排时无解。
- **一律按 A 类处理，总是先预缩**：比值 < 2 时无整数部分可摘，预缩无从定义。
- **一律按 B 类处理，总是单次重采样**：放弃 box 在真 1bit 网点上的去网点作用，正是 ADR 0001 要保住的那笔。

## 不要做的「简化」

不要加「源灰调级数 ≤ N 判为 A 类」这类检测器。有损转码会在平坦区制造伪影，
让真 1bit 网点源也报出 256 级灰调；B 类普查抽样的灰调级数中位数就在满级上（见《B 类素材普查》）。
一切建立在源灰调级数上的判断在真实片源上都会失效，加进来等于把本决定关掉的问题重新打开。
