# ADR 0001：重采样滤波器的选择比位深更能决定输出体积

状态：已采纳（2026-08-25）

## 背景

降采样滤波器决定源页还剩多少灰调级数，灰调级数决定 PNG 的熵，熵决定字节。均匀权重的完整窗口
平均对二值输入只能落在窗口内的黑点计数上，产出 n²+1 个取值；非均匀加权则产出准连续谱。
BILINEAR 无负瓣、不振铃，仍产出上百级——振铃是二级效应，不是主因，主因是权重是否均匀。
落到体积上：同一张网点基底，BOX 的 8bit 输出小于 LANCZOS 的 4bit 输出，滤波器一档的差距
吃掉了位深两档，见《滤波器与灰调级数》（该节基底为合成图，绝对数字待真实 A 类样本复验）。

网点是因，灰调是果。只有源页还带网点时，均匀窗口平均才同时是一级去网点低通；在已经是连续调的
源上，它贡献的只有额外模糊，是纯损失。因此均匀权重必须限定在「把网点解析成灰调」这一段，
不能当作全程的重采样器。

缩放比向整数吸附另有一份收益，但只有个位数到十几个百分点，且符号不处处确定，见《缩放比与熵》。
这个量级不足以换掉一条不变量。

## 决定

总缩放比 ≥ 2 时分两段：先做整数倍 box 预缩，把比值压到残差比 < 2，残差段用 Lanczos3。
总缩放比 < 2 时预缩退化为恒等，全程单次 Lanczos3。

box / area 只是预缩那一级，主重采样器恒为 Lanczos3。

不做整数比吸附：目标尺寸恒等于 fit-inside(面板分辨率)，缩放比是算出来的，不是凑出来的。

全套常见滤波器（box/area、bilinear、hamming、bicubic、lanczos3）暴露为 `--filter`，
覆盖上述默认组合，供标定与排查使用。

## 后果

**好的：**

- 体积的主控旋钮落在滤波器上，位深决策（ADR 0006）拿到的是一张灰调级数已经稳定的参照。
- A 类源上的去网点与 B 类源上的保真由同一条流水线覆盖，靠总缩放比自然分流，不引入类型检测器（ADR 0008）。
- `--filter` 让标定期的滤波器对比不必改代码。

**要认的代价：**

- 预缩在 B 类素材上不触发：三块面板的 ≥2.0 占比均为 0.0%，最高的页也只到 1.865，见《B 类素材普查》。
  整数预缩这条路径在现有全部实测素材上从不执行，改动它没有回归网可接。
- 三段流水线（预缩 + 残差 Lanczos3 + 边缘自适应锐化）从未被端到端测量过，现有数字全部来自单次缩放。
- unsharp 抬高高频、推高字节，作用方向与本决定相反，两者的净效应尚未测量。
- 关于 A 类素材的一切数值主张尚未测量。

## 备选方案

- **全程 box/area**。在 B 类连续调源上是纯模糊，且把灰调级数压到面板灰阶数以下，判据无从分辨候选。
- **全程 Lanczos3，不设预缩**。A 类源的高倍降采样里网点混叠进结果，非均匀权重无法替代一级均匀低通。
- **把目标尺寸吸附到整数比**。收益量级见《缩放比与熵》，代价是破坏「目标尺寸 = fit-inside(面板分辨率)」，
  抖动启用条件（ADR 0007）与灰阶硬上界（ADR 0003）都挂在这条不变量上。

## 不要做的「简化」

- 不要因为「预缩在实测素材上永不触发」就删掉它——那是 A 类路径，覆盖范围的空白不是结论。
- 不要把 `--filter` 的取值同时改写预缩级和残差级：两级职责不同，合并会让 area 悄悄变成主重采样器。
- 不要用灰调级数直接当判据。它是解释体积的机理量，判据另有定义（ADR 0002）。
- 不要在这一层考虑编码器差异。滤波器决定的是灰调级数，编码器选择在判据层之外（ADR 0004）。
