# ADR 0001：高倍降采样分两段，主重采样器恒为 Lanczos3

状态：已采纳（2026-08-25）；理由改写（2026-08-26）

## 背景

总缩放比 ≥ 2 时，一步缩到位要让 Lanczos3 的核跨过一个远大于目标的源。分两段可以先用最便宜的
一级把比值压下来：整数倍的等权块平均，算的只是块内均值。

网点是因，灰调是果。均匀窗口平均在带网点的源上同时是一级去网点低通；在已经是连续调的源上，
它贡献的只有额外模糊，是纯损失。因此均匀权重限定在预缩那一级，不能当全程的重采样器。

## 决定

总缩放比 ≥ 2 时分两段：先做整数倍 box 预缩，把比值压到残差比 < 2，残差段用 Lanczos3。
总缩放比 < 2 时预缩退化为恒等，全程单次 Lanczos3。

box / area 只是预缩那一级，主重采样器恒为 Lanczos3。

不做整数比吸附：目标尺寸恒等于 fit-inside(面板分辨率)，缩放比是算出来的，不是凑出来的。

全套常见滤波器（box/area、bilinear、hamming、bicubic、lanczos3）暴露为 `--filter`，
作用于残差段，供标定与排查使用。

## 理由为什么改过（2026-08-26）

初版论证是：等权完整窗口平均对二值输入只产出 `n²+1` 个取值，非均匀加权产出准连续谱，
灰调级数决定 PNG 的熵，于是滤波器一档的差距吃掉位深两档。**这条论证的前提在真实素材上不成立。**

- **没有二值输入。** 1bit 是输出档，不是输入形态；实测语料里灰调级数最低的一卷也有 29 级
  （见《A 类素材普查》）。产出 `n²+1` 级要求二值源，那个源不存在。
- **滤波器不改体积。** 同一卷只换残差段滤波器，极差 0.75%（量化到 2bit 后）至 4.9%（8bit 输出），
  而同卷位深的极差是 12 倍（见《滤波器在真实素材上不改体积》）。
- **滤波器在面板上也看不出。** area / bilinear / lanczos3 的 8bit 输出目视无差（见《位深盲测》）。

**决定本身没有被推翻**：预缩在真实 A 类上确实触发（实测 3× 与 5×），输出正确。换掉的是理由——
现在撑着它的是成本：等权块平均只算块内均值，比让 Lanczos3 的核跨过大数倍的源便宜。

**抗混叠不是它的理由。** 3 倍降采样真实网点页上，单次 Lanczos3 与 box 预缩目视无差，两者都不起摩尔纹。

## 后果

**好的：**

- 高倍降采样只让 Lanczos3 处理已经压过一轮的源。
- A 类与 B 类由总缩放比自然分流，不引入类型检测器（ADR 0008）。
- `--filter` 让标定期的滤波器对比不必改代码。

**要认的代价：**

- 预缩在 B 类素材上不触发：三块面板的 ≥2.0 占比均为 0.0%（见《B 类素材普查》）。
- **预缩省下多少时间尚未测量**，而它是现在唯一撑着这条决定的理由。
- 三段流水线（预缩 + 残差 Lanczos3 + 边缘自适应锐化）从未被端到端测量过。
- unsharp 抬高高频、推高字节，作用方向与本决定相反，净效应未测。

## 备选方案

- **全程 box/area**。在连续调源上是纯模糊，且把灰调级数压到面板灰阶数以下，判据无从分辨候选。
- **全程 Lanczos3，不设预缩**。少一级，代价是核要跨过大数倍的源。真实素材上两者目视无差，
  因此这条只差一个成本测量就能重新摆上桌。
- **把目标尺寸吸附到整数比**。收益见《缩放比与熵》，代价是破坏「目标尺寸 = fit-inside(面板分辨率)」，
  抖动启用条件（ADR 0007）与灰阶硬上界（ADR 0003）都挂在这条不变量上。

## 不要做的「简化」

- 不要把 `--filter` 的取值同时改写预缩级和残差级：两级职责不同，合并会让 area 悄悄变成主重采样器。
- 不要用灰调级数直接当判据。它是解释体积的机理量，判据另有定义（ADR 0002）。
- 不要在这一层考虑编码器差异。滤波器决定的是灰调级数，编码器选择在判据层之外（ADR 0004）。
