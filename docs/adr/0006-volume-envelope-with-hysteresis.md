# ADR 0006：位深按卷取上包络并加迟滞

状态：已采纳（2026-08-25）

## 背景

位深逐页选最低可用值，在体积上是最优的。但把这些结果按阅读顺序摆开，相邻两页会落到不同档上：同一位画师、同一套网点，读者翻过去的一瞬间，灰调的颗粒感换了一种粗细。两页单独看都合格，不合格的是这一次翻页。

tonefit 的前提是尽量不影响阅读效果。**颗粒感在翻页处突变就是一种影响阅读效果**，而逐页最优正是它的成因：判据越贴着每页的真实需要走，相邻页越容易分档。

阈值已经标定（ADR 0002），但「判据越准、跳变越密」这条因果仍**尚未测量**。它是本决定的动机，不是证据。

## 决定

1. **先裁候选集，再聚合。** 面板灰阶数的硬上界作用在判据之前（见 ADR 0003：面板灰阶数是位深的硬上界）：e-ink 上候选位深为 {1,2,4}，LCD 保持全集。本文的一切聚合都发生在裁完的集合内，顺序不能反。
2. 在该集合内逐页判定（判据形态见 ADR 0002：判据建立在低通后的局部均值上）。
3. 对全卷逐页结果取 **p95 上包络**，定卷内主体的**基准档**。取上分位而非最大值——极端内容不该独自定全卷的档。
4. 叠加**迟滞**：连续若干页要求高于基准档才升档，一页说了不算。
5. **离群页不参与上包络，单独定档。** 彩色 profile 下彩页走彩色分支，根本不进灰度上包络（见 ADR 0005：解码一次，缓存缩放后的图）；黑白 profile 下彩页转灰后按普通灰度页判定，转灰后多半仍落在离群侧。
6. `--per-page` 关闭上包络与迟滞，给「只要最小体积」留一条出口。

判定与理由写进输出 PNG 的 tEXt（见 ADR 0004：输出以 PNG 为默认，AVIF 为显式可选），形如 `volume-p95, driven by page 087`。同一批字段——工具版本、profile 名、参数哈希、源哈希——兼作幂等依据：参数或源变了就重跑，没变就跳过。

**源哈希的作用域是卷，跳过的单位也是卷。** 这是决定第 3 条的直接后件：基准档由全卷定，卷里多一页少一页都可能换一档。逐页的哈希看不见这件事——删掉一页之后，剩下每一页的哈希仍然各自对得上，而它们共用的那个基准档已经过期了。同理不逐页续做：补写的那几页会拿到一个由当前全卷算出的基准档，与旁边幸存的旧页对不上。透传文件一并算进源哈希——卷是不可分割的处理单元（见 ADR 0005：解码一次，缓存缩放后的图）。

p95 里的 95、迟滞要求的页数、离群页判据的立脚点分位与倍数，四个数均尚未标定。

**决定第 5 条的立脚点不是本文的 p95。** 偏离量得在某一档上量，而那一档不能由全卷聚合给出——
被判的页自己也在那个聚合里，最极端的那一页按定义永远落在自己那一档以内，第 5 条随之落空。
立脚点因此逐页各取一个、不含被判的这一页（`CONTEXT.md` 的《判据》：立脚点）。

## 后果

**好的：**

- **主体页那一侧**的翻页跳变密度从「逐页可变」降到「每卷至多若干次，且每次都要有持续证据」——持续证据由迟滞给出（决定第 4 条）。离群页那一侧不在此列，密度见《要认的代价》里「少」不再有结构保证那一条。
- 「这卷为什么是这个位深」有了随文件走、指得出驱动页的答案。
- 位深从页级局部选择变成**卷级属性**，profile 的阈值档位可以按卷复盘。
- 幂等性搭在同一批 tEXt 字段上，边际成本低（不是零：要算源哈希、读回 tEXt 比对）。

**要认的代价：**

- **这不是「整卷一个档」。** 离群页单独定档、迟滞可升档，两者都会在卷内造成档位差。任何对外说明都不许把上包络宣传成绝对一致。
- **离群页边界的跳变，恰恰发生在离群页判定做对的时候。** 这是结构性自伤：不摘，上包络被污染；摘了，交界处就有一次跳变。接受后者，因为跳变的位置可指认。至于有多少处，见《「少」不再有结构保证》。
- **「少」不再有结构保证。** 立脚点若取本文的 p95，越过它的页至多 5%，离群页的数量白得一个上界——而那个上界恰恰是第 5 条失效的成因，随立脚点一并去掉了。现在的上界由立脚点的分位定，且**随卷长变**：60 页的卷要 16 页才越界，5 页的卷要 3 页。短卷因此可能有近半的页各判各的档。可指认还在（报告逐页给出理由，并给出离群页占比），少不一定还在。
- **预算撑不住、退到 ADR 0005 的 32 页滞后窗口时，窗口边界处的档位差是本决定关不掉的跳变。**
- **卷级源哈希要在第一遍之前把源字节多读一遍。** 换来的是命中时整卷的解码、缩放、判据与编码全省，但没命中的那些卷是净亏。
- **输出必然滞后于输入。** 要看完全卷才能定档，本文因此是 ADR 0005 的需求方之一。
- **体积不再最优。** 内页要为最难的那部分页多付位深，这是明知故犯的交换。
- 「代价可控」建立在**卷内逐页判定分布集中**这个尚未测量的前提上；统一到 p95 的体积损失量同样尚未测量。若真实样本复现 measurements 的《滤波器与灰调级数》里 BOX 行那种 4bit/8bit 比值，动态位深的省体积收益要大幅下调，位深选择的正当性将整个压到本决定的翻页一致性上。
- `--per-page` 一开，本决定的保护即失效。选项说明必须写明它重新引入翻页跳变。

## 备选方案

- **逐页独立、固定质量下限**：体积最优、单遍即可、无输出滞后。代价就是背景里那个跳变。
- **逐页判定 + 只加迟滞、不做卷级上包络**：最强竞争者，省掉全卷缓存与输出滞后。不选的理由是定性的——迟滞只限频、不定档，档位仍会在卷内漂移且位置不可预测，tEXt 里也没有卷级驱动页可写。若标定显示两者跳变次数接近，本决定应当让位于它。
- **帕累托拐点**：拐点位置完全由该页内容决定，每页行为不一致，跳变比固定阈值更严重，且无法向人解释。
- **目标体积预算**：好卖，但不保证质量下限——预算不够时先崩掉的一定是灰调。

## 不要做的「简化」

**把上包络的作用域从卷缩小到滑动窗口，当作常规路径。** 局部 p95 更贴合内容、体积更省，迟滞规则还在原地，读起来像是纯粹的改进。它不是：窗口一移动，档位就在卷中间变一次，此时迟滞成了唯一防线，而**限频不等于消除**——稀疏的跳变仍是跳变，且因稀疏更难在测试里复现。tEXt 的解释单位也从卷降到窗口，「这卷为什么是这个位深」不再只有一个答案。ADR 0005 的 32 页滞后窗口是超大卷的退化路径，不是这条简化的许可。
