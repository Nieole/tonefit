# ADR 0002：判据建立在低通后的局部均值上

状态：已采纳（2026-08-25）；此后经五次修订，最近一次 2026-09-09（地板上界的推导订正：FS 的低通残留不是零）。变更史见 git

## 背景

判据要在候选（位深 × 抖动模式）之间选出一个。选谁取决于用什么距离函数量「候选离参照有多远」。这个量选错，后面的阈值标定、卷级上包络（ADR 0006：位深按卷取上包络并加迟滞）、仲裁边界带全都建在错的基础上。

逐像素度量在抖动候选上给出与目视相反的排序：1bit 上它判「无抖动」最优，而无抖动那张的灰调区已崩成白底散点。见 measurements 的《抖动》。机理写在抖动的定义里——用高频误差换低频保真，逐像素度量必然惩罚抖动：每个像素都偏了半个量化步，局部均值几乎无误差。

人眼在观看距离上本就做了一次低通。300 PPI、30cm 下 1 弧分的分辨极限约合 1 像素，抖动图案的高频成分落在这条线以下。

**但「分不开」不等于「看不见」。**分不开的是图案的形状，看得见的是它的起伏幅度——1bit 上颗粒的幅度到 100 灰度级以上，在一片平坦灰调里是明摆着的。真机盲测把这件事测了出来（见《决定》第 5 条），判据因此是两项，不是一项。

## 决定

判据 = **低通项 ＋ 颗粒项**，逐块相加再分块聚合。任何逐像素度量都不得单独作为候选之间的选择依据。

1. **参照**：缩放到目标尺寸后、未经目标位深量化的图，工作精度 8 位灰度。这样恰好把「量化」一个变量隔离出来。
2. **低通项 = 参照与候选各做低通之后的局部均值误差。低通核尺寸由 profile 所属面板的 PPI 推出**，
   取 2~4 像素量级：抹掉人眼分不开的那一层，保留看得见的那一层。它量的是灰调塌陷与 banding。
3. **分块 32×32，聚合取 p99 与「第 K 差的那一块」之间更严的那个**，不取全页均值。
   一页大部分是留白，均值会把崩掉的灰调区稀释掉；banding 是局部现象。
   块边长是**绝对尺寸，不随页尺寸缩放**——它对齐的是 banding 的空间尺度，不是页的尺度。
   分位那一半按比例算，K 那一半按绝对块数算：**尾巴按比例走，但永远不宽于 K 块。**
   K 的取值**仍未标定**，占位值往严的一侧取，报告里连同来源一并标出（见 `CONTEXT.md` 的《尚未确立》）。

   **为什么不能只取上分位**：p99 是**比例**，而值得报警的损伤是**绝对面积**。一块 128×128 的
   banding 在哪张页上都一样刺眼，眼睛不关心它占全页百分之几——可它是 512×512 页的 6.25%、
   1264×1680 页的 0.77%。基准面板的 1264×1680 铺出 40×53 = 2120 块，p99 的最近秩是 2099，
   站得上去的只有最差的 22 块；覆盖不到 22 块的损伤被整块丢掉，三档读数全是 0.000，
   那一页于是判成最低档——而那一小块正是唯一会崩的地方。

   > **一条踩过的坑，记在这里免得再犯**：「一页里大面积留白不会稀释局部劣化」这条性质，
   > 当初是在 512×512 页上量的（16/256 块 = 6.25%，恰好在 1% 门限之上）——
   > **测试在性质成立的那一侧挑了尺寸**，换成该 profile 的实际输出尺寸，同一条断言当场失败。
   >
   > 一个对照：同一套最近秩取法也用在卷级上包络上（p95 over 页），那儿没出事——
   > 因为 ADR 0006 给它配了特例页机制兜底，显著偏离分布的页不参与上包络、单独定档。
   > **分块聚合没有这层安全网**，尾巴一宽就真丢了。两处用同一个取法，只有一处有网。
4. **叠加对比度掩蔽加权**：平坦低对比区收紧，有结构的区域放宽。崩掉的从来是灰调，不是线稿。
   活动度量在**块这个尺度**上，不是低通核那一层：读数按块出，「这一块有没有结构」问的就该是块内的事，
   而核尺度只看得见网点残留。量法取「原值离块尺度局部均值有多远」——box 局部均值不改变线性斜坡，
   **平缓斜坡因此买不到掩蔽**，而斜坡正是 banding 最显眼的地方。
   加权的**地板跟着量法一起重定**（窗口见 measurements 的《位深盲测》）：量法换了活动度整体变大，
   旧地板打折太狠，灰调真崩在线稿密的块上时判据读不出来。拐点仍未标定。
   **为什么必须在块尺度上量**：光补颗粒项分不开 banding 那一对——画集 056 与 040 的 4bit 不抖
   目视是「明显色块」对「很好」，两页都不抖动、都没有颗粒。分开它们的是掩蔽：040 的坏块贴着
   画上的边，056 的坏块泡在一片没有内容的平滑渐变里，而核尺度的活动度只看得见网点残留，
   把两者读成一样的。改在块尺度上量之后落差从 1.04 拉到 1.545。
5. **颗粒项 = 候选比参照多出来的高频起伏里，超出可见度地板的那一部分。**
   它量的是抖动颗粒自身有多显眼——低通项按定义看不见这一项。
   减去参照那一份，是因为线稿与网点自带高频，照搬过来不算新长出来的颗粒；
   减去地板，是因为起伏低到一定程度真的看不见，**那一段是抖动该得的便宜**。
   地板是**格点间距的一个比例**，不是一个绝对值：`floor(n) = 比例 × 255/(2ⁿ−1)`。
   **一个比例，不是三档一张表**——地板的本质就是间距的一个份额，存成表这层算术关系就丢了，
   而且换一个位深要重标一次。

   **两端都要由真机夹，算术只缩得小上界的适用范围。**取一块平坦调，它离最近格点《离格量》`u`
   （`0 ≤ u ≤ s/2`，`s` 是那一档的《格点间距》）：不抖动整块偏 `u`，低通项读 `u`、颗粒为零。
   FS 那一侧要分两段看，**分界由低通核边长 `K` 定**（`K = 4` @300 PPI，见第 2 条）：

   ```
   FS 的颗粒 = sqrt(u(s−u))                 记作 g
   FS 的低通残留 ≈ g / K                     ← 不是零
   抖动输 ⟺ g/K + max(g − F, 0) > u
   ```

   **`u ≤ s/(K²+1)` 时抖动恒输，地板无关。**那一段上 `g/K > u` 已经成立，
   低通残留自己就把 FS 判输了，`F` 取什么都改不了（2bit 上这一段是 `u < 5`，
   1bit 上 `u < 15`，4bit 上 `u < 1`）。

   **`u > s/(K²+1)` 时地板才说得上话**，上界是

   ```
   F < g·(1 + 1/K) − u
   ```

   > **这一段是订正过的（2026-09-09）。**原先写的是「FS 保住局部均值，低通项近零」，
   > 由此推出 `F < s·(sqrt(r(1−r)) − r)`，并代 `u = 2` 得出三档上界 0.080 / 0.128 / 0.205。
   > **那个前提是假的**：低通核只有 4 像素宽，稀疏抖动在这个尺度上还没摊平。
   > 512×512 平坦块实测（`u` = 1 / 2 / 8 / 21 / 42）：不抖那一列**逐位等于 `u`**，
   > 而 FS 那一列是 2.218 / 2.958 / 3.009 / 2.340 / 1.606——**`u ≤ 2` 上 FS 反而高过不抖**。
   > 也就是说，原推导用来定上界的那个 `u = 2`，恰好落在**约束根本不存在**的那一段里。
   > 订正之后的上界形状变了，而且**它到底卡在哪个 `u` 上要由真机说**——
   > 那正是 `metric-recalibration/04` 的 L 组（平坦调阶梯）要答的。

   下界同样没有闭式解：它问的是「起伏低到什么程度真的看不见」，只能由真机盲测夹，
   与阈值、掩蔽那两个数同一批、同一块面板。

   **这一项为什么必须存在**：只有低通项时，判据在同一页之内把序排反——棋魂 0060 上
   1bit+FS 排第 5、不可接受，同页 2b位（p99）」。两个数各自都对，乘在一起却让
「多小的损伤会被丢掉」随页面积漂移：

- p99 是**比例**，而值得报警的损伤是**绝对面积**。一块 128×128 的 banding 在哪张页上都一样刺眼，
  眼睛不关心它占全页百分之几——可它是 512×512 页的 6.25%、1264×1680 页的 0.77%。
- 基准面板的目标尺寸 1264×1680 铺出 40×53 = 2120 块，p99 的最近秩是 2099，站得上去的只有最差的 22 块。
  覆盖不到 22 块的损伤被整块丢掉：三个候选位深读数全是 0.000，那一页于是判成最低档——
  而那一小块正是唯一会崩的地方。

发现它的用例本身也是证据。「一页里大面积留白不会稀释局部劣化」这条性质，当初是在 512×512 页上量的
（16/256 块 = 6.25%，恰好在 1% 门限之上）。**测试在性质成立的那一侧挑了尺寸。**
换成该 profile 的实际输出尺寸，同一条断言当场失败。这种错法会再犯，所以记在这里。

一个对照：同一套最近秩取法也用在卷级上包络上（p95 over 页），那儿没出事——因为 ADR 0006
给它配了特例页机制兜底，显著偏离分布的页不参与上包络、单独定档。分块聚合没有这层安全网，
尾巴一宽就真丢了。两处用同一个取法，只有一处有网。

## 后果

**好的：**

- 候选比较建立在一个「该不该抖」这一维上与目视一致的量上。
- 重算得出判据值的四页上，判据把 1bit+FS 排在同页其余候选之后，与「1bit 五组全垫底」一致。
- 有序抖动在 2bit 及以上不如不抖动——这个反直觉结果是低通判据看见的。
- 参照、低通核、分块聚合、加权、颗粒地板定死在一处，ADR 0006 由此拿到稳定的逐页输入。
- 判据的敏感度不再随页尺寸漂移：同一块损伤在任何目标尺寸上读数同量级。

**要认的代价：**

- **判据只答「颗粒有多显眼」，不答「颗粒长什么形状」。**颗粒项量的是超出可见度地板的高频起伏幅度，
  同样幅度的 Bayer、蓝噪声与误差扩散在它眼里一样。所以**仍然不能用判据分数挑抖动算法**。
  这一维的把关归仲裁（SSIMULACRA2）；若标定最终移除仲裁，必须改由人工确认顶上。
- **「同一档上抖动恒优于不抖动」这条性质已经作废，而且是判据主动放弃的。**
  它曾经是地板下界的全部依据（`F > 0.2071·s` 恰好等价于「抖动永不输」）。
  真机在离格量 2 的白底页上给出反例：2bit+FS 四对全输，而判据当时读 3.25~3.54、在界内
  （见 measurements 的《真机三组》与《第五轮》）。**那不是标定不准——按构造，
  贴着旧下界的地板不可能在平坦区上判抖动输。**约束因此翻向：从下界变成上界（见决定第 5 条）。
  代价是**抖动从此在平坦区上会输**，而且离格量越小输得越多；换来的是判据不再在那一段说谎。
- **2bit 不抖判在界外是对的，已复核。** 第二轮盲测改问「哪张更接近参考」，
  参考取 **4bit+FS**——它的灰阶数恰好等于面板灰阶数，逐像素原样显示，是这块面板做得到的最好；
  8bit 原图在 16 级面板上显示不出真面目，固件会先用自己的算法压一遍，
  上一轮它排第 4 排的正是固件的结果。两块面板各两页，**四组一致选 2bit+FS 更接近**。
  同一轮问「参考里有而它没有的东西」，**四组一致答没有**——差异是整体亮度偏移
  （2bit 不抖偏深 2–8%），不是内容丢失。判据对全局偏移天然敏感，读数大是对的。
  见 measurements 的《2bit 不抖复核》。
- **FS 的默认地位挂在机理与目视上**，不挂在分数上：误差扩散按邻域反馈摊开量化误差，低频保真最好，1bit 目视对照也指向它。判据分数只作旁证。此结论暂定，待真实样本复验。
- **参照必须活到第二遍**，不能在量化后丢弃。放在哪里由 ADR 0005：解码一次，缓存缩放后的图决定：内存优先，超出预算则溢写。本 ADR 只要求它活着。
- **贵。**每候选先低通再分块聚合，高于一次逐像素 MSE。在判据这一侧，fast 的吞吐下限只能靠减少候选数来保。
- **低通核绑定 PPI，判据数值不可跨面板比较。**换面板即换核尺寸，同一个数在两个面板上不是同一件事。
  阈值因此也不可跨面板搬运：标定在哪块面板上做的，是那个数的一部分。
- **「候选上界恒过关」不再成立，几何门成立那一侧也不成立。** 未标定的 8.5 是 4bit 量化步长的
  一半，4bit 因此恒在界内；标定出的 5.123 不保证这一条。**门成立那一侧从前还剩一层余量
  （上界是 4bit+FS、读数远在界内），颗粒地板改按格点间距收费之后那层余量没了**——
  门的两侧各有多少页越过界，见 measurements 的《候选上界不恒在界内：门的两侧各有多少页超出》。
  越界的页没有一档在界内，落到兜底取候选上界。**保守偏向没有消失，但它现在挂在兜底上**，
  而兜底逐页走（`crate::decide`）：受害的是那几页，不是整卷。
- **聚合多了一个未标定的常数 K。**它偏小则更严。漏掉真损伤的代价是输出崩了、用户看得见；
  误判的代价只是多用一档位深、文件大一点。两者不对称，所以占位值往严的一侧取。
  标定时它是第一批该被替掉的数。
- **颗粒地板的两端都还没定，而且已知有一段区间是空的。**上界的推导订正之后
  （`F < g·(1+1/K) − u`，且只在 `u > s/(K²+1)` 上说得上话，见决定第 5 条），
  它卡在哪个 `u` 上要由真机说；下界随「抖动恒优于不抖动」一起作废，也只能问眼睛。
  **更要紧的是：有两格真机答案，任何地板取值都配不上。**平坦调阶梯上
  （《离格量》×背景亮度十五格），`u = 21` 与 `u = 42` 两行里**同一个离格量在近白判「不抖更干净」、
  在中灰或偏暗翻向 FS**，而**判据对亮度几乎完全盲**——同一个 `u` 的三格读数最大只差 0.301。
  盲是构造使然：两项都建在**差**上，而同一个离格量在不同格点邻域上撒点的密度与幅度完全一样。
  **一个对亮度盲的量，阈值取在哪里都给不出相反的两个答案**，这一条不依赖任何地板取值、也不依赖反解。
  见 measurements 的《判据缺的那一维是《背景亮度》——同一个离格量，白底上看得见、灰底上看不见》。

  > **这一条原先还带着两句更强的话，都已撤回。**
  > 一句是「五行的三格答案都不一致」——第八轮复判把 `u=2 偏暗` 判定为真值 `2bit 不抖`
  > （第七轮那个 FS 是噪声）、`u=42 中灰` 判定在判读边界上记「平」，
  > 按真值只剩四行不一致、其中两行真正相反。
  > 另一句是「`u = 2` 偏暗那一格单独就否掉了地板」——**支点就是那一格**，
  > 代入真值之后判据读 2.000 < 3.474，与真机同向，它否不掉任何地板。
  > 原文与复判逐对见 `.scratch/metric-recalibration/judgements/第八轮复判04R.json`。
  >
  > **另有一种读法与本条并列，尚未分出胜负**：第九轮闸① 补测的原始记录自己写着
  > 「L 组与闸① 的差别主要是有没有色带，不是亮度」，而那十二对判读者给的理由逐字
  > 都是「另外一张有轻微色彩断层」。平坦块上不抖只是均匀偏色、没有色带，**L 组测不到色带**，
  > 两种读法在现有材料上分不开。见 measurements 的《对手读法》。
- **全库重跑。**地板一改，2bit 及以上每一页的判据读数都变，判定跟着变——同一批夹具上
  十来个卷从 2bit+FS 改判 4bit 或 4bit 不抖（`tests/golden-snapshot.txt`）。上一趟的输出
  因此在观感上已经不是这一趟会写出来的东西，**下一趟要按全库重跑来安排**。
  幂等**拦得住它**：参数哈希收**判据那三个结构体（`Composition`、`Aggregation`、`Masking`）
  的全部字段**，清单在 `metadata::params_hash`。判据参数改一个数，上一趟的输出整卷过期重做，
  不再被静默跳过——量与界是同一件事的两半，从此哪一半改了旧输出都作废。
- **把判据参数收进哈希，这一步本身让全库旧输出过期一次。**哈希多了输入，
  同一套参数算出来的就换了一串：判定一个都没变，盘上每一页的记录却都对不上。
  代价是那一趟全库重跑，**一次性**；换来的是此后每一次判据改动都自己带着过期，
  不必再靠「同一批里恰好还改了阈值」兜底。
- **判据又贵了一点。**参照多求一次块尺度的局部均值（一张参照一次），
  每个候选多求一次块内高频起伏。低通改成滑动窗口之后耗时与核边长无关，
  这两笔加起来仍在同一量级。

## 备选方案

- **逐像素 MSE / PSNR**：最便宜最标准，但在「该不该抖」这一维上符号反了。
  颗粒项**不是**它换了个写法：颗粒项减掉参照自带的高频，也减掉一道可见度地板，
  于是抖动把误差摊到眼睛分不开的尺度上这件事仍然免费——地板以下不收钱。
- **颗粒项按幅度线性计入，不设地板**：少一个常数，但那就退回逐像素度量的一半，
  每一档上的抖动都要挨罚，本 ADR 关掉的洞原样回来。
  **注意这不等于「地板取 0」**：新上界只是把地板压低，不是取消它——
  地板以下那一段仍是抖动该得的便宜，只是那一段比原先窄得多。
- **颗粒项换一个对稀疏敏感的统计量**（高分位、或越过可见幅度的像素占比），
  理由是 RMS 把「稀疏而响」读成「安静」。**未决。**
  > 这一条原先写着「查下来不必」，理由是「地板落进新窗口之后同一个 RMS 就判得对」。
  > **那次验算只覆盖了 B 组那一侧**（白底、`u≈2`），而闸① 是 `03` 号票结案后才有的约束，
  > 代进去之后不成立。`04` 的 L 组判完之后能说的是：**换一个对稀疏敏感的统计量仍然对亮度盲**，
  > 所以它翻不过 `u = 21`／`u = 42` 那两格相反的真机答案（见《后果》与 measurements 那一节）。
  > **这一条因此仍是「未决」，不是「不必」**——第九轮的原始记录把病灶指向色带而不是亮度，
  > 而「稀疏而响被 RMS 读成安静」与「色带」是两件事，前者还没有被任何一轮真机否掉。
  > 要结掉它，得先由闸① 那批页上 `4bit+FS` 对 `2bit+FS` 的一趟真机分出色带那一读法。
- **两项取更严的那个而不是相加**：抖动做的正是「拿低频换高频」，取更大的会让这笔交换免费。
- **直接把 SSIMULACRA2 当判据**：每页每候选都跑撑不住吞吐，且把「图案难看」与「灰调崩了」揉进同一分数，不可解释。留在边界带做仲裁性价比最高。
- **全页均值而非分块上分位**：省事，但留白会稀释掉崩掉的灰调区。
- **让块边长随页尺寸放大，以保持块数量级稳定**：修得了尾巴宽度，代价是 32×32 那条依据当场失效。
  1264×1680 要保持 256 块，块得放大到约 91×91，而那个尺寸的一块已经横跨多个内容区，
  **块内均值自己就开始把损伤与干净区平均掉**——分块要防的稀释降一级重新出现。
- **固定像素数的低通核**：省掉 PPI 推导，但同一个核在不同面板上对应不同视角，判据的严格程度随面板漂移。
- **一律不抖动**：体积最小，但 1bit 下保真与目视都明显更差。

## 不要做的「简化」

**「先用便宜的逐像素 MSE 粗筛掉明显不行的候选，只对活下来的几个跑低通判据」**——读起来是教科书式两级筛选，实则就是本 ADR 关掉的洞：粗筛会先把抖动候选淘汰掉，低通判据再准也只能在剩下的里挑。粗筛不是「更弱的判据」，是「在该不该抖这件事上结论相反的判据」。同理，「预缩已经低通过了，判据不必再做一次」是这个洞的另一个入口。

**「与其在聚合里加一个 K，不如让块边长随页尺寸走——块数稳住了，分位自然就对了。」**——读起来像同一件事的更简单做法，实则把稀释问题从页级降到块级重新引入一遍（见《备选方案》）。块边长对齐的是 banding 的空间尺度，页多大与它无关。
