# 08 — 样张去处里只剩这一次的那一叠

**What to build:** 往已经有旧样张的目录里再出一次：**出之前先删掉去处里这张图同一页名前缀的那一叠**，只动自己那一叠，别的图的样张不碰；**写到一半写不进去时把这一叠再删一次**（去处是这一趟现建的就连目录一起收回）。stdout 上照旧逐张列出写了哪几张（spec 的 story 27）。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 集成用例：同一张图换一套选项再出一次，候选集变小时旧的那几张不留；同一目录里别的图的样张一张不碰
- [ ] 写到一半写不进去：这一叠一张不留，回 `Err` 那一句照旧
- [ ] `cargo xtask gate` 三条全绿；票据的《数》记下三条各自最后一行

## 不做会怎样

同一张图出两次，新旧样张混在一起，读的人分不出哪几张是这一次的。

## 停车场结转

下面几条由停车场转来（`/settle` Q995–Q1388 → `/grill-with-docs` → 本 effort 的 spec），归这张票收；上面的做法是拷问的结论，与原文的推荐不同时以上面为准。

#### Q998 — 往一个已经有旧样张的目录里再出一次：同名的盖掉，别的留着——而 story 27 没有落在任何一张票上

- **From:** 票 `proof-sheet/02`
- **Kind:** 路过发现（spec 的 story 27 在 03–07 五张票里都没有验收条）
- **Where:** `src/proof.rs` 的 `write`（`create_dir_all` 之后逐张 `fs::write`）；spec 的 story 27；
  票 `proof-sheet/03`–`07`
- **Why it did not block:** 本票的验收只问「去处不在时自己建出来」与「文件数 = 候选数 + 1」，两条都在空目录上成立。
- **What this ticket actually did:** 最朴素的那一种：同名的盖掉，不同名的一张都不碰，也一句都不说。
  同一张图换一套选项再出一次，候选集相同时文件全被盖掉；候选集变了（门不成立少了抖动那三张）旧的那几张会留下来，
  与新的混在一起。
- **Why it matters:** story 27 说的正是这一种：「我不会把两次的样张混着看」。眼下它**静默地**混。
- **Options:** ① 照旧（已落地），stdout 上已经逐张列出这一次写了哪几张；
  ② 出之前先删掉这张图在去处里的**同一页名前缀**的那几张（`001.*.png`），只动自己那一叠；
  ③ 去处非空就拒绝，要一个空目录。
- **Recommend:** ②，归 06（它已经在管「去处写不进去」那一句）。③ 太硬——同一个目录里并排放几张不同的图正是常用法。
- **Whose call:** 拍板的人（归哪张票）
- **处置：** 拷问定案（2026-10-02，`/grill-with-docs`）→ `proof-sheet`（新添第 8 张），待 `/to-spec`／`/to-tickets`：出之前先删掉去处里这张图同一页名前缀的那一叠，只动自己那一叠。

#### Q1056 — 写到一半写不进去（盘满、某一张的名字被占）：已经落下的那几张留在去处里，不回头收

- **From:** 票 `proof-sheet/06`
- **Kind:** 票面没想到的第三种情形（验收只对解不开的图要「不留半成品」）
- **Where:** `src/proof.rs` 的 `written` 与 `Drafted::land`（逐张 `fs::write`）；`calibrate::write_chart` 的文档（同一种朴素写法的先例）；
  票 `proof-sheet/06` 第二、四条验收；停车场 Q998
- **Why it did not block:** 验收第四条只要回 `Err`、说得出是写不出去、不崩；两条路都做得到，翻过来只动落盘那一段。
- **What this ticket actually did:** 不回头收。拒绝那一句打头说「样张写不出去」、后半截指着写不进的那一张
  （`a_destination_that_cannot_take_the_sheets_comes_back_as_an_error_that_says_so` 的第二种：参照那一张的名字上摆一个目录，
  头一张就撞上）；在它之前落下的那几张照旧在盘上。盘满时写到一半的那一张可能是截断的。
- **Why it matters:** 验收第二条那句「不留半成品」只管解不开的图；盘满撞上的时候去处里会有一叠缺了几张、
  可能还带一张截断的样张，而 stdout 上一行都没有（那一趟是 `Err`）——用户是从 stderr 上知道它没做成的。
- **Options:** ① 不回头收（已落地），与灰阶测试图那一路同一种写法；② 撞上时把这一趟已经写下的那几张（连同写到一半的那一张）
  删掉，去处是这一趟现建的就连目录一起收回；③ 先写进去处旁边一个临时目录，全写成了再逐张改名进去。
- **Recommend:** ①，等 Q998 拍板再看。② 删的是这一趟刚盖掉旧样张的那几张，旧的也回不来；而「去处里那几张是什么」
  正是 Q998 要定的事——要是 Q998 照它推荐的 ② 走（出之前先删掉这张图自己那一叠），撞上时再删一遍那一叠就是 ② 的全部，
  不必另起一套。③ 是输出容器那一套，为一叠没人会回头读的样张付它不值（灰阶测试图那一路的理由）。
- **Whose call:** 拍板的人（记下即可）
- **处置：** 并入 Q998，随它走（拷问定案 2026-10-02：写到一半写不进去时把这一叠再删一次）。
