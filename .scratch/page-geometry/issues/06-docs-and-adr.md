### ADR 0007：逐处改，一共九处

那条不变量不是一句话，它散在六个位置上，只改《决定》会留下五处互相打架的陈述。

| 位置 | 从前 | 现在 |
|---|---|---|
| 《决定》抬头 | 「抖动仅在『目标尺寸 = fit-inside(面板分辨率)，且输出不再被下游缩放』成立时启用」 | 「**目标尺寸有一条边贴住面板**，且输出不再被下游缩放」——那正是 `GeometryGate::of` 判的东西 |
| 《决定》第 7 条 | 已由所有者改成随适配方式而定 | 补上**兜底上界**那一条例外：越界的页退回 fit-inside，门跟着照 fit-inside 判（07 号票） |
| 《背景》不变量那一段 | 「目标尺寸 = fit-inside(面板分辨率)」 | 「目标尺寸由适配方式算出」，并点明不变量管的是**后半句** |
| 《背景》1:1 那一段 | 只讲 fit-inside 的留边 | 两种适配方式各讲一遍，留边与溢出并列，要求不同 |
| 《背景》逐页那一段 | 「源比目标小的页……」当成通例 | 落进「不成立」那一支的是哪些页**跟着适配方式走**；以高为准下接近空集，逐页那套机制照旧要在 |
| 《后果》代价第 1、2 条 | 「留边」「B 类那批页门不成立」 | 「留边或溢出，二选一」；B 类那批页两条路各是什么形态，带实测（62/66 → 0 页，体积反降 16%） |
| 《备选方案》「输出高于面板分辨率」 | 一句拒绝 | **部分采纳**：宽高于面板而高仍贴住，1:1 未破；仍被拒的是「两条边都留余量」 |

另加两条，各对应票面一条验收：

- **代价里多一条「溢出的页把一件事推给了阅读器的配置」**——要求以原尺寸平移、不缩放也不适配屏宽，
  而 tonefit 看不到那条显示管线，因此**只写进文档、不进代码**（票面第 7 条）。
- **「无从感知，也无法在输出时补救」补了指路**（票面第 11 条、停车场 Q19）：那句话一个字没改——
  探测手段仍然不存在——变的是**人**查得出来，`calibrate` 的标定图上半就是像素完整性那一段。

《后果》里「任何改动目标尺寸的改动都要对 ADR 0003 负责」那一条留着，只把它押的那句断言
换成「目标尺寸只出自适配方式那一个入口」，并注明兜底上界是至今唯一的例外、账已经照它算过。

票面点名的《不要做的「简化」》**逐句查过，一个字都不用改**：那两条说的是「把目标尺寸往整数缩放比
上凑」与「让判据也按页决定抖不抖」，两条都不依赖目标尺寸怎么算，适配方式换了它们照旧成立。
不改也是本票的结论之一，因此在这里交代。

### 顺带订正的四篇 ADR

同一条不变量在别处也被引用着，只改 0007 会让它们变成假话：

- **0001**（两段降采样）——《决定》与《备选方案》各引一次。
- **0005**（解码一次 + 卷级缓存）——2.1 MB/页那个「上界」是拿 fit-inside 推的，
  以高为准下跨页越得过它。改成「这个数是 fit-inside 那条路上的上界」，并点明预算那道闸没被绕开。
- **0006**（卷级上包络）——幂等依据那句仍写「四项」，而**来路**成了命中的必要条件（停车场 Q29）。

### Q29 — 幂等的依据多了一项，而 ADR 0006 仍写着「四项」
