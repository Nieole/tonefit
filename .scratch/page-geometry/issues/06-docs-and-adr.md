# 06 — 文档与 ADR 收口

**What to build:** 本批改掉的那条不变量在文档里也改过来，新词进词汇表。

**Blocked by:** 01、02、03、04、05

**Status:** ready-for-agent

**已提前落地的两条**（所有者定案：那两处是明确的假话，不等 01–05 全部落定）：
ADR 0007《决定》第 7 条、`CONTEXT.md`《几何》的目标尺寸定义与那句「宽必然小于面板宽」，
并顺带把「适配方式」收进词汇表、把留边与溢出对阅读器要求不同写进不变量那一段。
其余各条仍等实现落定后照实际行为写。

**归属：** tonefit-0a。约定是等实现落地照**实际行为**写——这条不变量不是一句话，
是《决定》一条 +《后果》两条 +《备选方案》两条 + `CONTEXT.md` 一段互相咬着的一组陈述，
空对空改会改出一篇读着通顺但对不上代码的 ADR。

- [x] ADR 0007《决定》第 7 条由「目标尺寸只有一个来源：fit-inside 结果，不得为别的收益改动」
      改成随适配方式而定；《后果》《备选方案》《不要做的「简化」》里挂在它上面的各条随之重算
- [x] `CONTEXT.md`《几何》里「漫画页更瘦，目标尺寸的宽必然小于面板宽」订正——实测最宽 3.22 倍面板宽
- [ ] 新词进词汇表：**装订沟**、**连续跨页**、**适配方式**、**阅读方向**
- [ ] `CONTEXT.md`《尚未确立》里「几何门不成立时该用哪个位深集合」改写成
      「洞还在，只是以高为准这条路上没有页掉进去」——换回 fit-inside 就又有了
- [ ] 留边与溢出对阅读器的要求不同，这一条写进 ADR 0007：留边只要阅读器填背景不重采样，
      溢出要它平移不缩放
- [ ] 默认三项全开是有意的行为变化，代价（跨页卷体积约三倍）写在文档显眼处
- [ ] 横向平移的阅读器配置进文档，不进代码：tonefit 看不到阅读器的显示管线
- [ ] `docs/measurements.md`《真机像素完整性》那句「输出恒等于 fit-inside(面板分辨率)，
      面板这一层的适配是 1.0 倍」现在只对 `--fit inside` 成立。以高为准下高仍贴住面板，
      但「恒等于 fit-inside 结果」当场变假，而后半段拿它推出的结论需要一句更强的前提：
      溢出的页要求阅读器**平移不缩放**
- [ ] 同一节里「几何门恒成立」那一条现在有例外——`page-geometry/07` 让越界的页退回 fit-inside，
      那些页按 fit-inside 判门（ADR 0007 与 05 号票里的同源说法已经不含这句，只剩 measurements 一处）
- [ ] `docs/measurements.md`《A 类位深实测》那四个「哪一档更优」的页数是**旧判据**下数的。
      `metric-ordering/01` 换判据后同一批卷在 boox-poke6 上是 177/230、156/185、3/413、40/129——
      方向不变数变了。原文没写在哪块面板上数的，**要重跑那四卷**才补得出可比的一组
- [ ] ADR 0007《要认的代价》里「tonefit 无从感知，也无法在输出时补救」补一句指路：
      那句话仍然成立（tonefit 仍探不到阅读器的缩放），但**人**现在有办法自己查了——
      `calibrate` 出的标定图含像素完整性一段，见 `calibration-chart/01` 的落地记录
