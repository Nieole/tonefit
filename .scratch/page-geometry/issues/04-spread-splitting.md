# 04 — 跨页拆分：装订沟、阅读方向、每半再裁

**What to build:** 跨页被拆成两页，每半用满面板高、基本不必横向翻动（实测拆开后每半
0.88–0.95 屏）。**没有装订沟的连续跨页不切**——那是为视觉效果画满两页的整幅画面，
切开就毁了；它退回以高为准，靠横向平移看。

默认打开。

**Blocked by:** 01（没有沟时要退回以高为准）、02（每半再裁）、03（一页产出多页）

**Status:** ready-for-agent

- [ ] 命令行能开关拆分，**阈值可调**，默认打开
- [ ] 候选按宽高比与面板比挑出。混排卷是常态：一卷里有些页已拆好、有些还是连页，
      两者都要落对
- [ ] **装订沟定切点**，不切正中。实测沟中心在 0.441–0.507 之间，按正中盲切最偏一页
      会切进画面 340 像素——一条用例用「沟不在正中」的夹具钉住切点跟着沟走
- [ ] 找不到装订沟即判为**连续跨页**，不切，退回以高为准
- [ ] 拆开后**右半在先**，阅读方向可改；一条用例钉住反过来时两半的成员名顺序跟着反
- [ ] 每半各自再裁一次
- [ ] 真实素材冒烟记录装订沟在单页卷上的**误报率**。现有基线：哆啦A梦 15/16、改革之獸 16/16
      命中；棋魂 2/16、画集 1/16 误报，而误报的沟宽 21–24%、真装订沟窄得多——
      候选那一关本该把它们挡在外面，冒烟要能看出这道防线有没有漏
- [ ] 幂等依据含拆分开关、阈值、阅读方向
- [ ] 黄金快照重录，差异逐条确认

## 不要做的

- 不判断「这幅画该不该切」。只看几何与墨量分布，不看画面语义。
- 不读 ComicInfo.xml 取阅读方向。八卷素材里它出现 0 次，为它引入 XML 解析不划算。
