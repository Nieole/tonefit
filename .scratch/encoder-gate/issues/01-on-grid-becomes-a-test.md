# 01 — 《落格》在 `run` 那条缝上立成用例

**What to build:** 让下一个想加有损编码器的人，**在写第一行代码之前就撞上一条会红的用例**。

`CONTEXT.md`《量化》已经有《落格》那条不变量了（`dr/01` 落的）：走灰度路径写出的每一张页，
把字节解回来，每一个取值都还落在它那一档判定的格点上。今天它只是一段文字。
这张票把它变成一道机械的闸。

**测在 `run` 那条既有的主缝上，一条新缝都不加。**`tests/pipeline.rs` 头一条用例
已经是这个形状——跑一卷、把报告里那一页写出的文件读回来、拿判定比它的位宽；
落格只是在同一处多问一句「解回来的取值都在格点上吗」。

**「哪些页在这条不变量里」不另列名单。**《灰阶分布》那条词条已经写着
「彩页与坏页没有判定」，因此断的是一条**双向对应**：有判定的页落格必须成立，
没有判定的页必须是彩页、坏页占位或透传文件。将来多一类没有判定的页，
这条用例会逼人说清它是什么——例外因此是**被测出来的**，不是被跳过的。

**不碰生产代码。**产物一个字节不变。

**Blocked by:** 无——可以立刻开始

**Status:** ready-for-agent

- [ ] 跑一卷之后，报告里每一页写出的那个文件解回来，灰调级数不超过 `2^判定那一档的灰阶档位`
- [ ] **六个候选各走到一次**（1bit、1bit+FS、2bit、2bit+FS、4bit、4bit+FS）；判据自己挑不到的那几档用 `--bit-depth` / `--dither` 顶死，**顶死的页照样要落格**
- [ ] **灰度与调色板两支各走到一次**——`encode.rs` 在两者之间按字节取小者，两支都盖住，「取小者不牵动画质」那句话才算全验过
- [ ] `--gray-levels` 开到走得到 8bit 的那一档，**8bit 也在这条不变量里**（不因为上界是 256 就被跳过）
- [ ] **双向对应**：有判定的页落格成立；没有判定的页必须是彩页、坏页占位或透传文件。一个混排卷（彩页 · 坏页 · 透传文件 · 灰度页各一）一次盖住
- [ ] **《留下的页》**：跑两趟、第二趟按页跳过，从上一趟搬过来的页照旧落格
- [ ] `tests/single_source.rs` 加一条：《落格》那条不变量的说法只有 `CONTEXT.md`《量化》一处出处，用例与文档都只指过去、不抄第二份
- [ ] **黄金回归一格没动**，产物一个字节不变
- [ ] `cargo xtask gate` 三条全绿
