# 01 — 《落格》在 `run` 那条缝上立成用例

**What to build:** 让下一个想加有损编码器的人，**在写第一行代码之前就撞上一条会红的用例**。

`CONTEXT.md`《量化》已经有《落格》那条不变量了（`dr/01` 落的）：走灰度路径写出的每一张页，
把字节解回来，每一个取值都还落在它那一档判定的格点上。今天它只是一段文字。
这张票把它变成一道机械的闸。

**测在 `run` 那条既有的主缝上，一条新缝都不加。**`tests/pipeline.rs` 头一条用例
已经是这个形状——跑一卷、把报告里那一页写出的文件读回来、拿判定比它的位宽；
落格只是在同一处多问一句「解回来的取值都在格点上吗」。

**「哪些页在这条不变量里」不另列名单。**《灰阶分布》那条词条已经写着
「彩页与坏页没有判定」，因此断的是一条**双向对应**：有判定的页落格必须成立，
没有判定的页必须是彩页、坏页占位或透传文件。将来多一类没有判定的页，
这条用例会逼人说清它是什么——例外因此是**被测出来的**，不是被跳过的。

**不碰生产代码。**产物一个字节不变。

**Blocked by:** 无——可以立刻开始

## 落地记录

**本票做了什么。** 把《落格》从 `CONTEXT.md`《量化》里的一段文字，变成 `run` 那条既有主缝上
**一道机械的闸**。一条新缝都没加，一行生产代码都没碰，产物一个字节没变。

四条用例，共用一套问法：

- `tests/pipeline.rs::every_candidate_the_pipeline_writes_comes_out_on_grid` —— 六个候选各走到一次、
  8bit 也在里面、灰度与调色板两支各点名一格；
- `tests/pipeline.rs::a_mixed_volume_puts_every_page_on_one_side_of_the_invariant_or_the_other` —— 那条**双向对应**；
- `tests/pipeline.rs::a_retained_page_is_still_on_grid` —— 《留下的页》；
- `tests/single_source.rs::the_on_grid_invariant_lives_in_one_place` —— 说法只有一处出处。

### 一、问法：问**输出容器**，不问报告

`classify` 读的是页自己带着的那条记录（`tonefit:verdict`，见 `metadata`），不是 `VolumeReport::pages`。
两条硬理由：

- **《留下的页》不在报告里**（`VolumeReport::pages` 只列这一趟做了的），而它照样在这条不变量里；
- **透传文件根本不进报告**，而双向对应的另一头正要点到它。

`assert_the_report_and_the_files_agree` 另从报告那一侧再对一遍：有判定的页文件里写着同一个候选，
没有判定的页只能是彩色分支上的或坏页。**两头都问，一头都不缺。**

**格点不在用例里现算**：拿被测的 `quantize` 把 `0..=255` 打一遍，落下来的那一份就是格点集；
候选那串字也不自己解析，拿 `Candidate` 自己的写法逐个比过去——两处都不给已有的出处开第二份。

**两问的后一问由前一问推得出来**，这一点写在 `assert_on_grid` 的文档里、没有假装它独立：
格点集恰有 `2^灰阶档位` 个取值，取值都在格点上，级数自然不超过它——词条里那个「**因此**」
说的就是这件事。照样两问都问：验收写的是后一问的形状，而前一问将来若松动，后一问是仅剩的那道底。

### 二、例外是**被测出来的**，不是被跳过的

`OnGridSide` 那个枚举就是这条闸的形状：**里面一种**（有判定的页），**外面三种**
（彩页、空白占位页、透传文件），**第四种外面的当场 `panic!`**，说的是
「先去 `CONTEXT.md` 的《量化》把它为什么不在这条不变量里说清楚，再回来」。

三种在外面的**各问一句自己凭什么在外面**，一句都不是跳过。其中透传文件那一句
（与源里同名那一份逐字节相同）是**承重的**：没有它，任何一份认不出来的东西都会悄悄归成透传文件——
那正是这道闸要防的 `Ok(None)` 形状。

### 三、六个候选哪几格是判据自己挑的，哪几格是顶死的

**由判定的理由自己说出来**——用例断的是 `verdict.reason == Reason::Override` 与表里那一位相等，
不是两边各写一份名单。

| 候选 | 怎么走到的 | 夹具 |
|---|---|---|
| `1bit` | 判据自己挑 | 纯墨页（0 正落在 1bit 格点上） |
| `1bit+FS` | **顶死** | 渐变页 + `--bit-depth 1 --dither fs` |
| `2bit` | 判据自己挑 | 纯色 85（正落在 2bit 格点上） |
| `2bit+FS` | **顶死** | 渐变页 + `--bit-depth 2 --dither fs` |
| `4bit` | 判据自己挑（兜底） | 纯色 96，尺寸未贴合屏幕那条路 |
| `4bit+FS` | 判据自己挑（兜底） | 纯色 96，门成立那条路 |
| `8bit` | **判据自己挑** | 纯色 96，`--gray-levels 256` 抬开硬上界、两维都不点名 |

**顶死的只有两格。** 抖过的低档灰阶档位判据一格都不挑（颗粒可见下限跟着格点间距走，
ADR 0002 决定第 5 条），那两格因此只能顶死走到——而顶死的页照样落格，这正是票面第二条要的。

**8bit 是判据自己挑的，不是顶死的。**验收写的是「`--gray-levels` 开到**走得到** 8bit 的那一档」：
抬开上界之后纯色 96 在 8bit 上读 0.000、是界内最低的一档，判据自己就选了它
（`with_the_whole_set` 两维一个都不点名，理由那一位因此断出 `false`）。

**两支各点名一格，不靠碰巧**：抖过的 `1bit` 渐变页把两个格点铺满，调色板买不到更窄的位宽、
还要多背一个 PLTE → **灰度**；单取值的页在 `8bit` 上调色板只要 1 位而灰度要 8 位 → **调色板**。
两格各断各的颜色类型，末尾再断两支都在场作底。

### 四、这条闸真会红——弄坏过三处，各红在哪一句上

一条永远不会红的用例比没有用例更坏（`p0-hardening/09`）。三处各弄坏一次、跑、再
`git checkout -- src/` 还原，三趟各红一条：

| 弄坏哪一处 | 怎么弄坏 | 红在哪一句 |
|---|---|---|
| `src/encode.rs` 的 `png` | 不按判定那一档的格点写，**按 8bit 原样写、每个取值再挪开一级**（模拟有损编码器） | `tests/pipeline.rs:211`——`… 判定 2bit，却写出了格点外的 84` |
| `src/lib.rs` 的 `placeholder` | 让空白占位页多一个取值 | `tests/pipeline.rs:248`——`003.png 是空白占位页，写出去的却不止一个取值`（left 2，right 1） |
| `src/metadata.rs` 的 `FAILED_VERDICT` | `"failed"` 改成 `"blank"`（多出一类记录说不出自己是什么的页） | `tests/pipeline.rs:159`——`… 的记录写着「blank」：这是一类《落格》还没说过的页。先去 CONTEXT.md 的《量化》把它为什么不在这条不变量里说清楚，再回来` |

三趟各退 `101`，三趟之后 `git diff -- src/` 为空（**评审之后代码又动过，这三趟是照最终那一版重跑的**，
行号就是最终那一版的行号）。

头一处正是这张票存在的理由：**把 PNG 换成一个还不回格点的编码器，这条闸当场红**。
第三处证的是那条双向对应的另一头——**多一类没有判定的页，它不会被静默跳过去**。

### 五、8bit 那一档上落格恒成立，而它照样在闸底下

8bit 的格点就是全部 256 个取值，「解回来的取值都在格点上」在一张 8 位 PNG 上**恒真**。
票面第四条要的是**不被跳过**，而被跳过与问不出话是两件事——用例的文档把这一格恒成立写在明处，
详情与两条可选的补法见停车场 **Q938**。（这一格在**别的**维度上问得出话：它现在还断着
「判据自己挑得到它」与「调色板那一支」。）

### 六、原来那条只问半句的用例长成了这道闸

`tests/pipeline.rs` 原有 `the_written_levels_all_sit_on_the_grid_of_the_decided_bit_depth`，
问的是这八条验收里头一条的**半句**。并掉之前先证了**严格覆盖**，一条一条接过来：

| 旧那一条问的 | 新那一条接它的哪一处 |
|---|---|
| 「有没有格点外的取值」（`grid.pixels().contains(&level)`） | `assert_on_grid` 头一句——格点集同样由被测的 `quantize` 打出来 |
| （**旧的没问过**）「灰调级数不超过 `2^灰阶档位`」 | `assert_on_grid` 第二句（`distinct <= depth.levels()`） |
| 黑白面板上那张**彩页转灰之后**落不落格 | 混排卷那一条的**第二趟**（换黑白面板再跑一遍，见下） |

**两句不是同一句**，缺哪一句都是并的时候丢了东西；而第三行是评审揪出来的——
混排卷为了问「没有判定的页」那一侧走的是彩色面板，**旧那一条问过的黑白面板那条路会就此断掉**。
补法比原样留着更好：同一个混排卷**跑两台面板**，彩色面板给出没有判定的那一侧，
黑白面板上同一张彩页转灰之后**有了判定、从外面走进里面**，对照本身成了被测的东西。

旧那三页夹具里另外两张（`gradient(TYPICAL)`、`solid(DOUBLE_PANEL, 200)`）没有还原：
它们走的路被新那张候选表盖得更全。回滚办法与另外两个选项写在停车场 **Q936**。

### 七、`tests/single_source.rs` 那一条钉的是**这道闸的依据**

`tests/pipeline.rs` 问的是「写出去的页落不落格」，而**落格是什么**它一个字都不说、只指过去。
新那一条三件事一起问，与既有那四条同一个形状：别处没有第二份、
家里那三句例外真住着、指回来的那句路标还在。

**家里那三句是闸的依据，不是装饰**：双向对应断的是「没有判定的页必须说得出自己是三种里的哪一种」，
而「是哪三种」这句话只在词条里。把它们从词条里删掉，那道闸就成了一份没有依据的名单。

**用例那一半也拴上了**：`tests/pipeline.rs` 里那四句路标写的是与 ADR 0009 同一个字样
（`《落格》，见 \`CONTEXT.md\` 的《量化》`），并进了 `ON_GRID_SIGNPOSTED`（下界 4）。
**扫描那一侧仍够不着 `tests/`**——`delivered()` 不收它，收了那四条邻居会当场红
（它们自己的记号就住在那个文件里）。用例不抄第二份这件事，眼下靠的是路标那一半加评审。
