# 01 — 设计稿里出自库的字与样式类名对齐

**What to build:** 导出快照之前，设计稿里**凡是出自库与报告的字**要与库原话逐字相同——否则 Rust 侧画出来的整屏
与设计快照逐格比不上（停车场 Q718）。逐类对：

- 每页结果各列：尺寸、缩放、灰阶、原因、画质分、提示；
- 卷行行尾出自报告的句子：跳过、没做成的原因、隔离、需留意的那几样；
- 备注行与说明卡的全文：无法访问的地方、非漫画文件；
- 画质判定参数五行行内那一句，与设备设置里画质门槛那一截——取自报告抬头那一处（Q714）；
- 型号与屏幕规格表；
- 设置项的名字与取值写法（含每一项「没说」那一格怎么印）；
- 预设栏的说明。

对的办法是让库对设计稿假数据的**语义**说出原话，拿原话替换设计稿里的字。假数据的语义（哪一页判成哪一档、为什么、
哪一卷跳过或没做成）不动。界面层自己的字（按键提示、总览与确认条的句子、详情栏的长说明）不在此列。

另一件：设计稿里**聚焦框与光标**改用亮绿类名（浏览器里同色）。它们今天与完成记号共用一个绿色类名，
导出时分不开，而《语义色》要前者亮绿、后者绿（spec《颜色》）。

只改设计稿，不碰实现。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 上面每一类字，设计稿里的写法与库对同一语义说出的原话逐字相同；对过的每一处连同改前改后记进落地记录（两处逐字做不到、悬置在停车场：画质分那一列 Q725、预设栏的说明 Q728）
- [x] 画质判定参数五行与画质门槛那一截取自报告抬头那一处
- [x] 聚焦框与光标用亮绿类名，完成记号等其余绿色不变
- [x] 设计稿 11 个场景 × 120×36、80×24、56×14 在无浏览器环境下都画得出、零报错
- [x] 设计稿的交互（切场景、按键、切尺寸）照旧可用
- [x] 与 `CONTEXT.md` 对不上的地方记停车场，不顺手改词汇表

## 落地记录

**做了什么。** 让库对设计稿假数据的语义说出原话（一条临时的集成用例把 `Profile`／`Panel`／`Threshold`／`Scaling`／`Reason`／`Candidate`／
`Composition`／`Masking`／`Aggregation`／`Interlock`／`Salvage`／`Size`／各项 `name()` 的 `Display` 逐个打出来，用完即删，不提交；
`render.rs` 那几句是 `format!` 里的静态字，直接读源码），拿原话替换设计稿里的字；假数据的语义（哪一页哪一档、为什么、哪卷跳过或没做成）一处没动，
只补了两处让库说得出话的细节：`字体包.zip` 那一条的原因归 `NonVolumeReason::ArchiveWithoutAPage`（另两个文件归 `NeitherPageNorArchive`），
尺寸未贴合屏幕的页画质分那一格改印它判成的那一档（从前印的是 `+FS` 那一档的分，与判定自相矛盾）。
聚焦框与光标改用 `c-lgreen`（`FOCUS`／`CURSOR` 两个常量），完成记号、勾选框、`[自动滚动]`、回话里的 `✓` 等其余绿色不动。
设计稿旁边新建 `render.js`（jsdom 30.0.1，`package.json` 锁版本，`node_modules/` 进 `.gitignore`）：在伪 DOM 里跑设计稿自己的脚本，
冻住 `performance.now`、不跑主循环，11 个场景 × 120×36、80×24、56×14 各画一遍并检查整屏形状，再按 `j`／`k`／`?`／`Esc` 各一次重画；
`--text <场景> <宽x高>` 印字网格（一行一屏行、两侧加引号、宽字符后半格跳过）。`load()` 交出的把手（`design`、`clock`、`frame`、`press`、`chip`、`resize`）
