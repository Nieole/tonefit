# 01 — 设计稿里出自库的字与样式类名对齐

**What to build:** 导出快照之前，设计稿里**凡是出自库与报告的字**要与库原话逐字相同——否则 Rust 侧画出来的整屏
与设计快照逐格比不上（停车场 Q718）。逐类对：

- 每页结果各列：尺寸、缩放、灰阶、原因、画质分、提示；
- 卷行行尾出自报告的句子：跳过、没做成的原因、隔离、需留意的那几样；
- 备注行与说明卡的全文：无法访问的地方、非漫画文件；
- 画质判定参数五行行内那一句，与设备设置里画质门槛那一截——取自报告抬头那一处（Q714）；
- 型号与屏幕规格表；
- 设置项的名字与取值写法（含每一项「没说」那一格怎么印）；
- 预设栏的说明。

对的办法是让库对设计稿假数据的**语义**说出原话，拿原话替换设计稿里的字。假数据的语义（哪一页判成哪一档、为什么、
哪一卷跳过或没做成）不动。界面层自己的字（按键提示、总览与确认条的句子、详情栏的长说明）不在此列。

另一件：设计稿里**聚焦框与光标**改用亮绿类名（浏览器里同色）。它们今天与完成记号共用一个绿色类名，
导出时分不开，而《语义色》要前者亮绿、后者绿（spec《颜色》）。

只改设计稿，不碰实现。

**Blocked by:** None — can start immediately
