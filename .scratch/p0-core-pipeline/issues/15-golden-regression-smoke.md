# 15 — 黄金回归与真实素材冒烟

**What to build:** 一组固定夹具的判定位深与输出体积记进快照，任何变动都需要显式接受——防止调优在无人察觉时改变判定结果。

另有一条真实素材冒烟，通过环境变量指向本地路径，默认跳过，不提交任何素材。

**Blocked by:** 09 — 抖动与几何门；10 — 彩页识别与彩色分支；11 — 幂等与 tEXt 元数据

**Status:** resolved

- [x] 快照覆盖各类夹具的判定位深、抖动模式与输出体积
- [x] 快照变动需显式接受，默认导致测试失败
- [x] 真实素材冒烟默认跳过，环境变量未设时不影响测试通过
- [x] 冒烟用例断言的是不崩溃与产出合法，不断言具体体积
- [x] 仓库内不含任何真实漫画素材

## Comments

**两个文件，两件事。**`tests/golden.rs` + `tests/golden-snapshot.txt` 是黄金回归，
`tests/smoke.rs` 是真实素材冒烟。合成一个文件就得共用一段抬头，而它们连断言的东西都相反：
一个钉死数值，一个连体积都不看。

**与 `tests/metric.rs` 的分工是反的。**那边测判据**该有的性质**，数值动了不算错；
这边测**数值本身**，动了就要有人当场答一句「为什么」。判据的低通核、掩蔽加权、
上包络的分位、迟滞页数、编码器在灰度与调色板之间的取舍，任何一处动一下都在快照上露出来。

**快照按 `--no-metadata` 跑，字节数因此不含 tEXt。**记录里写着工具版本，收进来的话
改一次版本号整份快照跟着动，真正的判定变动会淹在里面。代价说清楚：记录那一侧的体积回归
（多写一遍、字段暴涨）在这份快照上是隐形的。它不是没人看着——`tests/idempotency.rs`
逐字段钉着写出的是哪六项、取值长什么样，而体积是字段的函数，字段动了那边先响。

**比对那一手自己有一条用例。**「快照变动需显式接受，默认导致测试失败」是票面第二条，
而主用例证不了它——快照对得上时它照样通过，比对写成 `Ok(())` 也照样通过。
`a_changed_snapshot_is_never_silently_accepted` 把比对拿出来单独喂六组：一模一样、
快照不在、体积差一个字节、候选变了、少一行、多一行。那句票面这才有一处真的断言。

**快照里一个平台相关的字符串都没有。**卷名取源路径的最后一段（前面是临时目录，每趟都不一样），
页名取相对卷根的路径并把分隔符归一成 `/`，失败页的原因整句不进快照——那句话里有成员名和
本机分隔符（原因见 `tests/isolation.rs`，那边才是它该被断言的地方）。读回来时把 CRLF 归一，
检出设置改不动这份快照。

**夹具覆盖 spec 点名的每一类页，外加两卷单页够不着的东西。**单页卷各出现一次：
B 类渐变、A 类渐变（预缩真走一遍）、网点、线稿、纯色、黑白面板上的彩页、跨页宽幅、
小于目标的页；彩色面板上另起一卷放彩页与灰度页。`mixed` 是多页混排——卷内档位一致，
以及驱动页落在哪一页，只有多页才看得出来。`damaged` 一卷收三种坏法：救回的页、失败的页、
原样透传的文件，顺带钉住占位页按卷内统一尺寸出、整卷进隔离目录。

**透传文件也占一行。**它不在 `VolumeReport.pages` 里（页才有逐页的报告），因此从输出容器
里数：除页之外剩下的就是透传过来的那些。少一个文件、多压一遍，页那几行一个都不会动——
「非图片文件」是 spec 点名的夹具之一，不给它一行，这一类在快照上就是空转的。

**`离群 0 页 · 迟滞升档 0 页` 是钉住「这批页不该触发它们」，不是覆盖了那两条。**
现有夹具驱不出非零值，真正的覆盖在 `tests/pipeline.rs`。想在这里驱出来就得反过来
照着阈值和分位捏夹具——那正是这份快照要防的调优，不该由它自己先做一遍。

**头一趟跑出来的数已经提出了一个问题。**`mixed` 里那张纯色页判在 2bit+FS 上，
体积比 `solid` 卷同一类页在 1bit+FS 上的大一个量级——抖动把一片均匀的灰打散成了噪声，
而 `Candidate` 的次序说的是「抖动的体积代价够不上升一档位深」。那条次序在纯色页上
还成不成立，是这份快照记下的第一个待答问题（measurements 的《抖动》量的是网点派生图）。
具体几个字节看快照本身，这里不抄——抄一遍就有两个出处，而下一次接受就让这里成了假话。

**数值理论上随机器可能不同。**重采样按 CPU 指令集分派（`fast_image_resize` 运行时探测），
换一台指令集不同的机器，像素可能差一两个取值，体积随之动。真发生了要认得出来：
整份快照一起动、而代码一行没改，那是环境不是回归——那时重新接受一份，并在这里记一句。

**冒烟指的是目录，不是卷。**直接子项里的子目录与 `.cbz` 各算一个卷；一个都没有时
把指过来的目录本身当成一个卷——手头只有一卷样本的人会直接指它。
`TONEFIT_SAMPLES` 没设就跳过、照样通过；**设了却指错地方不是跳过**，那是点名要跑，
静悄悄通过等于骗人，因此当场 panic。

**冒烟断言 `processed > 0`。**整批素材都读不出来时每一卷都是清一色的占位页，
而 `run` 一路 `Ok`——那一趟什么都没验证到，看上去却与验证过了一模一样。
除此之外只断言产出合法：每一页解得回来、尺寸与报告说的对得上、写出的位宽不超过判定那一档
（调色板可以更窄，更宽就是判定与写出对不上）。归档卷的页没有文件系统路径，
按成员名从归档里取，名字的算法与 `sink` 写进去时同一个。

**卷级判定那一行两处共用一份。**`fixtures::volume_verdict` 一个出处，黄金回归与冒烟
各取一次；成员名相对容器根、分隔符归一成 `/` 那一手同理（`fixtures::relative_name`，
与 `sink` 写归档成员名的算法同一个）。用词一律取自 `CONTEXT.md`：上包络定出的那一档叫
**基准档**（`上包络` 是那次聚合本身），升上去的页叫**迟滞升档**，失败页留下的那张叫**占位页**。

**冒烟这条路自己跑过。**仓库里没有真实素材，因此拿 `calibrate` 出的两张标定图搭了
一个目录卷和一个 CBZ 卷验过整条路径：目录与归档两支、透传文件、指向文件时的 panic、
直接指一个卷时的回退、以及整卷都坏时 `processed > 0` 真的拦得住。那批临时文件不入库。

**`CONTEXT.md` 没有动。**本票没有引入领域概念——「黄金回归」与「冒烟」是测试的说法，
而那份文件是领域词汇表。两个环境变量的说法在各自的测试模块文档里，
`samples-wanted.md` 只加了一行指过去。
