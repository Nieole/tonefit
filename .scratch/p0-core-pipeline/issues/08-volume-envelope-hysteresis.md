# 08 — 卷级上包络与迟滞

**What to build:** 位深不再逐页各判各的。逐页判定后取卷级 p95 上包络定出整卷的基准档，叠加迟滞限制切档频率，离群页单独定档。`--per-page` 关闭这层约束。

依据见 ADR 0006：位深按卷取上包络并加迟滞。这不是「整卷一个档」——离群页单独定档与迟滞升档都会在卷内造成档位差，任何对外说明都不许把上包络宣传成绝对一致。

**Blocked by:** 07 — 两遍管线与缓存

**Status:** resolved

- [x] 卷内主体页共用一个基准档，翻页时不逐页变动
- [x] 离群页不参与上包络，单独定档
- [x] 迟滞规则限制档位切换频率
- [x] `--per-page` 关闭上包络与迟滞，回到逐页最优
- [x] `Report` 的理由能区分 VolumeEnvelope、Outlier、Override
- [x] `Report` 指出驱动全卷档位的那一页
- [x] p95 的分位数、迟滞页数、离群页判据三者均未标定，`Report` 显式标注

## Comments

汇总落在 `src/envelope.rs`：`summarize(逐页判定, 阈值) -> Summary`，纯函数，不碰文件系统。
`lib.rs` 在两遍之间调它一次，把重定过的判定写回每一页，第二遍读的就是它——
07 号票空出来的那一段接的正是这个。

**三步的顺序是设计的一部分，不能反：**先按全卷取一次上包络得到**临时基准档**，
再摘离群页，最后在主体上重取上包络并叠加迟滞。离群页判据要有个立脚点才谈得上「显著偏离」，
而那个立脚点只能来自还没摘干净的分布。临时基准档确实被离群页污染过，
但上分位至多让 5% 的页越过它，污染因此有界；重取的那一次才算数——那一次才是
决定第 5 条「不摘就被污染」所说的那个上包络。

**离群页判据只有幅度这一维**：判据超过阈值的 3 倍（未标定占位值）。没有限额，也不看成段与否。
数量的上界是白送的：立脚点是临时基准档，判定不高于它的页判据必在阈值以内、永远落不到离群侧，
而高过它的页至多占全卷 5%。**成段与否不进判据形态**——CONTEXT 说离群是「判据显著偏离卷内分布」，
那是幅度概念；把段长写进去，ADR 0006 决定第 5 条自己举的例子（卷首连着几页的彩页）
反而会被排除在外。成段只在迟滞那一层说话，那一层管的是升不升档，不是摘不摘页。

**迟滞整段升到「满足整段的最低一档」**，即段内各页判定的最大值（格点套嵌，两者等价）。
这不是新规则，是逐页判定那条「界以内最低的一档」抬到段上。抬不到极端内容上去：
段内不会有离群页，那些已经摘走了。ADR 决定第 4 条只说了何时升档、没说升到哪，这是补上的那一半。

**上分位在短卷上退化成最高的那一页**：p95 的秩在 20 页以内就是页数本身。
与判据的分块聚合同一个取舍（`metric::upper_quantile` 也这样退化）——宁可严格，
也不要把仅有的几页平均掉。代价写在 `envelope()` 的注里：决定第 3 条要挡的
「极端内容独自定全卷的档」，在短卷上只剩离群页那一层挡着。

**全卷一页不剩地落到离群侧时一页都不摘。**候选上界都过不去的卷（`--gray-levels 4`
撞上整卷灰调）就是这个局面：那时「远在界外」不再说明谁偏离了谁，而主体不能空着。

**卷级判定按 spec 的卷报告形状落成 `VolumeVerdict`**：`Envelope` / `Override` / `PerPage`
三选一，判定位深、判定理由、驱动页绑在一起——它们不是每种情形下都同时成立，
`--per-page` 一开卷级根本没有位深。`--bit-depth` 不是「关掉」上包络：顶掉判定之后
逐页结果里没有分布可聚合，卷级基准档是**无从谈起**，报告里说的也是这一句。

**判定理由合并进同一个 `Reason`，不另起一个枚举**（06 号票留的那条注就是这么说的）。
新增三种：`VolumeEnvelope`、`Hysteresis`、`Outlier`。`Hysteresis` 在 spec 点名的那几种之外，
理由在 ADR 的后果里：**上包络不承诺卷内绝对一致**——升上去的那一段与主体之间就是一次翻页跳变，
并进 `VolumeEnvelope` 等于把这句话藏起来。

逐页那三种理由此后只在卷级那一层不在场时露面，两个原有用例因此改走 `--per-page`：
兜底取候选上界是**逐页**那一层的规则。「一档都不达标」这件事在默认路径上仍摆在同一页的判据值里，
与头一行的阈值并排——判据是量、阈值是界，判定可解释靠的是两者同时在场。

两处收口：最近秩取法抽成 `metric::nearest_rank`，判据的分块聚合与卷级上包络共用，
「同一套取法」于是是构造出来的事实而不是两边注释里的一句声称；离群页判据不读阈值的数值，
走新加的 `Threshold::far_outside`——判定只经 `Threshold`，倍数那个未标定的数留在上包络那一层。

`CONTEXT.md` 的《判据》补了两个词：**基准档**与**驱动页**。上包络那一条本来就在用它们，
只是没有各自的位置。

---

**09 号票（抖动与几何门）改了本票两处结论，记在这里免得两份说法并存：**

1. **`--bit-depth` 不再一给就是 `Override`。**本票写的是「`--bit-depth` 顶掉判定之后逐页结果里
   没有分布可聚合，卷级基准档无从谈起」。候选从此是 (位深, 抖动模式) 组合：只点位深而几何门开着时，
   抖动那一维**还有分布可聚合**，那时说「无从谈起」就是假话。09 号票因此把覆盖项统一成
   「裁候选集」——裁到只剩一个候选才是 `Override`，本票那句话的**理由**原样成立，
   只是触发条件收窄了。

2. **迟滞不再用「段内判定的最大值」。**本票靠格点套嵌论证它与「满足整段的最低一档」等价，
   那个论证只覆盖位深；抖动那一维上不成立（`1bit+FS` 排在 `2bit` 之前，判据却可能好过它）。
   规则本身没变，改的是照规则直接检验。同一个理由还改了迟滞的入段判据：
   「判定排在基准档之后」换成「基准档过不了这一页的界」。详见 09 号票的 Comments。
