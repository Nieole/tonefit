# 08 — 卷级上包络与迟滞

**What to build:** 位深不再逐页各判各的。逐页判定后取卷级 p95 上包络定出整卷的基准档，叠加迟滞限制切档频率，离群页单独定档。`--per-page` 关闭这层约束。

依据见 ADR 0006：位深按卷取上包络并加迟滞。这不是「整卷一个档」——离群页单独定档与迟滞升档都会在卷内造成档位差，任何对外说明都不许把上包络宣传成绝对一致。

**Blocked by:** 07 — 两遍管线与缓存

**Status:** ready-for-agent

- [ ] 卷内主体页共用一个基准档，翻页时不逐页变动
- [ ] 离群页不参与上包络，单独定档
- [ ] 迟滞规则限制档位切换频率
- [ ] `--per-page` 关闭上包络与迟滞，回到逐页最优
- [ ] `Report` 的理由能区分 VolumeEnvelope、Outlier、Override
- [ ] `Report` 指出驱动全卷档位的那一页
- [ ] p95 的分位数、迟滞页数、离群页判据三者均未标定，`Report` 显式标注
