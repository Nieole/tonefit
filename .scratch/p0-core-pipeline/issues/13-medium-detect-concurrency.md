# 13 — 介质探测与并发

**What to build:** 读取层与计算层分离。介质按路径映射到所在卷再探测寻道惩罚：有惩罚时读取串行，无惩罚时并发。计算层用 rayon 满核，有界通道按字节预算背压。长任务显示进度。

依据见 ADR 0009：处理点名的子集，介质按路径探测。同一次运行里不同路径可能落在不同介质上，判定不能一次性做。

**Blocked by:** 08 — 卷级上包络与迟滞

**Status:** ready-for-agent

- [ ] 介质探测按路径进行，同一次运行中不同路径可得到不同结论
- [ ] 有寻道惩罚的路径上读取串行
- [ ] 无寻道惩罚的路径上读取并发
- [ ] `--io-mode` 可覆盖自动探测
- [ ] 有界通道按字节预算背压，峰值内存不随并发度线性增长
- [ ] 探测失败时退到保守策略并在 `Report` 里说明
- [ ] 长任务显示进度
