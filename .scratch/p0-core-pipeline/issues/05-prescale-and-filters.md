# 05 — 预缩与滤波器选择

**What to build:** 总缩放比 ≥ 2 时先做整数倍 box 预缩再走残差段 Lanczos3；比值 < 2 时预缩退化为恒等，单次 Lanczos3。`--filter` 暴露全套常见滤波器，只作用于残差段。

依据见 ADR 0001：重采样滤波器的选择比位深更能决定输出体积。box/area 只是预缩那一级，不是主重采样器。

**Blocked by:** 02 — Profile 与面板表

**Status:** ready-for-agent

- [ ] 总缩放比 ≥ 2 时触发整数倍 box 预缩，预缩后残差比 < 2
- [ ] 比值 < 2 时不做预缩，直接单次重采样
- [ ] `--filter` 只改残差段，不改预缩级
- [ ] 二值网点夹具在高缩放比下经预缩后灰调级数受控（对照 measurements 的《滤波器与灰调级数》给出的机理）
- [ ] `Report` 标明每页实际的总缩放比、是否触发预缩、残差比
