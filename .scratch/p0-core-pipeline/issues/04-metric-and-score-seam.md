# 04 — 判据与 `score` seam

**What to build:** 把判据实现出来并暴露为纯函数 `score(参照, 候选) -> Score`，供数值与性质测试直接调用。`--dry-run` 的报告里出现每页的判据值，但此时还不据此改变输出。

判据形态见 ADR 0002：判据建立在低通后的局部均值上——低通核由面板 PPI 推出，分块取上分位而非均值，带对比度掩蔽加权。参照是缩放到目标尺寸后、未经目标位深量化的图，工作精度 8 位灰度。

**Blocked by:** 02 — Profile 与面板表

**Status:** ready-for-agent

- [ ] `score` 是公开纯函数，不依赖文件系统与全局状态
- [ ] 低通核尺寸由面板 PPI 推出，不是硬编码常数
- [ ] 分块聚合取上分位，一页里大面积留白不会稀释局部劣化
- [ ] 对比度掩蔽加权：平坦低对比区收紧、高频纹理区放宽
- [ ] 性质测试：渐变夹具上，抖动候选的判据优于不抖动候选（逐像素度量给出相反排序，见 measurements 的《抖动》）
- [ ] 性质测试：位深越高判据误差不增
- [ ] `--dry-run` 报告逐页给出判据值，且不写任何文件
