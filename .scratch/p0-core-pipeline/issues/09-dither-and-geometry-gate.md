# 09 — 抖动与几何门

**What to build:** 候选从单一位深扩展为 (位深, 抖动模式) 组合。低位深输出在需要时用 FS 误差扩散抖动，让平缓灰调不出现色带。

抖动是 profile 级的几何门，取决于几何而非页的内容：只有目标尺寸不会被下游缩放时才启用，否则整体关闭。依据见 ADR 0007：抖动仅在目标尺寸未被下游缩放时启用。

**Blocked by:** 08 — 卷级上包络与迟滞

**Status:** resolved

- [x] 候选是 (位深, 抖动模式) 组合，上包络取的是这个组合
- [x] FS 误差扩散实现，渐变夹具在低位深下不出现可测的色带
- [x] 几何门不成立时抖动整体关闭，不设页级抖动开关
- [x] `--dither` 可覆盖自动选择
- [x] `Report` 标明本卷的抖动模式与几何门的判定结果

## Comments

**几何门只有一处判定：`geometry::one_to_one(目标尺寸, 面板分辨率)`**——目标尺寸贴住面板的
一条边了吗。ADR 0003 末段要求它与灰阶硬上界同源、不许各写一份，这个函数就是那一处。
贴住才谈得上「输出不再被下游缩放」：fit-inside 把缩小的页顶到一条边上，另一条留边，
阅读器填背景、不重采样；一条边都贴不住只有一种来路，就是源比目标小、按不放大原样输出，
那一页到了阅读器手里还要被放大。

**门对整卷只有一个结果：卷内有一页贴不住，整卷的抖动整体关闭。**ADR 0007 的《决定》
把话说死了——「条件不成立时抖动整体关闭，不降级成更温和的抖动模式」，
成立时「抖不抖跟着位深一起按卷决定……不设页级抖动开关」。
两条合起来只剩这一种聚合方式。代价认下：B 类里源比目标小的页占比不低（1264×1680 面板上
19%，见《B 类素材普查》），这类卷整卷没有抖动可谈。`GeometryGate::Broken { page }` 因此
指出关门的那一页，做法与上包络指出驱动页一致——门关掉的是**整卷**的收益，不指名就没法处理。

**候选排序即体积由小到大**：位深先，同位深下不抖动在前。「界以内最低的一档」这条规则一字未改，
抖动只是多了一维。次序与体积同调有实测撑着（《抖动》：1bit+FS 13463 < 2bit 24263，
2bit+FS 25074 < 4bit 43590）——抖动的体积代价够不上升一档位深的那一步。

**判据值沿这个次序不单调，这是本次跑出来的，不是意外。**`TYPICAL` 渐变夹具（1441×2048）
在基准面板上的判据曲线：1bit 121.7 · 1bit+FS 11.7 · 2bit 38.8 · 2bit+FS 3.9 · 4bit 6.7 ·
4bit+FS 0.7（这几个数是本项目判据的输出，不是《抖动》那张表里的实测值）。
`1bit+FS` 比 `2bit` 好得多，`2bit+FS` 又好过 `4bit`。位深那一维上的格点套嵌在抖动这一维上
没有对应物，卷级那一层因此有**两处**跟着变，缺一处就会静默写出越界档：

- **迟滞的段内档位**不能再拿「段内判定的最大值」代替「满足整段的最低一档」。08 号票靠格点套嵌
  论证两者等价，那个论证只覆盖位深。现在按规则直接检验（`envelope::lowest_for`）：
  基准档之上、段内每一页的判据都在界以内的那个最低候选。只在基准档之上找——迟滞是升档规则，
  不是给一段页另配一档的口子。一档都满足不了整段时退回基准档与段内判定的较高者，
  而那个兜底恰好等于基准档时一页都没升，段留在基准档上、理由仍是上包络。
- **迟滞的入段判据**也一样。「要求高于基准档」原先写成「判定排在基准档之后」，两者在位深那一维上
  等价（判定是最低的合格候选，格点套嵌保证更高的档也合格），在抖动这一维上不等价：
  判定 `1bit+FS` 排在基准档 `2bit` **之前**，而 `2bit` 可能过不了这一页的界。照排序判，
  这样的页既进不了升档段、也未必远到能被摘成离群页，就被静默写成越界档。
  现在直接判「基准档过不过得了这一页的界」——新判据是旧判据的严格超集，
  用例 `a_page_the_base_cannot_admit_is_raised_even_when_it_sorts_below_the_base` 钉的就是它。
- 这条不单调也正是抖动买到的东西：灰阶压到 4 级时不抖动的 {1,2} 两档全部越界（走兜底），
  抖过之后 2bit+FS 落回界内。用例 `dithering_can_bring_a_page_back_within_the_threshold`
  钉的就是它。

**覆盖项裁的是候选集，一次裁一维。**`--bit-depth` 与 `--dither` 与两道界（面板灰阶数、几何门）
作用方式相同：都只从候选集里拿走东西。裁到只剩一个候选**且**给了覆盖项时判定被顶掉
（`Reason::Override`、`VolumeVerdict::Override`）；只点一维而另一维还有候选时，
那一维仍由判据说了算，报告说的也不是「被顶掉」。这与 08 号票写的「`--bit-depth` 一给就是
Override」有出入，改的理由是候选变成了二维：`--bit-depth 4` 而几何门开着时确实还有分布可聚合，
说「无从谈起」就是假话。裁空了当场报错——`--dither fs` 顶不掉几何门，正如 `--bit-depth 8`
顶不掉面板灰阶数。

**逐页定档从第一遍挪进汇总。**几何门要看完整卷才判得死，而候选集是判定的前提；在门还可能关上的
时候定档，定的是一套随后可能被裁掉的候选。第一遍现在只出判据曲线与缓存，`summarize_volume`
逐页定档再收成卷级。第一遍另有一手：一页关上门就当场把抖动那一维从候选集里去掉，
连同已经求过的抖动判据一并丢掉——「候选集全卷同一套」于是在任何时刻都成立（上包络与迟滞
靠的正是这一条），而门关得越早白求的判据越少。

**FS 的实现细节两处值得记：**误差只往右和往下传，两行的累积量就够，不必为整页留浮点缓冲；
落点由含累积误差的取值算出，而误差取它与格点的差、**不夹到 [0,255]**——夹一次就吞掉一部分误差，
纯黑纯白附近的平缓过渡会重新长出色带。夹具里那份 04 号票留下的 FS 实现随本票删掉，
判据的性质测试改用生产实现。

**色带要量得出来才算数。**用例把同一页同一档位深跑两遍（抖 / 不抖），比逐块均值相邻两块之间的
最大跳变：不抖动 53 级，抖过 4.5 级。**不能逐行量**——FS 把误差往下一行推，相邻两行的均值本来
就在几十级上下摆，那正是抖动买下的高频，量它等于量这笔交换本身。块高取低通核（4 px）的两倍。

**报告多一行。**`VolumeReport::gate` 与卷级候选里的抖动模式并排渲染成「几何门 X · 本卷 Y」：
两件事只有并排才解释得了对方——门关着时那个「不抖动」不是判据选的。

**留下的洞：几何门不成立时该用哪个位深集合。**ADR 0003 说上界的依据随对齐消失而失效、
「不得套用」，也说了该用哪个集合尚未测量。两者只能占一头：没有测量就实现不出「不得套用」之后
该用什么。P0 仍照 {1,2,4} 裁，并把这件事**说出来**——门不成立的卷，报告多一行
「面板灰阶上界的依据随门一起失效，P0 仍按它裁候选位深（ADR 0003：该用哪个集合尚未测量）」，
另记在 `BitDepth::candidates` 的注与 `CONTEXT.md` 的《尚未确立》里。
抖动那一维不同，它有 ADR 0007 给的明确答案：整体关闭。

**要请示的一处：几何门的粒度，ADR 0007 自己两处不一致。**《决定》说「条件不成立时抖动
**整体关闭**」「不设页级抖动开关」，《后果》却说「**这批页**没有抖动可谈」——前者是卷级，
后者读起来是页级。本票按《决定》实现（卷内一页贴不住，整卷关闭）：那是两条决定唯一自洽的读法，
页级开关正是《决定》点名拒绝的东西。代价按《B 类素材普查》算得出来：1264×1680 面板上
19% 的页源比目标小，一卷两三百页里几乎必有一页，**FS 在 B 类真实片源上因此近乎不可达**。
本票交付的是 ADR 写着的那个语义，不是最有用的那个。要让 FS 在 B 类上可达，得先改 ADR 0007
——例如把「源比目标小的页」整个排除在几何门之外（它们本来就没缩放，谈不上「被下游缩放」的是
阅读器的显示环节），或明确门只对**缩过的页**取与。这需要一次 ADR 修订，不在本票范围内。

`CONTEXT.md` 增《几何》里的**几何门**一词，并把《判据》的**判定**从「一页定下的位深」
改成「一页定下的候选」——候选现在是两维的。
