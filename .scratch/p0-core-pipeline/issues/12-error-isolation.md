# 12 — 错误处理与隔离目录

**What to build:** 一张坏图不再毁掉整卷。单页失败时仍强制统一尺寸以保证卷内一致，该卷被标记并输出到隔离目录，失败页与原因进 `Report`。问题因此可见且有界——可以选择忽略，但它不会藏起来。

**Blocked by:** 08 — 卷级上包络与迟滞

**Status:** ready-for-agent

- [ ] 截断的图片只要能解出完整尺寸就使用，解不出尺寸才算失败
- [ ] 单页失败时该页仍以目标尺寸产出，卷内尺寸保持一致
- [ ] 含失败页的卷输出到隔离目录并被标记
- [ ] `Report` 列出每一个失败页与原因
- [ ] 零字节文件、非图片文件、超大尺寸页均不导致进程中止
- [ ] 退出码能区分「全部成功」与「有卷被隔离」
