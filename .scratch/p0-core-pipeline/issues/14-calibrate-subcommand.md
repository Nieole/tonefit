# 14 — `calibrate` 子命令

**What to build:** 生成一张灰阶阶梯标定图，按目标 profile 的面板分辨率排布，供在真实设备上显示并目视数出从哪一档开始出现肉眼可分的台阶。

这是唯一能自证面板灰阶上界的路径。本票只负责产出标定图，反推阈值是标定完成后的独立工作。

**Blocked by:** 02 — Profile 与面板表

**Status:** ready-for-agent

- [ ] 生成的标定图尺寸匹配目标面板，可 1:1 显示
- [ ] 图中并排给出各候选位深的阶梯，每档可分别辨认
- [ ] 图内含判读说明，脱离文档也能用
- [ ] 标定图本身不经过位深判定，以无损方式写出
- [ ] 帮助文本说明目视数出的是感知可分辨级数，不等于面板物理灰阶数
