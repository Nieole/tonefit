# 11 — 幂等与 tEXt 元数据

**What to build:** 判定与理由写进输出 PNG 的 tEXt 区块，同一批字段兼作幂等依据：参数或源变了就重跑，没变就跳过。重跑一个已处理且参数未变的卷时不重复工作，`Report` 把它标为 `Skipped`。

记录随文件走，不依赖外部状态库——文件被移动、改名、重新打包都不会丢。

**Blocked by:** 08 — 卷级上包络与迟滞

**Status:** ready-for-agent

- [ ] tEXt 写入工具版本、profile 名、参数哈希、源哈希、判定位深与理由
- [ ] 重跑时参数与源均未变的卷被跳过，`Report` 标为 `Skipped`
- [ ] 参数变更触发重做
- [ ] 源文件变更触发重做
- [ ] 输出被移动或改名后，幂等判定仍然成立
- [ ] `--no-metadata` 关闭元数据写入，此时不再具备幂等能力，行为在帮助文本里说明
