# P0：核心管线（缩放 → 判据 → 位深 → PNG 输出）

Status: ready-for-agent

## Problem Statement

我有约 10 TB 漫画资源，格式跨 JPG、PNG、BMP、AVIF，来源跨原始超高尺寸扫描与网络发布版。
想把其中点名的若干卷送进电子墨水阅读器时，没有工具能替我做这件事：

- 页的尺寸和面板对不上，阅读器自己缩放的结果不受控
- 位深一律 8bit，体积远超必要（见 measurements 的《B 类位深实测》）
- 手工按卷统一参数很累，逐页各调又会让翻页时颗粒感突变
- 处理过的卷和没处理的混在一起，无法分辨，重复处理会静默劣化

## Solution

一个命令行程序，指向若干卷，产出设备优化副本。

对每一卷：把每页缩到该 profile 的目标尺寸，用判据为整卷选一档位深，需要时抖动，
写出带自描述元数据的 PNG。判定与理由随文件走，因此重跑会自动跳过没变的卷。

另有一个子命令生成灰阶阶梯图，供在真实设备上标定阈值。

## User Stories

1. 作为读者，我想把点名的几卷漫画一次处理完，这样我不用逐卷手工操作。
2. 作为读者，我想指定目标设备的 profile，这样输出直接匹配我的面板，阅读器不再二次缩放。
3. 作为读者，我想让工具自动决定每卷用几 bit，这样我不必理解位深也能拿到合理体积。
4. 作为读者，我想让整卷用同一档位深，这样翻页时颗粒感不会突变。
5. 作为读者，我想让彩页和高质量插图不被整卷的档位拖累，这样它们保持应有的质量。
6. 作为读者，我想在真正写文件之前先看一份报告，这样我能确认参数对了再执行。
7. 作为读者，我想知道某一卷为什么选了这个位深，这样判定结果对我是可解释的。
8. 作为读者，我想重跑时自动跳过已处理且参数未变的卷，这样中断后可以继续。
9. 作为读者，我想在改了参数后重跑时自动重做，这样我不会拿到过期的输出。
10. 作为读者，我想让源库保持只读，这样我的原始资源不会被误改。
11. 作为读者，我想处理散页目录，这样最常见的组织方式直接可用。
12. 作为读者，我想处理 CBZ，这样已经打包的卷不必先解开。
13. 作为读者，我想让 AVIF、JPEG、PNG、BMP 都能读，这样我的库不用先统一格式。
14. 作为读者，我想让包内的非图片文件原样带过去，这样阅读器仍能读到书籍元信息。
15. 作为读者，我想让彩页在黑白设备上转成灰度，这样它们不会显示成一团糊。
16. 作为读者，我想让转灰不丢失原本靠颜色区分的对比，这样彩色标题字仍然可读。
17. 作为读者，我想让源比目标小的页保持原尺寸，这样它们不会被放大得更糊。
18. 作为读者，我想在缩放时选滤波器，这样我能针对特定片源调整。
19. 作为读者，我想让工具对高分辨率源自动做去网点，这样网点不会在缩放后产生摩尔纹。
20. 作为读者，我想让低位深输出在需要时抖动，这样平缓灰调不会出现色带。
21. 作为读者，我想让抖动只在输出以原尺寸显示时启用，这样它不会被二次缩放毁掉。
22. 作为读者，我想设定质量档位，这样我能在体积和画质之间选一个立场。
23. 作为读者，我想覆盖自动判定的位深，这样特殊卷我能手工兜底。
24. 作为读者，我想让单页失败不毁掉整卷，这样一张坏图不会让我损失几百页。
25. 作为读者，我想让有失败页的卷被单独标出来，这样问题可见且有界。
26. 作为读者，我想拿到一份失败清单和原因，这样我知道该去修哪几张。
27. 作为读者，我想在自己的设备上标定阈值，这样判定贴合我实际看到的效果。
28. 作为读者，我想让机械盘上的处理不因并发而变慢，这样冷数据卷也能正常跑。
29. 作为读者，我想让固态盘上的处理吃满 CPU，这样热数据卷跑得够快。
30. 作为读者，我想看到处理进度，这样长时间任务我知道还要等多久。
31. 作为读者，我想限制内存占用，这样处理大卷时机器仍然可用。
32. 作为读者，我想让面板灰阶数可覆盖，这样内置表没收录的设备也能用。
33. 作为开发者，我想有一个进程内入口，这样测试不必启动子进程。
34. 作为开发者，我想能单独调用判据，这样数值与性质测试跑得快。
35. 作为开发者，我想让测试夹具由代码生成，这样仓库里不需要放有版权的素材。

## Implementation Decisions

### Seam

三个对外 seam，其余全部是内部实现，可自由重构。

**`run(Request) -> Report`** 是主 seam。CLI 是它之上的薄层，只负责把命令行参数拼成 `Request`、
把 `Report` 渲染成文字。**处理卷的每一种模式**走同一个入口。

`Request` 与 `Report` 的形状（编码了几个决定，故在此固定）：

```
Request  { 输入路径集, Profile, Mode, 覆盖项 }
Mode     = Process | DryRun
覆盖项    { 位深, 滤波器, 抖动模式, 缓存预算, 介质, 编码器 }

Report   { Profile, 卷报告集, 失败页集, 计时 }
卷报告    { 卷标识, 判定位深, 抖动模式, 判定理由, 驱动页, 页数, 输出路径 }
判定理由  = VolumeEnvelope | Outlier | Override | Skipped
```

`Report` 里的 Profile 是**本次实际用的**那一份：`--gray-levels` 覆盖之后，
「输出该拿去哪块面板看」只有报告能回答。

`Skipped` 是幂等命中的结果，与「处理过」在报告里可区分。

**`score(参照, 候选) -> Score`** 是第二个 seam：判据的纯函数形态。标定工具建在它上面。

**标定图的写出**是第三个 seam，不并进主入口。`CONTEXT.md` 把标定图定义为**量具**——
不读源、不走管线、不判定、无损写出。并进去会让 `Request` 的绝大多数字段对它全无意义，
而 `Report` 也装不下一个没有卷、没有页、没有判定的产物。要的不是「走同一个入口」，
是「库里调得到、落盘在库里」——第三个 seam 满足这一条。建父目录与写文件都在库内完成，
界面文案留在界面层。

### 管线

单遍解码 + 缓存缩放后的图（ADR 0005：解码一次，缓存缩放后的图）。第一遍完成解码、彩页识别、
几何、单次仿射与判据曲线；汇总阶段做卷级上包络、迟滞与离群页识别；第二遍只做量化与编码。

彩色 profile 下彩页走彩色分支：第一遍完成缩放与编码，不进灰度缓存、不求判据、不进卷级上包络；
写出与灰度页同一遍，按阅读顺序落位，编好的字节等在内存里、不受 `--cache-budget` 约束
（ADR 0010：彩页按 profile 分流）。黑白 profile 下彩页转灰，走与其它页相同的灰度路径。

### Profile 与面板

面板是 profile 的主键，含分辨率、PPI、灰阶数、彩色四项（ADR 0010：彩色是面板的第四项）。
阈值档位属于 profile。内置面板表覆盖 Kobo、BOOX、Kindle 的主力型号——黑白 e-ink 与 Kaleido 彩色
两类都收，同分辨率同 PPI 的黑白与彩色是两块面板。型号名到面板是多对一的别名表。
`--gray-levels` 覆盖面板灰阶数；Kaleido 的灰阶数说的是它黑白那一层，仍是 16。

面板灰阶数在判据之前裁剪候选位深（ADR 0003：面板灰阶数是位深的硬上界）。

### 缩放

总缩放比 ≥ 2 时先做整数倍 box 预缩，残差段走 Lanczos3；比值 < 2 时预缩退化为恒等
（ADR 0001：重采样滤波器的选择比位深更能决定输出体积）。源比目标小时保持原尺寸。
全套常见滤波器暴露为 `--filter`，只作用于残差段。

### 判据与位深

判据是低通后的局部均值误差，分块取上分位，带对比度掩蔽加权，低通核由面板 PPI 推出
（ADR 0002：判据建立在低通后的局部均值上）。

位深逐页判定后取卷级 p95 上包络定基准档，叠加迟滞，离群页单独定档
（ADR 0006：位深按卷取上包络并加迟滞）。

抖动由几何门逐页判定，抖动模式仍按卷统一
（ADR 0007：抖动仅在目标尺寸未被下游缩放时启用）。

### 编码器

编码器是接口，判据层对它无知（ADR 0004：输出以 PNG 为默认，AVIF 为显式可选）。
P0 只实现 PNG，含 1/2/4/8 位灰度与调色板两种颜色类型，取体积较小者。

判定与幂等字段写进 tEXt。

### 输入

目录与 CBZ。ZIP 成员名可能是 GBK 编码且无 UTF-8 标志，需要按启发式解码而不是假定 UTF-8。
解码覆盖 AVIF、JPEG、PNG、BMP、WebP、GIF、TIFF。非图片文件原样透传。

AVIF 解码走 dav1d（见 measurements 的《AVIF 解码吞吐》与《AVIF 解码的可用路径》）。
它是唯一能满足吞吐目标的选项：满核 140.2 页/秒，而纯 Rust 的 rav1d 只有 47.9 页/秒，
解码一步就会吃光单页预算。代价是构建与链接依赖 dav1d 系统库，换机器需重新备好。

### I/O 与并发

读取层与计算层分离，介质按路径映射到所在卷再探测寻道惩罚
（ADR 0009：处理点名的子集，介质按路径探测）。有寻道惩罚时读取串行，无则并发。
计算层用 rayon 满核，有界通道按字节预算背压。

### 错误

单页失败时仍强制统一尺寸，该卷标记并输出到隔离目录，失败页与原因进 `Report`。

## Testing Decisions

好的测试只断言外部行为：给定输入与 profile，`Report` 里的判定是什么、写出的文件有什么性质
（尺寸、位深、颜色类型、tEXt 字段、是否存在）。不断言内部调用顺序、不断言中间缓冲的内容。

**夹具由代码生成**，仓库里不放真实漫画。生成器要能造出：连续渐变页、二值网点页、线稿页、
纯色页、彩页、跨页宽幅页、尺寸小于目标的页、损坏文件、非图片文件。每类都对应一条待验证的性质。

**`run()` seam 上测**：格式与容器读取、非图片透传、尺寸策略（含不放大）、卷级档位一致性、
离群页单独定档、幂等跳过与参数变更重做、隔离目录、失败页报告、dry-run 不写文件。

**`score()` seam 上测**：低通性质（抖动候选在渐变页上应优于不抖动，与逐像素度量相反）、
分块上分位对局部劣化的敏感性、掩蔽加权方向、位深单调性。这些是性质测试，不是数值回归。

**黄金回归**：一组固定夹具的判定位深与输出体积记进快照，变动需显式接受。

**真实素材冒烟**是 opt-in，通过环境变量指向本地路径，默认跳过，不提交任何素材。

## Out of Scope

几何层全部：跨页拆分、裁边、内容外接框、deskew。
卷级分析里的固定元素检测。
CBR 与 PDF 输入。AVIF 与 WebP 输出。
SSIMULACRA2 仲裁、oxipng、`best` 模式。
Kaleido 面板的彩色分辨率折半、CFA 感知的锐化、色域映射、彩色判据与彩色位深。
32 页滞后窗口的退化路径。

## Further Notes

阈值尚未标定。P0 交付时用保守占位值，并在 `Report` 与文档里明确标注未标定；
`calibrate` 子命令负责产出标定图，反推阈值是标定完成后的独立工作。

A 类素材尚无真实样本，相关路径只能用合成夹具验证。这一点在 ADR 0008 里有记录。
