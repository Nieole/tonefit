# 待补的真实样本

Status: needs-info

样本放在仓库内的 `_samples/`，该目录不入版本库。真实素材冒烟测试通过环境变量指向它。

现有全部实测来自网络发布版（B 类，见 measurements 的《B 类素材普查》）。
A 类只有一个合成代理基底，因此凡涉及 A 类的数值主张目前一律标注「尚未测量」。

## 最关键

**A 类原始扫描，含真 1bit 网点，尺寸 ≥ 3000×4500。5~10 页。**
解开：整数倍预缩是否真的触发并去网点；A 类上 4bit 相对 8bit 的真实比例；
ADR 0001：重采样滤波器的选择比位深更能决定输出体积 在真实 A 类上是否成立。

**配对样本：同一页的干净原图 + 其有损转存版（JPEG 或 AVIF）。3~5 对。**
解开：ADR 0008：两类源由总缩放比自然分流，不设类型检测器 的核心依据——
有损转码是否真的让 1bit 源报出满级灰调。该论断目前无实证。

## 高

**8bit 灰度、带真实连续渐变的页（数码作画、喷枪、彩转灰）。5~10 页。**
解开：低位深不抖动是否严重 banding。现有抖动数据来自网点派生图，
那类图自带抖动，结论不能外推（见 measurements 的《抖动》）。

**PNG 与 BMP 源各若干页。**
现有真实数据只覆盖 AVIF 与 JPEG 解码路径。

## 中

- 跨页（双页拼一张），同卷 5~10 页，用于验证卷内相对尺寸判定
- 带扫描黑边或灰边的页
- 明显倾斜的扫描页
- 不同网点线数与角度的页；大面积渐变网点的页

## 低

- 超大尺寸源（8000×12000 级）1~3 页，验证高缩放比下的预缩链路
- 一整卷 100+ 页，质量不限，解开卷级上包络的真实分布与端到端性能

## 数量

每类 5~10 页足够。类型齐全比数量重要。
