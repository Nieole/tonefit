# 待补的真实样本

Status: ready-for-agent

样本放在仓库内的 `_samples/`，该目录不入版本库。真实素材冒烟按 `TONEFIT_SAMPLES` 指过来，
没指就跳过，跳过在测试输出里印成一行「跳过」、不计入通过：

```
TONEFIT_SAMPLES=_samples cargo test --test smoke
```

目录的直接子项各算一个卷（子目录或 `.cbz`）。它断言什么、不断言什么见 `tests/smoke.rs`。

现有语料见 measurements 的《A 类素材普查》与《B 类素材普查》。

## 还缺

- **带扫描黑边或明显倾斜的页**——几何层的裁边与 deskew 要靠它立基线。
- **不同网点线数与角度的页；大面积渐变网点的页**——判据在网点密度两端的表现未测。

## 不必再找

- **真 1bit 存储的扫描**：1bit 是输出档，不是输入形态。实测源里灰调级数最低的一卷也有 29 级。
- **干净原图与其发布版的真实配对**：发布版本身就是多次有损转码的产物，没有可复现的转存参数。
  受控转存对照见《有损转存与灰调级数》，结论不依赖配对样本。
- **BMP 源**：不在处理范围内。
- **HDD 介质**：见《介质与读取策略》。
