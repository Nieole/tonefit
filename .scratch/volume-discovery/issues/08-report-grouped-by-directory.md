# 08 — 会话：报告按目录分组

**What to build:** 一趟几百个卷时，报告区默认**每个目录一行**（N 卷 · 基准档分布 · 多少卷进了隔离），展开到卷、再展开到页。层次与发现出来的那棵树一致，一屏看得完。

《会话》的「展开」今天只有一级（卷 → 页），这张票把它变成两级。命令行那一侧要有对应的折叠——两边拿的是同一份报告数据。

「展开与左栏收起是同一件事」那条规矩不变：逐页那几行轻松过 100 列，左栏在那一刻仍是宽度里最贵的一截。

**Blocked by:** 03 — 发现（要先有一棵树才谈得上按目录分组）。

**Status:** resolved

- [x] 几百卷的报告默认每个目录一行，带卷数、基准档分布、进隔离的卷数
- [x] 两级展开：目录 → 卷 → 页，各有一个键回得去
- [x] 命令行那一侧有对应折叠，与 TUI 拿同一份数据
- [x] 屏幕快照按 `cell_width` 跳过宽字符占住的那一格
- [x] 展开到页时左栏仍收起，主区吃满宽度
- [x] `CONTEXT.md`《会话》的「展开」词条改成两级
- [x] 三条闸门全绿

### 勾得有保留：第三条

「命令行那一侧有对应折叠」勾了，但**只勾住了它的一半**。落地成的是
**每一枝那几卷前面多一行目录行**（`库/作品  12 卷 · 2bit+FS 9 · 隔离 1 卷`），
而卷级与逐页那两段**一行没少**——会话那一侧折得起来（默认只给目录那一级，
按 `⏎` 才往下摊），命令行这一侧摊的是三级全部。

- **硬的那一半成立**：「与 TUI 拿同一份数据」——目录行的聚合与措辞只有
  `render::grouped` 与 `render::directory` 一处出处，两边读的是同一批格（ADR 0016），
  一条用例（`the_command_line_folds_the_report_by_directory`）拿 `plain::directory`
  逐枝比过印出去的那一份。
- **软的那一半没做**：真把底下两级藏起来。命令行那一路**没有一个键**能把它们摊回来，
  藏起来的东西在屏上再也没有第二个地方看得到；真要藏得先有一个说得清的开关
  （`--brief` 之类），而那是票面之外的一项。

记在停车场 **Q171**。

## 落地记录

### 目录那一级的聚合只有一处出处

`src/render.rs` 新出四样，命令行与会话两路共用：

- **`Listed`**——报告上「目录那一级要数的一条」：收摊了的那几卷带着一份卷报告，
  没做成的那几卷只有一个路径与一句原因。`listed(&Report)` 按报告上的先后拼出那一列；
  会话另拼一份（决策点上攒着的那一份也占一条，`Live::listed`）——
  **拼法两处，分组只有一处**。
- **`grouped(&[Listed])`**——按**卷根的父目录**分组。那正是**发现出来那棵树**上它挂着
  的那一枝：`discover::expand` 列一层目录时，列出来的每个候选的父目录就是它站着的那一层。
  一个目录**既是卷又装着卷**时（ADR 0014），它自己归它的父目录那一组、它装着的那几卷
  归它自己那一组。**会话侧一棵树都没另切**——它拿到的是算好的那几枝（`live::Branch`）。
  **不重排**：目录按它头一条在报告上的先后排，组内也按报告上的先后。
- **`directory(&Group, &[Listed])`**——目录那一行：几卷 · 基准档分布 · 几卷进了隔离。
  分布逐条问 `base_column`（卷表那一列写的是同一批字，跳过与没做成也在里面），
  卷多的排在前、一样多的按头一次出现的先后。隔离那一格与分布那一格
  **一卷都没有就不在场**（一格在不在场本身就是一句话）。
- **`plain::directory`**——命令行那一副，摆在这一枝那几卷**前面**。

`base_column` 因此从 `cfg(any(feature = "tui", test))` 上解下来了：它此刻两路都读。

会话那一侧分成两半，**两半都只调 `render::grouped`**：`Live::branches()` 把分出来的
那几组翻成会话认得的东西（`Volume` 与「第几条没做成」）——那一半只是路径比较，
问「哪一枝底下有哪几卷」的地方多得多（光标停在哪一枝、展开哪一枝、`⇥` 在哪几卷之间转）；
`Live::branch_rows()` 出的才是那几行（与前者同序），**只有目录表要它**，
因为那一行的聚合要把每一卷的基准档问一遍。

### 报告区从两级变成三级

`Focus` 上多一个取值 `Opened(PathBuf)`（那一格装的是**哪一枝**）：

| 焦点 | 屏上那一副 | 一行是 | 左栏 |
|---|---|---|---|
| `Report` | 目录表（`draw/directories.rs`，**默认**） | 一枝 | 在场 |
| `Opened(dir)` | 卷表（`draw/table.rs`，按那一枝过滤） | 一卷 | 在场 |
| `Expanded(..)` | 逐页表（`draw/pages.rs`） | 一页 | **收起** |

**光标恒是一卷**（`CONTEXT.md` 的《跟随》一格没动）：目录表反白的是**光标那一卷所在
的那一枝**，`↑↓` 在那一级上挪的是一枝、落到相邻那一枝的**头一卷**上；一卷都停不住的
那一枝（底下的卷全没做成）跳过去——与卷表上没做成那几行停不上去是同一条规矩。
**只有一枝时那两个键一格不动、跟随也不停**（点名一个目录跑就是这一档）。
**展开着一枝时那个光标收在这一枝底下**（`Session::standing`）：跟随着的时候最新那一卷
随时可能落到另一枝上，而屏上摆的是这一枝的卷表——不收的话那一格一行都不反白，
而 `⏎` 展开的会是屏上根本没有的那一卷。两条都是评审揪出来的，各有一条用例。

**目录那一列与抬头印的是全路径**（不是最后那一段）：两枝的末一段常常一模一样
（`库/漫画/连载` 与 `库/图集/连载`），而这一副要答的正是「哪个目录出的事」；
命令行那一副印的也是全路径，两边因此说的是同一个身份。摆不下时从中间省略。

`Expansion` 多带一格 `directory`：**收起退的恒是一级**（`Expanded` → `Opened` → `Report`），
而「上一级是哪一枝」只有展开那一刻答得出；`⇥` 换一卷也只在这一枝底下转。
它因此不再是 `Copy`（多了一个 `PathBuf`）。

`draw/table.rs` 的 `entries` 多收一个 `&Branch`：收摊了的那几卷按 `Volume` 认、
没做成的那几卷按「第几条」认，**两处都由分组算好摆在 `Branch` 上**——
这一层一个路径都不再切一遍。行首记号那一套原样复用（`Mark::of_branch`
取这一枝底下**最重的那一种**：有一卷没做成就是出事，有一卷进隔离就是要注意，
全跳过了才是不要紧）——「记号与语义色出自同一个取值」（Q153）因此在新那一副上也成立。

### 多出来的那一下挑的是 `⏎`／空格

不是一个新字母。`⏎`／空格在左栏、预设栏一直是「就在这一行上动手」，而目录表上
这一行是**一枝**、动手就是展开它（`Action::Open`）。`e` 一格没动——它恒是
「展开这一卷的逐页」（左栏跟着收起），在左栏、目录表、卷表三块上是同一件事。
两个键因此各答各的：一个跳到底，一个走一级。`Esc` 退一级。

**挑之前在那张两维表里查过一遍**：`⏎` 与空格在报告区那一块上此前派的是 `Expand`
（`p3-session-legibility/10` 给的，本票把它让给 `Open`），别的焦点上各占各的
（左栏是 `Unfold`／`Edit`／`Toggle`、预设栏是 `Take`／`Edit`、取值栏是 `Choose`／`Drill`、
展开着不派），**阶段那一维一个都不派**——`a` 那种撞车（Q161）在这两个键上不存在。
`Esc` 在卷表那一块上是**另派**的一件事（收起一级），`means_the_same_everywhere`
因此照旧把它排除在「任何时候」那一组外面。`KeyGroup` 跟着多一组
（`展开一个目录 · 卷表`），`?` 那张表仍旧是**问出来**的，一个键都没另列
（`which_keys_do_what_in_which_state` 多了「六之五」那一段，逐个键问过）。

**一处让步记在这里**：`⇥` 在卷表那一块上与在目录表上一样切回左栏，
再切回来落的是**目录表**——展开着的那一枝没有留下来。`Pane` 只有两块（左栏与报告区），
而多留一格「切回来落在哪一级」要么给 `Pane` 添第三个取值、要么在 `Session` 上另记一格；
两条都是把一个状态拆成两处。`Esc` 那条路仍旧一级一级退得回去。

### 屏上取回来的字按 `cell_width` 跳格（Q60 收了）

`draw/probe.rs` 多一个 `read`：照那个字形的**显示宽度**往前跳，跳几格只有
`crate::wrap::width` 一处出处——折行按它折、砍列按它对齐、这里按它跳格。
`screen`／`painted`／`reversed_row` 三条路共用它；快照那一条走终端库自己的 `Display`，

`contains("设备层")` 从此问得出来（`the_screen_reads_back_the_wide_glyphs_as_the_words_they_are`
钉着）。`tight` 留着，只管**空白**——表上那几列靠空格对齐，而那与宽字符无关。

### 评审

`/code-review` 跑了一遍（**只读，没碰工作区**）。十五条**全收了**：

**屏上说错话的四条**

- **展开一卷之后抬头的「第 n/m 卷」按整趟算**，而 `⇥` 换一卷本票已经收窄成只在这一枝
  底下转——分母指的那些卷有一大半按不到。**已改**：分母改成这一枝底下那几卷。
- **跟随着展开一枝时，光标会随新卷收摊漂到别的枝上**：卷表一行都不反白，而 `⏎`
  展开的是屏上根本没有的那一卷。**已改**：`Session::standing` 在展开着一枝时
  **收进这一枝**（落到它的末一卷上）——「光标停在哪一卷」仍旧只有那一处答得出。
  一条用例钉着（`the_cursor_stays_inside_the_branch_that_is_open`）。
- **卷表那一级屏底漏了 `q 退出`**：那个键在收场了之后照旧按得动，而三块里只有这一块
  不摆它。**已补**，`THE_TABLE_NARROW` 那张快照跟着钉住。
- **只有一枝时按 `↑↓` 屏上一格不动，却把跟随停掉了**（点名一个目录跑就是这一档，
  仓库里的夹具也全是它）。**已改**：只有一枝时 `next_branch` 一格不动、跟随也不停——
  「按了没反应」比「按了偷偷改了个状态」好。一条用例钉着
  （`one_branch_alone_neither_moves_the_cursor_nor_stops_the_follow`）。

**同一份数据两种身份的两条**

- **目录表只印目录的最后一段**，同名子目录（`库/漫画/连载` 与 `库/图集/连载`）
  摆出来一模一样，而按目录折叠的目的正是「哪个目录出的事」；命令行那一副印的却是
  全路径。**已改**：目录那一列与抬头都印**全路径**，摆不下时从中间省略——
  与卷名那条规矩**有意不同**，理由写进了那两处的文档。
- **「隔离 N 卷」有两个出处**（`plain::line` 与目录表各写一遍，逐字相同）。
  **已改**：`render::isolated_note` 一处出处。这一条与卷表那个 `ISOLATED` 不同——
  那边两副产出的本来就不是同一串字。

**兜底兜出自相矛盾的两条**

- **`branch_of(...).unwrap_or_default()` 拿空 `PathBuf` 兜底**，兜出来的是一枝
  **不存在**的目录：收起之后屏上摆的是目录表、屏底说的却是卷表，`↑↓` 完全失效。
  **已改**：答不出哪一枝就说一句、不进展开态。
- **`level()` 退回目录表时屏底、按键表与 `↑↓` 三处都没跟着退**。上一条一改，
  这一支就**到不了**了（展开进来的那一枝恒是算出来的；报告换一趟要先 `⇥` 回左栏，
  那一下焦点已经不在这一级上）。**保留那一支并把「到不了」写进了它的文档**。

**逐帧开销的一条**

- **`Live::branches()` 每帧算一到两遍，而它为每一卷整份构造一次 `render::volume()`
  只为取出基准档那一格**——正是「一趟几百卷」这张票的目标场景。**两处都改了**：
  `Listed::base()` 改建[判定那几行](`verdict_rows`)（`base_column` 认的四种行全出自那一处，
  而 `volume` 还要把两条路径与读法、缓存各摆一遍）；`Branch` **不再带那一行**，
  行另出 `Live::branch_rows()`——**只有目录表要它**，而问「哪一枝底下有哪几卷」的地方
  多得多（光标、展开、`⇥` 换一卷），那一半只是路径比较。

**文档与死代码的四条**

- **`CONTEXT.md` 的《展开》仍留着「逐页那几行不折行、横着滚」**，而横滚 `p3/11` 就没了；
  更糟的是停车场那笔结转声称改过它。**已改**：那一条此刻说的是「三副都是表，
  横向摆不下时砍列，`←→` 一处都不横滚」，外加「默认只列要紧的页、`a` 切全部页」。
- **`KeyGroup::ALL` 的文档还写着「六组」**，而数组已经是七组。**已改**。
- **`Mark::of_branch` 先建两个中间 `Vec` 才去看提前返回那一句**。**已改**：
  没做成那一档先问（它一卷都不必开），余下走迭代器，两个 `Vec` 都没了。
- **`ABSENT` 与它那个卷数分支是文档自己承认到不了的死代码**，还挂着一条只测它的用例
  （测的是一个屏上不会出现的字形）。**已删**：这张表上真会不在场的只有分布那一格，
  而它排在末尾，空着就是「这一枝没有这件事」。
- **`branch_of` 与 `inside` 是同一次线性查找的两个副本**，换一卷那条路上一次按键
  把 `branches` 扫两遍。**已改**：一个查找函数出**整一枝**，调用处各取自己要的那一格。

### Q60 — 屏上逐格读回来的文字，每个宽字符后面多一个空格

- **From:** 票 `p1-session/08`
- **Kind:** 路过发现
- **Where:** `src/session/draw.rs` 的 `tests::tight`
