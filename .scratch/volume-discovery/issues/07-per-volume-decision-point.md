# 07 — 会话：多卷逐卷等答话

**What to build:** 点名多卷时，会话在**每一卷**的决策点停下来画出那一卷的报告、等你拿主意；答继续就接着做第二遍，第一遍不重算。答话多一个手势：**「剩下的卷都这样」**。

改的是 ADR 0012 **决定第 3 条**，不是第 1 条。第 1 条把续做限在单卷上，理由是内存——「全量试算要续做，就得同时押住全部卷的参照」。**那条理由不覆盖逐卷决策点**：决策点本来就是逐卷的（《会话》：「每一卷的『汇总之后、第二遍之前』，一卷一次」），逐卷停下来问，缓存**始终只押着当前那一卷**，内存一点不涨。真正拦住多卷续做的是决定第 3 条——那是会话的策略。

不改的话，发现落地那天起「试算满意就接着做」这条回路（会话存在的理由）就基本再也命中不了：点名一行从此常常是几十卷。

「剩下都这样」**不进那个闩**。《会话》明写「决策点认的是当场答的那个字，不是闩」，而这个手势也不是闩——闩只升不降，它却是个可以是「继续」的粘性答案。它记在观察者那一侧「决策点的默认答案」上，与库那一侧记「至今收到过最强指令」的那一格分开放。

**Blocked by:** 01 — 预扫只数不留（这条要在几百卷上试得动，而攥着几千个句柄时试不动）。

**Status:** resolved

- [x] 点名多卷，**每一卷**都停在决策点，主区画出那一卷到此刻为止的报告
- [x] 答继续时第一遍不重算：判定与报告与试算那一份**逐字相同**
- [x] 「剩下的卷都这样」答一次之后，余下的卷不再问
- [x] 这个手势**不动按停按到的那一级**——按停在前、答话在后，那一级答完话照旧作数
- [x] 峰值内存仍随**单卷**走，不随卷数涨
- [x] 等答话时按得动的仍只有答话那三个键；`Ctrl-C` 仍退得出去，退出走中止（那个数原写「两个」，与本票第 3 行的新手势对不上，落地时订正——见停车场 Q127）
- [x] ADR 0012 决定第 3 条就地修订，加一节说明决定第 1 条的内存理由为什么不覆盖逐卷决策点
- [x] `CONTEXT.md`《会话》改「续做」「决策点」「等答话」「指令」
- [x] 三条闸门全绿

## 落地记录

### 判据换了一个问题：不问「点名了几个路径」，问「是不是试算」

`src/session/terminal.rs` 的 `resuming()` 从 `mode == RunMode::DryRun && inputs.len() == 1`
变成 `mode == RunMode::DryRun`。**那个 `len() == 1` 判的是「点名了一个路径」，不是「一个卷」**
——`03` 落地之后 `inputs` 装的是「一批**在里面找卷的地方**」，一个路径常常就是几十卷，
两件事早已脱钩。用例 `only_a_single_volume_trial_resumes` 随之改写成
`every_trial_resumes_however_many_paths_it_names`：试算那两支（一个路径、两个路径）
现在是同一个答案。

跟着变的只有一处结论：**一个卷都没勾**的那一趟现在也算续做（从前算不续做）。
那一趟 `run` 当场拒掉、一条事件都不发，决策点根本到不了——闸起了也没有人用。
用例里那一段照这个改了断言，不再假装它是「不续做」的一例。

**库那一侧一个字没改。** `run` 本来就在每一卷的决策点上问观察者，等不等人是会话的策略
（ADR 0012 决定第 3 条）。

### 「剩下的卷都这样」落在哪三格里，各记什么

新键是 **`a`**（`all`）。它是这个状态自己的键，没有借旧主：它答的字与 `x` **逐字相同**，
差别只在**管几卷**，而那件事别处不存在；借 `x` 按两下也说不出它——两级停那个形状说的是
「再按一次更重一级」，而这一下不比 `x` 更重，只是更远。

`Action::Answer` 从带一个字变成带**一个字加它管几卷**（`Answer(Instruction, Reach)`）。
`Reach { ThisVolume, ForTheRest }` 摆在 `live.rs` 里 `Resuming` 边上——两个都是决策点的
小词汇，同一条「不爱看不出意思的裸值」的理由。

**三格分开放，各答各的问题**（`CONTEXT.md` 的《会话》：都这样）：

| 格 | 在哪 | 记什么 | 只升不降？ |
|---|---|---|---|
| 会话的闩 | `session::run::Latch` | **用户按过**的最强那一级 | 是 |
| 库的闩 | `tonefit` 的 `progress::Standing` | **观察者答过**的最强那一个 | 是 |
| 决策点的默认答案 | `session::run::Asked::for_the_rest` | 往下每一个决策点默认答什么 | **不是** |

末一格另有一份**给屏的**副本（`Live::for_the_rest`）：屏底那一行要说「往下不再问了」，
而等人那块表也要从这一刻起不再开，两件事都在 UI 那条线程上。两份由 `Running::decide`
同一句话写下（先写 `Live`、再写闸，次序见下一节）。**退出会话推进来的那个中止只写闸那一份**
——那一刻这一趟就此收场，屏上不会再画一帧，副本作不作数都一样。

末一格是本票加的，落在**观察者那一侧**（那道闸上），而不是任何一个闩里：
它是个**可以是「继续」的粘性答案**，而闩只升不降。它与同一道闸上那格 `said` 的差
就在**取不取走**——`said` 一问一答、答完清空，这一格答一次管到这一趟收场。
`Gate::ask` 一进来就短路：一句话都不问、连座都不落（`waiting` 一格不动），
`Running::deciding` 因此恒为假，屏上不会闪出答话那一副。

**按停按到的那一级一格不动**：这个手势走的是 `Running::decide`，一路都不碰闩；
状态机那一侧 `Action::Answer` 照旧只把状态放回「跑着」，闩原样带回去。
中止仍旧压得住它——`Watch::observe` 先读闩（是中止就当场答中止，一句话不问），
而闸上先到的那个字（`leave` 推进来的中止）也排在默认答案前面。

### `Running::decide` 的两句换了次序

从前是「先往闸上说，再记进 `Live`」。现在反过来：**先记进 `Live`，再敲闸**。
不反过来的话，那条线程会在 UI 这一头拿到那把锁之前就走到下一个决策点，
而那时 `Live` 还不知道「剩下的卷都这样」——**等人那一截于是又开了一次，而往下
没有第二次答话来关它**（关它的只有决策点上的答话）。屏上那两个数会从此不动，
Q41 钉住的那条性质在批量跑上正好反过来。`Live::pass_started` 同一条：
`for_the_rest` 摆上之后不再开那块表。

### `Live::decided` 改成取**最弱**的那一个

一趟里每一卷各答一次，而报告抬头只有一句。它问的是**这一趟落过盘没有**，
而答过一次继续就有一卷写了出去——头一卷答继续、第二卷答收尾的那一趟，盘上有头一卷，
抬头就不能说「只算不写」。取最弱与闩取最强正好相反，两处问的本来就不是同一件事。

### 屏上改了哪三句

前两句是票面点名的那两处（「两句措辞会因为本票改变含义」），第三句是评审揪出来的
同一类东西：

- **`resuming_line`**：「这一趟不续做：多卷时试算与执行各跑一趟……」那一句**删掉**——
  它说的事不再存在（试算一律续做）。续做那一句改成「**每一卷**第一遍走完都会停下来
  等你拿主意」，并把三个键一起预告出来：几十卷的一趟里，「还要按几下」是用户当场就想
  知道的那件事。答过手势之后换第三句：「剩下的卷都这样：往下的决策点不再停下来问」——
  不说的话，「它怎么不问了」与「它忘了问」在屏上没有分别。
- **`deciding_prompt`** 第二行原话是「输出根此刻一个字节都没有」。多卷时那是**假话**：
  答过继续的那几卷早写出去了。改成「**这一卷**此刻一个字节都没写」——决策点问的本来就是
  这一卷的第二遍还做不做。第一行多摆一个 `a 剩下的卷都这样（往下不再问）`。
- **`deciding_prompt`** 里 `s` 那一句添了半句：`s 收尾（这一卷不写，等价 dry-run；
  **剩下的卷也不开工**）`。决策点上答的字照样进库那一侧的闩（`CONTEXT.md` 的《会话》：
  「那一卷停在这儿之后，剩下的卷也不必开工」；用例是 `tests/resume.rs` 的
  `finishing_at_one_volume_decision_point_leaves_the_earlier_volumes_whole_and_starts_no_more`）
  ——一卷的时候这件事说不说都一样，五十卷的时候它是这个键**最大的后果**，
  而只说「这一卷不写」读起来像是「跳过这一卷」。**行为一格没改**，改的只有屏上那半句。

### 用例

新增三条，其余在已有的那几条里加断言：

- `session::run::every_volume_of_a_trial_waits_at_its_own_decision_point`——三个卷，
  **每一停都看一眼盘**：第 N 个决策点到来时输出根下恰好是前 N-1 卷。那一眼同时钉住
  「问在第二遍之前」「答继续的那几卷真写了出去」「停着的这一卷一个字节都还没有」，
  外加每一卷都画得出**它自己**那份「到此刻为止」。**峰值内存随单卷走**也钉在这里：
  三卷各报一页缓存，而不是 1、2、3——攒着不放的话第三卷会报三卷的页数。
  （真去量进程驻留内存要另起一条路，而那条路量到的数随分配器与页缓存走，钉不住东西。）
- `session::run::answering_for_the_rest_once_stops_the_asking_and_leaves_the_latch_alone`——
  头一卷答 `ForTheRest`，往下**一次都不再停**（循环里每转一圈问一次，真停了当场红，
  而不是挂在那儿等一个不会来的人）、三卷一个不少地写出去、**两边的闩都还停在「没按过」**。
- `session::terminal::pressing_the_rest_too_reaches_the_thread_waiting_at_the_decision_point`——
  接头处那一条：按 `t` 起两卷的试算 → 停住 → 按 `a` → 两卷都做完。

加断言的：`which_keys_do_what_in_which_state`（`a` 那一行，别的键仍旧一个都不生效）、
`the_decision_point_is_a_second_face_of_the_same_run_and_leaves_the_latch_alone`
（按 `a` 之后闩仍是收尾）、`a_trial_that_never_walked_the_second_pass_prints_as_a_dry_run`
（两卷两个次序，取最弱那一个）、`the_minutes_spent_deciding_are_charged_to_nobody`
（第二卷照旧等人、答过手势之后不再开表）、
`waiting_at_the_decision_point_shows_the_report_and_the_three_ways_out`（原
`..._two_ways_out`，三个键都在屏上）、
`a_trial_says_it_will_stop_at_every_volume_while_it_runs`（原
`a_trial_that_will_not_resume_says_so_while_it_runs`，问的换成了那三句）。

三个卷的夹具名字带序号（`卷01`/`卷02`/`卷03`）而不是「卷一卷二卷三」：
盘上那份清单是按字节排的，而中文数字那三个字的码位次序是一、三、二。

### 领域文档

- **ADR 0012 决定第 3 条就地修订**：会话在**每一次试算**上都逐卷等答话，答一次
  「剩下的卷都这样」之后由观察者那一侧的默认答案当场答掉；那个默认答案不是闩。
  加了一节《决定第 1 条那条内存理由不覆盖逐卷决策点》：那条理由否掉的是
  「一次押住**全部卷**的参照」，而缓存逐卷建、逐卷丢，逐卷停下来问押着的始终只有当前那一卷。
  **决定第 1 条与它的理由一个字没改**（票面点名要留在原处）；《后果》里那条
  「续做的好处只有单卷会话吃得到」改了——它整条都是决定第 3 条的后件，
  留着就是同一篇文档里两处对着说。这一处记进了 **Q126**。
- **`CONTEXT.md`**：《会话》改「续做」「决策点」「等答话」，新增「**都这样 (ForTheRest)**」；
  「等答话是一个状态」那一段的「答话那两个」改成三个，并点明那个手势进的是第三个格子。
  《进度》的「指令」点了一句「观察者拿什么字来答是它自己的事」——票面把「指令」列在
  《会话》名下，而那条词条实际在《进度》。票面没点名的词条一个字没动。

### 停车场
