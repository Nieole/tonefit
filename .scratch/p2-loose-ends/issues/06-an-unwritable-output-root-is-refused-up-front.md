# 06 — 输出根写不进去，开工前就拒

**What to build:** `--out` 指到一个建不出来的路径，现在每一卷各撞一次，各记一笔卷级失败，
退出码 `3`。报出来的东西没骗人——每一卷都指名说了「建不出输出容器」——但本该说一次的话
说了 N 遍，而 `3` 的含义（有卷没做成）弱于本该给的那个：这是**这一趟的参数**错了，
按词汇表该是拒绝执行（`1`）。

开工前探一次输出根写不写得进，写不进就一页不做地拒掉。

`Sink::create` 逐卷那条路仍要留着——某一卷的去处被占、单卷权限不同都到得了那里，
那些是真的「这一卷做不成」。本票只是不再让它承担「参数错了」这一种。

收停车场的 **Q51**。

## 落地记录

### 那道检查插在哪一格

新增一个私有函数 `ensure_the_output_root_takes_a_write`（`src/lib.rs`），`run` 在开工前
调它**一次**，位置是开工前那几道检查的**最后一道**，也在**预扫之前**：

```rust
ensure_no_two_volumes_share_an_output(request)?;
ensure_the_output_root_takes_a_write(&request.output_root)?;
...
let survey = survey::Survey::of(request)?;
```

两条边各有各的理由。**排在那几道之后**：它是开工前唯一**往盘上写东西**的一道，
让答得起而不必动盘的那几道先说话；尤其不能排在 `ensure_output_is_elsewhere` 之前——
输出落在源里的那一趟要是先把输出根建出来，就等于往一个只读的源库里写了一笔
（ADR 0009：源库只读）。**排在预扫之前**：预扫要把点名的每一个卷都枚举一遍，
慢盘上那正是贵的那一头，而输出根根本没地方落时那一趟枚举是白付的。
两边都是拒绝执行、都是退出码 `1`，次序只决定用户先看见哪一句，因此照「便宜的先说」办。

### 不戴 `Refusal`

**没有**给这个错误戴 `Refusal`，也**没有**给 `Sink::create` 的错误戴——后者是 Q51 明写的
判断，本票没有推翻它。前者的理由是那件外套此处无事可做：`Refusal` 认的是从
`process_volume` 里出来的错误（在那条路上「一卷做不成」与「整趟别做了」长得一模一样），
而开工前这几道检查的错误由 `run` 直接返回，调用方拿到 `Err` 本身就是「这一趟没做成」，
没有第二种可能要分辨。四道同辈检查一个都没戴，这一道跟着它们。

### `DryRun` 下**照探**

这是本票绕不过的那个判断，拍的是**不看模式**。

票面第三条要「探完之后盘上没有多出目录或文件」，而 `Mode::DryRun` 的契约是「一个文件都不
落盘」——**两者不是同一句话，但一个不留痕迹的探针同时满足它们**，模式因此不必进来。
那句契约说的是**输出**：页、记录、输出容器，也就是用户留得下的东西；探针一件都不留，
探完的盘与没探过逐字节一样。

反过来，照模式分岔的代价是致命的：试算就答不出「你这个 `--out` 根本用不了」。
拒绝执行说的是**参数**，而两种模式的参数是同一份，另外五种拒绝也都在试算里照样咬人
（`CONTEXT.md`《会话》：试算与执行是同一个 `run`，区别只在 mode）。一份说「都好」、
真跑起来却当场被拒的试算报告是在撒谎，而「先看一份报告再决定」正是这条回路要买的东西。

认下的那一笔照实写进了函数文档、也记进了停车场 **Q90**：探针那一个目录加一个文件在盘上
**真实存在过**，进程正好在试写与删探针之间被杀就会留下一个点开头的文件。

### 怎么探，怎么把痕迹收干净

「这个目录写得进吗」没有可移植的问法——`std::fs::Permissions::readonly` 读的是只读**属性**，
Windows 上的目录根本不认它，ACL、只读挂载、网络共享、配额一样都不在它视野里。
因此就真写一次：`create_dir_all` 之后在输出根里建一个 `.tonefit-<pid>.probe`（带进程号，
两趟同时探时各删各的），删掉，再把**自己现建的那几级目录**自底向上收回去。

三处细节各挡一种漏法：

- 收拾**不许**被 `?` 跳过——探不过的那一趟同样要把建出来的目录收回去，答案因此攒在
  `probed` 里，收拾完再交出去（评审的 Middle Man：原先拆成两个函数来保证这一点，
  已合成一个）。
- 「哪几级要现建」问的是 `symlink_metadata` 而不是 `exists`：后者跟着符号链接走，
  一条**断了的**链接会答「这里没东西」，照它记下来就会去删一个不是自己建的东西。
- 收拾用 `remove_dir`（只删空目录），删不掉就**就此打住**；相对路径走到头那个空路径
  （`Path::new("out").parent()` 是 `Some("")`）不记进单子。

竞态照实说了、没有假装拦得住：并发两趟同时探时可能删掉对方刚建出的空输出根（对方随后
自己再建一遍），以及上面那笔被杀留探针。两笔都窄，躲开要一份日志或一把跨进程的锁。

### 用例（新增四条，`tests/isolation.rs`）

- `an_output_root_that_cannot_be_written_is_refused_before_any_volume`：三个卷，
  输出根落在一个**普通文件**下面（两个平台上都建不出来，不必碰权限位）。
  四件事一起断言——整趟回 `Err`、那句话指得出是哪个输出根、**三个卷一个都没被点名**
  （说一次，不是三次）、那个文件逐字节没动且输出根没建出来。
  **变异验证**：把 `run` 里那一句去掉再跑，这一条当场红，报告里正是三笔一模一样的卷级失败
  （「建输出目录 …olume-a.partial: 当文件已存在时，无法创建该文件」×3），
  退出码 `3`——那就是本票之前的样子。
- `a_dry_run_probes_the_output_root_and_leaves_nothing_behind`：两半。试算照样拒得动；
  试算跑完**输出根仍不存在**。**变异验证**：把收拾那一段停掉，这一条与既有的
  `a_dry_run_names_the_isolation_directory_without_writing_anything` 一起红。
- `a_volume_whose_destination_is_taken_is_the_only_one_that_fails`：输出根好好的，
  只把中间那一卷的去处占成文件——那一卷记一笔卷级失败，前后两卷照常做完。
- `an_output_root_taken_after_the_probe_still_fails_volume_by_volume`：本文件里一个
  五行的观察者 `OccupyOnceTheRunStarts`，在**开工那条事件**上把输出根占成文件——
  那一刻排在开工前那几道检查与预扫之后，因此探那一次**真的过了**。
  三个卷各记一笔卷级失败，整趟回 `Ok`（不恐慌、不拒绝执行）。盘满是同一形状的另一种，
  仓库里造不出来。
