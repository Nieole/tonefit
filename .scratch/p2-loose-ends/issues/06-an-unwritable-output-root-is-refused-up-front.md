# 06 — 输出根写不进去，开工前就拒

**What to build:** `--out` 指到一个建不出来的路径，现在每一卷各撞一次，各记一笔卷级失败，
退出码 `3`。报出来的东西没骗人——每一卷都指名说了「建不出输出容器」——但本该说一次的话
说了 N 遍，而 `3` 的含义（有卷没做成）弱于本该给的那个：这是**这一趟的参数**错了，
按词汇表该是拒绝执行（`1`）。

开工前探一次输出根写不写得进，写不进就一页不做地拒掉。

`Sink::create` 逐卷那条路仍要留着——某一卷的去处被占、单卷权限不同都到得了那里，
那些是真的「这一卷做不成」。本票只是不再让它承担「参数错了」这一种。

收停车场的 **Q51**。
