# 07 — 中文长句折行，窄终端上「q 退出」不再被挤没

**What to build:** clap 按空格折行，而中文长句里一个空格都没有——整句因此原样印成一行，
窄终端上从行尾切掉。帮助、报告、会话屏底三处都吃这个亏，其中屏底那一行最咬人：
它挤掉的是「q 退出」，而不知道怎么退出是最难受的一种卡住。

界面层出一套按**显示宽度**折行的工具，三处共用。屏底那一行改成可折。

收停车场的 **Q32**（折行是根）、**Q75**（窄屏挤掉退出键，是果）、
**Q65**（折行之后有几行现在靠画一遍数出来）。Q65 那一条要判：给终端库开
`unstable-rendered-line-info` 那道门，还是自己的折行工具顺便答得出行数——
后者的好处是不欠一个 unstable 依赖。

**Blocked by:** 01 — 闸门盖住三种构建（本票动会话绘制，要三条命令都在才验得全）

**Status:** ready-for-agent

- [ ] 中文长句在窄终端上折行，不从行尾切掉；宽字符按两格算宽
- [ ] 折行不切开一个宽字符，也不把一个字的两格拆到两行上
- [ ] 屏底那一行折得开，且**最窄那一档上「q 退出」仍在屏上**——这条要有快照
- [ ] 帮助、报告、屏底共用同一套折行，不是三份
- [ ] 折行之后有几行答得出来，不再靠画一遍数：Q65 那道门开了还是自答，写明理由
- [ ] 有窄到放不下那一档的快照；黄金快照若因帮助折行而变，逐条确认后再接受并说清原因
