# 11 — 归档卷的幂等这一道不再串行

**What to build:** 跑一批归档卷的人，四分之一的墙钟花在幂等那一道上——剖面量到它是三段里
第二大的一块，仅次于第一遍，而它几乎全是 deflate：成员绝大多数是 PNG，压缩比接近 1，
白解一遍；喂哈希本身读作 0.0%。那一段没有可与之重叠的计算，整段暴露在墙钟上。

**这一票要改一条领域决定**：`CONTEXT.md`《I/O 与并发》明写「一个 ZipArchive 就是一个游标，
读取恒串行，点名也改不了」。改法是把**幂等那一道**排除在这条之外——同一个文件开几个
独立句柄，各解各的成员，哈希那一端仍按成员序喂。第一遍与第二遍照旧串行。

指纹逐字节不变是硬约束：并行的是**解**，不是**喂**。喂的次序变了，幂等就整个塌了
（上一趟的输出会被当成不匹配，全部重做）。

收停车场的 **Q78**。数与推法在 measurements 的《三段各占多少》与《分阶段耗时剖面》。

**Blocked by:** None — can start immediately
