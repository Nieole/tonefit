# 05 — 卷根整个消失算这一卷没做成

**What to build:** 跑一批卷的人想按退出码分岔：`2` 是「有卷被隔离」（做出来了，但里面有坏页），
`3` 是「有卷没做成」。眼下卷根在预扫之后整个消失走的是 `2`——每一页都读不出来，
于是整卷变成一沓占位白页进隔离目录，报告说得出「这一卷全是坏页」，却不说它压根不在了。

那不是一卷做出来了。改成卷级失败（`3`）。

这要动 `p0-core-pipeline/12` 定下的一条口径（「页读不出来是页级失败」），
改的是「一页都没成的卷算不算这一卷没做成」这一层，不是推翻页级失败本身。
现成用例 `a_volume_whose_every_page_fails_still_comes_out_whole` 正把旧口径钉着，
本票要连它一起改并说明理由。

收停车场的 **Q50**。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 卷根在预扫之后整个消失 → 卷级失败，退出码 `3`，报告指得出是哪一卷、说得出为什么
- [x] 单页读不出来仍是页级失败 → 隔离（`2`），这条口径没被顺手推翻
- [x] 「一页都没成」与「卷根不在」分得开：前者仍走隔离，后者走卷级失败——

- [x] 那条钉旧口径的用例改掉并写明理由，不是删掉了事
- [x] 其余卷照常处理、报告完整、已做完的卷不受影响
- [x] `CONTEXT.md`《失败》与实现一致——对不上就记进停车场，不要顺手改词条

## 落地记录

### 判据：**卷根还在不在**，不是「成了几页」

新增一个私有函数 `ensure_the_volume_root_is_still_there`（`src/lib.rs`），
`process_volume` 在**开卷那条事件之后、这一卷的第一件事之前**调它一次：

```rust
events.volume_started(&volume.root, steps);
ensure_the_volume_root_is_still_there(&volume)?;
```

卷根不在（`Ok(false)`），或者连「在不在」都探不到（`Err`：权限变了、盘拔了、路径中间少了一节），
都当场 `bail!`；那个错误顺着 `process_volume` 已有的 `Err` 出口走成一笔 `VolumeFailure`，
退出码 `3`。
判准是 `CONTEXT.md`《失败》里的**卷级失败**词条：「一整卷做不成：**路径不在**、
归档损坏、权限不够……预扫之后才出的记为卷级失败，其余卷照做，报告照出」。

**为什么不是「成功页数为 0」**：那个判据会把「卷根还在、里面每一页都读不出来」的卷一起
收走，而那一种正是 p0 的 12 号票定死的页级失败（一页读不出来不毁掉整卷），
也正是《失败》那句「失败是页级的，隔离是卷级的」说的东西。本票改的是它**上面一层**。
两种因此各走各的：

| 现场 | 走哪条 | 退出码 | 钉住它的用例 |
|---|---|---|---|
| 卷根在，每一页都读不出来 | 页级失败 → 整卷进隔离目录 | `2` | `a_volume_whose_every_page_fails_still_comes_out_whole` |
| 卷根不在 | 卷级失败 | `3` | `a_volume_whose_root_is_gone_did_not_get_made` |

### 为什么非得单问一句

卷根整个消失走不到别的任何一条卷级失败上（Q50 早已把根因定好）：读不出字节的成员在
`volume_fingerprint` 里被记成 `hasher.unreadable` 照样喂进哈希，在 `first_pass` 里变成失败页，
于是整卷成了一沓占位白页写进 `_isolated/`——报告说得出「这一卷全是坏页」，却不说它压根不在了。

问在这一卷的第一件事上，买的是**别白做一整卷**：往下每一步都要读它的字节，
幂等把整卷哈希一遍、第一遍逐页解一遍、第二遍再写一整卷白页出去，全是白工。

**竞态照实说了，没有假装拦得住**：卷根在这一问之后才消失的那一种仍旧落回页级失败那条路。
一次 stat 拦不住它，而管线也无处去拿「整卷读到一半才发现根没了」这个事实——
那时它手上只有一页一页读不出来，与「这一卷的页全坏了」长得一模一样。这一段写在函数文档里。

### 只问目录卷（评审揪出来的一条）

问的是**读取层真会去走的那条路**：目录卷的每个成员都现拿卷根接上相对路径开一次文件
（`source::read_file`），卷根没了就一个字节也读不出来。**归档卷不问**——它的字节从预扫时
就打开、此后一直握着的那个句柄里出（`source::Reader::Archive`），卷根被删掉也照读不误。
不加这道分岔的话，Unix 上把一个 `.cbz` 删掉会让一卷**本来做得出来**的输出改判成「没做成」，
那是撒谎；Windows 上那个文件还开着根本删不掉，这一支连走都走不到。
换句话说 Q50 那个缺陷本来就只在目录卷这一侧——归档卷上没有一沓白页可出。

分岔写成 `volume.reader.directory_root()`（`None` 就直接放行），
因为它返回的正是读取时被 join 上去的那个根，判据于是钉在真实读路径上，不是钉在容器枚举上。
**没有为它写用例**：可观察的差别只在 Unix 上（Windows 删不掉那个句柄），
本仓库的闸门跑在 Windows 上，写一条只在别的平台上有意义的用例是假绿。理由写在函数文档里。

### 那条钉旧口径的用例：**改了，没删**

`a_volume_whose_every_page_fails_still_comes_out_whole` 原本只说得出「整卷进隔离目录」。
现在它多担一件事——**钉住「一页都没成」不是「这一卷没做成」**：加了两句断言
（`failed_volumes` 空、`any_isolated()` 真），文档里写明为什么它留在隔离那一侧、
以及分开两种的判据是卷根而不是页数。名字一个字没改：它说的仍是真话，只是从此更尖。

两条用例互相指着对方，读到任何一条都找得到另一侧。

### 用例与夹具

- 新增 `a_volume_whose_root_is_gone_did_not_get_made`（`tests/isolation.rs`）：三个卷、
  坏的夹在中间，抽走整个卷根。五件事一起断言——指名、原因、**输出根与隔离目录两处都没留
  一个字节**（隔离目录那一句是分水岭：从前那一沓白页正落在那儿）、前后两卷照常做完且输出真在盘上、
  `any_volume_failed()` 真而 `any_isolated()` 假。

- 夹具 `RemoveOnceTheSurveyIsDone` 多一个构造 `volume_root(path)`：抽的从一个文件变成整棵目录树，

### 退出码在哪一层测

`exit_code` 那个纯函数一个字没改（`3` 压过 `2` 的次序本来就在），
两条新旧用例问的是它读的那两个谓词（`Report::any_volume_failed` 与 `Report::any_isolated`），
形状照 `a_page_that_gives_back_no_pixels_at_all_is_a_failed_page` 那一条的先例。
**没有加进 `tests/exit_code.rs`**：那份用例跑的是真进程，而「卷根在预扫之后消失」
要一个观察者在开工那条事件上动手，子进程里没有地方挂它。

### `CONTEXT.md` 一个字没动

> ### Q50 — 卷根整个消失时走的是**页级**失败 → 隔离（退出码 2），不是卷级失败
>
> - **From:** 票 `p1-session/05`
> - **Kind:** 票面没想到的第三种情形
> - **Where:** `src/lib.rs` 的 `volume_fingerprint`（读不出的成员记成 `hasher.unreadable`，
>   不报错）与 `first_pass`（读不出字节的页变成失败页）；`tests/isolation.rs` 的
>   `a_volume_whose_every_page_fails_still_comes_out_whole`
> - **Why it did not block:** 票面点名的三种诱因里，「透传文件搬不动、权限变了」走得到卷级失败
>   （读那一步回 `Err`），而**整个卷根消失**走不到：页读不出来是 12 号票定死的**页级**失败，
>   整卷因此进隔离目录、出一整卷占位白页，退出码 `2` 而不是 `3`。
>   验收那两条仍然成立——其余卷照常处理、报告完整、已做完的卷不受影响，这一条只是把
>   「没做成」记成了「做成了但整卷都是坏页」。
>   改它要动的是 12 号票那条口径（「一页都没成的卷算不算这一卷没做成」），而
>   `a_volume_whose_every_page_fails_still_comes_out_whole` 正把现在这条钉着——
>   那是一个领域决定，不是本票的实现细节。
> - **What this ticket actually did:** **没有改页级失败那条口径。**卷级失败收的是
>   `process_volume` 真回 `Err` 的那些（透传文件搬不动、建不出输出容器、撞名、
>   指纹那一道之外的 I/O 错），用例造的也是这几种。卷根消失这一路照旧走隔离。
> - **Whose call:** 下一张动《失败》那一节或退出码的票（一卷里一页都没成，该算隔离还是算没做成）
> - **处置：** **本票了结。**根因它已经定死了，本票照它指的两处改：判据落在
>   `ensure_the_volume_root_is_still_there` 上（卷根还在不在），
>   `a_volume_whose_every_page_fails_still_comes_out_whole` 留在隔离那一侧并多钉一件事。
>   它交给「下一张票」的那个领域决定——一卷里一页都没成算隔离还是算没做成——
>   答案是**算隔离**：12 号票那条口径没被推翻，改的是它上面一层。
