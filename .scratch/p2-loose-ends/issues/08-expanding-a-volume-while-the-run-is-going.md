# 08 — 一趟跑着的时候也展得开

**What to build:** 会话里按 `e` 展开一卷的逐页，现在只有浏览时按得动。而报告正是**跑着的时候**
在长——想看刚跑完那一卷判成了什么，得等整趟完。

让它跑着也展得开。这要把 `Mode` 拆成两维：**跑没跑**是一维，**在看什么**是另一维。
`p1-session/10` 与 `11` 各自判过「不拆」，依据都是「本票不需要」——本票需要。

`p1-session/14` 另指出一件更硬的：展开数的是已收摊的那份报告，而**正在跑的那一卷不在里面**，
它还在攒着的那一份上。跑着时展开要么等它收摊，要么把攒着的那一卷也画得出来——本票要判。

收停车场的 **Q72**。

**Blocked by:** 01 — 闸门盖住三种构建；07 — 中文长句折行（屏底那一行是本票新键的落点）

**搬走了：** 本票收进 `p3-session-legibility/11《展开的逐页表：默认只列要紧的页》`——
**两条硬约束的落点就是它**；模式拆成两维那一半在 `p3-session-legibility/10`（ADR 0017）。
那一批要把报告区换成卷表、给它光标与焦点，模式拆成两维是那件事的地基；按今天这一整段文字的
报告区先做一遍，做出来的那一套下一批就得拆掉重来。
票面这两条硬约束原样带了过去，两条都落在 `11` 上：「正在跑的那一卷要么展得开、要么明说它
还没收摊，不许摊开上一卷冒充它」（展开的索引改成 `live::Volume`，认得出「收摊了的第几卷」
与「决策点上攒着的那一份」两处）、「展开着的时候按停仍按得动，两级语义不变」
（按停与答话那三个键归**阶段**那一维，`stage_action` 一处答完）。
