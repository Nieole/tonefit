# 09 — 预设删得掉，覆盖不吃掉注释

**What to build:** 两件在预设那一栏上缺的事。

**删不掉**：会话里存得进一份预设、列得出、套得上，就是删不掉——攒错了一份要退出会话去手改 TOML。

**覆盖会重排**：覆盖一份同名预设要把整份文件按标准格式重排，手写的注释与排版留不下来。
存**新的**一份不吃这个亏（那一条是追加，原文一个字节不改），只有覆盖吃。
根子是写入端没有保住格式的能力。

收停车场的 **Q74**（删）与 **Q73**（覆盖重排）。Q73 的出路是换一个保住格式的写入端；
引不引那个依赖本票要判并说明。

**Blocked by:** 01 — 闸门盖住三种构建

**Status:** ready-for-agent

- [ ] 预设那一栏上删得掉一份，且删之前要确认——这是不可逆的写盘动作
- [ ] 删掉的是点名那一份，同一份文件里其余预设、注释、排版全部原样留着
- [ ] 覆盖一份同名预设之后，**手写的注释仍逐字节在原处**——这条要比盘上的字节
- [ ] 本版本读不懂的预设在删与覆盖之后都还在（不认识不等于可以丢）
- [ ] 写盘仍是先写临时再改名，整份读不懂就一个字节都不写
- [ ] 删到最后一份、以及对着一份不存在的预设按删，都说得清、不崩
