# honest-screen — 屏上每一句都站得住：盖住的露出来、截断的看得出、说错的改对、说漏的补上

**Status:** ready-for-agent

## Problem Statement

`design-parity`、`say-and-stop`、`one-source` 三批落地之后，停车场 `Q995–Q1388` 那一轮 `/settle` 里有一批要改东西、
却没有一张开着的票接得住的条目；经 `/grill-with-docs` 拷问（2026-10-02），19 件归到这里（条目原文与定下的做法在停车场
《待处理》里各条的《处置》）。用户眼下碰到的是：

1. **屏上的字被盖住，或者截得像已经说完了。**80 列上「添加路径」那一行，补全出的缓冲末尾与光标被右端那几件按键提示压住，
   看不见自己打到了哪儿；搜索词长过十八个汉字上下同样被压住。设置栏一行装不下时从行尾硬截——画质门槛那一行截在
   「（在 boox-poke6 」之后，读起来像只在一块面板上测过，后面那块面板根本看不出来。
2. **屏上有几句话说错了。**预设栏光标停在末行「＋ 把当前设置保存为预设」上时屏底写 `⏎ → 使用`，按下去开的是起名那一行；
   会话跑着时按 `C-c` 退出，印到 stdout 的报告末尾说「按停止停下」，而用户按的是退出；详情栏里画质门槛、设备配置两段说明
   仍说只在 boox-poke6 上定出来的，同一屏上一行之隔的那一行已经说两块面板；一页都不需留意的那一卷，实现写「需留意的页」，
   设计稿写「需要留意的页」；抬头那句「预计还要多久」，设计稿与实现两套算法——头几卷设计稿说「正在估算」、实现报出一个瞎估的数。
3. **屏上说漏了、说不出来。**清点途中按停止，结束那一屏设计稿里没有，会话停在开跑之前那一副、抬头却说「处理到第 0 卷」；
   套着预设、换了型号之后设置栏型号那一行带 `*`，光标停上去，详情栏说不出预设里写的是哪一块；确认点上答了「不写出」、
   分析时又坏了页的那一卷，行首是 `✓`、`]d` 跳不到它，而总览问题行数着它的坏页、挂着 `]d → 跳到下一个`；
   命令行 `--brief` 在默认那条路上，一枝十二卷全部跳过与全部重做印出来一模一样，说不出跳过了几卷；
   命令行进度条上分卷序列那一卷叫 `第01卷.part1`，会话里同一卷叫 `第01卷`——同一个程序的两副界面上两个名字。
4. **按下去的效果与屏上不一致。**输入行开着、补全框没候选时滚一下滚轮，挪的是输入行底下那一块的光标——而 `↓`／`↑` 在那儿什么都不做；
   起名那一行按 `Esc` 关掉之后，预设栏里那一问「再按一次 ⏎ 覆盖「X」」还挂着；设计稿套了没写型号的预设再按 `t` 照样开跑，实现说「先挑型号」。
5. **同一个目录用两种写法点名，不认作同一处。**`库` 与 `/当前目录/库` 点名同一棵树时，同名同级的那几卷在撞名那一道被拒绝开始、
   里外嵌套的那几卷各做一遍——用户换一种写法点名，结果就变了。
6. **验收的出处有缝。**场景夹具给干净的卷自己算一个去处，与库的镜像规则不是同一副结构；场景与终端那几条用例拿「从卷根推名字」的
   那个函数推屏上卷名的期望值，而产品代码早已改读清单；场景夹具里认光标之外的几处取值，认不出的拼写默默落到默认那一档——
   设计稿那头改个拼写，验收照样绿。

## Solution

屏上每一句都站得住：

- **摆不下时按哪一头要紧截，看得出被截过。**截法三种，各只有一处出处（《让位》）：抬头、卷名与路径**从中间省略**（不变）；
  设置栏一行**末尾放 `⋯`**；输入行的缓冲**前面放 `⋯`**。输入行摆不下时右端那几件**从前往后让**——先 `⇥`、再 `C-w`，`⏎` 与 `Esc` 最后——
  缓冲与光标恒在，全让光了缓冲才截。
- **说错的那几句改对，同一件事只有一处出处。**预设栏末行屏底写 `⏎ → 保存为预设`；结束方式那一句不再说「按停止」，写「停下（立即停止）」，
  命令行与会话退出时同一句；详情栏那两段说明里的面板名单从库里读，与报告抬头、设置栏那一行同一处；屏上一律用词条名「需留意的页」；
  「预计还要多久」以设计稿为准：分子取整步，进度不到 2% 不报。
- **说漏的补上。**清点途中按停止之后，结束屏抬头写「已停止 ⋅ 清点途中停下，一卷都没开始」，卷列表回到开跑之前那一副；
  详情栏型号那一项注套着的预设里写的是哪一块，没写就说「没写型号（套用时型号回到没挑）」；带坏页的预览过那一卷行首 `!`、`]d` 落得到、
  目录行算一处需留意，行尾仍是「已分析，未写出」；`--brief` 默认那条路上目录行只拿掉「逐页」那几笔，跳过、没做成、覆盖照数；
  命令行进度条从清点清单读卷名，分卷序列那一卷叫序列的名字。
- **按下去的效果与屏上一致。**输入行开着、补全框没候选时滚轮一件事都不做；起名那一行 `Esc`、收起预设栏时，覆盖那一问作废；
  设计稿开跑之前先问型号，与实现同一句。
- **相对写法接上当前目录再认。**《同一处》的字面规整先给相对路径接上当前目录，再照旧规整、比。
- **验收只从一处出处来。**设计稿给每一卷导出干净的去处，夹具照读；用例的卷名期望值读清单；场景夹具里每一处取值认不出就报错。

照 ADR 0019 决定第 13 条：凡是屏上要变的，**先改设计稿、重导，再让实现跟上**。

## User Stories

1. 作为会话用户，我想要在 80 列的终端上添加一条长路径时，输入行上始终看得见我打到的末尾与光标，以便知道补全补到了哪一级。
2. 作为会话用户，我想要输入行摆不下时先让掉 `⇥ → 补全` 与 `C-w → 删一段` 这两件提示，以便最要紧的 `⏎ → 确定` 与 `Esc → 取消` 留到最后。
3. 作为会话用户，我想要右端提示全让光之后缓冲仍放不下时，缓冲前面出一个 `⋯`、露出末尾，以便一眼看出前面还有、光标所在的那一截在眼前。
4. 作为会话用户，我想要在搜索那一行上打长搜索词时同样看得见末尾与光标，以便搜索与添加路径是同一副摆法。
5. 作为会话用户，我想要设置栏某一行装不下时末尾出一个 `⋯`，以便读得出这一行还没说完，不把截断读成说完了。
6. 作为会话用户，我想要设置栏三组（设备设置、处理选项、画质判定参数）都照这一条截，以便整张设置栏一副规矩。
7. 作为会话用户，我想要窄屏上画质门槛那一行截断时同样带 `⋯`，以便不把「其」字当成一句话的结尾。
8. 作为会话用户，我想要抬头、卷名与路径照旧从中间省略，以便这一批改动不碰已经站得住的那一种截法。
9. 作为会话用户，我想要光标停在预设栏末行「＋ 把当前设置保存为预设」上时屏底写 `⏎ → 保存为预设`，以便按下去的效果与屏上说的一致。
10. 作为会话用户，我想要光标停在一份预设上时屏底照旧写 `⏎ → 使用`，以便末行那一句的改动不波及别的行。
11. 作为会话用户，我想要会话跑着时按 `C-c` 退出，stdout 上那份报告末尾写「停下（立即停止）……」，以便它不把我的退出说成按了停止。
12. 作为命令行用户，我想要按停之后报告末尾那一句同样写「停下（……）」，以便命令行与会话同一句、同一处出处。
13. 作为会话用户，我想要详情栏里画质门槛与设备配置那两段说明说的面板，与设置栏那一行、报告抬头说的一致，以便同一屏上不出现两种说法。
14. 作为维护者，我想要那两段说明里的面板名单从库里的标定来源读，以便下一次加面板时只改一处、不会漏掉一处。
15. 作为会话用户，我想要一页都不需留意的那一卷，进去时那一句写「需留意的页」，以便屏上用的是词汇表里那个词。
16. 作为会话用户，我想要头几卷还没跑出一点进度时，抬头说「正在估算剩余时间」而不报一个瞎估的数，以便不被头一分钟的估计误导。
17. 作为会话用户，我想要「预计还要多久」按走完的整步算，以便屏上那个数与真程序拿得出的读数一致。
18. 作为会话用户，我想要清点途中按停止之后，结束屏抬头写「已停止 ⋅ 清点途中停下，一卷都没开始」，以便看得出停在了清点那一段，而不是第 0 卷。
19. 作为会话用户，我想要清点途中停下之后卷列表回到开跑之前那一副（带「＋ 添加路径」），以便改了路径直接再跑。
20. 作为会话用户，我想要光标停在型号那一行上时，详情栏注明套着的预设里写的是哪一块型号，以便那一行的 `*` 有解释。
21. 作为会话用户，我想要套着的预设没写型号时，详情栏说「预设「X」中：没写型号（套用时型号回到没挑）」，以便知道套这一份会把型号清掉。
22. 作为会话用户，我想要确认点上答了「不写出」、分析时又坏了页的那一卷行首是 `!`，以便与别的需留意的卷一眼分得开。
23. 作为会话用户，我想要 `]d` 跳得到那一卷，以便总览问题行上「坏页 N 页 ⋅ ]d → 跳到下一个」说的是真的。
24. 作为会话用户，我想要那一卷所在的目录行把它算一处需留意，以便收起目录也看得出里面有要看的。
25. 作为会话用户，我想要那一卷的行尾仍写「已分析，未写出」，以便不把它当成进了隔离。
26. 作为命令行用户，我想要 `--brief` 在默认那条路上，目录那一行照旧说出跳过了几卷、没做成几卷、覆盖顶死几卷，以便几百卷重跑一趟时扫一眼就知道这一枝有没有重做。
27. 作为命令行用户，我想要那一行在默认那条路上不再印「逐页 N」，以便它不重复卷数那一格已经说了的事。
28. 作为命令行用户，我想要 `--envelope` 那条路上目录那一行照旧有统一档位分布那一格，以便这一批不碰那条路。
29. 作为命令行用户，我想要进度条上分卷序列那一卷叫序列的名字（`第01卷`），以便它与会话、报告里叫同一个名字。
30. 作为会话用户，我想要输入行开着、补全框没候选时滚轮一件事都不做，以便滚轮与 `↓`／`↑` 在输入行上是同一件事。
31. 作为会话用户，我想要补全框有候选时滚轮照旧挪候选，以便这一条只收窄没候选的那一种。
32. 作为会话用户，我想要关掉起名那一行（`Esc`）之后，「再按一次 ⏎ 覆盖「X」」那一问不再挂着，以便屏上不留一句对着已经不在的名字说的话。
33. 作为会话用户，我想要收起预设栏之后那一问同样作废，以便重新掀开时从头开始。
34. 作为会话用户，我想要套了没写型号的预设再按 `t`，设计稿与实现都说「先挑型号」，以便设计稿上的那一屏与真程序一致。
35. 作为命令行用户，我想要用 `库` 与 `/当前目录/库` 两种写法点名同一棵树时，它们被认作同一处，以便换一种写法点名不改变结果。
36. 作为命令行用户，我想要报告里印的仍是我点名时的那一种写法，以便接上当前目录只用于比、不用于印。
37. 作为 Windows 用户，我想要相对路径接上当前目录时 `..` 照旧不被算掉，以便两个平台上《同一处》是同一个定义。
38. 作为维护者，我想要设计稿给每一卷都导出它干净时的去处，夹具照读，以便干净去处与隔离去处出自设计稿同一处算法，夹具不自己造数。
39. 作为维护者，我想要场景与终端用例里卷名的期望值读清点清单，以便期望值与产品代码同一个出处。
40. 作为维护者，我想要从卷根推名字的那个函数在进度条也读清单之后，改成只说「页名」的名字，以便它的名字不再暗示它管卷名。
41. 作为维护者，我想要场景夹具里每一处取值（视图、输入行的种类、覆盖层、配置视图的哪一栏……）认不出就报错，以便设计稿那头改个拼写当场红，不再默默落到默认那一档。
42. 作为维护者，我想要一条用例走遍全部场景与全部序列的场景数据，每一处取值都认得出，以便这条规矩对今天和以后导出的每一份数据都成立。
43. 作为维护者，我想要每一处屏上变化都先在设计稿里改、重导、比整屏，以便设计稿始终是验收的唯一出处。

## Implementation Decisions

- **设计稿先行（ADR 0019 决定第 13 条）。**凡是屏上要变的——输入行让位、设置栏 `⋯`、预设栏末行那一句、清点途中停下的结束屏、
  型号那一项的详情栏、带坏页的预览过、「需留意的页」、「预计还要多久」、滚轮、覆盖那一问作废、开跑前先问型号——先改设计稿、重导、
  新导一串或一屏钉住，再让实现跟上。重导会重写整棵设计快照，所以**改设计稿的票彼此串行**；重导之后既有快照的变动只许落在本票牵到的那几处。
- **截法三种，各一处出处（《让位》已写）。**从中间省略（抬头、卷名、路径，已有）；末尾 `⋯`（设置栏一行）；前面 `⋯`（输入行缓冲）。
  三种各只有一个实现，画法各处调它，不各自截。设置栏 `⋯` 那一种会让设置栏几乎每一屏变样，单独一张票。
- **输入行右端的让位次序（《让位》已写）。**右端那几件是按用途从按键表派下来的（`design-parity/02`）；摆不下时按 `⇥`、`C-w`、`⏎`、`Esc`
  的次序从前往后让，让到摆得下为止；全让光了缓冲才截（前面 `⋯`）。没到点的回话画在右端那几件的位置上那一条不变。
- **预设栏末行那一句。**按键表上给末行的 `⏎` 一句自己的短句「保存为预设」——末行上 `⏎` 在实现里本来就走起名那一支；屏底点名要哪一句，
  与卷行、目录行按行分短句同一副。
- **结束方式那一句只在一处写。**命令行报告末尾与会话退出时 stdout 那一份同一个出处；措辞去掉「按停止」，写「停下（立即停止）」「停下（做完再停）」、
  清点途中那一种同理。
- **面板名单只有库里一处。**详情栏那两段说明在拼句时向标定来源要面板名单（与报告抬头、设置栏画质门槛那一行同一处），说明文字里不再写面板名。
  设计稿那两段说明跟着改成同一句。
- **「预计还要多久」以设计稿为准。**设计稿那一侧分子取走完的整步（与总进度的步数向下取整同一族），实现补上「总进度不到 2% 不报、说正在估算」那道门。
- **清点途中停下的结束屏。**抬头整句换成「已停止 ⋅ 清点途中停下，一卷都没开始」；没有开工那一条，卷列表回到开跑之前那一副（处理路径列表，带「＋ 添加路径」）。
  CONTEXT《总览》《结束方式》《清点摘要》已在 `/settle` 里改对，本票只让屏上跟着。
- **型号那一项的详情栏（《详情栏》已写）。**套着预设时注预设里写的是哪一块型号；预设没写型号时那一句是「预设「X」中：没写型号（套用时型号回到没挑）」。
- **带坏页的预览过（《卷状态》已写）。**预览过的那一卷有需留意的页（坏页也算）时行首 `!`、`]d` 落得到、目录行与分区算一处需留意；没有时 `✓`。行尾不变。
- **`--brief` 目录那一行。**默认那条路上只拿掉「逐页」那几笔；那一格在不在场仍由「说没说出卷数之外的东西」定——跳过、没做成、覆盖顶死有一笔就在。
  `--envelope` 那条路不变。
- **命令行进度条读卷名。**进度条在开工那一条事件到时收下清点清单上的「卷根 → 卷名」，开一卷时按卷根查卷名；之后「从卷根推名字」那个函数
  只剩页名一个读者，改成页名那一头的名字。
- **滚轮在输入行上。**输入行开着时滚轮只管补全框：有候选挪候选，没候选一件事都不做；不再落到底下那一块。
- **覆盖那一问作废的时机。**关掉起名那一行（`Esc`）、收起预设栏、重开起名那一行、存下了——四种都作废它。
- **开跑前先问型号。**设计稿开跑前问的次序与措辞照实现那一侧（先型号、再输出目录、再路径）。
- **《同一处》接当前目录（《同一处》已写）。**字面规整的头一步：相对路径接上当前目录——自己接，不做任何别的规整，两个平台同一个做法；
  不用标准库那个会在 Windows 上算掉 `..` 的转绝对路径的函数。只拿来比，报告里印的仍是用户点的写法。收编、借住、撞名三处都走它。
- **设计稿导出干净去处。**设计稿给每一卷导出它干净时的去处（与隔离去处同一处算法），场景数据多一格；夹具照读，不再自己算。
- **用例的卷名期望值读清单。**场景与终端那几条用例按卷根问清点清单上的卷名，不再拿「从卷根推名字」的函数推。
- **场景夹具认不出就报错。**场景夹具里每一处读取值的地方把认得的写全，认不出交回错误（与认光标那一处同一副）；一条用例走遍全部场景与序列的场景数据。
  场景夹具是本轮的冲突热点，**碰它的票同一时间只放一张**。

## Testing Decisions

- **好的用例只问外部行为**：屏上那一格是什么、stdout 上那一句是什么、开工拒绝没拒绝——不问内部用了哪个函数、哪个字段。
  照 `docs/agents/testing.md` 那三条：守卫按反跑一次亲眼看见红；屏上改掉一句假话，留一条反着钉的断言说这句不许再出现
  （「按停止停下」「需要留意的页」「`⏎ → 使用`」在末行上）；用例点名取值，不借默认值。
- **接缝 ①：设计稿的期望屏，逐格比整屏。**会话屏上的每一处变化——输入行让位（80 列「添加路径」与长搜索词各一串）、设置栏 `⋯`（窄屏与宽屏画质门槛那一行）、
  预设栏末行、清点途中停下的结束屏、型号那一项的详情栏（写了型号与没写型号各一屏）、带坏页的预览过（行首、`]d`、目录行）、
  「需留意的页」（一页都不需留意的卷进去那一屏）、「预计还要多久」（不到 2% 那一刻与过了之后）、滚轮在输入行上没候选、
  `Esc` 之后覆盖那一问不在、开跑前先问型号——都由设计稿导出一屏或一串，实现比整屏。交互从终端层喂输入（按键、滚轮、点击），
  比走完之后的那一屏。先例：设计快照与交互期望屏、会话里比整屏的那一族用例、终端层经键码翻译喂输入的那一族用例。
- **接缝 ②：命令行那一路的文字。**结束方式那一句（命令行与会话退出时同一句、两级各一条、清点途中一条）、`--brief` 目录那一行
  （默认那条路上跳过有、逐页没有；`--envelope` 上分布照旧）——报告纯函数的用例；进度条上分卷序列的卷名——进度条那一侧的用例或起真进程比 stderr。
  先例：报告那一层的用例、起真进程比 stdout 的退出码与按停那两组用例。
- **接缝 ③：库的对外行为。**《同一处》判等是纯函数，相对写法与绝对写法各一组逐格钉住（含 `..` 不被算掉）；集成用例用两种写法点名同一棵树，
  同名同级的卷不再被拒绝开始、里外嵌套的不再各做一遍，报告里印的仍是点名时的写法。先例：「同一处」的单元用例、发现与容器那两组集成用例。
- **防第二份出处的闸门。**面板名单只住库里一处：单一出处扫描添一条，详情栏说明里不许出现面板名字面。场景夹具认不出就报错：一条用例走遍全部场景数据，
  往一份数据里写一个认不出的取值它红（试完还原）。先例：单一出处扫描那一组、走遍场景数据认光标种类那一条。
- **不许动的。**黄金快照一个字节不动（它不经过命令行报告与会话屏）；设计快照重导之后，既有快照的变动只许落在本票牵到的那几处。
