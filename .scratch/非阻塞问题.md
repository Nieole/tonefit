# 停车场：实现途中撞见、但没有为它停下来的东西

**状态：** 长期（本轮队列全部票据共用）
**路径：** `.scratch/非阻塞问题.md` — 每一份派活说明都要交出这个路径

---

## 这个文件是什么

落地票据会撞出票面没预料到、或者票面写错了的东西。**其中几乎没有一件该让队列停下来。**
它们落在这里：**记下来、绕过去、接着走、收尾时逐条了结。**

它不是产品的长期缺口清单（那是 `CONTEXT.md` 的《尚未确立》）：

| | 《尚未确立》 | 本文件 |
|---|---|---|
| 装的是 | **产品**本身的缺口 | **执行**中冒出的问题——票面写错、规格没说、两处文档互相打架 |
| 寿命 | 比这一轮队列长 | **收尾时应当清空**——每条要么就地了结、要么升进《尚未确立》、要么另立一张票 |
| 谁读 | 下一个动这个产品的人 | 收尾那一步，以及拍板的人 |

---

## 停线——只有这三种

停下来很贵：拍板的人要把整个上下文重新装回脑子。门槛：

1. **继续做下去会写出错的东西，而撤销它要伸手到这张票之外。**
   典型：票面的指示与上游一条仍然生效的决定相抵触。
2. **动作不可逆，而且不止一个方向说得通。**
   典型：删掉或改名一个被多处引用的东西——一个 id、一个字段、一个文件。
3. **前提根本不在，这张票无从下手。**
   典型：「在 X 之上做 Y」，而 X 不存在。

其余一律：记在这里，走最站得住的那条路，接着做。**包括**票面给的数与你量出来的对不上、
验收条读着含糊、票面没想到的第三种情形、路过发现的无关缺陷，以及你确实拿不准的单项。

> ⚠️ **绕过去要留下痕迹。** 条目记的是**你走了哪条路**，不是「当时有两条路」。
> 说不出自己做了什么的条目不算条目。

### Q32 — 中文的帮助与报告在终端上不折行，本票新加的那几行尤其长

- **From:** 票 `05`
- **Kind:** 路过发现

- **Why it did not block:** clap 按空格折行，而中文长句里一个空格都没有，整句因此原样印成一行。

### Q33 — 互锁 ③ 的判定在代码里有两处形态，靠一句 `debug_assert!` 拴着

- **From:** 票 `05`
- **Kind:** 路过发现
- **Where:** `src/lib.rs` 的 `candidates`、`nothing_left_error` 与
  `dither_outside_the_gate_error`；`src/interlock.rs` 的 `Interlock::dither_outside_the_gate`
- **Why it did not block:** 两者答的不是同一个问题。`candidates` 答「这一套候选还剩几个」——
  位深与抖动两维一起裁的结果；互锁那一条答「这一趟咬上了 ③ 吗」——只看抖动那一维加几何门。
  把拒绝改成由互锁驱动，要么让 `candidates` 先问互锁再裁（多一道判定，而位深那一维仍得
  自己判空），要么让互锁去数候选集（它就得知道候选集怎么算）。两条都是把一个模块的知识
  搬进另一个，而本票要的是**处置**只写一处，那一条已经做到了。
  还有一件跟着它：拒绝那句话在**碰卷之前**就备好（`Candidates::new`），那时没有页可量，
  因此答不出「手上这一页换个适配方式解不解得了」。真要按页分岔，得把这条拒绝挪到判门的地方（`gray_page`）。
- **What this ticket actually did:** 保留 `candidates` 的裁空判定；`nothing_left_error` 收了
  `gate`，那一支加 `debug_assert!(Interlock::dither_outside_the_gate(request.dither, gate))`
  与一句注释点名它就是互锁 ③。用例跑在调试构建上，等价关系因此每一趟都验。
  错误措辞改由 `Interlock` 自己说，措辞那一侧的出处只有一个。
  按页分岔那一步没做，换成**把话说全**：fit-inside 那一侧仍指 `--fit height`，
  但把「被兜底上界退回的页换过去仍被拒」那道例外一并写进去，用例两条路一起钉着。
- **Whose call:** 拍板的人（要不要让互锁真的驱动那条拒绝）
- **处置：** 待处理。

### Q21 — 「以高为准下几何门恒成立」现在有了一个例外，而那句话写在 ADR 0007 与 `page-geometry/05` 的票面上

- **From:** 票 `07`
- **Kind:** 两处文档打架
- **Where:** `docs/adr/0007-dither-only-at-native-resolution.md`《决定》第 7 条；
  `docs/measurements.md`《适配方式：fit-inside 与以高为准》那条「**几何门恒成立**」；
  `.scratch/page-geometry/issues/05-interlocks.md` 第三条互锁（「`--dither fs` 在以高为准下
  几乎打不着（没有页贴不住面板）」）
- **Why it did not block:** 兜底退回去的页从此是一张 fit-inside 的页，门照 fit-inside 那条判——
  它**可能不成立**（源两边都比面板小时）。两处文字因此不再对每一页成立。真实素材够不着那道线，
  这个例外在实践中是空集。
  `--dither fs` 撞上这样一页仍是**整趟拒绝**——那不是本票开的口子，是 ADR 0007《要认的代价》
  明写的行为（「覆盖项是用户的显式指令，不是可以按页悄悄放弃的东西」），05 号票的处置 ③
  也定的是「维持拒绝」。本票要恢复的是「**分配不下**不该中止整趟」，与「显式覆盖项撞上几何门」
  是两件事：前者用户没法预知也没法避开，后者是用户自己点的名，错误信息还指得出是哪一页。
  拒绝那条路径本身有用例（`tests/pipeline.rs` 的 `a_dither_the_geometry_gate_forbids_is_refused`），
  本票只是让它在以高为准上也够得着。
- **What this ticket actually did:** 代码那一侧照实际行为写全了（`GeometryGate::Broken` 与
  `GeometryGate::of` 的文档、`geometry` 那条扫描用例改名并断言例外真的被扫到过）；
  ADR、measurements 与 05 的票面**都没动**——06 号票明写着「等实现落定后照实际行为写」，
  且它已经在改 ADR 0007 同一条，两只手改一条会打架；measurements 那一句与 Q8 是同一类，
  照 Q8 的先例留给所有者。`CONTEXT.md` 只加了《几何》里「兜底上界」一行词汇。
