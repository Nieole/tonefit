# 停车场：实现途中撞见、但没有为它停下来的东西

**状态：** 长期（本轮队列全部票据共用）
**路径：** `.scratch/非阻塞问题.md` — 每一份派活说明都要交出这个路径

---

## 这个文件是什么

落地票据会撞出票面没预料到、或者票面写错了的东西。**其中几乎没有一件该让队列停下来。**
它们落在这里：**记下来、绕过去、接着走、收尾时逐条了结。**

它不是产品的长期缺口清单（那是 `CONTEXT.md` 的《尚未确立》）：

| | 《尚未确立》 | 本文件 |
|---|---|---|
| 装的是 | **产品**本身的缺口 | **执行**中冒出的问题——票面写错、规格没说、两处文档互相打架 |
| 寿命 | 比这一轮队列长 | **收尾时应当清空**——每条要么就地了结、要么升进《尚未确立》、要么另立一张票 |
| 谁读 | 下一个动这个产品的人 | 收尾那一步，以及拍板的人 |

---

## 停线——只有这三种

停下来很贵：拍板的人要把整个上下文重新装回脑子。门槛：

1. **继续做下去会写出错的东西，而撤销它要伸手到这张票之外。**
   典型：票面的指示与上游一条仍然生效的决定相抵触。
2. **动作不可逆，而且不止一个方向说得通。**
   典型：删掉或改名一个被多处引用的东西——一个 id、一个字段、一个文件。
3. **前提根本不在，这张票无从下手。**
   典型：「在 X 之上做 Y」，而 X 不存在。

其余一律：记在这里，走最站得住的那条路，接着做。**包括**票面给的数与你量出来的对不上、
验收条读着含糊、票面没想到的第三种情形、路过发现的无关缺陷，以及你确实拿不准的单项。

> ⚠️ **绕过去要留下痕迹。** 条目记的是**你走了哪条路**，不是「当时有两条路」。
> 说不出自己做了什么的条目不算条目。

- **Whose call:** 拍板的人（要不要在今天的默认下把 A 类的体积表整批重跑）

### Q38 — 两级停是 `run` 的能力，而命令行这一路还没有按的地方

- **From:** 票 `p1-session/02`
- **Kind:** 票面没想到的第三种情形
- **Where:** `src/main.rs` 的 `Bar::observe`（恒回 `Instruction::Continue`）
- **Why it did not block:** ADR 0013 决定第 3 条明写「收尾与中止是 `run` 的能力，不是 TUI 私有的：
  命令行那一路同样用得上」。本票把回路立起来之后，库这一侧已经收得下那两个字，
  缺的只是命令行那一头的**按键**——而那要接 Ctrl+C 信号处理，并决定按一次与按两次怎么分。
  本票的硬约束是「命令行现有行为一字不变」，接线当场就越了界；而它也不该由本票定形状：
  `04`（中止）落地之后中止才真的停得比收尾早，在那之前接上去，用户按第二下看不出区别。
- **What this ticket actually did:** **没有接。**`Bar::observe` 恒回继续，并在文档里点名
  这是「还没有那个键」，不是「命令行不该停」，同时点了 ADR 0013 决定第 3 条。
  Ctrl+C 仍然只有杀进程一条路——与本票落地之前逐字相同。
- **Whose call:** 拍板的人（命令行那一头要不要接 Ctrl+C 信号处理）——
  `10` 已落地会话那一侧的两级停（`s` 按一次收尾、再一次中止），命令行这一头仍然空着
- **处置：** 待处理。**`10` 没有接它**：本票的硬约束是「命令行那一路行为一字不变」，
  而接线要动 Ctrl+C 信号处理——那是命令行入口上的一处新行为，越了那条约束。
  会话那一侧的两级停已经落地，因此「按停是 `run` 的能力」现在**有了一个真的按的地方**；
  ADR 0013 决定第 3 条「命令行那一路同样用得上」仍然只兑现了一半。

### Q66 — 最后那一趟没做成，先前那一趟试算的报告也就印不到 stdout 了

- **From:** 票 `p1-session/09`
- **Kind:** 票面读着含糊
- **Where:** `src/session/run.rs` 的 `Running::report`；`src/session/live.rs` 的 `undone`
- **Why it did not block:** 票面说「退出会话时把报告照原格式印到 stdout」，
  没说一个会话里跑了好几趟时印哪一趟的。本票取**最后那一趟**：退出码也取它，
  两者取同一趟才对得上（`tonefit > 报告.txt` 之后读 `$?`，说的得是同一件事）。
  **没做成**的那一趟没有报告可带（`run` 返回的是错误本身），于是那一次 stdout 上
  一个字节都没有——哪怕先前刚跑过一趟好好的试算。这与命令行那一路是同一条规矩，
  那边没做成时同样什么都不印。
- **What this ticket actually did:** **取最后那一趟，没做成就不印。** 攒到一半的那一份仍留在
  `Live` 上、仍画在主区（会话不因此退出，用户当场改），只是不印到 stdout。
  「没做成」收着**两种**：拒绝执行，以及那条线程恐慌了——两者都没有报告可带、
  退出码都是 `1`，分得开它们的是那句话本身（主区上印的就是它）。
  用例 `a_refused_run_leaves_the_session_open_and_prints_nothing` 钉住这一条。
- **Whose call:** 拍板的人（一个会话跑了好几趟时，stdout 上该有哪一趟）
- **处置：** 待处理。

### Q118 — 闸门 2 的 `the_minutes_spent_deciding_are_charged_to_nobody` 五趟里红三趟，`overall()` 那两次读表之间被抢走就红

- **From:** 票 `volume-discovery/04`
- **Kind:** 既有缺陷（不是本票造出来的，但本票是撞得最狠的一次）
- **Where:** `src/session/live.rs` 的 `Live::overall`（`self.started.elapsed()
  .saturating_sub(self.deliberated())` 那一句）与 `the_minutes_spent_deciding_are_charged_to_nobody`
- **Why it did not block:** 那一句读了**两次表**：`started.elapsed()` 里一次（记作 T1），

  本票对 `live.rs` 的改动是 `Live::new` 里一行 `Vec::new()`，落在 `started` 记下之后、
  `rewind` 之前，只会让上式**前一项变大**，即让它更不容易红；
  库那一侧的计时路径一个字符没动。
- **What this ticket actually did:** **没有动它。** 修法是让 `overall()` 只读一次表

  停车场 Q41 那一串；在这张票里改它，等于顺手改掉会话屏上那两个数的算法。
  本票据此报的闸门 2 数字取的是**没撞上它的那一趟**（580 通过 0 失败），
  撞上时 cargo 会在那个二进制上停下、后面的二进制不再跑，总数因此看着少一截。
- **Whose call:** 拍板的人（`overall()` 要不要改成一次读表；或那条断言要不要留一格余量）
- **处置：** **了结。** 排队那一侧就地收掉（`b5603d7`）：`overall()` 取一个 `now`，
  被减数与减数都拿它算，`deliberated` 因此改成收 `now`、自己一次表都不读。
  那个窗口按构造消失，不是靠给断言加余量掩掉——断言原样不动。
  闸门 2 连跑两趟 580 通过 0 失败。计时**口径**一个字没改（减的仍是等人那一截），
  因此不必等 Q41 那一串。
