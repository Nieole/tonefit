# 04: 地板回到绝对灰度级，一个数管三档

**What to build:** 连续灰调的页不再被判成 `4bit 不抖`。真机在那一类素材上 **n=16、15:1 偏 `2bit+FS`**，而今天的判据 **0/16** 同向——判读者的理由是色带，并补了一句「除了轻微色带之外的观感几乎一致」。**2bit 上的 FS 颗粒本来就看不见，而判据在为它收费。**

改法是把颗粒项那道可见度地板从《格点间距》的比例改回**绝对灰度级**：1bit 的 FS 颗粒幅度约 **127**、2bit 的约 **42**，一个绝对地板夹在中间，「1bit 上收费」与「2bit 上不收费」这两条真机结论就都成立了。写成比例把三档绑死，那是这个矛盾的**唯一**来源。

**本票覆盖 `metric-recalibration/01`**（那张票把地板改成了比例）。它已 resolved，**《落地记录》原样留着**——覆盖的理由与新取值记在本票自己的落地记录里。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] `Composition` 的那一个数从「占格点间距的比例」换成**绝对灰度级**，`floor()` 不再乘《格点间距》——三档拿到同一个值。**仍然只有一个数**
- [ ] 取值 **55.0**：实测窗口 45~65 的正中（窗口两侧都塌：≤40 时真机排序掉到 6~20/21，≥70 时 `1bit+FS` 不再垫底），且与 `metric-recalibration/01` 之前的旧值逐位相同，那批《位深盲测》数据因此仍可比
- [ ] **地板不再依赖位深**——`score()` 那个 `depth` 参数原本的理由（「地板是格点间距的比例，而间距只有位深说得出来」）就此消失。**它的去留要一并交代**：删掉，或写明为什么还留着
- [ ] 报告《判据构成》那一行改回按绝对灰度级说，连同标定来源一并印。措辞只有一处出处（ADR 0016），会话那一层跟着走
- [ ] **翻掉钉旧形状的那几条用例**：钉「地板是格点间距的一个比例」的那一条要改成钉「地板是绝对灰度级、三档同一个值」；钉旧下界 `0.2071·s` 三档各钉的那一条重新表述（那条下界随「同一档上抖动恒优于不抖动」一起作废）
- [ ] **新钉一条**：「1bit 上收费、2bit 上不收费」——谁把地板改回比例，当场红
- [ ] **ADR 0002 决定第 5 条要翻**：「地板是格点间距的一个比例，不是一个绝对值」这条决定，连同它底下那条上界推导（`F < s·(sqrt(r(1−r)) − r)`）——那条推导把 FS 的低通项当成零，而平坦调阶梯上实测不是零（`u ≤ 2` 上是 2.86 / 3.47，已高过不抖的 1.00 / 2.00）
- [ ] `02` 那四条真机护栏**仍然全绿**
- [ ] **真机排序 21/21**：拿 `judgements/` 里已有的逐对数据重算（第六、七、九轮共 22 页有排序结论），新地板下判据与真机同向的页数不得低于 21。唯一容许的例外是 `metric-recalibration/03` 标注「不作定量依据」的 `1046-梦游盒-04-2`。**零新判读人力**
- [ ] **`1bit+FS` 仍垫底**：棋魂 0060 与 0148 上，它的读数仍高过同页 `2bit 不抖`
- [ ] **跨档相关性重跑**（`metric-recalibration/02` 那两个 ρ）：跨档不得变负，同档不得变差
- [ ] **黄金快照显式接受一次**：判据一改判定就变，差异审查后接受，不能顺手覆盖。那一篇存在的理由就是拦这种改动
- [ ] 闸门三条绿（`cargo xtask gate`）
