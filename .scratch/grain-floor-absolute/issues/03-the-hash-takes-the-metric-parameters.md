# 03: 判据参数进哈希，改了它旧输出就过期

**What to build:** 改了地板、掩蔽或聚合里任何一个数之后，用户下一趟跑同一个库，**旧输出自动过期整卷重做**，而不是被幂等静默跳过。今天 `params_hash` 一个判据参数都没收——ADR 0002 的《后果》自己记着这个缺口：「地板不在里面……旧输出会被静默跳过」。

**这一张是 `04` 的安全网，必须在它之前落地。**否则改地板那一趟，用户拿到的是上一趟的产物而不自知，而那**很难发现**——输出看着就是旧的那样。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] `params_hash` 收 `Composition`、`Aggregation`、`Masking` 三者的**全部字段**
- [ ] 收的是那三个结构体，不是散落的常数——将来加一个字段，哈希自动跟上，不必记得回来改这里
- [ ] `tests/pipeline.rs` 或 `tests/idempotency.rs` 上有一条用例钉住它：**改了判据参数之后旧输出过期重做**，写法照 `tests/idempotency.rs` 现有那几条
- [ ] **落地这一张本身就让全库旧输出过期一次**（哈希多了输入）。这一条写进 ADR 0002 的《后果》——不写下来，将来没人知道那次全库重跑是从哪来的
- [ ] 黄金快照：判定不变，但记录里的哈希会变。差异审查后显式接受
- [ ] 闸门三条绿（`cargo xtask gate`）
