# 01 — 判据要排得出真机上的偏好序

**Status:** resolved

**Blocked by:** None — can start immediately

**排期建议**：排在 `page-geometry/02 — 裁边`**之前**。本票引用的那几页判据值是在当前几何下
量的；棋魂与画集受高度约束，`page-geometry/01` 不改它们的尺寸，但**裁边会改内容与尺寸**，
那批基线随之作废。

## 要做到的

判据给出的次序，要和真机盲测给出的次序一致。现在在同一页之内就反了。

棋魂 0060（Poke6）：1bit+FS 判据 **6.157**，真机排第 5、不可接受；同页 2bit 不抖判据 **8.211**，
真机排第 2。判据说前者更好，人说后者更好。要挡住 1bit+FS，界须 < 6.157；要放行 2bit 不抖，
界须 > 19.300（棋魂 0148 的同一档）。两个条件不能同时成立——**这不是界定在哪的问题，
是判据把序排反了**。全部数据见 measurements 的《位深盲测》。

机理：FS 误差扩散的定义就是把量化误差摊进邻域、保住局部均值，而判据量的正是低通后的局部均值误差
（ADR 0002）。判据度量的恰好是抖动被设计来优化的那个量，于是结构性地偏袒抖动，
**看不见抖动颗粒自身的可见度**。缺的是这一项。

## 验收

- [x] 棋魂 0060 上，1bit+FS 的判据值大于 2bit 不抖的判据值
- [x] 真机盲测的五页里，1bit 档在每一页都排在同页其余候选之后
      （**四页**重算得出判据值；Bowing 那一组的输出现有管线产不出，见《落地记录》）
- [x] 画集 056 与 040 的 4bit 不抖能被判据分开：前者目视有色块、后者目视很好，
      现在两者只差 1.04，要拉开到能在两者之间定出一条界
- [x] 逐像素 RMSE 的错误排序不被重新引入——《抖动》记着无抖动 34.81「优于」FS 42.86 与目视不符，
      新判据在那组数据上不能退回这个结论
      （那组的基底不在仓库里，**按同一形状另造一张网点页重算**；真实页上另有一条收窄，见《落地记录》）
- [x] `Report` 逐页给出的各候选判据值随之更新，dry-run 的输出仍然自解释
- [x] 黄金快照重新录制，差异逐条确认
- [x] ADR 0002 修订：判据由几项构成、各项量什么，写进《决定》

## 候选次序：不变（已定）

判据修好之后，**2bit 不抖会变成一个真能被选中的候选**——真机上它排第 2，且比 2bit+FS
省 18% 体积（棋魂 Poke6：109 KB 对 133 KB）。现在的候选次序是「同一档位深上抖动排在
不抖动之后」，取阈值内最低的一档，于是它一旦达标就会排在 2bit+FS 之前被选走。

**所有者已定：次序不变，判据说了算。** 不抖真比得过就该被选走。

由此这张票的责任加重了一条：**判据的正确性直接变成产物**。次序不再兜底，修得不到位
就会当场写进每一卷。上面那几条验收因此不是形式——尤其「棋魂 0060 上 1bit+FS 的判据值
要大于 2bit 不抖」与「画集 056 与 040 的 4bit 不抖能被判据分开」，那两条正是不抖被选中时
会不会出事的分界。

落地时要在真实语料上给出**改判据前后的体积与判定对照**，写进落地记录。

（位深与抖动按卷统一，上包络取的是「位深＋抖动模式」这个组合，因此不存在一页抖一页不抖的
翻页跳变——这条不必担心。）

## 不要做的

- 不要靠调低阈值绕过去。序既然反了，任何标量界都同时挡不住 1bit+FS 又放不行 2bit 不抖。
- 不要把判据换成跨面板可比的量。它跟着面板走，那是 ADR 0002 的决定，不在本票范围。

## 落地记录

### 判据补了哪一项

**颗粒项**（ADR 0002 决定第 5 条）：候选比参照多出来的高频起伏里，超出可见度地板的那一部分。
一块的读数变成「低通项 ＋ 颗粒项」，再乘掩蔽加权，聚合形状不动。

同时改了**掩蔽的量法**（决定第 4 条）：活动度从核尺度（2~4 像素）挪到块尺度（32 像素，与分块同边长）。
只补颗粒项分不开画集 056 与 040 那一对——两页都不抖动、都没有颗粒，分开它们的是掩蔽。
掩蔽加权的地板跟着量法一起重定（0.25 → 0.5）：量法换了，活动度整体变大，旧地板打折太狠。

低通那一趟改成滑动窗口（耗时与核边长无关），否则块尺度那次局部均值要贵一个数量级。
它与逐格重算逐格对得上，`src/metric.rs` 有一条用例钉着。

三个标定出来的数——阈值、颗粒地板、掩蔽地板——连同各自的窗口列在 measurements 的《位深盲测》。

### 两条分界验收

| | 改前 | 改后 |
|---|---|---|
| 棋魂 0060：1bit+FS 对 2bit 不抖 | 6.157 对 **8.211**（反的） | **21.449** 对 8.250 |
| 画集 056 对 040 的 4bit 不抖 | 5.910 对 4.872（差 1.04） | **6.022 对 4.477**（差 1.545） |

四页全部候选的判据值见 measurements 的《位深盲测》。

**「五页」实际只证了四页。** Bowing 那一组的三个「放大」候选出自一条实验性的放大路线，
现有管线不放大、产不出同一批输出，判据值重算不出来；那一组的真机名次仍成立。
1bit 不抖动那一档从来没进过盲测（没有出图），判据给它的四页读数（33.119 / 28.188 / 92.075 / 86.250）
是算出来的，不是排出来的——四页都高过同页的 1bit+FS。

### 逐像素那组数据没有退回去

《抖动》那一组的基底不在仓库里，**新判据在它上面重算不出来**。按同一形状另造了一张：
聚集点阵二值页 2528×3360 缩到 1264×1680（网点是因、灰调是果），完整判据在 1bit 上读
**无抖动 21.402 对 FS 6.552**——结论不变，差距反而拉大。这张页由代码生成，
`tests/metric.rs` 新增的网点页用例与黄金快照的 `screentone` 各钉住它的一头。

**有一条收窄，如实记在 ADR 0002 的《后果》里**：平坦灰调上「1bit 抖动恒优于不抖动」
是算得出来的（地板 > 52.8），但真实页上抖动那一侧还要背自己的低通项，平坦的中浅灰会交叉——
八卷 1187 页里 76 页（6.9%）。**交叉一次都没落到界附近**：交叉处两者中较小的那个最低 20.824，
是阈值的 3.8 倍；界两倍以内的 19 页一次都没交叉过。判定够不着这条。

### 阈值重标定：仍取 5.5

窗口由同一批盲测重新夹出：**[4.930, 6.022)**——下界画集 040 的 2bit+FS（可接受），
上界画集 056 的 4bit 不抖（明显色块）。**上界从此由 banding 定，不再由 1bit 定**：
1bit+FS 已退到 21 以上，够不着界。5.5 落在窗口正中。

卷级扫描见 measurements（八卷 1187 页）：6.02 与 5.5 判定完全相同；降到 5.0 起虚抬，且抬中的是 **4bit 不抖**——
候选次序里它排在 4bit+FS 之前，一旦达标就被选走。**5.5 不虚抬，取值不变，改的是它的来历。**

### 真实语料前后对照

八卷 1187 页 / 4.7 GB（A 类四卷：棋魂完全版 Vol.01、画集 Venus、哆啦A梦 Vol.15、改革之獸 Vol_05；
B 类四卷：N和S 43 话、Bowing 1 话、长夏 2 话、Forget-me-not 1 卷），boox-poke6：

- **逐页判定 1187 页无一变动**，卷级基准档八卷全同。
- **输出体积逐卷差 0 字节。**

判据值本身动得不小，**六档都动，不止没被选中的那几档**——掩蔽那一改作用在全部候选上：

| 候选 | 最降 | 最升 |
|---|---|---|
| 1bit 不抖 | −17.654 | +23.546 |
| 1bit+FS | −0.210 | **+72.818**（11.368 → 84.186） |
| 2bit 不抖 | −8.147 | +3.419 |
| 2bit+FS | −1.763 | +1.162 |
| 4bit 不抖 | −2.041 | +0.500 |
| 4bit+FS | −0.286 | +0.211 |

判定没跟着动，是因为动得最狠的那一档（1bit+FS）本来就远在界外，
而界附近那两档（2bit+FS 与 4bit 不抖）挪动量小于它们离界的距离。

### 黄金快照差异逐条确认

整片没有变红，四组：

1. **`screentone` 卷**：1bit+FS 从界内挪到界外（重算 6.552 > 5.5），基准档 1bit+FS → 2bit+FS，
   103257 → 116301 字节。方向对——1bit 在网点页上正是盲测判不可接受的那一档。
2. **`solid` 卷**（纯色 128）：1bit+FS 重算 78.031，远在界外，同样升到 2bit+FS。
   纯灰调页在 1bit 上就是满屏散点，这一档本不该过。
3. **`mixed` 卷**：渐变页（1bit+FS 84.145）与纯色 200 页（64.451）在立脚点那一档上远超阈值 3 倍，
   **首次被摘成离群页**；主体剩三张线稿页，基准档随之落回 1bit+FS。那两页各自仍是 2bit+FS、
   字节不变。夹具注释本来就写着「五页的卷因此摘得出离群页」——**从前摘不出来，现在摘出来了**。
   落回 1bit+FS 的那三张是**纯二值线稿页**，各档判据读数全是 0.000：1bit 在那种页上无损，
   单独成卷时（`line-art`）从前就判 1bit+FS，这一改没有把它推到更低的档，
   只是上包络不再被那两张异质页拖上去。
4. **`archive.cbz`**：与第 3 组同一机理，一张渐变页成为离群页，线稿页落回 1bit+FS。

其余卷（含三个长卷、几何门那几卷、隔离卷）一行未动。

### 留给所有者的一条

**2bit 不抖真机排第 2，判据仍判它在界外**（棋魂两页 8.250 与 18.878），那一档比 2bit+FS 省 18% 体积。
这不再是「序排反了」，是判据认为那两页的灰调塌陷值这么多。同一轮盲测里 8bit 参考自己排第 4，
说明那一轮排的多半是「哪张更有劲」而不是保真度。两侧都只有一份数据——已记进
`CONTEXT.md` 的《尚未确立》，复核之前维持判据说了算。
