# one-source — 一处出处与判等：「是不是同一处」只有一把尺子，默认路径逐页到底，散着的第二份出处收齐

**Status:** ready-for-agent

## Problem Statement

用户看得见的毛病有两处，维护者看得见的毛病有一堆，根子都是**同一件事在仓库里有不止一处出处**：

1. **「两个路径是不是同一个地方」四处四把尺子。**收编按字面路径认「同一个卷根」，大小写、`./`、写法不同都认不出——
   在 Windows 上 `tonefit --out D:\out D:\库 d:\库\作品`，盘符大小写不同就够同一卷做两遍、写两份（停车场 Q241）；
   「谁住在谁的去处里」按镜像路径逐字节比，认漏了借住的卷就退回整个换掉（Q300）；撞名那条拒绝按编译平台折大小写——
   **macOS 上 `Abc.cbz` 与 `abc.cbz` 真会撞，今天被判成两个，两卷静默写进同一处**（Q366）；补全那一处已经改成运行期探大小写。
   另有一处撞名根本没有比：一张页的输出名（`N和S/001.jpg` → `001.png`）撞上一个借住的目录卷的去处（`N和S/001.png/`），
   三道撞名检查一道都拦不住，收尾时那一卷被清掉（Q301）。
2. **默认路径上有一角照旧攒整卷参照。**点了恰好一维覆盖项、卷里门那两组又混着时，「覆盖项把候选集裁到只剩一个」
   要等整卷判完门才答得出——于是那一角不开滚动窗口、参照照攒、页级依据不写、按页跳过不成立，改一页整卷重做（Q424、Q635、Q683、Q697）。
   四条例外，根子是一个问题问在了不该问的地方。
3. **维护者手里的第二份出处**：会话里 `Live` 旁边摆着清点那两张表、报告上又一份（Q745、Q964），开工一条事件在 `Live` 上分两个方法收（Q747）；
   转轮的算式两处、时钟起点两格（Q864）；隔离目录的名字在会话里写死第二份（Q870）；卷列表那一格的「跳过」「没做成」手抄了措辞层的词（Q961）；
   「摆进列里的字形宽度稳不稳」那一关跟着屏上的表缩了（Q962）；《砍列》《视口》说「这里不抄第二份」，却没有一条用例问得出（Q615）；
   场景数据里认不出的光标种类没有一条用例扫过（Q846）。
4. **行为上的两处白做与半截话**：试算那一趟照旧给每张输出页造一份没有读者的来路（Q490）；
   `why_nothing_is_left` 抖动那一支回半截话、没有一个用户看得到（Q583）。
5. **结构上的几处**：`lib.rs` 四千多行，滚动窗口那一簇与它的三态答案（嵌套 `Option`）混在里面（Q431、Q545）；
   `(相对路径, 第几张, 共几张)` 三个同型参数在四处同行旅行（Q494）；`score` 收的位深与手上那张候选图之间没有任何约束（Q306）；
   `is_junk` 的名字只说得出它判的一半（Q477）；透传文件那一份哈希借用了 `PageSource` 这个名字（Q699）。

## Solution

- **库里一把「是不是同一处」的尺子**：字面规整，再按那个文件系统分不分大小写决定折不折。每一趟开工时对每条处理路径与输出根
  各探一次大小写，不跨趟记任何东西。收编、借住、撞名三处都走它，补全改调它。撞名那一道再比进「一个卷的成员去处」与「另一个卷的去处」。
- **默认路径逐页到底**：默认路径上只有开卷之前答得出的那一种顶死（两维都点了）算覆盖顶死；答不出的那一角一律逐页判。
  四条例外一起消失。
- **第二份出处收成一份**，白做的那一处不做，半截话换成类型说的话。
- **结构**：滚动窗口那一簇连同分析与写出两个环节搬成一个 `pipeline` 模块，三态答案换成具名枚举；
  三个同行的参数捆成一个类型；`score` 只收绑定了位深的量化图；两处名字改对。

用户能看见的变化只有两处：同一个地方的两种写法不再各做一遍、会撞的两卷在开工之前被拒；默认路径上那一角的报告说「逐页」、
改一页只重做那一页。命令行报告在别处一个字节不变。

## User Stories

1. 作为 Windows 用户，我想要 `D:\库` 与 `d:\库\作品` 被认成嵌套的同一棵树，以便同一卷不做两遍、不写两份。
2. 作为用户，我想要 `库` 与 `./库` 被认成同一个处理路径，以便写法不同不改变这一趟做什么。
3. 作为 macOS 用户，我想要 `Abc.cbz` 与 `abc.cbz` 两卷要写进同一处时当场被拒，以便后一卷不静默盖掉前一卷。
4. 作为 Linux 用户，我想要在分大小写的文件系统上 `Abc.cbz` 与 `abc.cbz` 照旧是两卷、各写各的，以便不被一条不适用的规矩拦下。
5. 作为用户，我想要输出目录还不存在时，工具去问离它最近的已存在的上一级，以便新建的输出目录也判得出分不分大小写。
6. 作为用户，我想要探不出输出那一侧分不分大小写时，工具宁可多拒一趟，以便最坏的结果是多拒一次，而不是两卷写进同一处。
7. 作为用户，我想要探不出源那一侧分不分大小写时，收编按分大小写认，以便两个真不同的目录不会被错收成一个。
8. 作为用户，我想要一条软链与它指向的那棵树被当成两个名字，并且这件事写在《尚未确立》里，以便知道这是已知的边界。
9. 作为用户，我想要混装目录里一张页的输出名撞上一个借住的卷的去处时，开工之前就被拒，以便那一卷不在收尾时被清掉。
10. 作为用户，我想要那句拒绝说出撞的是哪一张页、哪一卷，以便知道去改哪个名字。
11. 作为会话用户，我想要逐层补全认不认大小写与撞名那一道用同一把尺子，以便屏上补得出的名字与跑起来认的名字一致。
12. 作为维护者，我想要「是不是同一处」只有库里一处判法，以便不再出现四处四把尺子。
13. 作为维护者，我想要一趟里探大小写的次数只有处理路径数加一，而且不跨趟记住，以便符合 ADR 0009 不建跨运行状态的决定。
14. 作为用户，我想要默认路径上点了一维覆盖项、卷里门那两组混着的那一卷照样逐页判，以便它的报告说「逐页」而不是一句取决于第一张灰度页碰巧是哪一种的「覆盖」。
15. 作为用户，我想要那一卷改一页只重做那一页，以便按页跳过在默认路径上没有例外。
16. 作为用户，我想要那一卷不再把整卷参照攒在缓存里，以便默认路径上的缓存用量照旧只是编好的字节。
17. 作为用户，我想要两维覆盖项都点了的那一趟照旧是覆盖顶死、分析环节就把字节编完，以便那条最快的路不变。
18. 作为 `--envelope` 用户，我想要那条路上的覆盖顶死照旧，以便上包络那条路不受这一改影响。
19. 作为维护者，我想要《覆盖顶死》写清它在默认路径上只剩两维都点了的那一种，以便词条与实现对得上。
20. 作为维护者，我想要 ADR 0005 那一节《覆盖项那一档答不出来时让位》改写成「默认路径上答不出就逐页」，以便决定与实现对得上。
21. 作为会话用户，我想要清点一到，报告上的非漫画文件与无法访问的地方就填上，以便屏上与退出时印到 stdout 的那一份读的是同一份。
22. 作为维护者，我想要 `Live` 旁边那两张表删掉、开工那一条只由一个方法收，以便一件事只有一个接收处。
23. 作为维护者，我想要转轮只有一段算式、会话的时钟只有一个起点，以便下一次合并不会再把两格起点摆错次序。
24. 作为维护者，我想要隔离目录的名字只在库里写一次，会话读它，以便改名时不必记得改两处。
25. 作为维护者，我想要卷列表那一格的「跳过」「没做成」读措辞那一层，以便 ADR 0016 那句「一套措辞」在会话里也成立。
26. 作为维护者，我想要「字形宽度稳不稳」那一关问措辞层出的全部格，以便下一次屏上换表时它不跟着缩。
27. 作为维护者，我想要《砍列》《视口》各有一条扫描用例问得出词汇表里没有第二份，以便那两句「这里不抄第二份」有闸门撑着。
28. 作为维护者，我想要一条用例走遍全部场景数据、核每一种光标都认得出，以便认不出的键名当场红而不是默默落到输出目录那一行。
29. 作为维护者，我想要试算那一趟一份来路都不造，以便「来路在场 ⟺ 记录器在场」这条不变量真的成立。
30. 作为维护者，我想要 `why_nothing_is_left` 交出一个枚举（位深那一支带一句话、抖动那一支只是个标记），以便不再有一句没人看得到的半截话。
31. 作为维护者，我想要互锁 ③ 那条「只有一处判定」的用例照旧成立，以便改返回类型不丢掉那道闸门。
32. 作为维护者，我想要滚动窗口、分析环节、写出环节住进一个 `pipeline` 模块，以便 `lib.rs` 只剩对外的那几个 seam 与装配。
33. 作为维护者，我想要「开卷之前答不答得出覆盖顶死」是一个具名的三态枚举，以便 `!= Some(None)` 这种写法再也写不出来。
34. 作为维护者，我想要 `(相对路径, 第几张, 共几张)` 捆成一个成员类型，以便算输出名、来路与幂等比对的那几处必然拿同一组值。
35. 作为维护者，我想要 `score` 只收一张绑定了位深的量化图，以便位深与像素传错一档编译不过，而不是安静地按另一道地板读数。
36. 作为维护者，我想要 `is_junk` 改名成说得出它判两件事的名字，以便往「不看的地方」名单里加东西的人知道它在成员那一侧同时作数。
37. 作为维护者，我想要 `PageSource` 改名 `MemberSource`、词条改成《成员源哈希》，以便透传文件那一份不再借一个说它是页的名字。
38. 作为维护者，我想要这几次搬家与改名之后全部用例照旧绿、黄金快照一个字节不动，以便证明行为没变。

## Implementation Decisions

### 「是不是同一处」一把尺子（Q241、Q300、Q366）

- 库里一个判等：**字面规整**（去掉 `.` 分量与尾分隔符；**不解析 `..`**——与软链一起时字面解析会指错地方），
  再加**折不折大小写**。折不折取决于那个位置所在的文件系统分不分大小写。判等本身是纯函数：
  两条路径加一个「这一侧不分大小写吗」的答案进去，一个布尔出来。
- **探法**：只读地翻一个已有名字的大小写去问盘（补全那一处今天就是这么做的，Q365 判过不造探针文件）；这份探法搬进库里，补全改调它。
- **每一趟开工时，每条处理路径与输出根各探一次**；不跨趟记任何东西（ADR 0009）。输出根还不存在时，探离它最近的已存在的上一级。
  补全照旧用它自己那一格进程内记忆，只是调库里这一个探法。
- **探不出时两侧取相反的一边**：
  - 源那一侧（收编）按**分大小写**——判错了，同一个目录被点了两次，随后撞名那一道当场拒绝，结果看得见；
  - 输出那一侧（撞名、借住）按**不分大小写**——判错了只是多拒一趟；反过来是两卷静默写进同一处。
- **收编**：`Found` 按判等之后的键认同一个卷根，`Candidate::root` 照旧留用户点的那一条（报告里印的路径不变）。
- **借住**：找住户那一步按判等认「这个卷的去处是不是那个卷去处的祖先」。
- **撞名**：`collision_key` 不再按编译平台折；按输出根探到的答案折。
- **软链不解析**：两个名字当两个东西。落地时记进《尚未确立》——今天也是这样，只是从此写明。

### 成员与卷撞同一个去处（Q301）

- 撞名那一道多比一种：**一个卷的成员去处**与**住在它去处里的另一个卷（借住的卷）的去处**。
- 一对一那一套输出名（`001.jpg` → `001.png`），清点时就比：借住关系在清点时已经算出，住户所在那一卷的成员清点时列过；
  撞上即**拒绝开始**，那句话说出撞的是哪一张页、哪一卷。《拒绝开始》里「两个卷撞同一个去处」那一种改成「两样东西撞同一个去处」（随这张票落地）。
- 只有解了像素才知道的那一半（一张跨页切开之后的名字），照旧在它那一卷里查，撞上照该处既有的做法走卷级失败——
  那一刻已经开工，不是拒绝开始的时点。

### 默认路径逐页到底（Q424、Q635、Q683、Q697）

- 默认路径上，**开卷之前答得出**的那一种顶死（两维都点了，两组门的候选集裁到同一个）照旧是覆盖顶死，分析环节就把字节编完。
- **答不出的那一角一律逐页判**：不再等整卷判完门再问 `pinned`。那一角的理由从「覆盖」变成逐页那两种、卷级那一行从「覆盖」变成「逐页」；
  开滚动窗口、参照不进缓存、写页级依据、按页跳过成立。第一遍那份档与汇总那份逐格相同那条断言照旧钉得住（两处问的是同一句）。
- `--envelope` 那条路不变：它本来就攒整卷，覆盖顶死照旧在整卷判完之后问。
- `CONTEXT.md`《覆盖顶死》加一句「默认路径上只有两维都点了的那一种」；ADR 0005《覆盖项那一档答不出来时让位》那一节改写；
  `VolumeVerdict::Override` 的文档跟着改一句。都随这张票落地。

### 会话里的第二份出处

- **清点那两张表**（Q745、Q964）：开工那一条一到，非漫画文件与无法访问的地方就写进报告；`Live` 旁边那两张删掉，屏上与 stdout 读同一份。
- **开工只一个接收处**（Q747）：`run_started` 与 `surveyed` 并成一个方法；喂前一半的那八十余处用例改成喂整条（清单与卷数对得上）。
- **转轮与时钟**（Q864）：会话的时钟起点只有一格——视图那一层那一格；行首记号的转轮从它算、再加自己那一行的错相，
  算式只有一段。场景夹具那两格起点的次序问题随之消失。
- **隔离目录的名字**（Q870）：库里那个常量公开，会话那一句读它。对外契约多一个常量——`cargo doc` 的告警水位跟着核一次。
- **卷列表那一格**（Q961）：跳过的卷读措辞层那一格，没做成的卷读措辞层那一行；`tally_column` 从此有非测试的读者，那句「期待成为死代码」拆掉。
- **字形宽度那一关**（Q962）：改问措辞层出的全部格（原样那一档照旧不问），不再跟着屏上摆成列的那几格走。
- **《砍列》《视口》的单一出处**（Q615）：各添一条扫描用例，照「拒绝开始的名单只住一处」那条的形状——词汇表那一条里只许有名字、不许有值。
- **场景数据的光标种类**（Q846）：一条用例走遍全部场景与全部序列的场景数据，每一种光标都认得出。

### 行为收紧

- **试算不造来路**（Q490）：来路在场的谓词从「指纹在场」收成「指纹在场且这一趟真要写」；试算那一趟一份都不造。
- **`why_nothing_is_left` 交出枚举**（Q583）：位深那一支带一句话，抖动那一支（互锁 ③）只是一个标记；各调用处按它造拒绝。
  互锁 ③「只有一处判定」那条用例照旧是它的闸门，形状跟着改。

### 结构

- **`pipeline` 模块**（Q431、Q545）：滚动窗口那一簇（窗口、座位、开卷之前那一问）连同分析环节、写出环节、输出页搬成一个模块；
  开卷之前那一问的答案从嵌套 `Option` 换成具名三态枚举（答不出 / 答得出而没顶死 / 顶死在这一档），`Settles` 从它派生。
  这一张排在「默认路径逐页到底」**之前**：先搬家、再改那一问，改的是搬好的那一处。
- **成员类型**（Q494）：`(相对路径, 第几张, 共几张)` 捆成一个类型；算输出名、来路、幂等比对与认写出的那一族四处都收它。
- **绑定了位深的量化图**（Q306）：量化交出一个带着它那一档位深的图，`score` 只收它；用例里两处合成候选（没被目标位深量化过）
  走一个明写的构造，不再靠「传 8bit」的约定。
- **两处改名**：`is_junk` → 说得出「不看的东西」两半的名字，连同三处文档、调用点与那条用例名（Q477）；
  `PageSource` → `MemberSource`，词条改成《成员源哈希 (MemberSource)》，tEXt 键不动（Q699，单独一次全仓改名）。

## Testing Decisions

### 什么是好测试

只断言外部行为：**一趟跑完的报告、写出去的文件、拒绝的那句话、事件流、整屏**。不断言判等里先比哪一段、探法缓存在哪、
枚举叫什么——那些换一种实现就该能换，结果不变。

### 库的集成用例（主力）

- 经 `run` 喂一整趟：收编认得出大小写不同、`./` 不同的同一棵树；借住认得出大小写不同的去处；撞名在不分大小写的文件系统上拦下
  `Abc.cbz`／`abc.cbz`（本机就是）；混装目录里一张页的输出名撞上借住的卷的去处时拒绝开始。

  改一页之后第二趟只重做那一页。两维都点了的那一趟照旧是覆盖顶死。
- 先例：`tests/discovery.rs`（收编）、`tests/container.rs`（混装目录与借住）、`tests/pipeline.rs`（覆盖顶死、缓存）、
