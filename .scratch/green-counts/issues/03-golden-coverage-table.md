# 03 — 黄金快照的覆盖表，已知三个空维各补一卷，`--envelope` 组砍重复的短卷

**What to build:** `tests/golden.rs` 的模块文档立一张表：**维度**（路径：默认逐页 / `--envelope`；适配方式；裁边与拆分；彩色分支；坏页与残缺页；
覆盖顶死；界边的逐页理由；纸色提白钳得动；上包络与迟滞……）× **由哪一卷盖住** × **明写不在的维度与理由**。先写表，再照表补：

- **覆盖顶死**：两维都点了的那一种，一个短卷；
- **界边的逐页理由**：逐页展开、不走卷级摘要；页上的取值**相对阈值算出来**（读画质门槛那一处出处），不写死一个数；
- **纸色提白钳得动**：一页纸白 253（现成的夹具）。

`--envelope` 组砍掉与默认组重复的短卷，只留默认组够不着的（长卷、彩色、fit-inside、`keep`）——「`--envelope` 那条路逐字节不变」的证人照旧是那几个长卷。
快照为这一张显式接受一次，diff 里只有新加的三卷与砍掉的那几卷。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 覆盖表在 `tests/golden.rs` 的模块文档里，每一维都点得出由哪一卷盖住或为什么不在
- [ ] 新三卷进快照；贴界那一卷的取值相对阈值算出来（改阈值常量它跟着走）
- [ ] `--envelope` 组砍掉重复的短卷，长卷、彩色、fit-inside、`keep` 照旧在
- [ ] 快照显式接受一次；「改了快照绝不会被静默接受」那条用例照旧绿
- [ ] `cargo xtask gate` 三条全绿；票据的《数》记下三条各自最后一行

#### Q473 — 黄金快照对「逐页理由」这一维只有一行覆盖，界边判定它拦不住

- **From:** `metric-recalibration/07`（票面指望黄金快照拦住判定变动，它没拦住，也拦不住）
- **Kind:** 路过发现（一道闸在某一维上是空的，而有人正指望着它）
- **Where:** `tests/golden-snapshot.txt`；`tests/golden.rs` 的 `Case::summary`
- **Why it did not block:** **换了 `tests/pipeline.rs` 拦住的**——
  `dithering_can_bring_a_page_back_within_the_threshold` 与
  `per_page_turns_the_envelope_off_and_gives_every_page_its_own_bit_depth_and_reason`
  在界降到 5.113 以下时当场红，本票的取点就是被它们钉出来的。闸没空，只是不在票面以为的那个地方。
- **What this ticket actually did:** 数了一遍：快照全份 **152 行**里，带**逐页**理由的只有 **1 行**
  （`002.png`，判 `1bit`、`阈值内最低的一档`，一张救回 49.8% 的页，离界很远）；
  其余页行的理由都是卷级那几种（上包络 30 · 迟滞升档 24 · 特例 3 · 几何门不成立 1）。
  **门成立那一侧的界边判定，快照一格都没盖到**——喂那种页的长卷（`envelope-hysteresis-gate-holds`）
  在 `tests/golden.rs` 里是 `Case::summary`，只记卷级两行，逐页那一列根本不进快照。
- **Options:** ① 记下，靠 `tests/pipeline.rs` 那两条兜着；
  ② 给黄金加一卷**不是 `summary` 的**短卷，页上摆一个贴着界的纯色取值，把逐页理由摆进快照；
  ③ 把 `envelope-hysteresis-gate-holds` 从 `summary` 改成逐页展开——**60 页会给快照加 120 行**。
- **Recommend:** ②。③ 的代价与收益不成比例：那一卷长正是为了走到非退化的上分位与迟滞，
  逐页展开只是把同一件事抄六十遍。②只加两三行，而且**贴着界的那个取值会随标定漂**——
  设计它的时候要让它相对阈值取，别写死一个数（同 `ONE_STEP_ABOVE_TWO_BITS` 今天栽的那一跤，Q467）。
- **Whose call:** 拍板的人（黄金要不要在「界边逐页理由」这一维上补一格）
- **处置：** 待处理。

#### Q544 — 黄金快照里一个「覆盖顶死」的卷都没有，那条路它从来没盖住过

- **From:** 票 `two-pass-rework/06`
- **Kind:** 路过发现（长期担保上的缺口）
- **Where:** `tests/golden.rs` 的 `request()`（写死 `bit_depth: None, dither: None,
  per_page: false`）；`tests/golden-snapshot.txt`；停车场 **Q473**
- **Why it did not block:** 本票的验收第 3 条是「输出字节与顶死之前逐字节相同」，而
  **黄金快照按 `--no-metadata` 跑、验的正是像素那一侧**，看上去正是这条验收的担保。
  数了一遍：快照那七个卷**一个都不点覆盖项**，也一个都不点 `--per-page`——
  快照盖住的是**默认那条路**。本票动的是顶死那条路，快照因此从头到尾一行都不会变
  （事实也是：`cargo test --test golden` 全绿，一次都没有显式接受过）。
  **「它没红」在这条路上不是证据，是它根本没看。**
  这一条与 `12` 号票动的逐页那条路同样成立——那一趟也没有一个 `per_page: true` 的卷进快照。
- **What this ticket actually did:** 用一条**脚手架**补上了这一次：把顶死那三条来路加三处
  险要角落（拆开的两张、部分救回页、关掉记录那一趟）写出去的字节各算一个 FNV-1a 校验和，
  **落地前后各跑一趟**，十二处逐字对上（表在票据的《落地记录》里）。
  脚手架照 `07` 的先例撤掉了——**它是一次性的证据，人走了就没了**，
  下一个动这条路的人会跟本票开工时一样，先以为快照兜着他。
- **Options:** ① 记下，靠动这条路的人各自临时造证据（也就是现在这样）；
  ② 给黄金加一个**顶死的**短卷（`--bit-depth 2 --dither off`，两三页），快照多一段；
  ③ 把「这一趟走的是哪条路」也进快照的卷行，让缺哪一维一眼看得出来；
  ④ 系统答一次「黄金快照盖住的到底是哪几维」，按那个答案一次配齐。
- **Recommend:** ②，代价是快照多一段（一个卷行 ＋ 两三个页行），而它买到的是
  **这条路从此有长期担保**，不再每次靠人临时造。但 ④ 才是根子上那一问：
  **这不是孤例**——`mr/07` 记的 **Q473** 是同一类（快照对「逐页理由」这一维只有一行覆盖，
  而那一行还是张离界很远的救回页），本条是「覆盖顶死 / 逐页」这一维整个空着。
  两条撞的是同一件事：**「黄金快照盖住的到底是哪几维」从来没人系统答过**，
  于是每张票都各自以为它兜着自己。settle 这两条时该并在一起看。
- **Whose call:** 拍板的人（黄金要不要在「这一趟走的是哪条路」这一维上补格，以及补几格）
- **处置：** 待处理。

#### Q550 — 黄金快照里一页纸白钳得动的都没有：抬默认值这件事它**一个字节都拦不住**（同族 Q544）

- **From:** 票 `tone-alignment/05`（差异审查那一趟，逐页量出来的）
- **Kind:** 票面写错了的东西（把语料统计当成了夹具的性质），外加一个覆盖缺口
- **Where:** `tests/golden.rs` 的 `mono_cases`／`color_cases` 那十九个卷；
  `tests/golden-snapshot.txt`；票面 Facts 那句「全语料 43% 的页纸白离格——
  **所以黄金快照大概率会大面积改判，那是预期的**」；票面第 4 条那个复选框
- **Why it did not block:** **改判一页都没有，快照逐字节不变**（`cargo test --test golden` 直接绿，
  `TONEFIT_ACCEPT_GOLDEN` 一次都没设，快照文件在 `git status` 下是空的）。
  判据是 `clamp_width = 255 − 纸白`，上限 4 ⇒ **只有纸白落在 251~254 的页钳得动**，
  而这批夹具逐页量下来 **89 页里 `Aligned` 出现 0 次**：纸白不是 255（离格量 0）
  就是 0~200（钳制宽度最小的一个是 55，差着一个数量级），外加 3 页量不出。
  **逐卷的数在票 `tone-alignment/05` 的《落地记录》里，那一节叫《黄金那一趟：没有差异可审，
  而那分两层》**（连同「这是一次性读数不是 measurements 实测记录」那句限定一起读）。
  **43% 是全语料的性质，而这批夹具全是合成图**——spec 自己写着「现有夹具全是合成图，
  纸白多半正好是 255」，两句话在票面里没有接上。
- **What this ticket actually did:** 没给黄金加夹具（票面硬约束是「只改一个默认值」）。
  票面第 4 条那个勾**照实留空**并注明。`tests/golden.rs` 那一句注释改写成真话：
  「它一个字节都没动，而那不是它拦住了什么」，并写下逐页量出来的那几个取值。
  这一票的端到端覆盖落在 `tests/pipeline.rs`（`the_default_run_aligns_an_off_grid_page` 那几条）。
- **Options:** ① 记下，认下黄金对这条路径瞎；② 给黄金加一卷纸白 253 的页
  （`fixtures::page_with_paper_white` 现成），快照跟着长一段、一次显式接受——
  **从此默认值再动一次，黄金当场红**；③ 更进一步：黄金那一篇立一条「每条改像素的管线步骤
  至少有一卷走得到」的规矩，逐条补齐。
- **Recommend:** ②。**成本几乎为零**（`fixtures::page_with_paper_white` 现成：加一卷、
  快照长一段、一次显式接受），而它防的正是同一类事再犯——**加了之后，默认值下一次再动，
  黄金当场红**；不加的话下一趟它照旧一个字节都不动。
  它与 **Q544**（黄金里一个「覆盖顶死」的卷都没有）、以及 `two-pass-rework/06` 记下的那一句
  （**「它没红」在这条路上不是证据，是它根本没看**）是同一件事的三种说法：
  **夹具集不覆盖某条路径时，那一篇绿着，而读的人把「黄金没红」读成「判定没变」。**
  三条 settle 时并着看——**黄金快照到底盖住了哪几维，从来没人系统答过。**
  ③ 是那三条的一般化，值得，但要先有人认下快照会长多少。
- **Whose call:** 拍板的人（改黄金的夹具集等于改那一篇的覆盖面，快照还要跟着接受一次）
- **处置：** 待处理。

#### Q634 — 黄金回归改成两路五组，多跑一组 14 卷（≈ +60 s），换的是「`--envelope` 逐字节相同」的证人

- **From:** 票 `two-pass-rework/11`
- **Kind:** 测试成本与覆盖的取舍
- **Where:** `tests/golden.rs` 的 `snapshot`／`Route`／`default_cases`；`tests/golden-snapshot.txt`
- **Why it did not block:** 两种取法都跑得绿。本票取的那一种把旧快照那 24 卷原样留在 `envelope` 组里
  （落地时用脚本核过：去掉标签那一格之后与 a87f0f2 的快照逐字节相同），再加一组默认（逐页）只跑逐页记行的 14 卷；
  单跑 `cargo test --test golden` 从 4 组涨到 5 组，落地那一趟 273 s（measured，热树、满核）。
- **What this ticket actually did:** 默认组排在头一组、只收 `height_cases` 里非 `summary_only` 的卷；
  `envelope` 组四组原样；卷行标签加第四格 `per-page`／`envelope`。
- **Options:** ① 保持五组；② `envelope` 组砍掉与默认组重复的短卷（`b-class-gradient`、`solid`、`line-art`……），
  只留长卷、彩色、fit-inside、`keep` 四组里默认组够不着的——省一组半的时间，代价是「`--envelope` 那条路一格没动」
  以后只剩长卷作证；③ 反过来只跑默认组，上包络那几卷全砍——那条路的四个未标定数从此没有快照钉着。
- **Recommend:** ①。`--envelope` 那条路眼下没有别的整卷级快照，而 `16` 号票（在新默认下重测）落地之前
  它是唯一一份「旧默认长什么样」的记录；60 s 买这份证人不贵。等 `16` 落地、两条路各有实测撑着，再回头做 ②。
- **16 号票的判（2026-09-14）：** 两条路的实测现在都有了（`docs/measurements.md`《A 类位深实测》第一批每卷一格 `--envelope`
  对照、《按今天的默认重跑那八卷》、《端到端吞吐》的《第三批：同一台机器上两版代码，翻默认之后快了多少》里棋魂两条路的墙钟），「唯一一份旧默认长什么样的记录」这条理由**退了**；
  但实测钉的是体积与秒，不是字节——`--envelope` 那条路逐字节不变仍只有黄金快照作证。**判 ①→② 可以做了、不急**：
  60 s 一趟，下一张碰 `tests/golden.rs` 的票顺手砍重复的短卷；本票不动代码（票面 `src/`、测试都不碰），不在这里做。
- **Whose call:** 下一张碰 `tests/golden.rs` 的票（做 ②）
- **处置：** 待处理。
