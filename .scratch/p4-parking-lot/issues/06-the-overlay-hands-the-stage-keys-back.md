# 06 — 覆盖层交键给阶段，等答话时左栏压暗

**What to build:** 两件屏上说得清、按得动的事：

- **覆盖层掀着时按停与答话那三个键仍旧按得动。** 今天掀开 `?` 那张键位表，
  跑着的那一刻 `s` 按不动、停在决策点上时 `x`／`a`／`s` 三个也按不动——
  而 `ADR 0017` 决定第 4 条写着它们「在焦点落在哪一块上都按得动」。
  **照 ADR 走**：覆盖层与别的五块一样，把自己不认的键交给阶段那一维。
  「进去之后别的键一律不派」收窄成「**除了按停与答话**，别的键一律不派」，
  票面与 ADR 两处同时改口。

  左栏不压暗、抬头那一格写死「跑着」（等答话时那是假话）。

`a` 那个键在等答话时归答话（「剩下的卷都这样」）、展开着时是「列全部页」，

## 落地记录

### 覆盖层与别的几块一样，把不认的键交给阶段那一维

```rust
fn overlay_action(covered: &Covered, key: Key, stage: Stage) -> Action {
    match key {
        Key::Up | Key::Char('k') => Action::Move(Step::Back),
        Key::Down | Key::Char('j') => Action::Move(Step::Next),
        Key::Esc => Action::Cancel,
        Key::Char('q') => Action::Ignored,
        Key::Char(letter) => match Overlay::ALL.into_iter().find(|o| o.key() == letter) {
            Some(same) if same == covered.overlay => Action::Cancel,
            Some(other) => Action::Reveal(other),
            None => stage_action(key, stage),
        },
        other => stage_action(other, stage),
    }
}
```

**这一支从此与 `report_action`、`opened_action`、`expanded_action` 同一个形状**：
末一行是 `stage_action`。从前它是六块里唯一不交的一块，代价写在 Q164 上——
跑着的时候掀开一张表就停不下来。

**这一块自己认下的只剩两个键**：`Esc`（关掉这一张，原样回到盖住的那一块）与
`q`（不派动作）。两个都是「交下去就会退掉整个会话」的键——没跑过与收场了那两个阶段上
`stage_action` 给这两个字派的正是退出。

**`Ctrl-C` 那一行删掉了**：它在 `stage_action` 的头一句接着（每一个状态下都是退出），
在这里再写一遍就是同一件事的第二处出处。

### 「两级语义一格不变」在结构上就是「一个键都不另派」

按停跑着时升的是[闩](Session::stopping)（一次收尾、再一次中止、到顶不再有），
等答话时答的是**当场那个字**——两副都在 `stage_action` 底下，这一块一个都不改、
一个都不挡。`the_overlay_hands_the_stage_keys_back` 顺着按下去问：掀着的时候按两下 `s`，
闩照旧升到中止，第三下 `Action::Ignored`；等答话时 `x`／`a`／`s` 三个各答各的，
答完当场回到「跑着」，而**这一张还掀着**——`Esc` 照旧原样还回底下那一块。

### 屏上那一半：抬头按阶段说话，压暗按只读给

`READ_ONLY_TITLE` 那个常量没了，换成一处按阶段分岔的**唯一出处**：

```rust
fn heading(stage: Stage) -> &'static str {
    match stage {
        Stage::Running(_) => "配置 · 跑着，三层都只读",
        Stage::Deciding(_) => "配置 · 等答话，三层都只读",
        Stage::Fresh | Stage::Ended => "配置",
    }
}
```

**等答话那一格抬头写的是 `配置 · 等答话，三层都只读`**：跑着那一句一个字没动，
新的那一句照它的形状来——前半说这一刻是哪一刻，后半说这一栏为什么按不动。
从前这一格在等答话时写着「配置」，而那一刻三层同样改不动（`Stage::read_only`）。

**压暗那一半跟着换成 `session.stage().read_only()`**（从前是 `matches!(stage, Running(_))`）。
两件事一起做：只做一件的话屏上自相矛盾——一栏压着暗、抬头却写着「配置」。
反白那一半一格没动：它按「焦点 + 只读」给，两个判断各答各的。

### `a` 那个键：判决写进词条，实现一格没动

`expanded_action` 上那一道 `if !matches!(stage, Stage::Deciding(_))` 与
`expanded_prompt` 里那一道 `if !session.deciding()` 都在原处。本票只把这个判决写下来：

- `CONTEXT.md` 的《展开》：「`a` 切全部页」后面补上「**等答话时 `a` 让给答话**
  （「剩下的卷都这样」，见**等答话**），那一刻这一副**切不过去**（列法停在按下那一下
  之前的那一副），屏底那一行也不摆它」。**措辞不是「那一刻只列要紧的页」**：
  `at_the_decision_point` 只改阶段那一维，一个字都不碰 `Expansion::listing`——
  跑着时切到全部页的那一卷走到决策点，屏上照旧列着全部页（评审提的）；
- 停车场 Q161 连同处置挪进下面的《停车场结转》。

覆盖层交键给阶段之后，这一条在 `?` 那张表上**自己显出来了**：等答话时
「任何时候」那一组里列着 `a 剩下的卷都这样（往下不再问）`——`means_the_same_everywhere`
问过每一块，`a` 在展开着那一块上此刻也交给阶段那一维，因此是「到处都是同一件事」。

### 「哪些键在哪个状态下有效」仍旧一处答完

`?` 那张表**一个键都没有另立一份**：`KeyGroup` 上没有覆盖层这一组——那张表是
**掀着的时候**在读的，它列的是[盖住的那一块](Session::beneath)上按得动什么。
覆盖层自己那几个键归 `overlay_action` 一处，屏底那一行照 `Session::reveals` 分岔。

### 屏上那两张长什么样

- **跑着时掀开 `?`**（`THE_KEY_TABLE_WHILE_RUNNING`，80×24）：屏底那一行摆着
  `s 停（按一次收尾，再按一次中止）`——**这一半从前不在**。表上「任何时候」那一组里
  那一句**从前就在**（`KeyGroup` 上没有覆盖层这一组），只是按下去没反应——

  在焦点落在哪一块上都按得动**。展开着又停在决策点上时，同一个字母有两个意思。
- **走了哪条路:** **让的是「列全部页」**：那一支先看一眼阶段，等答话时把 `a` 交回
  `stage_action`，屏底那一行跟着不摆它（屏上不摆按不动的键）。理由是等得起——
  换一副列法晚几秒没有代价，而一条停在决策点上的线程等着一个字。
- **处置：** **本票了结，照实现定下来。** 实现一格没动，判决写进 `CONTEXT.md` 的《展开》：
  「`a` 切全部页——**等答话时 `a` 让给答话**（「剩下的卷都这样」，见**等答话**），
  那一刻这一副只列要紧的页，屏底那一行也不摆它」。**「换一个自己的键」不做**：
  `?` 那张表排完之后腾得出字母，但屏上多一个只在展开着时有效的记号，
  换来的是「有一刻晚几秒换一副列法」——不值。两个意思都还在，
  收起（`Esc`）之后 `a` 照旧是答话，展开着而没停在决策点上时 `a` 照旧是列全部页。

### Q164 — 覆盖层掀着时按停与答话那三个键按不动，而 ADR 0017 决定第 4 条说它们「在焦点落在哪一块上都按得动」

- **From:** 票 `p3-session-legibility/12`
- **Kind:** 决定与实现对不上
- **Where:** `src/session/state.rs` 的 `overlay_action`（它不把不认的键交给 `stage_action`）、
  `docs/adr/0017-focus-and-a-two-dimensional-mode.md` 的《决定》第 4 条
- **现状:** ADR 0017 决定第 4 条写着「**按停与答话那三个键在焦点落在哪一块上都按得动**，
  两级语义一格不变」。`p3-session-legibility/12` 在焦点那一维上添了**覆盖层**这一个取值，
  而那一票票面第五条写死了「**覆盖层开着时别的键一律不派**」——两句话在这一块上互相排斥：
  跑着的时候掀开 `?` 那张键位表，那一刻 `s` 按不动；停在决策点上掀开它，
  `x`／`a`／`s` 三个也按不动。
- **走了哪条路（那一票）:** **照票面**：覆盖层是六块里唯一不把不认的键交给 `stage_action`
  的一块，ADR 一个字没改——改它是拍板的事。
- **处置：** **本票了结，照 ADR 走。** `overlay_action` 末一行换成 `stage_action`，
  与左栏、目录表、卷表、逐页表四块同一个形状。**两处同时改口，一处都没剩**：
  ADR 0017 决定第 2 条从「三块」改成「那几块（加上覆盖层）」、第 4 条添上
  「覆盖层掀着时也按得动」并说清它自己认下的只有 `Esc` 与 `q`；
  `p3-session-legibility/12` 票面第五条收窄成「除了按停与答话，别的键一律不派」，
  那一票的《勾得有保留》里那条判断也跟着改口指向本票。
  `CONTEXT.md` 的《覆盖层》跟着改（那一条写着「按停与答话那三个也在内」）。
  **`q` 没跟着交下去**：它既不是按停也不是答话，而交下去的话没跑过与收场了那两个阶段上
  它是退出会话——这一块的「退一步」是 `Esc`。停车场 Q163 第 5 条里那半句
  「而覆盖层上它们一个都不派」跟着改成「此刻照样按得动」。
