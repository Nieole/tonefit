# 15 — 嵌套点名收编到最外层

**What to build:** 点名两个互相嵌套的路径（`库/` 与 `库/作品/`），同一个卷会被
**发现两遍**、各写一份输出——白做一遍，盘上两份同内容不同位置的产物。

发现之后按**卷根**折一遍：重叠的点名**收编到最外层那个根**上，镜像路径以它为准。
这与「点名一个目录就把底下的卷全找出来」是同一条读法——点名 `库/` 已经包含了
`库/作品/` 底下的一切，再点一次不该改变结果。

收停车场的 **Q111**。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 点名两个嵌套的路径，同一个卷只被做一遍
- [ ] 镜像路径以**最外层**那个根为准，输出结构确定且可预测
- [ ] 预扫报出的总步数与实际做的卷数对得上（不再多数一遍）
- [ ] 点名同一个路径两遍与点名嵌套路径走同一条收编
- [ ] 非卷文件那几栏不因收编而重复列出
- [ ] 三条闸门全绿
