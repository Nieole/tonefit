# 12 — 重开归档时核一次指纹

**What to build:** 归档卷的成员表出自开卷那个句柄，字节出自重开的那个。
两者之间归档被换掉（下载工具补完、用户手动替换），并发那一支就会
**静默读到别的字节**——不报错、不退回，产物里混着两个版本。

重开时拿一次**指纹**（中央目录偏移 + 条目数，或 mtime + 大小）与开卷那一份核对，
核不上就**退回串行**读。

**不是把源再读一遍**：那会把并发省下的当场还回去一大半。指纹要便宜。

收停车场的 **Q99**。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 重开的句柄核一次指纹，核不上退回串行、并说得出为什么
- [ ] 核得上时并发照走，开销不显著（指纹不重读全部字节）
- [ ] 有一条用例造出「跑到一半被换掉」的归档，断言它退回串行而不是读错
- [ ] 那笔句柄账仍只有一处出处
- [ ] 三条闸门全绿
