# 02 — 左栏与预设栏的折行搬进折行那一层

**What to build:** 左栏与预设栏此刻走的是终端库自带的折行，而视口数的是**逻辑行**——
两个数对不上。62–81 列那一段屏上因此有两个毛病：光标走到格子外面去，
而且**内容已经被截掉、滚动条却不画**。取值栏摊开之后左栏更长，这两处更显眼。

搬过来之后屏上**一个字不变**（折出来的样子与终端库那一套相同），换来的是视口数得准、
滚动条画得出来。

这一票**推翻 `p2-loose-ends/07` 那条「左栏那两栏原样留着」的决定**——那条决定的理由是
「折在哪儿读起来都一样」，而它没算上视口。理由与代价写进那张票的修订或本票的落地记录。
