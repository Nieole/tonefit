# 13 — 摊开一整卷途中的检查点

**What to build:** `.7z` 与 `.rar` 开工前要整卷摊到临时目录。几百兆的卷上这一段要跑很久，
而**其间一条事件都不报、按中止也不停**——进度条一动不动，看着像挂死了。

给这一段加一个检查点：**按中止当场停得住，期间事件照报**。

**这是本批唯一一处新缝。** 读取那一层至今对进度、事件、指令一无所知。
做法是**把既有的观察者回路往下递一格**——不新造第二条回路、不新造第三种停法，
问的仍是 `ADR 0013` 立下的那个**页边界那一级**的检查点（管中止），
只是问的地方多了一处。理由与代价写进 `ADR 0013` 的修订或本票的落地记录。

收停车场的 **Q121**。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 摊开途中按中止当场停得住，不必等整卷解完
- [ ] 停下来时那个临时目录收干净，最终位置上一个字节都没动过
- [ ] 摊开途中报得出事件，进度条看得出在动
- [ ] 检查点仍只有两个（卷边界管收尾、页边界管中止），没有第三种停法
- [ ] 观察者那条回路的**形状**一格不变
- [ ] 有一条用例造出够大的卷，断言它在整卷解完之前返回
- [ ] 三条闸门全绿
