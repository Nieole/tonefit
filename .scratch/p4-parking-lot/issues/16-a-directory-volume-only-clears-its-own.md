# 16 — 目录卷收尾只动自己那几个成员

**What to build:** 混装目录里，一个目录卷的输出去处**同时是它兄弟卷的父目录**。
那一卷收尾时把最终位置整个换掉，于是**把兄弟卷的既有产物一起删了**。
一趟没走完（按了收尾／中止、或某个兄弟卷做不成）时，
**上一趟好好的兄弟产物跟着没了**——用户丢东西。

`ADR 0013` 那句「盘上因此只有完整的卷」在这个形状上今天弱一格。

做法：把发现的结果一路喂到写出那一层——它今天只认识「一个卷写到哪儿」，
要认得出「这个去处里还住着别的卷」。那条「最终位置整个换掉」因此收窄成
「**这一卷那几个成员整个换掉**」。「不产出半成品」与「清掉陈旧产物」两条**都要保住**。

收停车场的 **Q113**。

**Blocked by:** 15 — 嵌套点名收编到最外层（同动发现到写出那条线）

**Status:** resolved

- [x] 混装目录里一卷重做时，兄弟卷的既有产物**一个字节没动**
- [x] 那一卷自己的陈旧产物照旧清得掉
- [x] 中途失败时最终位置上不留半成品
- [x] 有一条「盘上」用例：造混装目录、跑一趟、中途按停，断言兄弟产物还在
- [x] 三条闸门全绿

> **勾得有保留，一处：第三条。** 先说这一处，再说五处判断。
>
> **第三条「中途失败时最终位置上不留半成品」勾了，但「不产出半成品」这条性质在
> 窄的那一支上弱了一格，弱在哪儿要写明。**
>
> 验收那句话问的是**这一趟中途失败**：最终位置仍旧**只在收尾这一步**被碰到，
> 中途按停、中途失败、页边界上中止都走不到那一步，最终位置上一个字节都动不了。
> 这一条一格没弱，钉它的是 `a_mixed_directory_that_fails_partway_leaves_the_whole_place_as_it_was`
> 与本文件既有的那三条。
>
> 弱的是**收尾这一步自己**。从前它是「一次 `remove_dir_all` 加一次 `rename`」；
> 去处里住着别的卷时，如今它是「逐个成员改名，再清一遍陈旧产物」。
> 收尾**自己没走完**时——搬那一步回 `Err`（改名撞上权限、盘满、腾位置那一句失败），
> 或者进程被硬杀（`SIGKILL`、掉电）——两者留下的现场不同：
>
> | | 收尾中途没走完，最终位置上是 |
> |---|---|
> | 从前（整个换掉） | **整个去处不存在**——`remove_dir_all` 成功而 `rename` 还没跑 |
> | 如今（窄的那一支） | 上一趟那一份，**加上本趟已经搬到位的那几个**——一个超集 |
>
> 换掉的次序是**搬在清之前**，就为了让它是超集而不是子集：反过来那一小段里
> 最终位置上会是一本**缺页**的书。超集这一头下一趟自己会收干净——两趟的页记着不同的指纹，
> 幂等对不上，整卷重做，重做那一趟再清一遍；而回 `Err` 那一种当场就记成一笔卷级失败，
> 用户知道这一卷没做成。
> **两相比较不算变坏**（从前那一格是「书整个没了」），但它不是一次原子改名。
> 记在 **Q304**，也写在 `sink::DirectorySink` 的文档里。
>
> **回 `Err` 那一种没有用例**：要让一次 `rename` 在同一个文件系统的同一层上失败，
> 得去改权限或者填满盘——与「磁盘不够摊不开」是同一类造不出来的失败
> （`tests/container.rs` 那几条早就认过这一笔）。
>
> 五处**判断**（不是保留，但要写明读法）：
>
> - **收尾分两支，不是一支。** 票面写的是「收窄成『这一卷那几个成员整个换掉』」，
>   照字面只留窄的那一支也做得出来，但那样**头一趟**也变成逐个成员搬进最终位置——
>   而头一趟最终位置本来不存在，逐个搬进去的那一小段里它真的是一本缺页的书。
>   宽的那一支（一次腾位置加一次改名）因此留着，且是绝大多数目录卷走的那一条。
> - **分岔的依据是「盘上此刻真住着谁」，不是那份名单。** 名单不空而借住的卷一个都还没
>   写出来（头一趟正是这样）时走宽的那一支：既安全，又只有一次改名。
>   **初稿在这里写下过一句写下时就已经是假的话**——「发现是先序的，混装目录那一卷恒排在
>   住在它里面的那些之前，因此这一问只可能答『上一趟留下的那些还在』」。
>   推翻它的是 **`p4/15` 立下的收编规则**：收编按「头一回被发现」占座
>   （`discover::Found::absorb` 只换去处、不挪位置），因此点名
>   `N和S/第1话.cbz N和S` 时那一话排在混装目录那一卷**之前**——它先写出来，
>   随后那一卷才收尾，于是这一问也答得出「**本趟**已经写出来的那些还在」。
>   **结论一格没变**（两种来路都走窄的那一支，都对），假的只是那句「只可能」。
>   订正在 `Lodgers::any_under` 的文档上，两种来路各写一条。
> - **窄的那一支上，「这一卷自己的」= 直接那一层里不通往借住的卷的一切。**
>   这条界线立得住是因为目录卷只收直接那一层（ADR 0014 决定第 1 条）：它写出的成员
>   全在那一层上，而那一层上的一个**目录**必然通往别处。清那一步因此照旧扫得掉
>   源里删掉的页、上一趟的陈旧文件、以及上一趟留下而如今没有卷指着它的整棵子树。
>   代价记在 **Q303**：一个这一趟**点不开**的兄弟卷不在名单里，它上一趟的产物照旧被清
>   ——与本票之前逐字节相同的行为，不是回归。
> - **隔离目录里，借住的卷的过期副本从此留着。** 上一趟那一话失败去了
>   `out/_isolated/N和S/第01话.cbz`、这一趟它做成了去了干净去处，而混装目录那一卷
>   这一趟失败也去了隔离——清那一步放过它，从前整个换掉会顺手删掉。
>   **留着才是与既有规矩一致的那一个**：它是**别人的**过期副本，而 `crate::superseded`
>   写着「tonefit 在别处一律不做破坏性动作，删不删由用户定」，ADR 0013 的
>   《不要做的「简化」》说的是同一件事。本票的主题就是「只动自己那几个成员」，
>   在隔离目录里破例会自相矛盾。记在 **Q305**。
> - **一处撞名今天没人查，本票没有为它新长一种失败。** 源里同时有 `001.jpg` 这一页与
>   `001.png` 这个目录卷时，两者的去处同名，而三道撞名校验一道都拦不住（**Q301**）。
>   窄的那一支腾位置那一句因此可能清掉一个借住的卷——**与从前逐字节相同**
>   （那时整个去处都被删掉）。改成「报一笔卷级失败」是新长一种失败，
>   它的口径属于撞名那一道，不在本票范围里。
>
> **对外 seam 一格没开**：`run(Request) -> Report` 没动，事件流没加格。
> `Sink::create` 多收一个参数，而 `mod sink` 是私有模块——那是 crate 以内的事。
> **`p4/15` 立下的收编规则一个字没动**：镜像路径仍以最外层那个点名根为准，
> 本票只是把它算出来的那套去处**接着往下喂**。

## 落地记录

### 一、缺的那一截：发现算出来的东西没被喂到写出那一层

`p4/15` 之后，发现那一侧已经知道「这一趟有哪些卷、各镜像到输出根下的哪里」
（`discover::Candidate::output_relative` → `survey::Surveyed::output_relative`）。
写出那一层只收到一条接好的绝对路径，于是它只答得出「一个卷写到哪儿」，
答不出「这个去处里还住着别的卷」。本票补的就是这一截。

### 二、新的那个词：**借住的卷**（`sink::Lodgers`）

```rust
/// 一个卷的输出去处里**借住着的那些卷**：各按相对那个去处的一段相对路径。
#[derive(Debug, Default, Clone)]
pub struct Lodgers(Vec<PathBuf>);
```

两个问句，就是它的全部：

- `any_under(place)`——`place` 这个去处里此刻**真住着**别的卷吗（收尾走哪一支）；
- `leads_to_one(name)`——去处直接那一层的 `name` 是通往某个借住的卷的吗（清那一步放过谁）。

它相对的是**这一卷的去处**而不是输出根，因此干净去处与隔离目录里那个去处**共用同一份**：
两棵树镜像出来的结构一模一样，隔离只是在中间插一级 `_isolated`。

词条同时进了 `CONTEXT.md` 的《输出》——实现引入了一个新概念，加进词汇表是落地的一部分。
**已有词条一个字没动**；撞见对不上的那一句记在 **Q302**。

### 三、发现那一侧：`survey::lodge`

```rust
fn lodge(volumes: &mut [Surveyed]) {
    let at: HashMap<PathBuf, usize> = /* 镜像去处 → 它在这一批里的第几个 */;
    for volume in volumes.iter() {
        for host in volume.output_relative.ancestors().skip(1) { /* 找祖先 */ }
    }
}
```

排在 `Survey::of` 那两段循环**之后**：一个卷住不住在另一个卷的去处里，得等两条镜像路径
都在手上才答得出。**逐个卷往上找祖先，不两两比**——卷数是几千的量级（点名一个库就是
几千个卷），两两比是它的平方，而一条镜像路径的级数是个位数。

比的是**镜像出来的相对路径**而不是卷根：借住这件事发生在输出那一侧，两个卷的源可以躺在
完全不同的地方却镜像到同一棵输出树上。按分量逐字节比的代价记在 **Q300**
（与 Q241 是同一把尺子的第二个受害点）。

### 四、写出那一侧：`DirectorySink::finish` 分两支

```rust
fn finish(mut self) -> Result<()> {
    let partial = self.partial.clone().expect("收尾之前临时目录恒在");
    if self.lodgers.any_under(&self.path) {
        self.swap_members(&partial)?;      // 只换这一卷那几个成员
    } else {
        self.swap_the_whole_place(&partial)?;  // 最终位置整个换掉，与从前逐字节相同
    }
    self.partial = None;
    Ok(())
}
```

`swap_members` 两步，**搬在清之前**：

1. 临时目录直接那一层——那就是本趟的全部成员——逐个改名到最终位置；
2. 最终位置直接那一层里，既不是本趟成员、也不通往借住的卷的，清掉。

借住的卷**连搬都不搬**。次序与它换来的那个「超集」写在票面上方那段保留里，
也写在 `DirectorySink` 的《换的是「这一卷那几个成员」》一节。

`Drop` 一格没动：收尾没走完就还留着那格 `partial`，析构照旧丢掉它。

### 五、外面看得见的差别

`N和S/` 一张封面加两话，跑完一趟之后源里的封面变了，第二趟**按了收尾**（停在封面那一卷
之后）。从前：

### 六、评审改掉的那几处

`code-review` 两轴跑完之后改了五处，**行为一格没动**，改的是文档与一个私有函数名：

| 来自 | 改了什么 |
|---|---|
| Spec 轴 | `Lodgers::any_under` 那句「只可能答『上一趟留下的那些还在』」是**写下时就已经是假的**——推翻它的是 `p4/15` 的收编规则（见上面那条判断）。就地订正成两种来路 |
| Spec 轴 | 收尾这一步自己回 `Err` 时的现场是宽的那一支产生不出来的，初稿的保留只写了硬杀——扩写，并记 **Q304** |
| Spec 轴 | 隔离目录里借住的卷的过期副本从此留着——初稿没写，补进 `DirectorySink` 的文档并记 **Q305** |
| Standards 轴 | **单一出处**：`out\N和S` 那个例子在 `src/sink.rs` 里写了两遍（`Lodgers` 与 `DirectorySink` 各一遍），`survey` 里还有第三遍。权威位置留在 `CONTEXT.md` 的《输出》与 `DirectorySink` 的那一节，另两处改成指过去 |
| Standards 轴 | `survey::lodge` → `find_the_lodgers`：`lodge` 当动词有歧义，而这个仓库的函数名一向是一句话 |

**两条评审建议没有采纳**，理由写在这里：

- **「`Lodgers` 该声明在 `survey` 而不是 `sink`，否则发现层反向依赖写出层」**——
  没有改。这个仓库既有的形状就是**类型与消费者同住、由生产者构造**：`survey` 早就
  `use crate::report::{NonVolumeFile, NonVolumeReason, UnreachablePlace}`，那三样同样是
  survey 算出来、别处消费的值类型。`Lodgers` 照它办，不另立一套。
- **「`Sink::create` 多收一个只对一个变体有意义的参数是 Speculative Generality」**——
  没有改。`Sink::create` 那个 `match container` 是**全 crate 唯一**知道「两种形态各要什么」
  的地方；把这一格挪到调用方，调用方就得先自己分一次形态，那才是把知识撒出去。
  那一句的文档改写成正面理由。

| **Q302** | `CONTEXT.md`《会话》末尾那句「改名成功才算数」在窄的那一支上不再字面成立（它要说的事没变，字面变了）；**没有用票面点的 Q163**，理由照 `p4/15` 的先例 |
| **Q303** | 这一趟**点不开**的兄弟卷不在借住名单里，它上一趟的产物照旧被当成陈旧产物清掉——与本票之前逐字节相同的行为 |
| **Q304** | 收尾这一步**自己**没走完时（搬那一步回 `Err`，或者硬杀），最终位置上是两趟拌在一起的一份——一个超集，但不是一次原子改名；宽的那一支产生不出这个现场 |
| **Q305** | 隔离目录里**借住的卷**留下的过期副本从此不再被顺手删掉——那与 `superseded` 那条「在别处一律不做破坏性动作」是同一条 |

**票面点的 Q163 没有用上，另开了 Q302。** 票面写「撞见 `CONTEXT.md` 对不上记 **Q163**」，
而 Q163 的标题与正文写死了它收的是《会话》那张**表**上的四条词条；本票撞见的那一句落在
同一节的**引文**上、说的是容器怎么收尾。`p4/15` 遇到同样的处境时另开了 Q240，
这里照它办。**这是本票唯一一处没有照票面字面执行的地方。**

### Q113 — 混装目录的输出去处同时是它兄弟卷的父目录，目录卷收尾时会把它们整个删掉

- **From:** 票 `volume-discovery/03`
- **Kind:** 本票造出来的缺陷
- **Where:** `src/sink.rs` 的 `DirectorySink::finish`（`remove_dir_all(self.path)` 那一句），
  与 `src/discover.rs` 定出来的那套去处
- **Why it did not block:** ADR 0014 决定第 1 条「一个目录可以既是卷又装着卷」落地之后，
  `N和S/`（一张封面 + 56 个 cbz）这一卷的去处 `out\N和S` **同时是**
  `out\N和S\第01话.cbz` 那些兄弟卷的父目录。目录卷收尾时把最终位置整个换掉——
  那是「不产出半成品」与「清掉陈旧产物」两条换来的，写在 `DirectorySink` 自己的文档里——
  于是父卷真被重写的那一趟会先 `remove_dir_all(out\N和S)`。
  **同一趟里不咬人**：发现是先序的，父卷恒是候选里的头一个，兄弟卷随后照写，末了的盘是对的。
  咬人的是**那一趟没走完**：中途按了收尾/中止，或某个兄弟卷做不成，上一趟好好的兄弟产物
  就跟着没了。源库一个字节没动，重跑一趟全回来，因此这不是不可逆的破坏；
  但 ADR 0013 那句「盘上因此只有完整的卷」在这个形状上弱了一格。
  顺带一笔：父卷没被幂等跳过的那一趟，兄弟卷的输出被删掉之后也一定重做——省不下来。
- **What this ticket actually did:** **没有动 `sink`。** 要修得改掉「最终位置整个换掉」
  这条决定（那是 `DirectorySink` 文档里明写的两条理由换来的），或者让收尾这一步知道
  「这个目录里还住着别的卷的输出」——后者要把发现的结果一路喂到 `sink`，
  而那一层至今只认识「一个卷写到哪儿」。两条都是拍板级的改动，不在这张票的范围里。
  本票把这笔代价写进了 ADR 0014 的《要认的代价》。
- **Whose call:** 拍板的人（目录卷收尾要不要保住「住在自己去处里的别的卷」）
- **处置：** **走本条自己列出的第二条出路：让收尾这一步知道「这个目录里还住着别的卷的
  输出」**（本票）。第一条出路（改掉「最终位置整个换掉」这条决定）没走——那两条理由
  一条都不必退让，退让的只是「整个换掉」的**范围**。
  发现那一侧算出来的那套去处一路喂到写出那一层：`survey::lodge` 认出「谁住在谁的去处里」，
  `sink::Lodgers` 把它交给 `DirectorySink`，收尾因此分两支——去处里此刻一个借住的卷都没有
  就整个换掉（与从前逐字节相同），住着别的卷就只换这一卷那几个成员。
  「不产出半成品」与「清掉陈旧产物」两条都保住了，弱的那一格（收尾这一步自己不再是
  一次原子改名）写在本票票面的《勾得有保留》里。
  本条说的「ADR 0013 那句『盘上因此只有完整的卷』在这个形状上弱了一格」因此不再成立；
  ADR 0014 的《要认的代价》那一条跟着改写成当前成立的事实。
