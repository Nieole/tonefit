# 16 — 目录卷收尾只动自己那几个成员

**What to build:** 混装目录里，一个目录卷的输出去处**同时是它兄弟卷的父目录**。
那一卷收尾时把最终位置整个换掉，于是**把兄弟卷的既有产物一起删了**。
一趟没走完（按了收尾／中止、或某个兄弟卷做不成）时，
**上一趟好好的兄弟产物跟着没了**——用户丢东西。

`ADR 0013` 那句「盘上因此只有完整的卷」在这个形状上今天弱一格。

做法：把发现的结果一路喂到写出那一层——它今天只认识「一个卷写到哪儿」，
要认得出「这个去处里还住着别的卷」。那条「最终位置整个换掉」因此收窄成
「**这一卷那几个成员整个换掉**」。「不产出半成品」与「清掉陈旧产物」两条**都要保住**。

收停车场的 **Q113**。

**Blocked by:** 15 — 嵌套点名收编到最外层（同动发现到写出那条线）

**Status:** ready-for-agent

- [ ] 混装目录里一卷重做时，兄弟卷的既有产物**一个字节没动**
- [ ] 那一卷自己的陈旧产物照旧清得掉
- [ ] 中途失败时最终位置上不留半成品
- [ ] 有一条「盘上」用例：造混装目录、跑一趟、中途按停，断言兄弟产物还在
- [ ] 三条闸门全绿
