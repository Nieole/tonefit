# 19 — 闩的编码收成一处

**What to build:** 闩（至今收到过最强指令）的编码今天在两个 crate 里**各有一份**，
靠两条用例分别拴着。18 号票给命令行接上两级停之后，它会变成**三份**。

收成一处。这意味着那个编码**从内部形状变成对外可见的东西**——
这是一次**对外契约的扩大**，不是新增缝：把只有两三个内部用户的形状钉进公共 API 是有代价的，
理由与代价写进落地记录。

**这是本批唯一一处动到库对外形状的地方。** 事件流不加格、决策点不单开事件、
全局条的结清不做进卷完成那一条、`Report` 不加跨两列的先后——那几条都判为不动。

收停车场的 **Q70**。

**Q183（不许断的那个空格提成公共 API）不在这一票上**——它与「库自己造的字形宽度要稳」是同一件事的两半，一起归 `30`：
两票此刻都不等谁——`18` 已经落地。

**Blocked by:** None — `18`（命令行也接上两级停）已落地，闩此刻真有三份

**Status:** resolved

- [x] 「闩只升不降」这条性质一格不变

## 落地记录

### 一、收成一处：公开的是**编码**，不是**闩**

三份手抄件（`src/progress.rs` 的 `Instruction::code`／`from_code`、`src/session/run.rs`
的自由函数 `code`／`from_code`、`src/main.rs` 的同名两个）删掉两份，留下库那一份并把它
**从私有改成 `pub`**。三处读写照旧各存各的 `AtomicU8`，只是编码那一句改成调库那一份：

| 哪一份闩 | 记的是 | 改动 |
|---|---|---|
| `progress::Standing`（库，`pub(crate)`） | 观察者答过的最强那一个 | 一个字节没改，被调的那两个方法改成 `pub` |
| `session::run::Latch`（会话） | 会话里用户按过什么 | `fetch_max(level.code())`／`Instruction::from_code(..)`，本地两个函数删掉 |
| `main::Latch`（命令行） | 命令行这一头用户按过什么 | 同上，外加 `Latch::new` 那个 `const` 也走 `Instruction::Continue.code()` |

**公开的只有两个 `const fn`，一个符号都没删。**整份 `git diff` 里 `+pub fn` 两行、
`-pub fn` 零行——这一票对外形状的全部就是这两行。

**为什么不公开一整个闩类型**（第二条路，站得住）：三份闩真正共有的只有「那个序怎么编成
一个字节」；**存什么、由谁往上推三处都不同**——库是 `fetch_max` 记答复，会话是 `fetch_max`
记按键，命令行是 `fetch_update` 升一级（还要一个只有它用得着的 `press`，交回升到的那一级）。
提一个公共 `Latch` 类型，公共 API 上多的是一个**带状态的类型**加一个**单用户方法**，
换掉的只是三行 `fetch_max`。记进停车场 **Q551**，附推荐。

### 二、「只有一份 / 三处读回来相等」靠什么钉着

**两层，一层管「别处没有第二份」，一层管「这一份用的就是它」。**

**第一层：`tests/single_source.rs` 新添一条 `the_latch_encoding_lives_in_one_place`。**
spec 的《Testing》要「出处收拢那三条各要一条『只有一处』的用例」，01 号票为此建起了这一支
（扫文件本身，不扫某个运行时取值）；本票照它的形状再添一条，三件事一起问：
别处没有第二份、家里那三格真住着、另外两份闩指回来的路标还在（各 ≥2 句）。
**真验过它会红**：往 `src/` 丢一份不编进去的假抄件（照 `from_code` 抄一遍），那一条当场红、
指名是哪个文件；删掉再跑就绿。

记号挑在**读回来那一侧**（`0 => …::Continue`／`_ => …::Abort`），两种写法各列一条
（家里写 `Self::`，别的 crate 手抄只能写 `Instruction::`）。**不挑编进去那一侧**，
因为 `Continue => 0` 那张表在本仓库有第二个正当用处——`src/session/draw/footer.rs`
的 `running_prompt` 用它说「推到这一级要按几次 `s`」，那不是抄件（记进停车场 **Q554**）。

**第二层：三份闩各一条，问的是存进去的那个字节。**

```
assert_eq!(标的.0.load(Relaxed), 那一级.code(), "存进去的不是那一份公共编码给的字节");
assert_eq!(标的.读回来,          那一级,        "推进去的那个字读回来变了");
```

- `src/progress.rs`：新增 `tests::the_latch_reads_back_what_was_recorded`（库那一份）。
- `src/session/run.rs`：`tests::the_latch_only_ever_goes_up` 里那一段（会话那一份）。
- `src/main.rs`：`tests::the_latch_only_ever_goes_up` 里那一段（命令行那一份）。

**问字节而不是问「读回来的那个字」**，这是评审改出来的一格：只问读回来的话，
`标的.get()` 的定义**就是** `from_code(load())`，而 `record` 存的**就是** `.code()`——
那一问是同义反复，本地重新手抄一份编号不同的编码它照旧绿。问字节就不是：抄件的编号一变，
这一条当场红。形状与 spec 点名的先例
（`assert_eq!(BAR_WIDTH, crate::BAR_WIDTH as u64, "横条宽度长出了第二份")`）同——
右边那一半直接指着库那一份公共编码。

**编码本身的性质收进一条**：序与力度同向、记进去读回来不变、**不认得的数按最强的算**、
默认是继续——只由 `progress::tests::the_three_instructions_are_ordered_by_how_hard_they_stop`
验，它的文档写明「这一条是那个编码唯一的出处所在」。「越界按最强」那一条从二进制那两份
搬进了它（库那一份从前没验它）。

**外加一条评审揪出来的盲区**：`main::Latch::new()`（`const`，走
`Instruction::Continue.code()`）与派生的 `Default`（`AtomicU8` 归零）是两条起手路径，
而生产里那个 `static PRESSED` 走的是前者、用例走的是后者。两者相等靠的正是那一份公共编码——
`src/main.rs` 那条用例因此多问一句 `Latch::new().pressed() == Continue`，别让它是巧合。

### 三、对外契约扩大了什么，代价是什么（票面点名要写的那一节）

**扩大的**：`Instruction::code() -> u8` 与 `Instruction::from_code(u8) -> Instruction`
从私有变成公共。随之变成契约的有三样：

1. **那三个数字**（`0`／`1`／`2`）。改一个就是破坏性变更。
2. **它们与派生的 `Ord` 同序**。
3. **`from_code` 是全函数，不认得的数按最强的算**（宁可多停一趟，不可漏停一趟）。
   这一条另记停车场 **Q553**——它是三个数字之外唯一顺手变成契约的语义。

**代价认下来是这么算的**：这个形状今天只有三个用户，其中一个是库自己；把只有三个内部
用户的形状钉进公共 API 是有代价的（票面原话）。**换来的是「按了中止却退回收尾」这件事
再也不会静默发生**——两份手抄件在**另一个 crate** 里，库不公开这一份的话它们只能各抄各的，
而抄错了没有任何一条断言够得着（`Standing` 是 `pub(crate)` 的，二进制那一侧连拿它当基准
都做不到）。**这正是「不扩大契约也收得住」那条路走不通的地方**：不公开就没有共同的基准，
连 `BAR_WIDTH` 那种「两份拴住」的写法都写不出来。

代价那一半反过来也小：三级本身是 ADR 0013 拍死的形状，`Instruction` 因此本来就不非穷尽，
公开的这两个函数不给库外多一份自由度——**造不出第四级，也读不出第四级**。

### 五、`CONTEXT.md` 加的那一段

《进度》那一节「指令只升不降」那段之后加了一段四行的散文：**闩不止一份，编码只有一份**，
而那份编码是库的公共 API。**这是加一条事实，不是改写既有词条的含义**——原有那几段
（《收尾》《中止》《检查点》《都这样》，以及《会话》里「三格各答各的问题」那一段）
一个字都没动，它们说的是**有几份闩、各答什么**，本段说的是**编码有几份、在哪儿**。
加它的理由是仓库自己那条规矩：这一票让「编码是公共 API」成了一个领域事实，
而领域事实的唯一出处是 `CONTEXT.md`；不写进去，三处代码文档就是它仅有的出处。
