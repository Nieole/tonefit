# 19 — 闩的编码收成一处

**What to build:** 闩（至今收到过最强指令）的编码今天在两个 crate 里**各有一份**，
靠两条用例分别拴着。18 号票给命令行接上两级停之后，它会变成**三份**。

收成一处。这意味着那个编码**从内部形状变成对外可见的东西**——
这是一次**对外契约的扩大**，不是新增缝：把只有两三个内部用户的形状钉进公共 API 是有代价的，
理由与代价写进落地记录。

**这是本批唯一一处动到库对外形状的地方。** 事件流不加格、决策点不单开事件、
全局条的结清不做进卷完成那一条、`Report` 不加跨两列的先后——那几条都判为不动。

收停车场的 **Q70**。
