# 27 — 「列前几条，剩下的说个数」抽一套公共件

**What to build:** 这个形状在仓库里已经有**五处**，各写各的：撞名那条拒绝、
报告里的几处清单上限、失败卷那一段、非卷文件那一段、预扫那条拒绝，
加上几何门那一句。停车场为它记了**三次**（Q45 记「现在是三处」、Q49 记「四处」、
Q115 记「五处」）——每一条都只是在数，没有一条在收。

抽一套公共件，五处共用。**共用的是形状**（列几条、剩下的怎么说），**不是句子**——
五处的措辞各不相同，条目怎么渲染做成参数。

**这张排最后**：它的施工面含报告区，而报告区在本批里还要被动好几次。

收停车场的 **Q45**、**Q49**、**Q115**。
