# 27 — 「列前几条，剩下的说个数」抽一套公共件

**What to build:** 这个形状在仓库里已经有**五处**，各写各的：撞名那条拒绝、
报告里的几处清单上限、失败卷那一段、非卷文件那一段、预扫那条拒绝，
加上几何门那一句。停车场为它记了**三次**（Q45 记「现在是三处」、Q49 记「四处」、
Q115 记「五处」）——每一条都只是在数，没有一条在收。

抽一套公共件，五处共用。**共用的是形状**（列几条、剩下的怎么说），**不是句子**——
五处的措辞各不相同，条目怎么渲染做成参数。

**这张排最后**：它的施工面含报告区，而报告区在本批里还要被动好几次。

**末尾那三小结是这个形状里最硬的一处（停车场 Q204）：** `render` 的 `non_volume_tail`、
`failed_volume_tail`、`unreachable_tail` 三个函数**逐字同形**——各自一个
`const SHOWN: usize = 5`、一句空表就回空串、一句抬头、一个「路径一行 + 原因一行」的循环、
一句「……另有 N X」。差的只有抬头那句话、字段名与量词（个／卷／处）。
Q45 当初说「三处各不相同」，因此不值得抽；如今**五处里有三处一个字不差**，
那条理由在这三处上不成立了。抽件先从它们下手，剩下两处（撞名那条拒绝、几何门那一句）
条目形状不同，按参数收。
