### 一、抽出来的是什么：`tonefit::listing`

新模块 `src/listing.rs`，公共面两样：

```rust
pub const LIST_LIMIT: usize = 5;
pub struct FirstFew<'a, T> { .. }
impl FirstFew { pub fn of / at_most;  pub fn stacked / strung }   // 公共面只有这四个
```

**`shown` / `rest` / `says_the_rest` 三个是私有的**：调用方要的是**一整段摆好的字**，
而两副排版都住在本模块里。开出去等于给「剩下的怎么说」留第二条路——那正是本模块要收的东西
（评审 Standards 轴判的 Speculative Generality，见第八节）。

**共用的是形状，不是句子**（票面写在最前面的那条硬约束）：

| 共用的 | 不共用的 |
|---|---|
| **列几条**（`LIST_LIMIT`，点名头几页那一句自己给一个更小的） | 抬头那句话（六处一个字都不一样） |
| **收口那一句怎么说**（`says_the_rest` 出的 `另有 N X`） | 量词（个／卷／处／页）——入参 |
| **两副排版**（`stacked` 摞成一块 / `strung` 串在一句里） | **条目怎么渲染**——一个闭包，六处各写各的 |

**它在库里，不在界面层**：说这一句的几张嘴里**有两张在库内**——预扫那条拒绝与撞名那条拒绝，
两段字都是库自己写下、直接落到 stderr 上的。收口那一句留在界面层，等于把它劈成两份。

**这与[字形约定](../../../CONTEXT.md)不是同一条理由**（评审 Standards 轴指出来的，
我头一版把两条并着说了）：那一条是「库会把自己造的字直接送进一条对齐的**列**里，
规矩得跟着字递过去」，这一条是「同一句话从几张嘴里出来，其中一张在库内」。
两条都让库担了一点界面层的事，买的东西不同。`src/lib.rs` 顶上那段
「三个 seam 之外另有**一样**对外的东西」跟着改成两样，**两条各说各的理由**。

**与 ADR 0016 的那道张力，摊开写在 `src/listing.rs` 上**：决定第 2 条逐字点名
「点名的头几页 `001.png、002.png，另有 5 页`」是**措辞**，决定第 3 条说措辞只有
`render` 一处。收口那一句搬进库里**没有造出第二处出处，只是把那唯一一处挪进了库**——
与互锁那几句话（`Interlock` 的 `Display`）同一类，而 ADR 0016 自己认下的那处例外
说的正是这件事。**ADR 原文一个字没动**：给一条决定添一支是改决定，不是订正说法
（与 25 号票对 Q202 的判法同一条），记进 **Q606**。

**`--no-default-features` 上一条 `dead_code` 都没有**：`listing` 是 `pub mod`，
公共项不会没有读者。21 号票踩的那个坑（`session` 整个模块不在、新函数因此死掉）
在这一票上不成立——两处库内调用点在两种构建里都在。

### 二、六处调用点，以及那个「3 不是 5」

| 哪一处 | 上限 | 摆法 | 量词 |
|---|---|---|---|
| `render::non_volume_tail` | `LIST_LIMIT` | `stacked` | 个 |
| `render::failed_volume_tail` | `LIST_LIMIT` | `stacked` | 卷 |
| `render::unreachable_tail` | `LIST_LIMIT` | `stacked` | 处 |
| `survey::refuse` | `LIST_LIMIT` | `stacked` | 个 |
| `lib::ensure_no_two_volumes_share_an_output` | `LIST_LIMIT` | `stacked` | 处 |
| `render::first_few_names` | **自己给的 3** | `strung` | 页 |

**那个 3 没有被拍平成 5**（票面点名的那条）：它不是清单，是一句话里的抓手——
真要逐页看，逐页那几行一页不落地列着。`FirstFew::at_most` 的文档写着
「给别的数要有别的理由」，而钉着这件事的是一条会红的用例
（`listing::tests::a_handhold_may_name_fewer_than_a_list_does`：同一批条目上
`at_most(_, 3)` 与 `of(_)` 各问一次，把 `at_most` 写成忽略入参当场红）。

**六处的输出逐字节相同**，收拢前后逐处比过：
`stacked` 出的收口那一行是 `  ……另有 N X\n`（五处从前各写一遍的正是这一句），
`strung` 出的是 `甲、乙、丙，另有 N 页`。

### 三、「只有一份」怎么钉——钉的是「抄出第二份会红」

**前车之鉴那一条**：五处的措辞一个字没变，收成一处之后任何「两处读回来相等」的断言
都必然是同义反复。因此没有写那种断言，走 19 号票开的那条路——
`tests/single_source.rs` 加第三条 `the_way_to_truncate_a_list_lives_in_one_place`，
与那个文件里另外两条同一个形状，**三件事一起问**：

1. **别处没有第二份**——记号是 `另有 {`（「另有」后面紧跟一个占位符）。
   挑这个形状而不是「另有」那两个字，是因为那两个字在本仓库的散文里有十几处
   （「另有一处」「另有人」「另有去处」），拿它当记号会把真话全判成抄；
   而**把这一句现拼出来**只有一处要做——它报的是一个当场算出来的数。
2. **家里那两格真住着**——`pub const LIST_LIMIT: usize`（**只问名字，不问值**：
   把 `= 5` 一并抄进记号，这个用例就成了仓库里第二处写着那个数的地方）与那句话本身。
   少问哪一格，把那一格删掉这一条都还是绿的。
3. **用着它的那三个文件还在用**——`FirstFew` 在 `src/render.rs` 至少 9 处、
   `src/survey.rs` 与 `src/lib.rs` 各至少 3 处。这一问拦的是第 1 问拦不住的那一种：
   某一处把它拆回去自己数，**而且连收口那一句一并省了**（只列前几条、剩下的一个字不说）。

### 四、Q574：隔离那一小结那句指路（21／22 交接过来的活）

那一句从前是「原因逐条**列在上面**」。「上面」是一句关于**这一副印出来长什么样**的话，
而措辞这一层不知道正文折没折（ADR 0016 划的正是这条线）——折起那一副（`--brief`）
把正文整个折掉，**会话里没展开的那一卷同样一行不印**：那句话在这两处都指着一段不在场的正文。

改成 **「原因逐条写在各卷的逐页那几行上」**：点名那几行是哪几行，三副里句句成立。
**这是本票唯一一处输出变了的地方**（验收第 3 条要的「逐条说得出为什么」就是这一条）。
**丢的信息一格没变**——折起那一副本来就看不到逐页，变的只有这一句还骗不骗人；
剩下那一半（要不要在折起那一副里把隔离的那几卷逐条列出）是排版决定，
Q574 本来就留给拍板的人，转记进 **Q602**。

**收掉一条既有停车场条目是三个动作，不是嘴上说一句**（这一条是评审 Spec 轴抓出来的：
我头一版只在票面里当它收了，而 Q574 的原文还躺在《待处理》里、写着
`处置：待处理`、`What this ticket actually did: 一个字没改`——后来人会照它再做一遍）：

1. **从《待处理》里摘出来**，那一段整条不再留在上面；
2. **原文转进票据的《停车场结转》**（`.scratch/非阻塞问题.md`《已了结》那一节自己的规矩：
   「条目原文已挪进对应票据的《停车场结转》」），并在原文末尾把 `处置：` 那一行改写成
   **这一票怎么处置的**、以及没收的那一半转去了哪儿；
3. **《已了结》表里添一行索引指回来**（`| Q574 | … | p4-parking-lot/27《停车场结转》 |`）。

同一趟把 Q45／Q49／Q115／Q204 那四行的去处也补齐了《停车场结转》四个字——

#### 「记号抄了值」——这不是「永远绿」，是**断言自己变成了它要防的那个重复**

这一批攒下的四条教训都是**永远绿**那一类：断言是同义反复，把实现改坏它不红，
而**变异测试抓得到**——改一处、看它红不红，当场露馅。

`TRUNCATION_HOME_MARKS` 里那个 `= 5` 是**第二类**，此前没人命名过：

- 它**不是永远绿**。把 `LIST_LIMIT` 从家里删掉，这一条当场红——断言本身好使；
- **变异测试抓不到它**。任何一处实现改坏，它照旧按设计红或按设计绿，行为一格不差；
- 抓得到它的只有一问：**「这条断言自己算不算第二份？」**
  而这条用例存在的全部理由就是「上限只有一处出处」——它把 `5` 抄进记号的那一刻，
  仓库里写着那个数的地方就成了两处，**验收第 2 条被钉着它的那条断言自己破坏了**。
  更坏的一半是：那天真要改上限，这一条会以「家里少了那一格」这句**错话**变红，
  把人引到用例上去，而该改的是那一个常量。

判法因此是一句：**扫描式的断言，记号里只许有「名字」，不许有「值」**——
名字是「这件事住在哪儿」，值是「这件事是什么」，而后者正是它要保证只有一处的东西。
（`tests/single_source.rs` 另外两条本来就守着这一条：拒绝执行那一条的记号是词条**字样**，
闩那一条的记号是 `0=>Self::Continue` 那种**形状**，都不是某个可调的取值。）

### 七、函数签名：既有的一个都没动

派活说明点名要报的那一项。**六处调用点的签名逐个原样**——

`mod` / `pub use` 的落点。
