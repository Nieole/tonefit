# 28 — `CONTEXT.md` 那批词条一次改齐

**What to build:** 词汇表里有一批词条说的还是上一批之前那一副屏，
而 `CLAUDE.md` 写着「类型名、模块名、测试名、issue 标题一律取自它」——
取不出来，那条规矩就执行不了。

**这一票就是那次拍板**（`CLAUDE.md`《改 CONTEXT.md 的规矩》：改写已有词条的含义要先拍板）。
逐条改到与实现一致：

- 《失败》的**拒绝执行**从五种改**六种**（1 号票收拢之后只改一处）；
- 《模式》那句「一个文件都不落盘」写明它说的是**输出**；
- 《会话》那句「两条横条边跑边画的『已用』与『剩』」改成总览块；
- 《视口》那一条列的三处补上报告区那两张表；
- 《展开》《砍列》补上逐页表与目录那一级；
  （**《折行》补三条判据那一项归 `30`**——硬空格那一条要等它提成库的公共 API 之后才写得准，而禁则与缩进那两条与它同一句，劈开会让一个词条被两张票各改一半）；
- 《卷表》《下钻》《行》三条各有一句对不上；
- 《焦点》那个「六个」现在是第八个取值。

顺带把 **08 号票**定下的那一条写进去：**出事行答「此刻」、末尾小结答「已定案」**——
两个不同的问题、两个答案，不是一个数摆两处。

**《失败》那一条不只是漂移，此刻是一句读得出的自相矛盾（停车场 Q173）：**
`01` 号票把五份抄件收成指路之后，整个仓库里说得出「输出根写不进去算拒绝执行」的
**只剩 `src/lib.rs` 的 `ensure_the_output_root_takes_a_write` 那一句**——
而它偏偏是一句指路，指过去看到的五项里没有它。行为一格没错（那一种照旧拒得住，
`tests/isolation.rs` 钉着），错的只有文档。**本票落地那一刻这条自动消失。**
