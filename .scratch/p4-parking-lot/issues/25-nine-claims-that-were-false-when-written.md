# 25 — 九处「写下时就已经是假的」说法订正

**What to build:** 交付过的文档里有九处与事实对不上。
`docs/agents/issue-tracker.md` 把这两类分得很清楚：

> 交付记录**不因后来的工作被改写**；**订正一条写下时就已经是假的说法不算改写——
> 那是记录里的缺陷**。

**逐条判它属于哪一类**：写下时就假的**就地订正**，后来才被取代的**原文不动**、
由后来那张票的记录承担。

九处：`fast` 模式在实现里并不存在；spec 那句「解码一步就会吃光单页预算」被剖面证否；
折算系数 8 的两处残留；「卷根整个消失」的判据写成「一页都没成」；
《卷至少有一页》与《非卷文件》两节互相打架；ADR 0012 决定第 1 条与改过的第 3 条对着说；
补全候选那条与 spec 的表相抵；「八块面板 / 二到五个型号 / 31 个内置型号」
（实测 12 块 / 1 到 7 个 / 34 个）；「顶上三个框九行」（屏上只有两个框六行）。

顺带两笔：**`.rar` 默认固实**那句订正成实测的说法（行为不改，见 17 号票）；
**`docs/agents/gate.md` 说一句构建前提**——那一份此刻三条命令一句前提都没写，
而这个仓库**有两条**，两条都是「换一台机器就要重新备」的那一类：

- **C++ 工具链**（停车场 Q123）——收下 `.rar` 之后 `unrar-ng-sys` 的 `build.rs` 要用 `cc`
  编 UnRAR 的 C++ 源码。`06` 之前 tonefit 的依赖树里一个 C/C++ 编译单元都没有，
  clone 下来只要一个 Rust 工具链就构建得起来；如今换一台没装 MSVC／clang 的机器，
  第一条闸门就跑不起来，而报错来自 `cc`、与 tonefit 无关；
- **dav1d 系统库与 `PKG_CONFIG_PATH`**——`image` 的 `avif-native` 特性把 AVIF 解码交给 dav1d
  （spec 的《输入》：解码覆盖 AVIF，而 B 类素材整批是有损 AVIF）。
  `p0-core-pipeline/spec.md` 早就认下了这笔代价（「代价是构建与链接依赖 dav1d 系统库，
  **换机器需重新备好**」），但那句话住在一份 spec 里，**跑闸门的人不会去读它**。
  本机是 vcpkg 装的 dav1d，环境里没有 `PKG_CONFIG_PATH` 时平时靠 `target/` 里的旧产物蒙混，
  **一旦构建指纹失效（`24` 号票加 workspace 那次就是）当场红**，而报错来自 `pkg-config`。
  写清要什么、以及本机那条路径长什么样。

**两条都只写「跑得起来需要什么」，一个决定都不改。** 尤其 dav1d 那条：
`measurements` 的《AVIF 解码的可用路径》里另有一条产物无系统依赖的路（`zenavif`／rav1d，
构建期改要 NASM），而选它要重跑 AVIF 解码吞吐——那是另一张票，不在这里判。

**再添一处（停车场 Q194）：** `p4-parking-lot/08` 票面验收第四条写着
「80×24 上两条横条连同**步数与已用整条在屏上**」——量下来这一档上做不到，
且与横条宽不宽无关：主区 30 列里能写字的 28 格，而全局那一行不带横条已经 31 格。
已拍板**认下省略**（窄档没有横条、正文从中间省略），这一条因此要改口。
判它属于哪一类与上面那九处同一条：写下时就假的就地订正，后来才被取代的原文不动。

**本轮 `/settle` 又并进来四处**，判法与上面那九处同一条：

- **ADR 0016 决定第 2 条那句示例里的分隔记号还写着 `·`**——`p4-parking-lot/05` 把它换成了
  `⋅`（U+22C5），那一条说的道理一个字没变，插图里的字形却与实现对不上（停车场 Q185）；
- **ADR 0014 决定第 5 条只列了归档那一支，如今那里有三支**——`11` 号票给「发现的**目录**
  走不进去」开了第三支，而**退出码进 `3`**。那一条不是错的，是**不全的**，
  而末一句「退出码一格不动」照字面读会把第三支也算进去（停车场 Q202）；
- **spec 的《取值栏》说取值栏带着「下钻到第几层」，实现记的是「下钻进了哪一块面板」**
  ——`p3-session-legibility/05` 与 `06` 两处落地记录都点过这一句。
  它属于「后来才被取代」还是「写下时就假」，正是本票要逐条判的那一问（停车场 Q179）；
- **`p4-parking-lot/02` 票面第五条说「四档现存快照照旧通过、不必重录」，实际重录了两张**
  ——两套折法在折得起来的宽度上本来就不同，Q136 写下那一刻就点着这一条。
  重录的两张逐格核对过，变的是折在哪儿与缩进，一个字都没多也没少（停车场 Q176）。
