## 落地记录

### 一、卷表光标停得上没做成的那几卷（Q159）

**`Volume` 添了第三档**（`src/session/live.rs`）：

```rust
pub enum Volume {
    Settled(usize),
    Failed(usize),          // 指进 `Report::failed_volumes`
    Summarized { after: usize },
}
```

它答的是**「卷表上停得住的那几卷各是哪一卷」**，而没做成的那几卷在表上占着一行——
**一行看得见就该选得中**。`Live::volumes` 因此收下它们，次序与卷表摆行的次序**逐格相同**
（收摊了的 → 没做成的 → 决策点上攒着的那一份）。

**`Branch::failures` 那一列没了。** 从前一枝底下的卷分两处存（`volumes` 收停得住的、
`failures` 收没做成的下标），此刻**一枝底下有几行，`volumes` 里就有几卷**——
同一批东西两处存就是两个出处，而卷表、目录表、`↑↓`、`⇥` 四处都读它。

**停得住 ≠ 展得开**，判据只有一处：

```rust
impl Volume {
    pub fn expandable(self) -> bool { !matches!(self, Self::Failed(_)) }
}
impl Branch {
    pub fn expandable(&self) -> Vec<Volume> { /* volumes 里展得开的那几卷 */ }
}
```

三处问它：`⏎`（展不开就说一句）、`⇥`（只在展得开的那几卷之间转）、
报告区抬头上那个「第 n/m 卷」（分母是展得开的那几卷——`⇥` 转不到的不该算进分母）。

**按 `⏎` 时那一句**（`src/session/terminal.rs`）：

```rust
const CANNOT_EXPAND: &str =
    "这一卷展不开：它一整卷没做成，连一份卷报告都没有，逐页那几行无从谈起——行尾那一句说的就是为什么";
```

它**不重说那一卷为什么没做成**：那句原因跟在同一行的行尾，出自 `render::failed_volume`
（措辞一处，ADR 0016）。这一句只答「按下去为什么没有第二层」，并指回屏上已经写着答案的地方。

**跟随分出去了一处**（`Live::latest`）：`Follow::Latest` 从前读 `volumes().last()`，
此刻读「最新**收摊**的那一卷」。没做成的那几卷排在收摊卷后面（Q151），跟随落上去之后
后面每收摊一卷它都还钉在原地——「跟着最新的走」当场成假话。一卷都还没收摊时它退到
表上最后一行（那时屏上有行就该有光标）。`Live::nearest` 的兜底跟着改读 `latest`：
那一道收下来的东西随后多半要展开，收到一卷展不开的上面等于把人推进「这一卷不在这一趟的报告里了」。

**`↑↓` 一枝都不跳了**：`next_branch` 从前先把「一卷都收不住的那几枝」滤掉，
那一道随 `Branch::volumes` 收下没做成的那几卷一起没了。

**`expand` 劈成两半**：`expand`（找那一趟要报告）与 `expanding(&mut Session, &Live, Action)`。
后者测得动——用例造得出一份 `Live`，造不出一趟真跑着的（起线程那一处在 `session::run`）。

### 二、逐页表收进那五格（Q162）

`PageColumn` 从六列变成**十一列**，从左到右三段：**这一页是谁**（记号 · 页名）、
**它这个样子是怎么来的**（尺寸 · 裁边 · 缩放 · 跨页 · 彩页）、**它判成哪一档、凭什么**
（判定 · 理由 · 判据），末一格是**去处**。

五格逐格对着 `render::pages` 出的那几格，一个字都没在这一层重写：

| 列 | 格 | 从哪一行来 |
|---|---|---|
| 裁边 | `Field::Crop` | 几何那一行（一个像素都没裁就不在场） |
| 缩放 | `Field::Scaling` | 几何那一行（**失败页说的是它的尺寸从哪来**） |
| 跨页 | `Field::Cut` | 几何那一行（不是切出来的就不在场） |
| 彩页 | `Field::ColorToGray` | **判定那一行**（不是彩页转灰就不在场） |
| 去处 | `Field::Output` | 几何那一行 |

**兜底退回那一格仍不进表**，而它不是漏掉的：那件事由行尾那个词（`兜底上界`）说，
两处都摆就是同一件事说两遍。

**砍列次序八步，仍只有 `PageColumn::DROPPED_IN_TURN` 一处出处**：

```
去处 → 裁边 → 跨页 → 彩页转灰 → 判据 → 尺寸 → 缩放 → 理由
```

排法按「这一副要答的那一问」——**哪一页把整卷拉下来**：去处离那一问最远（一整条路径，
最宽的一格）；几何那三格说的是「这一页的形状是怎么来的」，比判定隔着一层；
判据是证据，比结论深一层；缩放是几何那一组里**唯一压到最后的**，只为一件事——
失败页那一行靠它说出「它的尺寸是卷内统一尺寸」，那一句在别处一个字都没有。
记号、页名与判定照旧不在这个次序里（`p3-session-legibility/13` 立的那三格）。

**另添一步与宽度无关的第零步**（`columns::fit`，三张表共用）：

```rust
let mut kept: Vec<C> = C::ALL.iter().copied()
    .filter(|column| widths.filled(*column) || !C::DROPPED_IN_TURN.contains(column))
    .collect();
```

**一整列都不在场时那一列连列头都不占。** 非有它不可：多数卷一页都没裁过、没切过、
没有彩页转灰，三个空列头挤掉的正是判据那一串。`Widths` 因此多记一笔「这一列上有没有
一格真写着字」——**列头不算一格字**，它是这一列的名字，不是这一列上的内容。
**只让得掉砍得掉的那几列**：恒在的那几列是这张表的身份，空着也留着（那时那一格的空白正是答案）。

### Q159 — 卷表上的光标跳过没做成的那几卷，而它们在表上占着一行

- **From:** 票 `p3-session-legibility/10`
- **Kind:** 路过发现
- **Where:** `src/session/live.rs` 的 `Live::volumes`（光标走的那一列）、
  `src/session/draw/table.rs` 的 `Entry::at`（没做成那一行是 `None`）
- **现状:** 报告区那个光标停得住的是**说得出报告的那几卷**——收摊了的那几卷，
  加上决策点上攒着的那一份。**没做成的那几卷停不上去**：它们连一份卷报告都没有
  （`VolumeFailure` 只有一句原因），逐页那几行无从谈起，光标停上去按 `⏎` 没有第二步。
  表上它们照旧占一行（红、行首 `✗`、那句原因跟在行尾），于是 `↑↓` 一路按下去
  会**从它们上面跨过去**——屏上看得见一行，光标却停不上。
- **Why it did not block:** 两条路都说得通，而本票没有依据挑一条：
  停得上去要给它一个「按了有话说」的展开（与 `t`／`x` 在型号没挑时的待遇同一条），
  停不上去则是「屏上不摆按不动的键」的字面。两条都不影响这一票要的那几件事
  （选一卷、展开它、跟随停不停）。
- **What this ticket actually did:** **走了「停不上去」那一条**，并把理由写在
  `live::Volume` 的文档上（「没做成的那几卷不在这里」）与 `table::Entry::at` 上。
  ADR 0017 的《后果》把这一笔当作要认的代价记着。
- **Whose call:** 拍板的人（光标要不要停得上没做成的那几卷；要的话，`⏎` 在那一行上说什么）
- **处置：** **了结。**光标此刻**停得上**没做成的那几卷，而 `⏎` 停在那一行上**明说这一卷展不开**
  ——走的正是这一条列出来的两条路里的头一条（与 `t`／`x` 在型号没挑时同一条待遇）。
  `Volume` 添了 `Failed(usize)` 那一档（指进 `Report::failed_volumes`），
  `Live::volumes` 与 `Branch::volumes` 因此**与卷表上那几行逐行对得上**；
  `Branch::failures` 那一列没了——两处存同一批东西是两个出处。
  **停得住与展得开分成了两件事**：`Volume::expandable` 一处答后者，
  `⏎`、`⇥` 与抬头上那个「第 n/m 卷」三处都问它。
  那一句话在 `session::terminal::CANNOT_EXPAND`，它不重说那一卷为什么没做成
  （那句原因跟在同一行的行尾，出自 `render::failed_volume`）。
  **排序一格没动**（Q151 照旧认下），**跟随也没跟到它们身上**（新记的 Q200）。

### Q162 — 逐页表把裁边、缩放、跨页、彩页转灰、去处五格留在了表外

- **From:** 票 `p3-session-legibility/11`
- **Kind:** 本票认下的一处折扣
- **Where:** `src/session/columns.rs` 的 `PageColumn`（这张表有哪几列）、
  `src/session/draw/pages.rs` 的模块文档《表有意不带的那几格》
- **现状:** 展开那一副从前是把 `render::plain::pages` 那一段散文原样摊出来，逐页两行
  什么都有；改成表之后列只剩六个（记号 · 页名 · 尺寸 · 判定 · 理由 · 判据），
  **裁边、缩放、跨页哪一侧、彩页转灰、去处五格不进表**。跟着丢掉的有一句话：
  失败页那一行从前说得出**它的尺寸是卷内统一尺寸**（`Field::Scaling` 那一格，
  `p1-session/11` 的验收），表上它此刻只剩尺寸与行尾那句原因。
- **Why it did not block:** 票面第一条写死了「逐页也是一张表，与卷表同一套砍列」，
  而 120 列的屏上判定加理由加判据已经占满——多一列就要从判据那一串里砍。
  丢掉的那几格**命令行印出来的那一份一格不少**（同一批格，另一副排版，ADR 0016），
  而这一副要答的是「哪一页把整卷拉下来」。
- **What this ticket actually did:** 六列定在 `PageColumn` 上，砍列次序（判据 → 尺寸 → 理由）
  与它并排；不进表的那五格连同理由写在 `pages.rs` 的模块文档里。
- **Whose call:** 拍板的人（要不要给逐页表添一列缩放，代价是窄终端上判据更早被砍掉；
  或者给失败页那一行补一句「卷内统一尺寸」）
- **处置：** **了结。**五格全进表——`PageColumn` 从六列变成**十一列**：
  记号 · 页名 · 尺寸 · **裁边** · **缩放** · **跨页** · **彩页** · 判定 · 理由 · 判据 · **去处**。
  失败页那一行因此又说得出**它的尺寸是卷内统一尺寸**（那一句就在缩放那一格里，
  `p1-session/11` 的验收回来了）。
  **这一条列出来的那个代价照收**：砍列次序把判据排在缩放前面，窄终端上判据更早被砍掉
  ——136 列的屏上此刻是「缩放在、判据让掉」，而 80×24 上仍是记号 · 页名 · 尺寸 ·
  缩放 · 判定 · 理由六列。次序仍**只有 `PageColumn::DROPPED_IN_TURN` 一处出处**，
  八步：去处 → 裁边 → 跨页 → 彩页转灰 → 判据 → 尺寸 → 缩放 → 理由。
  **另添了一步与宽度无关的第零步**（三张表共用）：一整列都不在场时那一列连列头都不占
  ——多数卷一页都没裁过、没切过、没有彩页转灰，不砍掉那三个空列头，挤掉的正是判据那一串。
  **哪几列在场按整卷算，不按这一副列出来的那几页算**（`Widths::note`）：
  彩页转灰与跨页都不在「要紧的页」那七种里，按 `shown` 量的话，一个只管「列哪几页」的
  `a` 会连整张表的列一起换掉。
  **那个代价在行这一维上还有一半**：缩放那一格宽 25 格，80×24 上行尾那几句因此恒定折行
  ——一页从占一行变成占两行，一屏看得到的页数少一半。票面那两条验收只量列、不量行，
  这一笔在这里记着。
