# 07 — 屏底从按键表取键，`?` 再滤一道，打字那两块也调得出全部键

**What to build:** 三件让「屏上不摆按不动的键」真正成立的事：

- **屏底那一行的键从按键表取**，不再手抄。今天同一个键在屏底与 `?` 那张表上有两处措辞，
  改一处漏一处。每句提示因此要**长短两份**：短的给屏底、长的给那张表；
- **`?` 那张表再滤一道**：滤掉「按键表派得出、而输入那一层挡着」的键——
  今天表上列得出它们，按下去却没反应；
- **编辑一行与打预设名那两块也调得出全部键。** 那两块上每一个字符都进缓冲，
  `?` 与 `i` 也是字，所以屏底摆不出「`? 全部键`」——「看不见的东西等于不存在」
  在这两块上因此仍旧成立。给它们一个**不进缓冲的键**。会话此刻只认十二个键码，
  这要往输入那一层加一个。

收停车场的 **Q165**、**Q166**、**Q167**。

**Blocked by:** 03 — 取值栏那两层照实现定下来；06 — 覆盖层交键给阶段

**Status:** resolved

- [x] 屏底那一行的键出自按键表，同一个键不再有两处措辞
- [x] 长短两份措辞只有一处出处，屏底取短的、`?` 那张表取长的
- [x] `?` 那张表上没有「派得出、而输入那一层挡着」的键
- [x] 打字那两块上有一个不进缓冲的键调得出全部键，屏底提示得到

>
> - **屏底那一行摆哪几个键，此刻由按键表一处答完；摆哪几件事仍由屏底这一层挑。**
>   那一层挑的是**动作**（「就在这一行上动手」「试算」「退出」），派得出它的是哪几个键、
>   那一句怎么说，一律问 `Session::keys_here` 与 `draw::keys::says`。

>   左栏上印的是 `Esc Ctrl-C q 退出`。次序照 `every_key`，不是屏底自己排的——

>   前提那一张的那一句连同它那道闸整个删掉，展开那两支（`expand`／`open`）的留着并
>   在文档里点名「这一支到不了」（`Running::live` 的取值域上它在，而悄悄什么都不做更坏）。
> - **`?` 那张表第三道滤只加在「任何时候」那一组上。** 判据是「此刻按下去有没有第二步」：
>   别的块上那几行说的是「**站到那一块上**按它做什么」，而「任何时候」那一组宣称的正是

> - **评审提的四条都收了。** 一条是真的：屏底那句「按 ⇥ 列出这一层」从前无条件摆着，
>   而 `⇥` 只有路径项补得动——改文本项时上一行不摆那个键、下一行却劝人按它，

## 落地记录

### 一、屏底那一行的键出自按键表：长短两份措辞一处出处

新模块 `src/session/draw/keys.rs`——**屏上摆键的那两处共用的一份**：

```rust
pub(super) struct Says {
    /// 屏底那一行上那一句：**提示**。
    pub(super) short: &'static str,
    /// `?` 那张表上那一句：**解释**。
    pub(super) long: &'static str,
}

pub(super) fn says(group: KeyGroup, stage: Stage, action: Action) -> Says
pub(super) fn spelled(key: Key) -> String
pub(super) fn merged(group, stage, keys: &[(Key, Action)], wording: Wording)
    -> Vec<(String, &'static str)>
```

`says` 从 `draw/overlay.rs` 挪了出来，连同 `spelled` 与 `merged`：那三个从前是
`?` 那张表私有的，而屏底那一行手抄第二份。**两处此刻走同一条路**——
`merged` 把「派得出同一句话的那几个键」并成一行（`↑ ↓ j k` 是一件事，不是四件），
覆盖层取 `Wording::Long`，屏底取 `Wording::Short`。

键那一头由状态机新出的一条答：

```rust
/// **眼下这一块上派得出动作的每一个键**，连同它派的那件事，次序照 [`every_key`]。
pub fn keys_here(&self) -> Vec<(Key, Action)>
```

与 `key_table` 差的是问的对象：那一张问**每一块**（屏上此刻不在的那几块也列），
这一条问**眼下这一块**——屏底那一行答的正是「此刻按什么」。它因此不过
「到处都是同一件事」那一道滤：屏底不分组，一个键摆一次就够。

屏底那一层因此只剩「摆哪几件事」：

```rust
fn config_prompt(asked: &Asked) -> Prompt {
    with_stage(
        asked,
        vec![
            asked.hands_on(),
            asked.on(|action| matches!(action, Action::Start(_))),
            asked.on(|action| matches!(action, Action::Focus(_))),
        ],
        String::new(),
    )
}
```

`Asked` 是「问出来的那一份」：`keys_here` 出的那张表，加上**屏上这是哪一块**
（`KeyGroup::of(focus)`）与**这一趟走到哪个阶段**——措辞随这两样变
（同一个 `Esc`：取值栏上是「一格不改地退一步」、编辑到一半是「丢掉」；
同一个 `Ctrl-C`：跑着时那一句要说出「当前卷中止，盘上不留半卷」）。

**跟着一起没了的手抄**（都不必再在屏底那一层判一次，问出来就是空的）：

| 从前手抄的 | 此刻问出来的 |
|---|---|
| `⇥ 报告区` 只在 `Stage::Ended` 时摆 | `browsing_action` 那一道 `if` 说了算 |
| 展开着时 `a 列全部页` 等答话不摆 | `expanded_action` 把那个字母让给答话 |
| 报告区那一行 `i` 要 `live.is_some()` | 一趟都没跑过时它根本不派（见二） |
| 按到中止之后不摆 `s` | `running_action` 在那一级上派 `Ignored` |
| 打预设名时恒摆 `⏎ 存下` | 一个字都没打时 `⏎` 是「算了」，摆的因此是 `⏎ Esc 回列表` |
| `Overlay::prompt()`（`? 全部键` 那句拼法） | 整个删掉——键出自按键表，措辞出自 `says` |

**Q180 就此了结**：取值栏那两层上三个键同义，屏底此刻印 `→ ⏎ 空格 定`。

**留下的两处，都记在新的 Q190**：一趟都没跑过时总览块与报告区各说的那一句里
`t`／`x` 仍是手抄的（`START_KEYS` 从 `footer` 挪进了它唯一的用处 `overview`）；
屏底那几句**说明**里也各提着一个键（`按 ⇥ 列出这一层`、`按 x 接着做第二遍……`、
`g 把它交回给最新那一卷`）——那几句是散文，不是按键那一行。

### 二、`?` 那张表再滤一道：判据是「此刻按下去有没有第二步」

两处来源，各走各的路：

**按键表自己那一头**（Q167）——一趟都没跑过时那两支根本不派：

```rust
Key::Char('e') if self.stage == Stage::Ended => Action::Expand,   // browsing_action

fn revealing(key: Key, stage: Stage) -> Option<Action> {
    match opens(key)? {
        Overlay::Premises if stage == Stage::Fresh => None,
        overlay => Some(Action::Reveal(overlay)),
    }
}
```

**「任何时候」那一组多过的那一道**（Q189）——它宣称的是「此刻在哪一块上都按得动」：

```rust
if group == KeyGroup::Always && self.action(key) != action {
    return None;
}
```

覆盖层掀着时 `q` 一个动作都不派（那一块的「退一步」是 `Esc`），而底下那几块上它是
退出会话——照实列的话表上白纸黑字写着 `q 退出会话`，按下去却没反应。
掀着的那一张自己那个键同理：按回去是**关掉**，不是再掀一张。

滤掉的是**此刻按不动**，不是「这个键没有了」：关掉那一张，`q` 照旧退得出去；
跑过一趟，那两支照旧派得出来。用例
`the_key_table_leaves_out_the_keys_that_go_nowhere_right_now` 两头都问过。

### 三、打字那两块也调得出全部键：`Key::F1`

`Key` 那个枚举添了第十三个键码，`translate` 认 `KeyCode::F(1)`：

```rust
/// **不进缓冲的那一个键**：`F1`。
F1,
```

**挑它的理由**（票面要写下来的那一条）：

- **它不是一个字符**，进不了任何一个缓冲——那正是这两块要的；
- 「按 F1 看帮助」是键盘上最不必学的一条；
- **它在六块焦点、四个阶段上一处都没有主**——`the_key_that_does_not_go_into_the_buffer_is_spoken_for_nowhere_else`
  逐块逐阶段问了一遍（六组 × 四阶段各答 `Ignored`，加上编辑一行与打预设名那两张表），
  与 `p3-session-legibility/12` 挑 `i` 时同一个做法；`a` 那种撞车（Q161）不存在。

**代价写在 `Key::F1` 的文档里**：终端自己截走它的话会话一个字都收不到（有几种终端把
`F1` 绑在自己的帮助上）——出路一个不少，那两块退出去是一个 `Esc`，出去就有 `?`。

「这一块自己认字母」那一条跟着改口成「**这一块自己认下这个键**」：

```rust
fn minds_this_key_itself(focus: &Focus, key: Key) -> bool {
    match focus {
        // 覆盖层自己认下全部三个：按回去就是关掉。
        Focus::Overlaid(_) => true,
        // 打字那两块只认下**字母**：`?` 与 `i` 在那儿是字，而 `F1` 不是。
        Focus::Editing(_) => matches!(key, Key::Char(_)),
        Focus::Picking(picker) => picker.naming.is_some() && matches!(key, Key::Char(_)),
        ...
    }
}
```

`Session::reveals()` 整个删掉：屏底那一行末尾摆不摆「全部键」此刻由
`Asked::all_keys()` 问按键表答——打字那两块上问出来的是 `F1 全部键`，
掀着那一张的时候问出来的是 `None`（那一刻那个键是「关掉」）。
**「掀得开的每一块上恒在末尾」因此仍旧一处接完**，而「掀得开的」多了两块。

### Q165 — 「屏底末尾恒是 `? 全部键`」在打字的那两块上摆不出来

- **From:** 票 `p3-session-legibility/12`
- **Kind:** 票面与实现对不上
- **Where:** `src/session/state.rs` 的 `minds_its_own_letters` 与 `Session::reveals`、
  `src/session/draw/footer.rs` 的 `footer`
- **现状:** 票面第一条要「屏底瘦身成此刻最常用的四五个，**末尾恒是 `? 全部键`**」。
  **编辑一行**与**打预设名**这两块上摆不出来：那儿每一个字符都进缓冲，`?` 与 `i` 也是字
  （`editing_action`、`naming_action`）。屏底那两副因此照旧只摆自己那三个键
  （`⇥ 补这一层 · ⏎ 收下 · Esc 丢掉`），而 `?` 那张表上也没有这两块——
  一张按键表说不出「a 到 z 各进缓冲」。
- **走了哪条路:** **两块一起划出去**，由一处说了算（`minds_its_own_letters`）：
  屏底摆不摆那一句问 `Session::reveals`，`?` 那张表列不列那一组由 `KeyGroup` 定，
  两处读的是同一条规矩。**「恒是」因此读作「掀得开的每一块上恒是」**。
- **Why it did not block:** 那两块本来就只有三个键，全摆在屏底上，一个都没藏起来——
  「看不见的东西等于不存在」在这两块上不成立。退出去是一个 `Esc`，出去就有 `?`。
- **Whose call:** 拍板的人（要不要给这两块留一个非字符的键掀开覆盖层，例如 `F1`——
  代价是会话此刻只认十二个键码，添一个要动 `Key` 与 `translate` 两处）
- **处置：** **了结。**给了这两块一个**不进缓冲的键**——
  `Key::F1`（第十三个键码，`translate` 认 `KeyCode::F(1)`）。这一条问的正是 Q165 记的
  「要不要给这两块留一个非字符的键」，答案是要，挑的理由与代价写在 `Key::F1` 的文档里
  （不是字符、按 F1 看帮助最不必学、六块焦点四个阶段上一处没有主；代价是有几种终端
  自己截走它）。`minds_its_own_letters` 改口成 `minds_this_key_itself`：
  那两块认下的只有**字母**。屏底那一行末尾摆不摆「全部键」此刻问按键表答
  （`Asked::all_keys`），`Session::reveals` 整个删掉——**「掀得开的每一块上恒在末尾」
  仍旧一处接完，而「掀得开的」多了那两块**。

### Q166 — 屏底那一行的键是手抄的，`?` 那张表的键是问出来的：同一个键有两处措辞

- **From:** 票 `p3-session-legibility/12`
- **Kind:** 本票认下的一处折扣
- **Where:** `src/session/draw/footer.rs`（各状态那几个 `*_prompt` 函数里的字面串）、
  `src/session/draw/overlay.rs` 的 `says`
- **现状:** `?` 那张表的**键**从按键表当场问出来（`Session::key_table`），改一处按键表
  它跟着变；屏底那一行的键仍是各状态那几个函数里手写的字面串（`t 试算 · x 执行`）。
  同一个键因此有两句措辞：屏底是 `t 试算`，覆盖层是 `t 试算：只算不写，报告照出`。
  改一个键位（比如把 `t` 换成别的字母）要动两处，而只动一处不会有任何一条用例红。
- **走了哪条路:** **两处答的不是同一个问题**，这一刀写进了 `footer` 的模块文档：
  屏底答「**此刻按什么**」（最常用的四五个，随焦点与阶段变），覆盖层答
  「**这个键做什么**」（按焦点分组的全部键）。短的那一句是提示，长的那一句是解释，
  合成一句的话两头都不好用——屏底那一格摆不下解释，而一张只有提示的表读不出所以然。
- **Why it did not block:** 「哪些键在哪个状态下有效」仍旧一处答完（`Session::action`），
  两处都只是它的两副读法；而**屏上不摆按不动的键**照旧靠状态分岔守着，
  屏底手抄的那几句一处都没有绕过按键表去摆一个派不出动作的键。
- **Whose call:** 拍板的人（要不要让屏底那一行也从 `Session::key_table` 取键，
  代价是每一句提示都要有一个「短说法」与一个「长说法」两份措辞，
  而屏底那几副此刻是按**这一块此刻最该说什么**排的，不是按键排的）
- **处置：** **了结。**屏底那一行的键此刻出自 `Session::keys_here`（眼下这一块上派得出
  动作的每一个键），措辞出自 `draw::keys::says`——**长短两份，一处出处**：短的给屏底、
  长的给 `?` 那张表。`says`／`spelled`／`merged` 从 `draw/overlay.rs` 挪进了新的
  `draw/keys.rs`，两处共用。Q166 预告的代价照实付了：每一句提示都有一个短说法与一个
  长说法；而屏底那几副此刻仍按「这一块此刻最该说什么」排——**挑的是动作，不是键**
  （「就在这一行上动手」「试算」「退出」），派得出它的是哪几个键由那一处答。

### Q167 — `?` 那张表滤得掉「这个阶段不派」的键，滤不掉「派得出、而 press 那一层挡着」的键

- **From:** 票 `p3-session-legibility/12`
- **Kind:** 本票认下的一处折扣
- **Where:** `src/session/state.rs` 的 `Session::keys_of` 与 `KeyGroup::reachable`、
  `src/session/terminal.rs` 的 `press`（`Action::Expand` 与 `Action::Reveal(Overlay::Premises)`
  那两道 complain）
- **现状:** 票面第二条要「只列此刻这个阶段派得出的键」，而这张表只问得到**按键表**那一层。
  有两支的闸门在 `press` 那一侧——它们要读那一趟攒下来的报告，而状态机读不到：
  **`e` 展开**（一趟都没跑过时说「还没跑过：先按 t 试算或 x 执行」）与
  **`i` 这一趟的前提**（同一个形状）。一趟都没跑过时按 `?`，左栏那一组照旧列着 `e`、
  「任何时候」那一组照旧列着 `i`，按下去只换来一句话。
  **屏底那一行没有这个毛病**：它收得到 `live`，`browsing_keys` 用 `expandable(live)` 挡 `e`、
  `report_prompt` 与 `overlaid_prompt` 用 `live.is_some()` 挡 `i`。
- **走了哪条路:** **按阶段挡得住的那几处都挡了**：`KeyGroup::reachable` 把取值栏与预设栏
  在跑着与等答话时整组撤掉（只从左栏进得去，而那时左栏一个改动键都不派），
  把报告区与展开着在「一趟都没跑过」时整组撤掉。剩下的两支挡不住——挡它们要 `live`，
  而 `Session::key_table` 是状态机上的一个纯函数，收 `live` 就等于让状态机读那一趟攒下来的
  东西（`CONTEXT.md` 的《会话》与 ADR 0017 都把那条线画在这里）。
- **Why it did not block:** 那两支**按下去有话说**，不是按了没反应——本仓库明写着这两者
  不是一回事（`browsing_keys` 的文档：「型号还没挑时它照样摆着……那不是按不动，
  是**按了有话说**」）。而这张表本来就在列**别的块**上的键，读它的人不会指望每一行
  此刻都按得动。
- **Whose call:** 拍板的人（要不要给 `key_table` 收一个「这一趟有没有报告」的布尔——
  那是画法那一层现成就有的一个数，代价是状态机上多一个它自己答不出的参数；
  或者反过来，把 `e` 那一支在 `Stage::Fresh` 上就不派，代价是 `press` 那句
  「还没跑过」从此只有 `Stage::Running` 且一卷都没有时到得了）
- **处置：** **了结，走的是 Q167 记的第二条路**（「把 `e` 那一支在 `Stage::Fresh` 上就不派」）：
  `browsing_action` 的 `e` 加了 `if self.stage == Stage::Ended`，`revealing` 收了 `stage`
  并在 `Stage::Fresh` 上不派前提那一张。第一条路（给 `key_table` 收一个「这一趟有没有报告」
  的布尔）没走——那等于让状态机读那一趟攒下来的东西，而 `CONTEXT.md` 的《会话》与
  ADR 0017 把线画在别处。代价照 Q167 预告的兑现：`super::press` 里那两句「还没跑过」
  从此到不了——前提那一张的那一句连同它那道闸整个删掉，展开那两支的留着并在文档里
  点名「这一支到不了」。**Q189 是同一条滤的另一半**，它由「任何时候」那一组多过的一道
  收掉（见下）。

### Q180 — 屏底那两行印的是「`⏎`／`→` 定」，而取值栏那两层上三个键同义

### Q189 — 覆盖层掀着时 `?` 那张表上照旧摆着 `q 退出会话`，而那一下按不动

- **From:** 票 `p4-parking-lot/06`（评审提的）
- **Kind:** 既有实现在新说法下露出的一处不齐
- **Where:** `src/session/state.rs` 的 `Session::keys_of`／`means_the_same_everywhere`
  （那两道滤问的是 `KeyGroup`，而 `KeyGroup` 上没有覆盖层这一组）、`overlay_action`
  的 `Key::Char('q') => Action::Ignored`
- **现状:** 本票把覆盖层不认的键交给了 `stage_action`，**`q` 除外**——那一块的
  「退一步」是 `Esc`，交下去的话没跑过与收场了那两个阶段上它会退掉整个会话。
  而 `?` 那张表列的是**盖住的那一块**加「任何时候」那一组：没跑过时 `q` 在左栏、
  取值栏、预设栏与阶段那一维上都是退出，`means_the_same_everywhere` 因此为真，
  表上白纸黑字写着 `q 退出会话`——**而此刻按 `q` 一个动作都不派**。
  这一笔与《覆盖层》立的「屏上不摆按不动的键」相左，形状与 Q164 记过的那一句一样
  （表上摆着、按下去没反应），只是换了个字母。**不是本票引入的**：`q` 在覆盖层上
  从 `p3-session-legibility/12` 起就不派，那张表也从那时起就列着它。
- **Why it did not block:** 出路一个不少——`Esc` 一下关掉，关掉之后 `q` 照旧退得出去；
  `Ctrl-C` 在每一个状态下都退得出去。按错一下的后果是「没反应」，不是「退错了地方」。
- **走了哪条路:** **本票不滤。** 滤它要让 `keys_of` 在焦点落在覆盖层上时按
  `overlay_action` 再复核一道，而**「`?` 那张表再滤一道」正是 `p4-parking-lot/07`
  票面第二条**（本票票面写死了「不要提前做 07 号票的事」）。07 那一条收的 Q167
  是同一类（「派得出、而另一层挡着」），这一条给它添一个新的成因：
  **挡它的不是输入那一层，是覆盖层自己那张按键表**。
- **Whose call:** `p4-parking-lot/07`——那一票要给 `?` 那张表再滤一道
- **处置：** **了结。**`keys_of` 多了第三道滤，只加在「任何时候」那一组上：
  `if group == KeyGroup::Always && self.action(key) != action { return None }`。
  判据是「**此刻按下去有没有第二步**」——别的块上那几行说的是「站到那一块上按它做什么」，
  而「任何时候」那一组宣称的正是「此刻在哪一块上都按得动」。覆盖层掀着时 `q` 因此不列，
  掀着的那一张自己那个键（按回去是「关掉」）同理。**滤的不是「这个键不存在」**：
  关掉那一张，`q` 照旧退得出去（用例 `the_key_table_leaves_out_the_keys_that_go_nowhere_right_now`
  两头都问过）。
