# 18 — 命令行也接上两级停

**What to build:** 两级停是 `run` 的能力，会话里接上了，**命令行那一路至今没有按的地方**——
`ADR 0013` 决定第 3 条只兑现了一半。批量跑几十卷时按 `Ctrl-C` 今天是硬杀，
当前卷靠 partial 丢弃兜底。

接上信号处理：**一次收尾**（当前卷跑完才停，盘上多一个完整的卷）、**两次中止**
（立刻停，当前卷那格丢弃）。**两级的语义与会话那两级一格不差**——
那是同一条闩、同一个检查点，不是命令行另立的一套。

**这张排在 19 号之前**：接不接决定闩的编码将来是两份还是三份。

收停车场的 **Q38**。

**Blocked by:** None — can start immediately
