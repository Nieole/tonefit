# 04: 真机标定，一次定四个数

**What to build:** 一次真机盲测，把地板与掩蔽改动之后所有失效的常数一起重标。地板与掩蔽一改，判据读数全变，阈值 5.5 立刻不成立——这四个数本来就是同一批盲测夹出来的，重标也该一次付清，不分两轮。

**Blocked by:** 01, 03

**Status:** ready-for-human

- [ ] 四个数各有取值与窗口：**地板上界**（现行 1bit 上是 60，2bit/4bit 无数据）、`MASKING_FLOOR`（现 0.5）、`MASKING_KNEE`（现 8.0）、**阈值**（现 5.5）
- [ ] 每个数的窗口**两端各由某一页某一档的目视结论钉住**，照《位深盲测》的先例
- [ ] 材料用**一手素材**，不用成品库——两者的判读读数差着一档（《判读的可辨性依赖材料是不是一手的》）
- [ ] 判读**整页 1:1**，不用局部放大块（《成品库上判不出阈值的原因是空间尺度》）
- [ ] 施测条件（面板、素材、张数、问法）随四个数一同记进 `docs/measurements.md`
