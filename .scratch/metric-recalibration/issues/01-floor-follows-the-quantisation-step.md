# 01: 地板跟着格点间距走

**What to build:** 颗粒项的可见度地板不再是一个绝对值，而是**格点间距的一个比例**。跑完之后，同一页同一候选在 **2bit 上的判据读数会变**——颗粒项在那一档不再恒读零，判据不再退化成只剩低通项；而 **1bit 上的行为逐位不变**，`_samples` 那批盲测数据的可比性因此保住。报告《判据构成》那一行改成按比例说，读的人仍然一眼看得出这个数是怎么来的。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] `Composition` 带的是**一个数**（占格点间距的比例，值 0.2158），不是三档的表；地板由它乘 `255/(2^n − 1)` 算出
- [x] 1bit 上算出的地板**逐位仍是 55.0**——这是兼容性底线，一动《位深盲测》整批数据就不可比了
- [x] 取一页真实素材，同一候选在改动前后：**2bit 上的判据读数不同**，1bit 上相同
- [x] `src/metric.rs` 里那条算术下界不变量从**只管 1bit 扩成三档都管**：谁把比例调到 0.2071 以下，任一档当场红
- [x] `tests/metric.rs` 与 `src/render.rs` 里钉着旧形状的那两处断言已跟着改（前者断言 4bit+FS「读数贴着零」，后者印「颗粒超出 {} 灰度级」）
- [x] 黄金快照的差异**逐条审查后接受**，不是顺手覆盖——判定变了才是这张票成立的证据
- [x] ADR 0002 就地说明：决定第 5 条设的颗粒项原来只覆盖 1bit；**全库重跑**（地板进参数哈希，旧输出全部不命中幂等）写进《后果》
- [x] 闸门三条绿

## 落地记录

### 一、地板从一个绝对值变成一个比例

`Composition` 仍然只带**一个数**，换的是那个数说的是什么：

```rust
pub struct Composition {
    /// 颗粒项那道可见度地板**占格点间距的比例**。
    pub grain_ratio: f32,
}

impl Composition {
    pub fn floor(self, depth: BitDepth) -> f32 {
        self.grain_ratio * quantisation_step(depth)   // 255 / (2^n − 1)
    }
}
```

比例取 **`0.215_686_27`**。选它不是因为好看：`GRAIN_RATIO × 255` 要**逐位**等于旧的
`GRAIN_FLOOR = 55.0`，那是《位深盲测》整批数据的可比性底线（闸 ②）。三档因此是
**55.0 / 18.33 / 3.67**，与 measurements 的《颗粒项只在 1bit 上生效》里那张闭式解表逐格对上。

`quantisation_step` 是新添的私有函数，格点套嵌（255 = 3×85 = 15×17）保证三档都是整数。

### 二、位深怎么进到判据里：`score` 多收一个参数

`score(&Reference, &GrayImage)` → `score(&Reference, &GrayImage, BitDepth)`。

**没有从候选图上反推格点数**——一张纯色页在任何一档上都只用得着一个格点，反推出来恒是
1bit，而纯色页恰恰是判据最要说话的那一类。每个调用点手里本来就有 `Candidate`
（`src/lib.rs` 的 `candidate_scores`、`src/render.rs` 十来处、`tests/metric.rs`），
穿进去是一次编辑。留下的那一格（没有东西逼参数与像素一致）记在 **Q306**。

**合成候选一律传 `BitDepth::Eight`**：`tests/metric.rs` 里整页 +8 的那两处、
`src/render.rs` 里编一个判据值用的那八处 1×1、`src/session/live.rs` 那一处，
共十一处——它们都没有经过目标位深量化，工作精度就是它们那一档。同一个约定一种传法。

### 三、报告那一行改成按比例说

```
判据构成 低通后的局部均值误差 ＋ 颗粒超出格点间距 21.6% 的那一部分（地板盲测标定于 boox-poke6，其余面板未复核）
```

措辞仍只有 `metric::Composition` 的 `Display` 一处出处（ADR 0016）。说比例而不说某一档的
绝对值：逐页那一行一次排开好几档位深，说死其中一档，另几档那几个数就没有出处了。
会话「这一趟的前提」那张覆盖层的快照跟着重录——它是一张**录下来的屏**，本来就该跟着变。

### 四、用例：一条扩成三档，一条重新表述，一条新增

| 缝 | 用例 | 变化 |
|---|---|---|
| `composition()` | `the_grain_floor_is_a_share_of_the_quantisation_step` | **新增**。`floor(1bit).to_bits() == 55.0f32.to_bits()`，另两档对上 18.33 / 3.67，三档两两之比就是间距之比 |
| `composition()` | `the_grain_floor_stays_above_what_an_undithered_flat_tone_pays` | **从只管 1bit 扩成三档都管**。每一档各验一次闭式解 `0.2071·s`，再验 `floor(depth) > worst`：比例调到 0.2071 以下，三档里任何一档当场红 |
| `score` | `grain_below_the_visibility_floor_is_not_charged_for` | **重新表述**。旧断言「4bit+FS 读数贴着零」在新地板下不成立（4bit 地板降到 3.67）；现在页换成**纯中灰 128**，三档各断言**两半**：颗粒穿得过那一档地板的一半（收得到），且抖动仍赢得过同档不抖动（不多收——地板一格不减，这一半当场翻） |
| `score` | `the_grain_term_reads_back_on_two_bits_too` | **新增**。纯色页上 2bit+FS 的低通项近零，读数却明显大于同档不抖动的一半——那个数只能出自颗粒项，而它从前在这一档恒读零 |

**「不多收」那一半挑页**。头一版写在 solid-200 上，1bit 当场红：1bit+FS 读 63.363、
1bit 不抖读 55.000。那不是回归——200 在 1bit 上离格点 55 级，落在闭式模型给不出余量的那一段，
而真实 FS 的起伏比闭式解高一成上下；ADR 0002 的《后果》早写着「平坦的中浅灰上两者会交叉」。
换成**纯中灰 128** 两半就都成立：三档上它都落在两个格点正中（差 127 / 42 / 8），
抖动买到的便宜最大，读数 76.976 对 127.000、26.380 对 42.000、5.583 对 8.000。

### 五、黄金快照：逐条审查后接受

十三处不同，**没有一处是意外**。逐处归到五类里：

- **判到 1bit 的每一行连字节数都逐位没动**——`line-art` 10748、`mixed` 的 001/002/004、
  `archive.cbz`、`damaged` 那两页、两个 `envelope-outlier`、`envelope-hysteresis`。
  这是闸 ② 的端到端证据。
- **改判的全是 2bit+FS 那一档**，十来个卷改判 `4bit+FS` 或 `4bit` 不抖。机理正是这张票要修的：
  2bit+FS 的颗粒项从前恒读零，那一档因此以近乎纯低通的读数落在界内，而候选按体积排序、
  2bit+FS 排在 4bit 之前——「两档都在阈值内、按体积被选成 2bit+FS」（spec 记的 68.1%）。
  颗粒项收得到费之后 2bit+FS 越界，判定落到 4bit。
- **`mixed` 的 005 页从 2bit+FS 215607 字节变成 4bit 不抖 2246 字节**：那是一张 solid(200) 页，
  从前白付了 213 KB 的抖动噪声去换一个恒读零的颗粒项。spec 的 story 9 说的就是这一格。
- **网点页一格没动**（`screentone` 仍是 2bit+FS 116351）：网点自带高频，参照那一份把颗粒项的
  触发线抬高，候选的超出量穿不过地板——measurements 的《颗粒项只在 1bit 上生效》里
  带网点那两页预言的正是这件事。
- **不抖动的候选一格没动**（`envelope-hysteresis-gate-holds` 仍是 2bit）：就近取整只会抹掉高频，
  颗粒项在它身上本来就是零。
- **两处只换了定档页，判定档一格没变**（`mixed-size` 在 `height crop` 与 `inside crop`
  两条路上都从 `定档页 002.png` 变成 `004.png`，基准档仍是 `4bit+FS`）：定档页是站在上包络
  分位秩上的那一页，逐页读数一变，站在那个秩上的就换了人。**它不是判定的变化**，
  是同一个判定换了个说得出的来由。

两档 2bit 的端到端覆盖因此都还在：`screentone` 站着 2bit+FS，`envelope-hysteresis-gate-holds`
站着 2bit 不抖。

### 六、`tests/pipeline.rs` 六条跟着改，两条动的是夹具

票面第五条只点了两处断言，实际上端到端那一侧还有六条钉着旧判定。四条**只换期望值**
（判定从 2bit+FS 变成 4bit+FS，用例的主语——几何、门逐页判、逐页模式、迟滞——一格没动）。
另两条的**前提**塌了，动的是夹具：

- `a_gradient_written_at_a_low_bit_depth_comes_out_without_measurable_banding`：从前跟着判定
  走那一档，如今渐变页判到 4bit，而 4bit 的格距只有 17，色带小到分不出「看得见」与「消掉了」。
  **色带那一档改成点名 2bit**（新常量 `BANDING_DEPTH`），判定那一维交给上一条用例钉。
- `one_undersized_cover_does_not_take_the_dither_away_from_the_rest_of_the_volume`：它要基准档
  **落在抖过的那一档、且低于封面自己判出来的那一档**。渐变页正片如今判到 4bit+FS，与封面
  自己那一档齐平，夹具的自检当场红。正片改成**四边顶着墨的网点页**（新夹具
  `fixtures::full_bleed_screentone`）：基准档 2bit+FS，封面自己 4bit，两档重新分得开。
- `dithering_can_bring_a_page_back_within_the_threshold`：从前把灰阶数压到 4 级、让 2bit+FS
  落回界内。新判据下 2bit 上抖不抖都够不着界（27.695 对 38.796），抖动买回来的那一档是
  **4bit**（5.113 对 6.713）——**那一条性质本身还在**，只是发生在另一档上，
  压灰阶数那一步因此去掉了。

`fixtures::ONE_STEP_ABOVE_TWO_BITS`（96）的文档跟着重写——它是那几个读数的单一出处，
门成立那条路上如今是 96.000 / 81.431 / 11.000 / 14.538 / 6.000 / **5.168**。

### 七、ADR 0002 与 CONTEXT.md

ADR 0002 决定第 5 条就地改成「地板是格点间距的一个比例」，《第 5 条从哪来》补一段
**「这一条原先只覆盖 1bit」**（55 卡在 1bit 与 2bit 之间，颗粒项在那两档恒读零），
下界的推导从 1bit 的 52.8 抽成三档通用的 `0.2071·s`。《后果》两条：
上界那一条补上「只有 1bit 那一档有真机数据」，新增一条 **《全库重跑》**。

**《全库重跑》没有照抄票面那句括号。**票面写「地板进参数哈希，旧输出全部不命中幂等」，
而 `metadata::params_hash` 收的是面板四项、阈值、适配、裁边、拆分、滤波器与三个覆盖项，
**地板不在里面**。判定确实全变了，但让旧输出过期的是阈值（04 号票会改它）与工具版本号；
这一步单独落地时旧输出会被静默跳过。ADR 里因此写的是实际的机制，这一格记在 **Q307**。

CONTEXT.md 改三处：《颗粒项》与《判据构成》两个词条（地板跟着格点间距走、`Composition`
带的是一个比例）、《尚未确立》里主语就是这道地板的那一条（从「只覆盖 1bit」改写成
「上界只有 1bit 那一档有数据」）。**已有词条的别处一个字没动**；撞见的另外两句
（measurements 末段、《尚未确立》里迟滞那一条的括号理由）各记一条，见下。

### 九、票面有两条与实际对不上

**第三条：「取一页真实素材」——用的是合成夹具。** 原话是
「取一页**真实素材**，同一候选在改动前后：**2bit 上的判据读数不同**，1bit 上相同」。
一手素材不进仓库（spec 的《Testing Decisions》：「真实素材冒烟照旧 opt-in，不提交任何素材」），
「改动前后」还要两个版本各跑一趟。实际用的是黄金快照那批代码生成的夹具。
**方向上还有一格**：measurements 记着的那两页一手素材（五星物語 P00091、武器種族傳說 P00097）
是网点页，参照自带高频把触发线抬得很高，新地板 18.33 照样吞掉——那两页的 2bit 读数改完
**仍然不变**。与本票不矛盾（改动咬的是连续灰调），但照字面找页找不出来。记在 **Q311**。

**第一条：「值 0.2158」——实现取 0.215_686_27。** 0.2158 × 255 = 55.029，照它写闸 ② 当场破。
真正的值是 `55 / 255`，也正是「0.2071 × 1.0414」算出来的那个数；印到报告上两者都是
`21.6%`，分别只在那条逐位断言上。票面没有改，记在 **Q312**。
