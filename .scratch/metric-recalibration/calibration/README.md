# 04 号票的标定

`04` 要一次真机盲测定六个数。判读很贵，所以分两半走：先算掉能算的，再为剩下的造材料。
两半都走完了，判读也做了——这个目录装的是那两半的工具，以及**这一路走岔过两次的记录**。

判读的原始作答与逐格解码在 `judgements/` 下那几份 JSON；量出来的数在 `docs/measurements.md`。

## 结论：真正的矛盾只有一条，而它被「地板是比例」这个形式绑死了

**一个绝对地板 45~65 灰度级，同时满足这两条真机盲测的结论**（撇开一个已知反例，
排序 21/21，且 `1bit+FS` 仍每页垫底）：

| 真机结论 | 出处 | 它要什么 |
|---|---|---|
| **`1bit+FS` 每页垫底** | measurements《位深盲测》，两块面板 | 1bit 上颗粒项**要收费** |
| **连续灰调上 `2bit+FS` 优于 `4bit 不抖`** | 闸① n=16、**15:1** | 2bit 上颗粒项**不该收费** |

物理很直白：**1bit 的 FS 颗粒幅度约 127，2bit 的约 42**。一个绝对地板夹在中间就两头都对。
而地板一旦写成**格点间距的比例**（`floor(n) = 比例 × 255/(2ⁿ−1)`），两档就被绑死
——同时归零或同时不归零，怎么调都解不开。

> **`GRAIN_FLOOR = 55.0` 正落在 45~65 这个窗口的正中**——那是 `01` 号票改掉的旧值。
>
> `spec` 当初把「颗粒项只在 1bit 上生效、2bit 及以上恒读零」当成缺陷去修。
> **真机说那不是缺陷**：2bit 上的 FS 颗粒本来就看不见（判读者原话
> 「除了轻微色带之外的观感几乎一致」）。

**这直接指向 ADR 0002 决定第 5 条**「地板是格点间距的一个比例，不是一个绝对值」
——那条决定可能要翻，而 `01` 号票整个建在它上面。**翻不翻是拍板的事，不在本票。**

唯一错的那一页是 `1046-梦游盒-04-2`，即原闸① 四对里反向的那一对——`03` 的落地记录
早就写着它「n=4、其中一对反向，**不作定量依据**」。合并后是 16 里的 1。

## 走岔过的第一次：把约束写成了「判定档」

**这一条是方法论教训，比上面那个结论更该记住。**

真机每一组测的都是**两档之间的对比**（`2bit+FS` 对 `4bit 不抖`），它说的是
**哪一档更干净**或**分不出**。而我把它翻成了「这一页的**判定档**该是什么」：

| 组 | 真机实际说的 | 我写成的 | 差在哪 |
|---|---|---|---|
| B 组 | 4/4 判 `4bit 不抖` 更干净 | 判定**不得低于** 4bit | 「零接受」是《第五轮》**模型判读**的结论，而模型那几轮**不作标定依据** |
| C 组 | 6 平 2 偏、零个 `✗` | 判定**就该是** `2bit+FS` | 真机**没测过** `2bit 不抖`，无从要求判定落在哪 |

`04` 票面那句「重标之后那四页必须落在阈值之外」，依据正是那条模型判读的「零接受」。
**我照着票面形式化，于是造出了一个数据里本来没有的矛盾。**

改成真机实际测过的**两档排序**之后，那个「B 组 vs 闸①」的倒挂从 **2.93 → 0.93 → 消失**。

> **教训**：约束要写成「真机比过的那两样东西之间的关系」。判定档是标定之后的**推论**
> ——真机没测过的档，不能出现在约束里。

## 走岔过的第二次：六个方向的证伪，是在错约束上跑的

在发现上面那件事之前，试过六个方向找新形状，全部证伪。**那些结论现在要收回**
——它们排除的路未必真该排除，因为跑的是错的约束。清单留着，是因为**跑法与数据仍然有效**，
将来若要重跑，改一下约束即可：

| # | 试的 | 当时的结果 |
|---|---|---|
| 1 | 颗粒项乘一道**按块亮度**的权重 | L 组 15/15，真实页 0 组 |
| 2 | 低通项也加一道（方向相反） | 倒挂只从 2.66 缩到 1.95 |
| 3 | **两项各用各的活动度** | 两种活动度几乎相同，窗口没动 |
| 4 | 换**颗粒项的聚合**（p90/p75/中位/均值） | 四种窗口完全相同 |
| 5 | 残留的**空间结构**（低频占比） | 方向相反 |
| 6 | 颗粒的**幅度分布**（高分位、超阈占比） | 整页统计全分不开 |

**「缺的那一项是《背景亮度》」这个说法因此也要收回。**L 组那三行分歧（同一个《离格量》、
不同背景亮度、真机答案相反）**本身仍是实测事实**，但它解释不了真实页——真实页上的矛盾
是上面那一条，与亮度无关。

两条顺带查出、**与约束形式无关**因而仍然成立的发现：

- **ADR 与实现的一处偏差**：ADR 0002 说掩蔽的活动度取**局部**均值是为了让平缓斜坡透明，
  而 **`STRUCTURE_KERNEL` 就等于 `TILE`（都是 32）**——核与块一样大时，「离局部均值多远」
  与「离块内均值多远」几乎是一回事。**那条设计意图在当前取值下几乎不生效。**
- **聚合在挑什么**（`which_tile_decides.py`）：闸① 那 12 页里 **11 页**被聚合取到的块，
  活动度远低于该页中位（块 0.0~9.3，页中位 6.0~52.0）。**判据挑的是那一页上最平的一块**
  （32×32，占整页 0.05%），而判读者看的是整页观感。

## 闸① 补测：n 从 4 提到 16

`judgements/第九轮闸1补测.json`。新 12 对 **12:0 判 `2bit+FS` 更干净、判据 0/12 同向**，
合并原四对是 **15:1**。判读者的理由是**色彩断层**（色带），并补了一句
「除了轻微色带之外的观感几乎一致」——**那一句正是「2bit 上的颗粒看不见」的直接证词**。

拆成两项看，新 12 页上：

| | `2bit+FS` | `4bit 不抖` | 真机说 |
|---|---|---|---|
| 低通项 | 3.2 ~ 3.7 | **5.8 ~ 8.0** | 色带**看得见** |
| 颗粒项 | **13.7 ~ 24.2** | 0.00 | 颗粒**看不见** |

**低通项那一侧方向本来就是对的。**

## 口径自检

**每一个数都过了自检**，口径与当初一致：

- 判据的 Python 复现 vs `tonefit --dry-run`：**每次导出都重做，对不上就非零退出**。
  18 页 × 6 档最大偏差 0.0008，闸① 补测那 12 页 0.0010。
- B 组四页的读数与 measurements《真机三组》记的**逐位吻合**；D 组那四页的 2bit 读数同样对得上。
- 闸① 四页的几何（1208 / 1141 / 1380 / 1140 × 1680）与 AB 交错本答案表**逐页一致**。
- 阶梯上 **2bit 不抖的读数逐位等于《离格量》**，正是 ADR 0002 决定第 5 条推导里的那一项。
- 真机包的编排由 `verify_bundle.py` **逐页比字节**并查配平。页上没有标注，编排对不对只能靠它
  ——第五轮正是栽在这里（五位判读者里三位数错一格，整批作废）。

材料一律**一手**：武器種族傳說 v01 原档 rar、N和S 与 Bowing！的一手 B 类发布版、
哆啦A梦 v15 的一手 8K 源目录。没有一份来自成品库。这一趟也**没有开纸白对齐**
（`--white-align-limit` 保持 0）。

## 这些脚本

按「导出一次、任意参数重算」组织——判据的那几个数只从三处进判据，逐块的原始量与它们无关。

| 脚本 | 做什么 |
|---|---|
| `metric_replica.py` | 判据的 Python 复现：逐块的低通项、颗粒、活动度、亮度 |
| `export_tiles.py` | 把页导成一份 npz，**并当场做口径自检** |
| `feasible.py` | 四维网格上搜可行域 |
| `diagnose.py` | 把读数拆成两项 |
| `which_tile_decides.py` | 判据的读数出自**哪一块** |
| `survey_flat.py` · `survey_clamp_cost.py` · `survey_continuous_tone.py` | 三种普查：无文字白底、纸白对齐钳掉多少、连续灰调面积 |
| `build_flat_ladder.py` · `build_anchor.py` · `pick_gate_one.py` | 造材料：平坦调阶梯、生态锚点、闸① 补测选页 |
| `pack_device_bundle.py` · `pack_gate_one.py` · `pack_recheck.py` | 编成交错的 cbz ＋ 答案键（**配平只在 `arrange` 一处实现**） |
| `verify_bundle.py` | 逐页比字节，自检编排 |
| `decode_answers.py` | 把判读者交回的答案解码成逐对结论 |
| `ladder_calibrates_floor.py` · `ladder_verdict.py` | 阶梯的对照表（判读前）与定案（判读后） |
| `try_luminance.py` · `check_shape_on_pages.py` · `residue_structure.py` | 试形状那六个方向用的（结论已收回，跑法仍有效） |

**怎么从零重跑**见同目录的 `怎么重跑.md`。中间产物都不入库——由源素材重算得出。
