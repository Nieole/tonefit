# 04 号票的标定：算得出来的那一半

`04` 要一次真机盲测定六个数。判读很贵，**先算掉能算的，剩下的才值得上机**——
这个目录装的是算掉的那一半（脚本与逐块数据），以及为剩下那一半造的材料。

**量出来的数不在这里。**它们的单一出处是 `docs/measurements.md` 的
《四条真机结论在现有判据形状下互不相容》与它底下的
《顺带：平坦调阶梯上，FS 的低通残留不是零》。本文只说**这一轮做了什么、材料在哪、怎么读**。

## 结论一句话

**四条真机结论在现有的判据形状下同时满足不了**，两处独立的不可满足，缺口是闭式的。
数与推导见上面那一节。**要动只能动判据的形状**，而那是拍板的事——
票面写着本票只出数与出处、一行代码都不改，`05` 才落地。

**搜的第四条不是票面列的。**票面《已经有的约束，不要重测》那四条里，
A 组明写「归 `06`，不占本票的数」，所以实际进网格的是 B 组、C 组、闸①，
外加一条票面未列、由 `tonefit-c2` 提出的 **「1bit+FS 每页垫底」**
（出处是 measurements《位深盲测》，不是本票新测的）。这一条撑起缺口的一端；
**另一处不可满足（严版与 B 组倒挂）不依赖它**，所以「满足不了」这个结论
去掉第四条仍然站得住。

## 真机包 04：三组二十一对

在 `_samples/_实验-判据重标定/真机包04/`（仓库之外，与 `_samples/` 同理）。

| 组 | 对数 | 问什么 | 材料 |
|---|---|---|---|
| **L 平坦调阶梯** | 15 | 这一格上抖动看得出比不抖脏吗 | 武器原档一块 512×512 **无文字**白底，平移出《离格量》×亮度十五格 |
| **M 离格量 1 的真实页** | 4 | 这四页上 `2bit+FS` 够用吗 | N和S 第 23 话（纸白 254），补 C 组只覆盖离格量 0 的缺口 |
| **N 生态锚点** | 2 | 真实连续灰调上抖动看得出脏吗 | 哆啦A梦 v15 闸① 那几页里真实的平滑渐变，验 L 组的平移口径 |

**重心是 L 组**：缺口的两端一端要地板小、一端要地板大，L 组答哪一格，定它落在哪一段。

### L 组判完怎么读

`ladder_calibrates_floor.py` 印的对照表（材料里另存一份 `参照8bit/标定表.txt`）：

| 真机从哪一格起判「FS 不比不抖差」 | 颗粒地板比例落在 |
|---|---|
| `u = 8` | 0.250 ~ 0.500 |
| `u = 21` | 0.245 |
| `u = 42` | 0.045 ~ 0.240 |
| 整条阶梯都判「不抖更干净」 | 0.000 ~ 0.040 |

**这张表只说「判据的翻转点跟着地板怎么移」，不说哪一段可用。**可用与否要再拿
measurements 那一节的两端去卡——例如真机答 `u = 8` 时这张表给的是 0.250~0.500，
而闸① 要的是 ≥0.450，垫底要的是 ≤0.320，**两端一卡，0.250~0.450 那一截并不可用**。
照这张表直接取中间值会取到一个不满足约束的数。

### 掩蔽那两个数，这一包**钉不住**

L 组是平坦块，逐块活动度几乎一致，掩蔽在它上面标不出来。`MASKING_FLOOR` 与
`MASKING_KNEE` 这一轮只有**算出来的可行域**（宽版 0.02~0.35 与 2~6），
**没有目视结论钉着它们的窗口两端**——票面《口径》第一条要的那种钉法，这两个数还欠着。
要钉住它们得另造一组「同一档、块内活动度分层」的材料，不在本轮范围内。

## 六个数各自走到哪一步

| 要定的数 | 这一轮的进展 |
|---|---|
| **颗粒项地板的下界** | 两条盲测结论把它夹成不相交的两段，L 组答哪一格定它落在哪段 |
| **低通项的可见度地板比例** | **算出来它与 B 组冲突**：要挡掉 4bit 那 2.0 得 ≥0.1176，而比例才抬到 0.06，B 组 `2bit+FS` 就已归零（真机在那四页是零接受）。**Q433 那件事这道地板治不了**，治它的是纸白对齐 |
| **`MASKING_FLOOR` / `MASKING_KNEE`** | 只有算出来的可行域，**没有材料钉窗口两端**（见上） |
| **阈值** | 宽版可行域有解，严版与 B 组倒挂 |
| **《纸白对齐》的上限** | 可算的一半已算（见下）；**真机材料造不了**——`--white-align-limit` 还没落地（`tone-alignment/01` 是 `ready-for-agent`，未实现） |

### 《纸白对齐》的上限：钳掉的那一段有多少东西

`survey_clamp_cost.py` 逐作品抽样量「纸白与纯白之间那些像素」——被 `[纸白, 255] → 255`
一起抹掉的，正是画面上最淡的那一层网点：

| 作品 | 纸白 | 离格量 | 钳掉的那一段占页 |
|---|---|---|---|
| N和S | 254 | 1 | **0.0000%** |
| 武器種族傳說 原档 | 253 | 2 | 1.57% |
| Forget-me-not | 252 | 3 | 3.45% |
| Bowing！· 8月31日的长夏 | 255 | 0 | 不钳 |

**上限取 4 与取 8 在这批素材上没有区别**——抽样里没有任何页的离格量落在 4~8 之间，
与 measurements《全语料普查：四成三的页纸白不落在格点上》一致。

被抹掉的是 253/254 这一两级。**4bit 的格点上 247~255 全部落到 255**，2bit 上 213~255 也是
——所以钳与不钳，**不抖那几档的输出逐字节相同**，变的只有 FS 那几档（不再撒点）。
真机要确认的因此不是「网点还在不在」，而是**「FS 在纸白附近撒的那些点，是网点还是噪声」**。

## 口径自检

**每一个数都过了自检**，口径与当初一致：

- 判据的 Python 复现 vs `tonefit --dry-run`：18 页 × 6 档 = **108 格，最大偏差 0.0008**
  （读数只印到小数点后三位）。`export_tiles.py` 每次跑都重做这一条，对不上就非零退出。
- B 组四页的读数与 measurements《真机三组》记的**逐位吻合**；D 组那四页的 2bit 读数同样对得上。
- 闸① 四页的几何（1208 / 1141 / 1380 / 1140 × 1680）与 AB 交错本答案表**逐页一致**——
  这一趟重渲的几何与产出交错本那次相同。
- 阶梯上 **2bit 不抖的读数逐位等于《离格量》**，正是 ADR 0002 决定第 5 条推导里的那一项。
- 真机包的编排由 `verify_bundle.py` **逐页比字节**：cbz 里每一页与答案键说的那一档对得上，
  且强制配平。页上没有标注（有标注就不是盲测了），编排对不对只能靠它——
  第五轮正是栽在这里（`judgements/README.md` 的《第五轮》：五位判读者里三位数错一格，整批作废）。

材料一律**一手**：武器種族傳說 v01 **原档 rar**、N和S 与 Bowing！的**一手 B 类发布版**、
哆啦A梦 v15 的**一手 8K 源目录**。没有一份来自成品库（measurements《329 对同一物理页》）。
这一趟也**没有开纸白对齐**（`--white-align-limit` 保持 0），
`tone-alignment/05` 挂在本票之后正是为了这一条。

## 这些脚本

按「导出一次、任意参数重算」组织——那四个数只从三处进判据，逐块的四个原始量与它们无关。

| 脚本 | 做什么 |
|---|---|
| `metric_replica.py` | 判据的 Python 复现：逐块的低通项、候选颗粒、参照颗粒、活动度 |
| `export_tiles.py` | 把标定用的那些页导成一份 npz，**并当场做口径自检** |
| `feasible.py` | 四维网格上搜可行域，四条约束逐条判 |
| `diagnose.py` | 把读数拆成两项，量闸① 的缺口缺在哪一项 |
| `survey_flat.py` | 普查每页最大的无文字白底，连同纸白与《离格量》 |
| `survey_clamp_cost.py` | 普查纸白对齐钳掉的那一段有多少像素 |
| `build_flat_ladder.py` | 造 L 组：《离格量》×亮度交叉的十五格平坦调 |
| `build_anchor.py` | 造 N 组：闸① 那几页里真实平滑渐变的裁块 |
| `pack_device_bundle.py` | 编成交错的 cbz ＋ 答案键（**配平只在这里做**） |
| `verify_bundle.py` | 逐页比字节，自检编排 |
| `ladder_calibrates_floor.py` | 印「真机翻转点 → 颗粒地板比例」的对照表 |

**怎么从零重跑**（含中间产物 `tiles.npz` 与逐页 dry-run 读数怎么重生成）见同目录的
`怎么重跑.md`。中间产物都不入库——它们由源素材重算得出，留着不如留重算的路。
