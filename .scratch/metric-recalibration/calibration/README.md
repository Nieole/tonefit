# 04 号票的标定

`04` 要一次真机盲测定六个数。判读很贵，所以分两半走：**先算掉能算的**（脚本与逐块数据），
**再为剩下的造材料**（真机包 04）。两半都走完了，判读也做了——这个目录装的是那两半的工具。

**量出来的数不在这里。**它们的单一出处是 `docs/measurements.md` 的
《四条真机结论在现有判据形状下互不相容》与它底下的
《顺带：平坦调阶梯上，FS 的低通残留不是零》。本文只说**这一轮做了什么、材料在哪、怎么读**。

## 结论：真机判完了，六个数在现有判据形状下定不出来

判读的原始作答与逐格解码在票面 `04` 的《落地记录》与 `judgements/` 下那几份 JSON；
汇总数在 `docs/measurements.md`。

**L 组（平坦调阶梯）量出来的是**：近白那一列 5/5 判「不抖更干净」，而中灰与偏暗随
《离格量》翻向 FS——同一个 `u`、不同亮度，答案相反，共三行分歧。**而判据对亮度是盲的**
（同一个 `u` 的三格读数逐位几乎相同）。

> **「缺的那一项是《背景亮度》」这个说法，后来被证伪了**——见下面《六个方向，全部证伪》
> 的第 1、2 条：给颗粒项加亮度权重能让 L 组 15/15，**拿到真实页上却一组都不成立**。
> 亮度这一维在**平坦调**上是真的，但真实页上的矛盾另有来源。这一段留着，
> 因为 L 组那三行分歧本身仍是实测事实。

## 闸① 补测：n 从 4 提到 16，病灶指到颗粒项

`judgements/第九轮闸1补测.json`。新 12 对 **12:0 判 `2bit+FS` 更干净、判据 0/12 同向**，
合并原四对是 **15:1**。判读者的理由是**色彩断层**（色带），并补了一句
**「除了轻微色带之外的观感几乎一致」**。拆成两项看，新 12 页上：

| | `2bit+FS` | `4bit 不抖` | 真机说 |
|---|---|---|---|
| 低通项 | 3.2 ~ 3.7 | **5.8 ~ 8.0** | 色带**看得见** |
| 颗粒项 | **13.7 ~ 24.2** | 0.00 | 颗粒**看不见** |

**低通项那一侧方向本来就是对的**（3.2 < 6.0，与真机一致）。

## 六个方向，全部证伪

`04` 之后一路试形状，**没有找到任何一个能同时满足这 28 页的判据形状**。
六次证伪各自排除了一条路，列在这里免得下一个人重走：

| # | 试的 | 结果 |
|---|---|---|
| 1 | 颗粒项乘一道**按块亮度**的权重 | L 组 15/15，**真实页 0 组**（13260 组） |
| 2 | 低通项也加一道（方向相反） | 无改善，倒挂只从 2.66 缩到 1.95（22680 组） |
| 3 | **两项各用各的活动度**（颗粒项换块内均值式） | 两种活动度几乎相同，窗口一格没动 |
| 4 | 换**颗粒项的聚合**（p90 / p75 / 中位 / 全页均值） | 四种窗口**完全相同**——最优解总把颗粒项压零，窗口只由低通项决定 |
| 5 | 残留的**空间结构**（低频占比＝核32 RMS ÷ 核4 RMS） | **方向相反**：B 组最低（12.9%）却是唯一看得见的 |
| 6 | 颗粒的**幅度分布**（p99 / p99.9 / 超阈占比） | 整页统计**全分不开**：B 组 089-1 的「>60 占比」10.99% 与 C 组 001 的 10.02% 几乎一样，而结论相反 |

**第 3 条顺带查出 ADR 与实现的一处偏差**：ADR 0002 说掩蔽的活动度取**局部**均值是为了
让平缓斜坡透明，而 **`STRUCTURE_KERNEL` 就等于 `TILE`（都是 32）**——核与块一样大时，
「离局部均值多远」与「离块内均值多远」几乎是一回事。**那条设计意图在当前取值下几乎不生效。**

**第 4 条顺带查出聚合在挑什么**（`which_tile_decides.py`）：闸① 那 12 页里，**11 页**
被聚合取到的块，活动度远低于该页中位（块 0.0~9.3，页中位 6.0~52.0）。
**判据挑的是那一页上最平的一块**（32×32，占整页 0.05%），而判读者看的是整页观感。

## 收敛到的那件事

窗口的两端始终是这两个，而且都是**低通项**：

    闸① `0969` 的 `2bit+FS` 低通残留   6.19   要它被选中 → 阈值 ≥ 6.19
    B 组的 `2bit+FS` 低通残留          3.25   要它落选   → 阈值 < 3.25

**残留更大的那个反而是真机接受的。**再往下量，两处的物理差别落在**背景**上：
B 组是**纸白 253（离格 2）**的白纸，白底上 FS 撒 1.8%~2.1% 的点；闸① 那些页要么纸白 255
（离格 0，一个点都不撒），要么被聚合取到的是一片**浅灰画面**（`0969` 上是 233，
撒了 14% 却看不见）。

**这就是 measurements《分界线：纸白落不落在输出格点上》记的那件事**——不是新发现。
而**纸白对齐正好消掉 B 组那一侧**（实测：对齐后 B 组 `2bit+FS` 从 3.25 降到 1.70）。

> **所以「判据形状先不动、等对齐落地后重测」这个决定，被这六次证伪反过来支持了**：
> 现在这个矛盾的一端就是对齐要消掉的东西，在它消掉之前设计新形状，
> 很可能是在为一个即将不存在的约束做设计。

## 这一轮的脚本干了什么

判读很贵，所以先算掉能算的、再为剩下的造材料。事后看，两半都有用：

- **算的那一半**把「四条真机结论在现有形状下互不相容」这件事**先证了出来**，
  于是真机那一趟不是去碰运气标一个数，而是去回答「缺的是哪一项」。
- **造的那一半**（真机包 04 三组二十一对）里，**N 组两块锚点**证明了 L 组平移口径的
  一处局限：平坦块上不抖只是均匀偏色、**没有色带**，真实渐变上才有——
  而闸① 上 4bit 不抖输掉的正是色带那一项。没有锚点，这个局限查不出来。

## 口径自检

**每一个数都过了自检**，口径与当初一致：

- 判据的 Python 复现 vs `tonefit --dry-run`：18 页 × 6 档 = **108 格，最大偏差 0.0008**
  （读数只印到小数点后三位）。`export_tiles.py` 每次跑都重做这一条，对不上就非零退出。
- B 组四页的读数与 measurements《真机三组》记的**逐位吻合**；D 组那四页的 2bit 读数同样对得上。
- 闸① 四页的几何（1208 / 1141 / 1380 / 1140 × 1680）与 AB 交错本答案表**逐页一致**——
  这一趟重渲的几何与产出交错本那次相同。
- 阶梯上 **2bit 不抖的读数逐位等于《离格量》**，正是 ADR 0002 决定第 5 条推导里的那一项。
- 真机包的编排由 `verify_bundle.py` **逐页比字节**：cbz 里每一页与答案键说的那一档对得上，
  且强制配平。页上没有标注（有标注就不是盲测了），编排对不对只能靠它——
  第五轮正是栽在这里（`judgements/README.md` 的《第五轮》：五位判读者里三位数错一格，整批作废）。

材料一律**一手**：武器種族傳說 v01 **原档 rar**、N和S 与 Bowing！的**一手 B 类发布版**、
哆啦A梦 v15 的**一手 8K 源目录**。没有一份来自成品库（measurements《329 对同一物理页》）。
这一趟也**没有开纸白对齐**（`--white-align-limit` 保持 0），
`tone-alignment/05` 挂在本票之后正是为了这一条。

## 这些脚本

按「导出一次、任意参数重算」组织——那四个数只从三处进判据，逐块的四个原始量与它们无关。

| 脚本 | 做什么 |
|---|---|
| `metric_replica.py` | 判据的 Python 复现：逐块的低通项、候选颗粒、参照颗粒、活动度 |
| `export_tiles.py` | 把标定用的那些页导成一份 npz，**并当场做口径自检** |
| `feasible.py` | 四维网格上搜可行域，四条约束逐条判 |
| `diagnose.py` | 把读数拆成两项，量闸① 的缺口缺在哪一项 |
| `survey_flat.py` | 普查每页最大的无文字白底，连同纸白与《离格量》 |
| `survey_clamp_cost.py` | 普查纸白对齐钳掉的那一段有多少像素 |
| `build_flat_ladder.py` | 造 L 组：《离格量》×亮度交叉的十五格平坦调 |
| `build_anchor.py` | 造 N 组：闸① 那几页里真实平滑渐变的裁块 |
| `pack_device_bundle.py` | 编成交错的 cbz ＋ 答案键（**配平只在这里做**） |
| `verify_bundle.py` | 逐页比字节，自检编排 |
| `ladder_calibrates_floor.py` | 印「真机翻转点 → 颗粒地板比例」的对照表（判读**之前**用） |
| `decode_answers.py` | 把判读者交回的三行答案解码成逐对结论（判读**之后**用） |
| `ladder_verdict.py` | 拿解码后的答案去问「有没有哪个地板配得上」 |
| `try_luminance.py` · `check_shape_on_pages.py` | 试形状：L 组十五格 ＋ 真实页两边同时判（第 1、2 条证伪出自它们） |
| `which_tile_decides.py` | 判据的读数出自**哪一块**——查出「挑的是最平的那一块」 |
| `residue_structure.py` | 低通残留按尺度衰减，量它是簇状还是均匀（第 5 条证伪） |
| `survey_continuous_tone.py` · `pick_gate_one.py` · `pack_gate_one.py` | 闸① 补测：量连续灰调面积、分层选页、编成包 |
| `pack_recheck.py` | 造复判包（同一格放两次、左右相反） |

**怎么从零重跑**（含中间产物 `tiles.npz` 与逐页 dry-run 读数怎么重生成）见同目录的
`怎么重跑.md`。中间产物都不入库——它们由源素材重算得出，留着不如留重算的路。
