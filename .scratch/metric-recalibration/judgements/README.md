## 第四轮：95 格逐页原始数据

`docs/measurements.md` 的《第四轮：十九页五判读员，只测有争议的两档》给的是汇总；
这里是它背后的逐页数据。**02 号票的验收要用的就是这一份。**

### 口径

模型判读，未经真机复核，不作标定依据——与 measurements 那一节同一条。
判读者是五个各自独立、无上下文的模型实例，看的是屏幕上的放大裁切（每页一块 320×320 放大 2 倍，
五格并置：参照 4bit+FS 加三个盲标候选），每页的 A/B/C 顺序各自打乱。

评级四档：`1` 几乎察觉不到 · `2` 看得出但不影响阅读 · `3` 明显影响观感 · `4` 严重损坏。
`接受` 是与评级独立作答的一问（存进阅读器长期看，收不收），`Q5` 是「只能留一格，选哪个」。

**评级是从五位判读者的报告转录来的**，原文在当时的会话记录里。转录之外没有加工。

### 数据

`第四轮判读.json`，19 页，每页：

| 字段 | 是什么 |
|---|---|
| `素材类型` | 五类之一，与 measurements 的分层表对得上 |
| `源` | `_samples/` 下的相对路径（`/_samples/` 是 gitignore 的，文件在本地） |
| `旧判据读数` | 六个候选的判据值，**旧判据算的**（`GRAIN_FLOOR = 55.0` 绝对值）——02 要重算的正是这一列 |
| `盲标映射` | 那一页 A/B/C 各是哪一档 |
| `判读[档].评级` / `.接受` | 五位判读者，顺序固定（j1…j5） |
| `Q5只留一个` | 五位各选了哪一档 |

`新判据读数.json` 是同一批页、同一批候选在**地板改成格点间距的比例之后**重算的那一列
（02 号票量的），格式就是 `recompute.py` 收的那一种：`{页 id: {候选: 读数}}`。
怎么跑出来的、口径自检怎么过的，见 measurements 的《跨档不再选反，幅度仍不相关》。

### 三个 ρ 是怎么配对的

每一页贡献一个点，19 页 19 个点。三个相关各自的两轴：

| | x | y | 判据有效时该是 |
|---|---|---|---|
| **同档排页** | 该页 `2bit+FS` 读数 | 五位对 `2bit+FS` 的评级均值 | **正** — 读数高的页判读也该更差 |
| 同档·接受率 | 该页 `2bit+FS` 读数 | 五位对 `2bit+FS` 的接受率 | **负** — 读数高则接受率低 |
| **跨档选谁** | `2bit+FS` 读数 − `4bit` 读数 | `2bit+FS` 评级均值 − `4bit不抖` 评级均值 | **正** — 判据说谁更差，判读也说谁更差 |

两轮各自实测的那三个数，见 measurements 的《跨档不再选反，幅度仍不相关》。

**02 只换 x 的那一半。** y 问的是「图好不好看」，与判据算出什么无关，因此不重做判读。

### 重算

`recompute.py` 读同一份 JSON，把 `旧判据读数` 换成新判据的读数，重算三个 ρ。用法写在脚本头部。

**先过自检**：拿新判据在这 19 页上跑一遍之前，先确认能用**旧**判据复现 `旧判据读数` 那一列——
同一页同一候选对得上，才说明重算的口径（缩放、裁块、面板）与当初一致。对不上就先查口径，
别拿一把没对准的尺子去证明另一把尺子修好了。

（**02 号票没有照这一条做**，走的是另一条对法，理由与「下一次该走哪条」的提案在
`.scratch/非阻塞问题.md` 的 **Q315**。这一条**原样留着**——改自检的口径是拍板的事，
不是走过一次的人顺手改的。）

## 第六轮：真机四组（人，整页 1:1）

`第六轮真机四组.json`。汇总在 `docs/measurements.md` 的
《真机三组：4bit 上的抖动分不出，白底上的抖动分得出，分界线是纸白落不落在格点上》。

**这一轮与前五轮不是同一类证据。**前五轮是模型看局部放大块，`docs/measurements.md`
《成品库上判不出阈值的原因是空间尺度》记着那条能力边界；这一轮是人在 Kobo Libra 2 上
整页 1:1、关掉缩放与白边裁切、不放大。**它可以作标定依据。**

四组各问一件事，逐对数据带着**源纸白**（`纸白` / `白底占页` / `到2bit格点` /
`FS在白底上要撒的点`）——B 组与 C 组问的是同一件事而答案相反，分界线就在这一列上。

**材料位置**：`_samples/_实验-判据重标定\真机包\`（三本 cbz ＋ `怎么看.md` ＋ `答案（判完再看）.json`），
在仓库之外，与 `_samples/` 同理。三本 cbz 由该目录下的 `参照8bit`（tonefit 以
`--gray-levels 256 --bit-depth 8 --dither off` 渲出的参照灰图）逐页量化而成，
量化用的是与 `src/quantize.rs` **逐像素等价**的复现实现（FS 在整页上 0 处不同、
4bit 就近取整逐字节相同，见 measurements 的《边缘门控抖动救不了那三页》口径自检）。


## 第七轮：真机包 04（人，整页 1:1）

`第七轮真机包04.json`。汇总在 `docs/measurements.md`。**04 号票的标定判读，
三组二十一对**，材料在 `_samples/_实验-判据重标定/真机包04/`，怎么造的见
`.scratch/metric-recalibration/calibration/`。

与第六轮同口径（人、真机、整页 1:1、关缩放与白边裁切、不放大），
**另有两条这一轮特有的**：

- **材料没有开纸白对齐**（`--white-align-limit` 保持 0）。`tone-alignment/05` 挂在
  `04` 之后，正是为了避开「标定用的素材已经被对齐过」这个循环。
- **L 组是平移出来的**：同一块 512×512 无文字白底（武器原档 MHZ01_090，纸白 253、
  近白占比 1.000、块内只有 5 级起伏）**只动直流**平移到十五个灰度，再铺满整页。
  像素全部来自一手素材、噪声与纹理原样保留，但**平移之后它不再是那一页的纸白**。
  N 组两块真实渐变是这个口径的锚点。

**这一轮最要紧的一条**：`L` 组的近白那一列 5/5 判「2bit 不抖更干净」，
而中灰与偏暗随《离格量》翻向 FS——**同一个 u、不同背景亮度，答案相反**，
共三行分歧。判据对背景亮度是盲的（同一个 u 的三格读数逐位几乎相同），
因此这一组不是「把地板标出来」，是**量出了判据缺哪一项**。


## 第八轮：复判包 04R（人，整页 1:1）

`第八轮复判04R.json`。第七轮 L 组有两格与相邻格的模式反着，怀疑在判读边界上——
**边界上的答案是随机的，不该拿去定形状**，但这只能问判读者。

问法：**那两格各放两次，左右顺序相反、位置隔开**，判读者不知道哪两对是同一格；
另加四格锚（上次答得明确的）看这一趟整体稳不稳。

结果：**锚 4/4 与第七轮一致**；`u02_偏暗` 两次一致（真值是 `2bit 不抖`，
第七轮那个 FS 是噪声）；`u42_中灰` 两次相反（**在边界上**，记成「平」）。

> **这个问法值得留作先例。**同一格放两次、左右相反，是判「这一格是真信号还是边界噪声」
> 最省的办法——比加判读者便宜，也比重判一整组干净。


## 第九轮：闸① 补测十二对（人，整页 1:1）

`第九轮闸1补测.json`。闸① 原来只有 n=4（AB 交错本第 9~12 对），而 `03` 的落地记录
自己写着「不作定量依据」——偏偏它是卡住判据标定的那一端。这一轮把 n 提到 16。

选页**按连续灰调面积分层**（31.5%~63.4%，四层各三页），**不按判据读数挑**
——按读数挑等于用判据给自己出题。排除已判过的四页、非正文页、同一话最多两页。

**结果：12/12 判 `2bit+FS` 更干净，判据 0/12 同向。**合并原四对，**n=16、15:1 偏 `2bit+FS`**。
位置偏好已排除：答案 `2 1 2 1…` 与编排的交替配平完全对应，FS 在左在右都被选中。

**判读者给的理由是关键**：*「理由都是另外一张有轻微色彩断层」*，并补充
*「除了轻微色带之外的观感几乎一致」*。翻成判据的话：

- `4bit 不抖` 的**色带看得见**（虽轻微）——而判据的低通项给它 5.8~8.0
- `2bit+FS` 的**颗粒看不见**——而判据的颗粒项给它 13.7~24.2

**低通项那一侧方向本来就是对的**（FS 3.2 < 4bit 6.0，与真机一致）；
**问题全在颗粒项**，它把方向顶反了。
