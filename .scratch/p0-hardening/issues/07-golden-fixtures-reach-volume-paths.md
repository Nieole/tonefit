# 07 — 黄金回归要走得到卷级判定

**What to build:** 黄金快照要能挡住迟滞与离群这两条判定路径的回归。

现在挡不住，变异实验证明：把迟滞页数改掉、把离群倍数改掉，快照逐字节不变。根因是夹具退化——十来个夹具卷里大半只有一页，最长五页，每一卷的摘要都是「离群 0 页 · 迟滞升档 0 页」。这两条路径在黄金回归里从未被走到。

归档卷也整个不在射程内。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 补一个页数足够的夹具卷，让上分位走非退化路径
- [ ] 补一个含离群页的夹具卷
- [ ] 补一个能触发迟滞升档的夹具卷
- [ ] 补一个归档卷夹具，让归档输出进快照
- [ ] 改动迟滞页数或离群倍数会让快照变红
- [ ] 快照体积可控：长卷只记卷级摘要与判定，不逐页展开
