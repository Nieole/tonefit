# 07 — 黄金回归要走得到卷级判定

**What to build:** 黄金快照要能挡住迟滞与离群这两条判定路径的回归。

现在挡不住，变异实验证明：把迟滞页数改掉、把离群倍数改掉，快照逐字节不变。根因是夹具退化——十来个夹具卷里大半只有一页，最长五页，每一卷的摘要都是「离群 0 页 · 迟滞升档 0 页」。这两条路径在黄金回归里从未被走到。

归档卷也整个不在射程内。

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] 补一个页数足够的夹具卷，让上分位走非退化路径
- [x] 补一个含离群页的夹具卷
- [x] 补一个能触发迟滞升档的夹具卷
- [x] 补一个归档卷夹具，让归档输出进快照
- [x] 改动迟滞页数或离群倍数会让快照变红
- [x] 快照体积可控：长卷只记卷级摘要与判定，不逐页展开

## 落地记录

四个夹具卷：`envelope-outlier`（20 页，秩 19 非退化，摘出离群 1 页）、
`envelope-outlier-heavy`（20 页，离群占比 10%，**当下摘出 0 页**——加固批 01 号要修的缺陷，
录在这里是先钉住「现在是什么样」，好让那张票的效果在快照 diff 里可指认）、
`envelope-hysteresis`（60 页，迟滞升档 3 页）、`archive.cbz`（归档输出与透传进快照）。

迟滞卷 60 页是数学下限而非估计：3 页要占到 5% 以内、秩才落得回填充页上，
即 `ceil(0.95n) ≤ n-3`，解得 `n ≥ 60`。

长卷用小页，源比面板小、几何门不成立、抖动整卷关闭。这是有意接受的形态——
这几卷考的是上包络、离群与迟滞，不是几何。代价是测试多跑约 3 秒（基线 48.5 秒）。

变异验证：`HYSTERESIS_PAGES` 3→8、`OUTLIER_FACTOR` 3.0→1.2、`ENVELOPE_QUANTILE` .95→.50，
三者现在都让快照变红；前两者在改动之前怎么改都逐字节不变。
