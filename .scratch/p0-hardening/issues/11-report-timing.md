# 11 — `Report` 补上计时

**What to build:** 调用方能从 `Report` 拿到每卷与整体的耗时，不必自己在外面掐表。

spec 把 `Report` 的形状标为固定，其中列了计时，但它掉在票与票之间——十五张票没有一条认领它。现在任何耗时数据只能靠外部计时得出。

**并行进行的 TUI 改造会消费 `Report`，计时的形状应当由那边的设计一并定下**，避免两边各改一版。

**Blocked by:** 与 TUI 改造的设计口径 —— 等那边定下 `Report` 的消费方式。
