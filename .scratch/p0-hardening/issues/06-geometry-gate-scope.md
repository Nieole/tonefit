# 06 — 几何门不该被一张小图否决整卷

**What to build:** 一卷里混进一张比目标尺寸小的封面时，正片各页仍然能用上抖动。

实测一卷 180 页，其中封面是四百来像素宽，比目标小 → 原样输出 → 几何门不成立 → **全卷 180 页禁用抖动**。按 ADR 0007：抖动仅在目标尺寸未被下游缩放时启用 的字面这是对的（几何门是 profile 级、不参与卷级统计），但让一张不具代表性的封面否决 179 页正片的抖动，结果说不通。

本票要先定口径再改：几何门保持卷级但改判定方式，还是允许按页判定而抖动模式仍按卷统一。定下来之后 ADR 0007 需要同步修订。

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] 口径定下来并写进 ADR 0007
- [x] 一卷里少数页触发不了 1:1 时，其余页的抖动不被连坐
- [x] 真正会被下游缩放的页不抖动
- [x] `Report` 说明几何门的判定范围与被排除的页
- [x] 混合尺寸卷有用例覆盖

## 落地记录

**口径：几何门按页判定，抖动模式仍按卷统一**（票面两个备选里的后一个，写进 ADR 0007
的《决定》，第 1～5 条）。前一个备选（门保持卷级、改判定方式）过不了第三条验收标准：
门只有一个结果，会被下游缩放的那几页仍会带着抖动写出去，换个判定方式只是把误判换到另一侧。

### 决定摊开是四句话

1. **门逐页判**，判定范围是灰度路径上的每一页。彩色分支上的页不在范围内（ADR 0010
   决定第 4 条不变），失败页连几何都没有。
2. **门不成立的页不进卷级上包络**。理由是构造性的，不是口味：它那套候选里没有抖动那一维，
   而上包络取的是 (位深, 抖动模式) 这个组合——**候选集不同的页排不进同一条序列**。
3. **门不成立的页跟着基准档的位深走，不低于它，抖动关掉**。门只拿走抖动，不拿走档次：
   让它们各按自己那条曲线定，位深那一维也会跟着逐页变，而它们并没有偏离卷内分布；
   只给基准档也不行——抖动被拿走之后同一档保真更差，那一页可能真的还要高一档。
   两头都堵上就是「取更严的那一个」。
4. **一页门成立的灰度页都没有时，不成立的那些页就是主体**，基准档由它们定出、必然不抖。
   与 04 号票那条「一页不剩地落在同一侧时一页都不摘」是同一条规矩。

### 部分救回页收了回来

04 号票把部分救回页摘出几何门，理由是「门对整卷只有一个结果，一张没解全的页不该替另外
一百多页回答这个问题」。门改成逐页判之后**那条理由整个不在了**：它答的只是自己那一页。
它的尺寸是文件头里的真尺寸，答得出「这一页会不会被下游再缩一次」，因此收回判定范围。

04 号票记着的那处「与 ADR 0007 的冲突」随之关闭——混排卷里那张贴不住面板的部分救回页
不再跟着整卷一起抖动。上包络那一侧的豁免没有跟着变：它那条判据曲线仍是在一页大半留白的
图上求出来的。两处于是分了家，`a_salvaged_page_answers_the_geometry_gate_for_itself_only`
把这个分家钉住。

**两刀落在同一页上时门那一刀在外层**（ADR 0007 决定第 3 条）：既没解全、又贴不住面板的页
拿「基准档的位深、不低于它、抖动关掉」，不是 04 号票那条「按自己那条曲线单独定档」。
理由是 04 号票自己的理由反过来用——摘它的根据是那条曲线不具代表性（一页大半留白，
误差恒为零，判出来必偏低），而不具代表性的曲线更没有资格把这一页压到基准档以下。
这个组合两条规矩各自的用例都碰不到，因此单立一条
`a_salvaged_page_outside_the_gate_never_falls_below_the_volume_base`。

### 实现上是删掉一套机制，不是再加一层

从前门要看完整卷才判得死：两个 `AtomicUsize` 记着「关门的最小页序」（完好页一格、
部分救回页一格），收尾处定出卷级的门，再把已经求过的抖动候选**统一裁一遍**。
那一裁正是「一页否决整卷」在实现上的落点。

现在算到哪一页就判哪一页的门，候选集当场定下，判据只在那一套上求。两个原子、
那一次统一裁剪、`Scored` 那个包装结构、`ScoredPage::speaks_for_the_gate` 全部删掉；
换进来的是 `Candidates`（两套候选备一次，`for_gate` 现取一套）。
`first_pass` 的返回值从 `Scored` 变回 `Vec<ScoredPage>`。

**并发那一条没有变弱**：门与调度本来就无关了，唯一还要「指名道姓」的是
`--dither fs` 撞上门那一支的错误——它仍报序号最小的那一页，靠的是页序归位之后才短路取错
（那一手本来就在）。

### 报告：判定范围与被排除的页

`VolumeReport::gate` 这个字段**删了**。门是页的判定，报告里因此跟着页走
（`PageBranch::Gray` 的 `gate`），卷级那两个数从页数出来：
`judged_by_the_gate()` 是判定范围，`outside_the_gate()` 是被排除的页。
单一出处的老规矩——与 `failures()` 不另占一个字段是同一条。

范围非说不可，否则「几何门成立」读不出它替多少页说了话：一卷全是彩页时门同样成立，
而那是「无人可关」，不是「每一页都贴住了面板」。

逐页那一行由新的 `Reason::OutsideTheGate`（`几何门不成立，本页不抖动`）标出来，
tEXt 那一侧是 `outside the geometry gate, dither off`。整卷都不成立时不走这个理由——
那时它们就是主体，理由仍是「卷级上包络」：`OutsideTheGate` 说的是「摘出去了」，
而那样的卷没有别人可摘给。

### 覆盖项撞上门仍是整趟拒绝

`--dither fs` 撞上一页贴不住面板，那一页的候选集被裁空，整趟报错——错误指得出是哪一页。
不改成「按页放弃抖动」：覆盖项是用户的显式指令，不是可以按页悄悄放弃的东西。
理由写在 ADR 0007 的《后果》里。

### 真实卷上的效果

拿 Forget-me-not 第 1 卷（Poke6 上只有两页贴不住面板）实测过一遍，
数与对照口径记在 `docs/measurements.md` 的《混排卷：这笔代价只落在贴不住面板的那几页上》。

**买到的是候选，不是名次**：那些页重新够得着抖动候选，而 2bit+FS 与 4bit 不抖谁好看，
盲测里两张页给的是相反的答案（见 measurements 的《位深盲测》）。这一票不主张画质变好。

### 四组变异，各跑全套 `cargo test`（基线 268 条全绿）

| 变异 | 转红 |
|---|---|
| 门不成立的页只拿基准档，不再往上取更严的那一档 | 2 条——混排卷那条、黄金回归 |
| 门不成立的页照旧跟着基准档抖动 | 4 条——混排卷、部分救回、并发混排、黄金回归 |
| 部分救回页重新被摘出判定范围（04 号票那条豁免回来） | 3 条——部分救回那两条、上包络那条 |
| 门那一刀不切：门不成立的页照旧进上包络 | 10 条——`score_at` 当场炸在「候选集全卷同一套」上 |
| 门外的部分救回页改按 04 号票单独定档（去掉那道下限） | 1 条——两刀落在同一页上那条 |

末一条那 10 条不是覆盖面广，是**混候选集根本走不通**：上包络按候选排序，
而门不成立的页缺着抖动那一维。第 2 条决定因此不是口味。

黄金夹具新增 `mixed-size`：四页正片贴住面板、一张封面比目标小，是快照里**唯一两套候选集
都用得上**的那一卷。封面判 4bit 不抖（自己那条曲线要到 4bit，基准档只有 2bit，取更严的），
另外四页 2bit+FS。已有各卷的判定与字节数**一个都没动**——这次改动对全成立与全不成立的卷
不产生任何差别，快照里只有几何门那一行换了写法。
