# 01 — 离群页判定不再拿自己当尺子

**What to build:** 一卷里彩页占比过高、或卷本身页数不多时，离群页仍然能被摘出来，主体页不被少数极端页拖着走。

现在的判定拿一次全卷聚合当立脚点，于是两种日常情形下一页都摘不出来：

- **离群页超过 5% 时**：它们自己把临时基准档抬上去，检验又在那一档上做，人人达标，一个都摘不出。实测 60 页卷、6 页离群 → 摘出 0 页，54 页主体被整体拖高一档。触发条件就是 ADR 0006 自己举的例子——黑白 profile 下的彩页转灰。
- **卷不足 20 页时**：上分位的秩落在排序末位，临时基准档就是最极端那页自己，它按定义必在自己那档内。实测 19 页与 20 页的相邻对照，结论相反。CBZ 章节包普遍落在这个区间。

离群页机制是卷级分位聚合的安全网。判据那一层的分块分位聚合原本就没有这层网，
由 02 号票补上——**两处分位聚合目前等于都在裸奔，两张票合起来才算把这件事做完。**

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent
