# 01 — 离群页判定不再拿自己当尺子

**What to build:** 一卷里彩页占比过高、或卷本身页数不多时，离群页仍然能被摘出来，主体页不被少数极端页拖着走。

现在的判定拿一次全卷聚合当立脚点，于是两种日常情形下一页都摘不出来：

- **离群页超过 5% 时**：它们自己把临时基准档抬上去，检验又在那一档上做，人人达标，一个都摘不出。实测 60 页卷、6 页离群 → 摘出 0 页，54 页主体被整体拖高一档。触发条件就是 ADR 0006 自己举的例子——黑白 profile 下的彩页转灰。
- **卷不足 20 页时**：上分位的秩落在排序末位，临时基准档就是最极端那页自己，它按定义必在自己那档内。实测 19 页与 20 页的相邻对照，结论相反。CBZ 章节包普遍落在这个区间。

离群页机制是卷级分位聚合的安全网。判据那一层的分块分位聚合原本就没有这层网，
由 02 号票补上——**两处分位聚合目前等于都在裸奔，两张票合起来才算把这件事做完。**

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] 离群判定不锚在包含被判页自身的聚合上
- [x] 60 页卷含 6 页离群时，离群页被摘出，主体档不被抬高
- [x] 卷页数从 1 到 20 逐个覆盖，19 与 20 的相邻对照有用例钉住
- [x] `Report` 给出离群页占比，让「一页都没摘出来」在报告里看得见
- [x] 黄金快照重新录制，差异逐条确认是本票的预期效果

## 落地记录

立脚点从「全卷取一次上包络」改成**逐页各取一个、且不含被判的这一页**
（`src/envelope.rs` 的 `outlying`）。把这一页从按逐页判定排好的序列里抽掉，
站在 `ANCHOR_QUANTILE` 秩上的那一页就是它的立脚点。一次排序换来逐页 O(1)——
抽掉的那一页排在秩之前，后面整段前移一格；排在秩之后则不影响这个秩。

**两处退化各要一手，缺一不可**。三组变异，各跑全套 `cargo test`（基线全绿）：

| 变异 | 转红 |
|---|---|
| 去掉留一：立脚点按全卷取 p75，全卷共用一个 | 3 条——1–20 逐档、上界那条、黄金快照 |
| 留一还在，立脚点退回 p95 | 5 条——60 页含 6 页离群、上界、占比、集成那条、黄金快照 |
| 每页拿自己当立脚点 | 12 条 |

去掉留一之所以只红 3 条而不动 19/20 那一对：`⌈0.75n⌉` 在 n=19 与 n=20 上都落在填充页身上，
两卷仍同结论。留一真正挡住的是 `n ≤ 3`——那时秩上那一页就是最极端的那页——
以及每个卷长上被放宽的那一页占比余量。

`ANCHOR_QUANTILE` 取 0.75 是**未标定占位值**，两侧余量摆在一处：p95 只经得住 5%，
而再往下取（如中位数）会翻到另一侧——一卷里过半页要更高一档时，那些页会被当成离群页
整片摘走，而它们才是主体。ADR 0006 那句「三个数均尚未标定」随之改为四个数，多出来的正是它。

摘得出来的占比有个上界，`n+1-⌈0.75(n-1)⌉`，**随卷长变**：60 页要 16 页，20 页要 6 页，
5 页要 3 页——长卷上才趋近四分之一，短卷宽得多。这条算式由
`one_page_past_the_bound_is_where_the_anchor_moves_in_and_nothing_is_taken_out` 在界线两侧各钉一处，
不留成注释里的声称：本票修的原缺陷，正是一句「上分位至多让 5% 的页越过它」被当成了成立的性质。
p95 那个 ≤5% 的结构性上界随立脚点一并去掉，ADR 0006 的《后果》补了一条认下这件事。

`Envelope::outlier_share()` 是这张网**有没有张开**的唯一外部观测点：光看计数，
「离群 0 页」读起来像「本来就没有离群页」，而它同样可能是判定整个失灵——本票修的就是后者。
CLI 那一行随之写成 `离群 0 页（0.0%）`。

黄金快照三处变动，逐条确认都是本票的效果，两种成因各占一边：
`envelope-outlier-heavy` 是**离群占比越过 5%**，另两卷是**短卷上立脚点站到了被判页自己身上**——
票面点名的正是这两种日常情形。

- `envelope-outlier-heavy`（20 页，离群占比 10%）：`基准档 4bit · 主体 20 页 · 离群 0 页`
  → `基准档 1bit · 主体 18 页 · 离群 2 页`。07 号票正是为这一刻把它录进来的。
- `mixed`（5 页：3 线稿 + 1 渐变 + 1 纯色）：三页线稿从 2bit+FS 落回 1bit（16730 → 10436 字节／页），
  两页灰调保持 2bit+FS、理由改为「离群页单独定档」。
- `archive.cbz`（2 页：线稿 + 渐变）：同上，线稿落回 1bit，渐变成为离群页。

三处**只有主体页变便宜，离群页一个字节没动**（192766／215607 前后一致）——本票移除的是
「被少数极端页拖高」这一件事，没有别的副作用。该变而没变的卷一个也没有：单页卷走
`len < 2` 那道挡板，`color-on-color` 只有一页灰度页，`damaged` 两页同为 1bit，
`envelope-outlier` 与 `envelope-hysteresis` 的立脚点前后都落在填充页上。

代价认下来：`archive.cbz` 现在是「主体 1 页 · 离群 1 页」，两页的卷各判各的档。
短卷上离群页可能占到近半，而 ADR 0006 认下的「位置少且可指认」里，「少」不再有结构保证。

`mixed` 与 `archive.cbz` 从前那个「离群 0 页」不是性质，是缺陷：卷不足 20 页时上分位的秩
落在排序末位，立脚点成了最极端那页自己。`golden.rs` 里把 `mixed` 说成「不该触发离群」的
那条注释一并改掉——那句话当初就建立在缺陷上。（`archive.cbz` 没有对应的注释：它那条讲的是
归档成员串位，是另一条性质的现场。）
