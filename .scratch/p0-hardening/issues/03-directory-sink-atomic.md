# 03 — 目录卷重做时清掉陈旧产物

**What to build:** 源里删掉一页后重做，输出里那一页也要消失。

现在目录卷只覆盖本趟写出的文件，从不清理不该再存在的旧成员。于是删页重做之后，那一页原地不动、还带着上一趟的元数据，下一趟又被幂等跳过，从此永久留在输出里，在阅读器里与真页毫无分别。

归档卷没有这个问题（整个容器重写）。同一条标准在两种容器形态上给出不同答案。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 目录卷写出后，输出里只剩本趟的产物与透传文件
- [ ] 源删掉一页后重做，输出里对应的页消失
- [ ] 中断时不留下半成品目录
- [ ] 两种容器形态在同一批输入上给出一致的输出成员
- [ ] 「源变更触发重做」那条用例补上「重做之后输出里有什么」的断言
