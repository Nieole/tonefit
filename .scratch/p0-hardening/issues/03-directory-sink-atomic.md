# 03 — 目录卷重做时清掉陈旧产物

**What to build:** 源里删掉一页后重做，输出里那一页也要消失。

现在目录卷只覆盖本趟写出的文件，从不清理不该再存在的旧成员。于是删页重做之后，那一页原地不动、还带着上一趟的元数据，下一趟又被幂等跳过，从此永久留在输出里，在阅读器里与真页毫无分别。

归档卷没有这个问题（整个容器重写）。同一条标准在两种容器形态上给出不同答案。

本票的做法已与会话层协调过：目录卷改成整目录重写、中断时不留半成品，
于是它与归档卷同形——半卷永远不出现在最终位置。ADR 0013：两级停——收尾与中止
里「中止时删半卷」那一条会随之降级为「丢弃未改名的临时容器」，由会话层在本票落地后修订。
**照原样做，不要为那条 ADR 留后门。**

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] 目录卷写出后，输出里只剩本趟的产物与透传文件
- [x] 源删掉一页后重做，输出里对应的页消失
- [x] 中断时不留下半成品目录
- [x] 两种容器形态在同一批输入上给出一致的输出成员
- [x] 「源变更触发重做」那条用例补上「重做之后输出里有什么」的断言

## 落地记录

目录卷改成**整目录重写**：`Sink::create` 在最终位置旁边建一个 `<名字>.partial` 临时目录，
整卷写进它，`Sink::finish` 先把最终位置整个删掉、再把临时目录改名到位
（`src/sink.rs` 的 `DirectorySink`）。归档卷本来就这么走，两支于是同形——
两者各留一格 `partial: Option<PathBuf>`，改名成功才清空，析构按它决定要不要清。
`ArchiveSink` 因此把「临时文件 + 写入器」那一格拆成两格：收尾要取走写入器，
而临时文件得留到改名之后；顺带补上了「收尾自己失败时也不留临时文件」这一手。

改名不跨卷（临时容器与最终位置同一层），因此不退化成一次逐字节复制。

**为什么先删后改名**，而不是「把旧的改名到一边、放好新的、再删旧的」：多出来的那个中间名字
要么留在输出里让用户猜，要么还得为「删它又失败了」再写一手。删这一步失败就整趟失败，
最终位置原样不动，临时目录由析构收走。代价是最终位置有一个「旧的已删、新的未到」的窗口，
崩在那里就两头落空——但下一趟幂等看不到输出，整卷重做，结果仍然是对的。

**「中断时不留半成品」怎么测的。** 目录卷造不出归档那种坏 CRC——文件系统上一个文件
要么读得出来，要么根本不在。用观察者当注入口：`volume_started` 恰好落在「成员枚举完」与
「读到任何字节」之间，在那里把源里的透传文件抽走，页就会先写进临时目录、
再在第二遍读透传文件时失败。同一个口子还钉住了一条**过程中**的性质——
每报到一步看一眼最终位置，整卷写完之前那里一个成员都没有。

**两组变异，各跑全套 `cargo test`（基线全绿）：**

| 变异 | 转红 |
|---|---|
| 目录卷退回逐页直写（临时目录与改名一起去掉） | 7 条——容器 5 条、幂等 2 条 |
| 保留临时目录与改名，但析构不清临时目录 | 2 条——中途失败那两条 |

退回逐页直写只红 5 条容器用例而不是 6：`a_directory_volume_that_fails_partway_...`
在那个变异下仍然通过，因为变异只拿掉了临时目录、没拿掉析构，
析构于是直接把最终位置删了——两组变异合起来才盖住这一条。

幂等那两条（`a_changed_source_redoes_the_volume`、`renaming_a_source_page_redoes_the_volume`）
此前只断言「没被跳过」。补上「重做之后输出里有什么」之后，「少了一页」与「给一页改名」
两行才真的钉得住本票——重做本身从来没坏过，坏的是重做没清掉不该再存在的成员。
`rerun` 因此改成返回判定与成员清单两样：清单在函数内取好，工作区是临时目录，一返回就没了。

### 交给会话层的三处陈旧说法

那一条降级（「中止时删半卷」→「丢弃未改名的临时容器」）按票面交给会话层，
与 `p1-session` 的 04 号票一起改。**在那之前，下面三处从本次提交起就不成立了**——
票面只点了头一处，另两处一并记在这里，免得改的时候漏掉：

1. ADR 0013 的《背景》与 `CONTEXT.md`《会话》末段：「目录卷逐页直写」。
2. ADR 0013 的《后果》：「中止删用户输出目录里的东西。**这是 tonefit 唯一一处主动删除**」。
   收尾时腾出最终位置也是一次删除，且发生在**成功**这条路上。范围仍是「本趟要写的那个去处」，
   另一个去处留着的过期副本照旧碰都不碰——变的是那句「唯一」。
3. `p1-session/issues/04-abort-and-the-half-volume.md` 正文里同样的那句「目录卷是逐页直写的」。

### 两处够不着的边

**验收第 1 条只管「写出后」。** 幂等跳过的卷根本走不到写出这一步，`can_skip` 也只问
「该在的成员在不在」、不问「有没有多出来的」。因此有人手动往输出里塞一个文件、而源一动没动时，
那个文件会一直留着。要挡这一下，跳过这条路上就得列一遍输出、并在一趟什么都没做的运行里
动手删东西——那正是 ADR 0013 的《不要做的「简化」》拦下的方向。本票不碰。

`ArchiveSink::finish` 自己失败时清掉临时文件的那一手**没有用例覆盖**，也**不是本票验收标准里的
任何一条**：收尾的三步（写中央目录、刷出、落盘）在测试里注入不出失败。留着它是因为
「`partial` 只在改名成功后清空、析构清掉剩下的」这条不变量要在两支上同时成立，
第 4 条要的同形才不只是长得像。
