# 08 — 补上两处能让真 bug 溜过去的哨兵

**What to build:** 两类回归目前能全绿溜过，各补一道断言。

**归档输出的像素无人断言。** 变异实验：让归档写出时每个成员都写第一页的字节（整卷页页相同的串位缺陷），全套测试一项都没红。目录卷那一侧有哨兵，归档卷没有。

**彩页判据的两个常量可以任意改。** 现有用例的夹具是从被测常量自己算出来的，常量取任何值都恒真。变异实验：把色度门限调高一倍半、覆盖率门限调高二十倍，全绿；反方向调到会把有损转码的近灰页整批误判成彩页，同样全绿。

## 落地记录

两处各补各的，验收标准同一条：**把被保护的那个行为改坏，这条哨兵红不红。**

### 归档端：`tests/container.rs` 的 `every_archive_member_carries_its_own_pixels_at_its_own_size`

归档这一侧此前只问过成员名、成员顺序、成员非空、透传字节四件事，**成员里装着什么**没人问。
根子在读法：目录卷的页有文件系统路径，`pipeline.rs` 与 `isolation.rs` 里一大批用例按
`page.output` 逐页读回来比尺寸、比像素、比记录；归档成员没有路径，读它只有
`fixtures::read_cbz` 一条路，而在这条用例之前没有一处用它解过页。

**票面那句「目录卷那一侧有哨兵」指错了地方，据实订正**：它指的多半是 `isolation.rs` 的
`a_color_page_a_gray_page_and_a_failed_page_keep_their_own_pixels`，而那一条五页同尺寸、
断的是「003 与 005 这两张同一夹具写出来逐字节相同」——把票面那个变异套上去它照样绿，
它钉的是缓存序号错格，不是成员装的是不是自己的像素。目录那一侧真正的哨兵是散在
`pipeline.rs` / `isolation.rs` / `idempotency.rs` 里那些逐页读回文件的断言，见下面的变异数据。

夹具是一个 CBZ：三张灰度页（尺寸 160×224 / 120×200 / 200×160，黑带高度 8 / 96 / 151）、
一张彩页（180×240）、一个透传文件，跑在彩色 profile 上，两条分支都走到。断言逐个成员：
灰度页比**尺寸**与**整幅像素**，彩页比尺寸与六条色带，透传文件比字节。

灰度页断得起逐字节的等号，靠夹具的两条性质（见 `fixtures::black_top_band` 的文档）：
页小于面板因此一步都不缩放，页上只有纯黑与纯白因此在 {1,2,4,8} 每一档上都是格点、
量化与抖动都是恒等。判定落在哪一档都不影响这个等号。

顺带给夹具补了三样：`black_top_band`、`luma_pixels`，以及 `read_color_png_bytes`——
归档成员没有文件系统路径，彩色那一侧此前只有收路径的读法。

### 彩页判据：`src/color.rs` 的测试模块

四个夹具数字从判据常量里挪出来，写死在测试模块顶上：`COLORED_NEEDED = 100`（两万像素的
0.5%）、`NOISE_CHROMA = 12`、`FLOOR_CHROMA = 16`、`PAINT_CHROMA = 20`。夹具页尺寸从
64×64 改成 100×200，为的是让覆盖率有个整数落点——两万像素上 0.5% 恰好是 100 个。

用例排成三对：

| 用例 | 钉住什么 |
|---|---|
| `a_near_gray_page_with_transcode_noise_stays_gray` | 噪声铺满全幅，覆盖率那一维帮不上忙，只有地板拦得住 |
| `a_small_color_stamp_leaves_the_page_gray` | 印章色度饱和，幅度那一维帮不上忙，只有覆盖率拦得住 |
| `a_half_page_painting_is_a_color_page` | 两维都不该拦住：色度只比地板高四级，覆盖率只有半页 |
| `the_chroma_floor_sits_at_a_literal_level` | 地板的位置本身，15 判灰 / 16 判彩 |
| `the_colored_fraction_sits_at_a_literal_pixel_count` | 覆盖率的位置本身，99 判灰 / 100 判彩 |

后两条是「任一门限被改动就变红」那一条验收的落点：门限往哪个方向动，那一对里都有一句对不上。
前三条是页形状的哨兵——门限动到某个幅度之外，它们跟着红，而红出来的话是「这类页被判错了」，
不是「一个数变了」。两类哨兵都留着，是因为它们在标定之后的命运不同：那一对钉的是
**这个数是多少**，标定要改数就得连它一起改；前三条钉的是**这类页该判成什么**，
只要新数字仍在同一个区间里就不必动。

**「任一改动」有一处颗粒度的余量，据实记下**：地板是整数，±1 必红；覆盖率那一侧
`needed = ceil(20000 × f)`，`f` 落在 `(0.00495, 0.005]` 里算出来都是 100，
往下不到 1% 的改动两句断言都还绿。这是两万像素这个页尺寸定的下限，不是断言形式的问题。

### 变异验证

每一组都跑两次：先在新用例上（该红），再把改动前那一份测试放回去、变异不动（对照）。

| 变异 | 新用例 | 旧用例 |
|---|---|---|
| 归档写出时每个成员都写第一页的字节 | 红：`2.png 的尺寸不是它自己的 left: 160x224, right: 120x200` | 除黄金快照外**全绿**，见下 |
| 同上，但夹具四页改成同一尺寸 | 红：`2.png 装的不是它自己的像素` | —— |
| 同一个变异改加在**目录**那一侧 | —— | 红 8 条：`idempotency` 1、`isolation` 2、`pipeline` 5 |
| `CHROMA_FLOOR` 16 → 24（一倍半） | 红：地板那一对 + 半页彩绘 | **全绿**（全套 268 通过） |
| `CHROMA_FLOOR` 16 → 4（反方向） | 红：地板那一对 + 近灰噪声页 | **绿**（`--lib color::` 四条全过） |
| `COLORED_FRACTION` 0.005 → 0.1（二十倍） | 红：覆盖率那一对 | **全绿**（全套 268 通过） |
| `COLORED_FRACTION` 0.005 → 0.002（反方向） | 红：覆盖率那一对 + 小面积印章页 | **绿**（`--lib color::` 四条全过） |

第二行是补出来的对照：三张灰度页尺寸各不相同时，先红的总是尺寸那一句，像素那一句
是不是也有牙看不出来。把四页改成同一尺寸再跑同一个变异，红的就是像素那一句——两半都有牙。

第三行量出了两侧的真实差距：同一个缺陷落在目录容器上，现有用例红 8 条；落在归档容器上，
红的只有黄金快照那一条。票面说的「目录卷那一侧有哨兵，归档卷没有」方向是对的，
指的那一条用例不对。

**票面那句「全套测试一项都没红」今天只对了一半，据实记在这里**：归档那个变异会让
`tests/golden.rs` 的 `the_fixed_fixtures_still_decide_the_same_way` 变红。那是 07 号票之后
才有的事——它给黄金快照加了一个归档卷，让写进容器的页字节数也进快照。但它逮住这个变异
靠的是**输出字节数**那一列（`192766` 变成 `16730`），两页编出来的长度恰好相同就漏了；
而快照本身「一条性质都不主张」，还有 `TONEFIT_ACCEPT_GOLDEN=1` 这个正当的接受通道。
本票补的这条问的是「这个成员装的是不是它自己的像素」，两者不是同一件事。
彩页判据那两个变异则与票面完全一致：全套 268 通过 0 失败。
