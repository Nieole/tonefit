# 04 — 一行都没救回来的页不算好页

**What to build:** 截断到解不出任何像素的图片，不能当成正常页写出去。

现在只要文件头给得出尺寸、装配得出图，就算成功——救回 99% 和救回 0 行是同一种结果。实测把一张页截在第一个数据块的头部（零行像素），输出是一张全白页，带着正常的判定元数据，卷没进隔离目录，退出码为 0。

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] 救回过程能给出「救回了多少」
- [x] 零行救回按失败页处理：进隔离目录、进失败清单、退出码反映失败
- [x] 部分救回是独立的第三种页状态，不参与几何门与卷级上包络
- [x] `Report` 能区分完好页、部分救回页、失败页
- [x] 零行救回与部分救回各有用例

## 落地记录

界线从「解不解得出完整尺寸」（12 号票）挪到**「救不救得回像素」**。尺寸只买到几何，
买不到一个像素——这是本票全部改动共用的那一句。

### 救回了多少怎么量出来的

`salvage` 现在解**两趟**：一趟填纸白（那就是返回的那张图），一趟填 `PROBE`（0）。
两趟里对得上的字节就是解码器真写下的——没写过的地方一边 255、一边 0，恒不相等
（`src/decode.rs` 的 `measure`）。量出来的比例装进 `Salvage`，跟着 `Decoded` 交给管线。

**换不成「数一数缓冲里还剩多少个纸白」**：漫画页的天地留白本来就是纸白，那样数出来，
一张只救回了页眉留白的页会被判成零救回——而零救回正是本票拿来打成失败页的那条判据，
判错的方向还是把一张救回来的页打成失败页。

这一手不认格式，也不假定救回来的是一段前缀（隔行 PNG 写进缓冲的位置本来就不连续）。
代价是救回这条路上解两趟、峰值多占一份缓冲，而它整个落在**整解已经失败**的那条路上，
正常页一趟都不多解。

比例量的是缓冲字节，而每个像素占的字节数处处相同，因此就是像素的比例。

### 三种页状态

`PageOutcome` 从两个变体变成三个：`Whole(Processed)`、`Salvaged { page, salvage }`、`Failed`。
前两者共用 `Processed`（缩放、彩页识别、分支）——它们在这几项上一模一样，差别只有救回了多少。
`PageReport::salvage()` 是**分辨三者的唯一口子**：`failure()` 有值的是失败页，
`salvage()` 有值的是部分救回页，两处都没有的才是完好页。

部分救回页在管线上真的与另外两种都不同：

| | 几何门 | 卷级上包络 | 隔离目录 | 退出码 |
|---|---|---|---|---|
| 完好页 | 参与 | 参与 | — | 0 |
| 部分救回页 | **不参与** | **不参与，单独定档** | 不进 | 0 |
| 失败页 | 不参与 | 不参与 | 整卷进 | 2 |

部分救回页那两个「不参与」各有一条兜底，见《摘出去的规矩，两处同一条》。

**为什么摘出上包络**：它那条判据曲线是在一页大半留白的图上求出来的，而留白在任何位深上
都是格点、误差恒为零——那条曲线代表不了这一卷。摘法与离群页并列（ADR 0006 决定第 5 条），
只是摘的理由是页残缺，不是判据偏离。

**为什么摘出几何门**：门对整卷只有一个结果，而一张连像素都没解全的页不该是替另外
一百多页回答「输出会不会被下游再缩一次」的那一张。少数页否决整卷这件事本身归 06 号票收口，
本票只是往那份名单上添了第二类页（第一类是彩色分支，ADR 0010）。

### 摘出去的规矩，两处同一条

**一页不剩地落在救回那一侧时，两处都不摘。** 摘一页是为了护着别人，而那时没有别人可护：
上包络那一侧主体不能空着（与 `envelope::summarize` 里「一页不剩地落到离群侧」同一条规矩），
几何门那一侧则改听它们自己的几何。

几何门那条兜底不是为了对称好看：没有它，一整卷贴不住面板的页会带着抖动写出去，
而 ADR 0007 拦的正是这件事。实现上多一格 `salvaged_breaker`，最终的门在第一遍收尾处定
（`src/lib.rs` 的 `first_pass`）；求判据那条快路不读它——晚定下来的门由收尾处那次统一裁剪
兜住，那套机制本来就在。

### 与 ADR 0007 的冲突：留着，但指出来

**混排卷里那张贴不住面板的部分救回页会跟着整卷一起抖动**，而 ADR 0007 的决定写着
「抖动仅在目标尺寸未被下游缩放时启用」。这是本票第三条验收标准（部分救回页不参与几何门）
的直接后件，不是实现走样。

不在本票里改 ADR：06 号票的第一条验收标准就是「口径定下来并写进 ADR 0007」，
而它要收的正是「少数页否决整卷」这同一件事——那里定的口径会一并覆盖本票添的这一类页。
对照先例：彩页那次豁免写进了 ADR 0010 决定第 4 条；这一类页眼下只在 `CONTEXT.md`
与 `first_pass` 的文档里，两处都点名说了它与 ADR 0007 冲突。

### `Reason` 没有新增一项

「这一页只救回了一段」是页的状态，不是「这一档是怎么来的」，而单一出处要求它只有一个存放处。
tEXt 那一侧因此在理由前面**添一句**（`salvaged 49.8% recovered, volume-p95, driven by page 001`），
不另占一个关键字：占位页那句自证是同一个道理——一张只救回了一半的页离开报告的上下文，
就再没有地方说得出它不全。它不进指纹：重做与否只看源字节，源字节没变，救回的比例也不会变。

### 报告三处各说一遍

逐页那一行标出救回了多少（`救回 49.8% · 判定 1bit（阈值内最低的一档）`），卷级那一行说
这一卷有几页不全、它们没参与哪两件事，末尾那一小结让几十卷跑下来的人不用往回翻。
末尾那一行比隔离那一行更需要存在：**部分救回页没有退出码替它喊**，卷也照旧落在干净的去处，
从进程那一侧看这一趟与全部成功一模一样。

### 四组变异，各跑全套 `cargo test`（基线 260 条全绿）

| 变异 | 转红 |
|---|---|
| 零救回照收（去掉那道拒绝） | 3 条——失败页那条、退出码那条、黄金回归 |
| 部分救回页照旧关几何门（豁免去掉） | 1 条——几何门那条 |
| 去掉几何门那条兜底（部分救回页永不投票） | 1 条——整卷全救回那条 |
| 部分救回页照旧进上包络 | 2 条——上包络那条、黄金回归 |

黄金夹具 `damaged` 现在四页占齐三种状态：完好页、部分救回页（`救回 49.8%`）、
两张失败页（一张分配不下缓冲、一张零救回）。驱动页因此从 `002.png` 挪回 `001.png`——
上包络的主体从 2 页减到 1 页，正是本票要的那个变化。

### 峰值内存在救回那条路上翻倍

量救回了多少要第二份等长的缓冲，`MAX_DECODED_BYTES` 因此不再是那条路上的峰值上界，
2 倍才是。拒绝的门槛仍是同一个数、不为救回另设一个更小的——那就成了「整解收得下、救回嫌大」，
正是 12 号票立那个常数时要消灭的东西。翻倍整个落在**整解已经失败**的那条路上，
正常页一份都不多占。常数处的注释已按新口径改写。

### 一处够不着的边

判据是「解码器报没报错」。解码器**声称成功却一个像素都没写**的文件躲得过去——
救回那一趟根本不会启动，而给每一页都解两趟去查，代价落在全部正常页上，不划算。

`docs/measurements.md` 的《截断页的解码容忍度》末尾那条「另测」记着这样一种文件
（PNG 只留文件头 + IHDR 时 `decode` 成功，出一张全黑图）。**用当前依赖复测，它不再成立**：
`image` 0.25.10 / `png` 0.18.1 上，只留文件头 + IHDR 报 `unexpected end of file`，
补上 IEND 报 `IDAT or fdAT chunk is missing`，两种都到不了「成功」。那个洞因此眼下是空的，
但判据仍然是解码器的错误，不是像素本身。

**那一行没有随本票改**：`docs/measurements.md` 当时正带着另一批未提交的实测改动，
动它会把两件事搅在一起。它是一处已经不成立的实测记载，该由改那个文件的人一并收口。
