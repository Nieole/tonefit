# 04 — 一行都没救回来的页不算好页

**What to build:** 截断到解不出任何像素的图片，不能当成正常页写出去。

现在只要文件头给得出尺寸、装配得出图，就算成功——救回 99% 和救回 0 行是同一种结果。实测把一张页截在第一个数据块的头部（零行像素），输出是一张全白页，带着正常的判定元数据，卷没进隔离目录，退出码为 0。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 救回过程能给出「救回了多少」
- [ ] 零行救回按失败页处理：进隔离目录、进失败清单、退出码反映失败
- [ ] 部分救回是独立的第三种页状态，不参与几何门与卷级上包络
- [ ] `Report` 能区分完好页、部分救回页、失败页
- [ ] 零行救回与部分救回各有用例
