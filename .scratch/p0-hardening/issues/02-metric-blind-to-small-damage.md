# 02 — 判据在真实页尺寸上不再对小面积损伤失明

**What to build:** 一页里只有一小块灰调崩坏时，判据要读得出来，而不是给 0。

现在的分块上分位在真实输出尺寸上把小面积损伤整块丢掉：基准面板的目标尺寸铺出两千多块，上分位取的是倒数第二十几差的那块，覆盖不到那么多块的损伤读数为 0——三个候选位深全是 0，于是该页被判成最低档，而那一小块正是唯一会崩的地方。

现有用例用的页比真实输出尺寸小得多，损伤占比恰好越过门限所以通过。这条性质要在**真实会写出去的那个尺寸**上成立。

本票改动触及 ADR 0002：判据建立在低通后的局部均值上 里定死的聚合方式，需要一并修订该 ADR。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 聚合带一条与页尺寸无关的下限秩，局部损伤的可见性不随页面变大而消失
- [ ] 在基准面板的真实目标尺寸上，占页面约 1% 的灰调崩坏区判据显著大于 0
- [ ] 现有那条「留白不稀释局部劣化」的用例改到真实目标尺寸上量，仍然通过
- [ ] ADR 0002 同步修订，写明新的聚合方式与它防的是什么
- [ ] 黄金快照重新录制
