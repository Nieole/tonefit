# 04 — 中止：页边界检查点与半卷清理

**What to build:** 按停的第二级。收尾要等当前卷跑完（02 已经给了）；**中止**立刻停，
并把当前卷这一趟**已经写出去的成员清干净**。

半卷不是一份对的输出。目录卷是逐页直写的，半卷里每一页都带着完全正确的元数据，
摆在文件管理器里与一本处理好的书没有分别。幂等会因为「输出不齐」重做它，结果不会错——
但它和「过期副本」是同一类陷阱，而这一个是我们自己留下的。

依据：ADR 0013（两级停——收尾与中止）。

**注意：按当下的容器形态实现，不要为 `p0-hardening` 的 03 号票留后门。**
那一票把目录卷改成整目录重写之后，本票的清理动作会降级为「丢弃未改名的临时容器」，届时再简化。

**Blocked by:** 02 — 事件流。

**Status:** ready-for-agent

- [ ] 观察者在页边界答中止 → 处理当场停下，不等当前卷跑完
- [ ] 目录卷：当前卷这一趟写出的成员清干净；**别的卷的输出一个不动**
- [ ] 归档卷：只留一个改不了名的临时文件，不留冒充成品的归档
- [ ] 上一趟留下的过期副本不被中止碰到——删的只有本次运行写出去的那些
- [ ] 中止之后重跑，被中止的那一卷整卷重做，幂等不把它误判为做完了
- [ ] 卷边界与页边界各有一个检查点，两者行为分得开
