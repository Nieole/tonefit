# 13 — 会话：设备层里一键写出标定图

**What to build:** 光标停在设备层时按一个键，按当前 profile 写出**标定图**。

设备层里最重要的那个数——感知可分辨级数——的获得方式是出一张图、拷进真机、
目视数出来再填回去。这条路现在完全在会话之外：用户得退出会话、敲另一条命令、
找到文件、拷设备、回来再填。

标定仍是**量具**：不读源、不走管线、不判定、无损写出。会话只是调用库里那个写出接口。

**Blocked by:** 08 — 会话骨架；`p0-hardening/12 — 标定图的落盘移进库`；`calibration-chart/01 — 标定图一并回答像素完整性`。

要的是移进库之后的那个写入口，**加上** C01 改过的图内容——否则一键写出来的还是只答一半的旧图。
**外部依赖：** `p0-hardening` 的 12 号票（标定图的落盘移进库）。
在那张票落地之前，界面层是唯一自己碰文件系统产出产物的地方，本票没有可调的库接口。

**Status:** ready-for-agent

- [ ] 光标停在设备层时按一个键，按当前 profile 写出标定图
- [ ] 会话调库里那个写出接口，界面层不自己建目录、不自己写文件
- [ ] 屏上说清此刻要做对的那一件事：拷进设备、以**原尺寸**打开（关掉缩放，也关掉适配屏幕）
- [ ] 怎么数**不在屏上重抄一遍**——图内已印，`calibrate --help` 里也写着
- [ ] 写出失败（父目录建不了、盘满）在会话里说得清，不崩掉会话
- [ ] 标定图仍不走管线：不判定、不量化、无损写出、不带自描述元数据
