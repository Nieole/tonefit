# 11 — 会话：逐页展开与左栏收起

**What to build:** 报告区默认只给卷级；选中一卷可以**展开逐页**，
追查是哪一页把整卷的档位拉下来。展开时左栏收起，主区吃满宽度——
逐页那两行轻松过 100 列，宽度是稀缺资源。

**Blocked by:** 09 — 会话主区。

**Status:** resolved

- [x] 报告区默认只给卷级
- [x] 选中一卷可展开逐页：每页的尺寸、缩放、判定与各候选判据值都看得到
- [x] 展开时左栏收起，主区吃满宽度；收起后能一键回到配置
- [x] 逐页行不被折断；终端窄到放不下时横向可滚，页面不整体错位
- [x] 失败页在逐页里标得出来，且说得出它的尺寸是**卷内统一尺寸**而非它自己的
- [x] 走彩色分支的页标得出来（它不量化、不进上包络）

## 落地记录

**逐页那几行一个字都没有新写。** `render::pages` 早就在（命令行那一路印的就是它），
而它已经说得出失败页的尺寸是卷内统一的、彩色分支的页不量化也不进上包络——
后两条验收因此不是「补一句措辞」，是**把现成那一份接到屏上**。
本票做的是它周围那圈事：一个状态、一批键、一副不折行的画法。

### 展开与左栏收起是同一件事

`Mode::Expanded(Expansion)`。**不是两个开关**：spec 的《会话：布局与交互》写的是
「展开逐页时左栏收起、主区吃满宽度」，而分成两个开关的话，「展开着而左栏还在」
这种没人要的组合就得靠某处代码守着。`CONTEXT.md` 的《会话》跟着加了**展开**这个词条。

```
Browsing --e--> Expanded --e／Esc--> Browsing
                   ⇥／⇧⇥ 换下一卷／上一卷（两头都转一圈）
                   ↑↓（kj）翻一行 · ←→ 横着滚
```

`Expansion` 记四格：展开哪一卷、这一趟报告有几卷、报告从第几行画起、往右滚了几列。
**「有几卷」是进来那一刻记下的**——展开着的时候报告不会再长，因为展开只从浏览进得去
（见下面「跑着时展不开」）。

### 展开 `e`，收起 `e` 与 `Esc`

`c` 留给 `13`、`p` 留给 `12`，两个都没动。

**换卷是 `⇥` 与 `⇧⇥` 两个方向**，不是只往后转一圈：票面要的是「**选中**一卷」，
而只往后的话，几十卷的一趟里往回看一卷要按二十九下。方向用 `Step`——
与三层那几个取值环同一个取值，两处都是「在一圈上挪一格」。
`⇧⇥` 在终端上是一个**单独的**键码（crossterm 的 `BackTab`），因此 `Key` 上多一格，
`translate` 多一行。

**收起有两个键，而这不是重复**：`e` 是展开那个键按回去，`Esc` 是「退一步」——
编辑到一半按它是丢掉缓冲回浏览，展开着按它是收起回配置，同一个意思。
两级停那个 `s` 不给第二个键，理由在 `10` 的落地记录里：**中止退不回收尾**，
而收起退得回去，因此不必守着只有一个入口。

`q` 在展开着时**仍是退出会话**（与浏览时同一件事）：读报告没有「按错一下就丢掉一卷」
那种后果，不必像跑着时那样把它按不动（`10` 在 Q63 上判的那一条）。
`t` 与 `x` 在这里按不动——起一趟要先收起，而新的一趟会当场把报告换掉。

四个方向键在展开着时改的是**报告区**，不是左栏：左栏此刻不在屏上，
把它们留给一栏看不见的东西才是「按了没反应」。`j`／`k` 跟着 `↑↓`，
与浏览时一个待遇（`browsing_action` 本来就认这两个）。两根轴上一格的大小不同——
上下一行、左右八列（`SIDEWAYS`），因此是 `Toward` 四个方向，不是两个 `Step`。

**`e` 只在有卷可展开时才摆在提示条上**：一趟都没跑过时按下去只换来一句话，
而摆一个只会说「还没跑过」的键与本仓库反复引的「屏上不摆按不动的键」相左。
判据与 `press` 挡在前面的那两条是同一个（`draw::expandable`）。

### 展开出来长什么样

左栏一格都不画（`config_width` 在展开着时直接出零），主区从第 0 列吃到最后一列；
报告区那一格的抬头说清展开的是哪一卷、它是第几卷、以及那两个键：

```
┌报告 · 展开 卷二（第 2/2 卷）· ⇥ 换一卷 · e 收起──────────────────────────┐
│库/卷二 → 出/隔离/卷二（3 页，其中彩页 1 页）                              │
│  隔离 1 页失败：本卷整卷写到隔离目录 出/隔离/卷二，失败页以卷内统一尺寸…  │
│  几何门 判定范围 灰度页 1 页 · 不成立 0 页 · 本卷 不抖动                  │
│  卷级 基准档 4bit · 主体 1 页 · 离群 0 页（0.0%）· 迟滞升档 0 页（上包络… │
│    驱动页 库/卷二/001.jpg                                                 │
│  介质 无寻道惩罚（固态盘） · 读取并发 8                                   │
│  缓存 1 页 1.0 MiB（压缩前 4.0 MiB），未溢写（预算 512.0 MiB）            │
│  1182×1680  缩放比 1.219 · 未预缩  出/隔离/卷二/001.png                   │
│    判定 4bit（阈值内最低的一档）  判据 1bit+FS 32.000 · 2bit 20.000 · 4b… │
│  1182×1680  缩放比 1.219 · 未预缩  出/隔离/卷二/002.png                   │
│    彩页 · 彩色分支：只缩放，不量化，不进灰度缓存也不进卷级上包络           │
│  1182×1680  失败页 · 卷内统一尺寸留白  出/隔离/卷二/017.png               │
│    失败 解不出完整尺寸：JPEG 数据截断                                     │
└───────────────────────────────────────────────────────────────────────────┘
```

抬头非说不可：逐页那几行自己不说它属于谁（卷级那一行早翻到几十行之外去了），
而换过一卷之后，屏上第一眼看不出换没换成。卷名走 `render::volume_name`——
命令行的进度条与会话的当前卷条印的是同一个。

**抬头只说卷、屏底只说键**：一个数（第几/共几卷）与一批键各只有一个出处，
与本票给按停立的那一条（`stopping_name`）同一条规矩。按键提示的家是屏底那一行，
`10` 已经立过；抬头因此一个键都不提，退回裸「报告」时也不会把出路一起弄丢。

**展开是「添」，不是换一份**：卷级那几行两副样子里都在，展开的那一卷后面多出逐页那几行。
`report_text(live, expand)` 一趟走完拼出正文，顺手出**那一卷落在第几行**——
`⇥` 换过一卷之后视口对到那一卷的抬头上靠的就是它。两个数一起算而不是另数一遍，
理由与「渲染只有一处出处」同一条：另数一遍就要把「哪一段在哪一段前面」抄第二份。

### 不折行，横着滚

默认那一副与展开那一副是同一格的两副样子：

| | 只给卷级（默认） | 展开一卷 |
|---|---|---|
| 逐页那几行 | 一行不给 | 展开的那一卷全给（`render::pages`） |
| 长过一格 | **滚到底**，留最后那几行 | 用户自己翻 |
| 一行放不下 | 折行（中文按显示宽度回绕） | **不折**，横着滚 |
| 左栏 | 在场 | 收起 |

默认那一副滚到底是 `09` 定的，理由没变（报告只增不减，「一卷跑完当场看得见」说的正是
刚添上去的那几行）。展开那一副不折行，是因为票面写着**逐页行不被折断**——
折了就看不出哪几个数是一页的。**横着滚的是格子里的正文**，边框、抬头、屏底那两行
一格都不动，页面因此不整体错位。

### 滚动量由画法收，不由状态机收

往上、往左收在零上，那是 `saturating_sub` 的事，状态机自己答得出；
**另外两头它答不出**——那要知道这一格装得下几行几列，而 `state` 一个终端都不碰。
于是 `draw::report_pane` 每帧调一次 `Session::clamp_report`，
`shell` 因此收 `&mut Session`。**那是画法这一层唯一改状态的地方**，认键那一路一步不经过它。

不收会怎样：往下翻过了头之后再往回翻，头几下**按了没反应**——
而那正是 `10` 反复在躲的那件事（「屏上不摆按不动的键」）。

### 展开与换卷落在 `press` 那一层

与起一趟、按停同一条分法：这两件事要读**那一趟攒下来的报告**（有几卷、那一卷落在第几行），
而状态机读不到它。`session::press` 把 `Action::Expand` 与 `Action::Turn` 接走，
从 `Running::live()` 上数出那两个数，再调 `Session::expand`。
收起不在这一层——它不必读报告，`Action::Collapse` 就在状态机里做掉。

一趟都没跑过、或者报告里一卷都还没有：说一句、不进展开态。
展开的是**报告上的一卷**，那样东西不在时展开无从谈起。

### 跑着的时候展不开

**这是本票拿的主意**（停车场 Q72）。跑着时 `e` 派 `Action::Ignored`。
要让它按得动，`Mode` 就得拆成两维（「正跑着」与「正展开着」同时成立），
而那正是 `10` 在 Q69 上判过不拆的那件事。还有第二重代价：那一刻按得动的只有 `s`，
而展开态要吃掉上下左右与 `⇥`，按停那个键在一屏滚动键里会被挤没。
代价写在 Q72 上：几十分钟的一趟里想回头看第一卷的逐页，得等它收场。

### 库与命令行一个字节都没动

`src/lib.rs`、`src/progress.rs`、`src/render.rs`、`src/main.rs` 一行未改。
`render::pages` 本来就是 `pub` 的，`09` 把 `volume` 与 `pages` 拆成两个函数时
留的正是这个位置（那时的文档就写着「分成两个函数是给会话用的」）。
**命令行那一路因此行为一字未变，`--per-page` 那条路的措辞也没有分叉，
黄金快照未变、未重录。**

### review 之后改的

`/code-review` 两轴各出了几条，收了这些：

- **换卷只有一个方向**（Spec 轴，最重的一条）。票面要的是「**选中**一卷」，
  而只往后转一圈的话，几十卷的一趟里往回看一卷要按二十九下。
  `Action::Turn` 因此带上 `Step`，`⇧⇥` 接成另一头（`Key::BackTab` 是一个单独的键码）。
- **「第几/共几卷」有两个出处**（两轴都出了：Standards 的单一出处、Spec 的 (c)1）。
  抬头与屏底各拼了一份，措辞还不一样（「换一卷／换下一卷」「第 2/2 卷／（2/2）」），
  而 `expanded_lines` 的文档正写着「展开的是哪一卷不在这里说」——注释与实现对不上。
  改成**抬头只说卷、屏底只说键**，两边各只有一个出处。
  顺带解掉 Spec 轴的 (c)2：抬头退回裸「报告」时不再把唯一的出路提示一起弄丢。
- **`e` 无条件摆在浏览时的提示条上**（Spec 轴）。一趟都没跑过时按下去只换来一句话，

  与 `press` 挡在前面的那两条是同一个。
- **`CONTEXT.md` 写进了一条没拍板的决定**（Standards 轴，偏硬）。
  「跑着的时候展不开」是 Q72 的题目、`Whose call` 记着是拍板的人，
  而词汇表把它写成了既成事实——两份文档对同一件事一个说成立、一个说待办。
  那一句从 `CONTEXT.md` 删掉，只留在本票与 Q72 上。新加的**展开**词条本身留着
  （新词当场加是落地的一部分）。
- **Q64 的了结存疑**（Spec 轴）。跑着的那一副仍旧翻不回去，而它被整条挪进了《已了结》。
  改成**了结一半、另一半点名转给 Q72**：「跑着时能不能展开」与「跑着时能不能翻回去」
  是同一件事的两半，拍一条就一起拍了，因此不另立第三条。
- **展开那一副只有「有失败页」一种快照**（Spec 轴，对着 spec 的《Testing Decisions》）。
  补 `a_volume_without_a_failed_page_expands_to_page_rows_and_nothing_about_failure`。
- **`report_text` 返回裸 `(String, u16)`，调用处遍布 `.0`／`.1`**（Standards 轴，
  Primitive Obsession）。收成 `Unrolled { text, opens_at }`。
- **`Session::expand` 那三个参数是一伙的**（Standards 轴，Data Clumps）。
  收成 `Expansion::new(volume, volumes, from)`，转圈那一步也搬上去成了 `Expansion::next`。
- **测试里 `expanded_screen` 与 `screen` 逐行同形、`expanded_snapshot` 只是一行转发**
  （Standards 轴，Duplicated Code + Middle Man）。`screen` 收下 `Option<&Live>`，
  转发那个换成 `snapshot_of`。

两条没收，各有理由：

- **`j`／`k` 是多绑的**（Spec 轴 (b)2）。不是——`browsing_action` 本来就认这两个
  （`Key::Up | Key::Char('k')`），展开着时跟着它才是一致的。屏底不摆它们同样跟着浏览时
  （那一行也只写「↑↓ 选」）。改的是文档：`expanded_action` 原先只说「上下左右四个键」，

## 停车场结转

### Q64 — 报告区长过一格就只留最后那几行，翻不回去

- **From:** 票 `p1-session/09`
- **Kind:** 票面没想到的第三种情形
- **Where:** `src/session/draw.rs` 的 `past_the_top` 与 `report_pane`
- **Why it did not block:** 报告只增不减：十几卷跑下来，报告区一格早就装不下。
  从头画的话新添的那几行全掉在格子外面，而 `09` 的验收要的正是
  「已完成卷的判定、驱动页、失败页**当场**可见」——那一条会当场落空。
  真正的解法是报告区能滚、能展开、能收起左栏，而那整件事是本票的题目。
- **What this ticket actually did:** `09` 走了「滚到底」，代价是跑到中途看不到抬头那几行。
  **本票没有动那一副**：跟着跑的时候滚到底仍旧是对的落点。
  翻回去落在**展开那一副**上——`e` 展开之后报告区不再自动滚，`↑↓` 一行一行翻得动，
  翻到零就是抬头那几行。展开那一下 `from` 取零，因此按下去当场看到的就是抬头。
  用例 `the_expanded_report_can_be_scrolled_back_to_the_header` 钉住
  「翻下去抬头让位、翻回来一屏不差」。
- **Whose call:** `11`（逐页展开与左栏收起）
- **处置：** **由本票了结一半，另一半转给 Q72。** 跑完之后翻得回去，而
  **一趟正跑着的时候仍旧翻不回去**——展开只从浏览进得去（Q72）。
  两件事是同一件事的两半：「跑着时能不能展开」与「跑着时能不能翻回去」
  拍一条就一起拍了，因此不另立第三条，Q72 的《处置》里点了名。
  **没有给默认那一副加翻页键**：那一副的落点是「最新的那几行」，
  而翻回去是一个**读**的动作——读报告就是展开那一副在做的事，两副样子各答一件事。

### Q71 — 按停的状态只在屏底那两行说，主区两条进度条上看不出来

- **From:** 票 `p1-session/10`
- **Kind:** 确实拿不准的单项
- **Where:** `src/session/draw.rs` 的 `running_lines`（屏底那两行）
  与 `overall_bar`／`volume_bar`（主区两条）
- **Why it did not block:** 按下收尾之后进度条照旧往前走，而「它在等什么」只写在屏底。
  眼睛盯着进度条的人要往下扫一行才看得到。`10` 记着两处摆得下、两处都有代价：
  **全局条**那一行在 96 列的屏上只剩十几列空白，中文一句话就要二十几列，会被截掉；
  **当前卷条**在卷与卷之间是空的，而收尾恰恰最可能按在一卷刚跑完的时候。
- **What this ticket actually did:** **摆到全局条那一格的抬头上**——
  「整趟 · 收尾中」／「整趟 · 中止中」。抬头在**边框**上，两条代价一条都不吃：
  一列正文都不占，也不随卷与卷之间那一段空白消失。
  措辞不长第二份：抬头与屏底那一行读的是同一个 `stopping_name`，
  没按过时它没有名字（「跑着」不是按停的一级）。
  用例 `the_overall_bar_says_on_its_title_that_the_run_is_stopping` 钉住三级各是什么、
  以及两处用的是同一个词。
- **Whose call:** `11`（逐页展开与左栏收起）
- **处置：** 由本票了结。**当前卷条一个字都没加**：Q71 记着的第二条代价没有解法——
  那一格在卷与卷之间本来就是空的，摆一句会跟着消失，而那比不摆更坏。
  `09` 录的那三张主区快照因此一格都没动（没按停时抬头仍是「整趟」）。
