# 11 — 会话：逐页展开与左栏收起

**What to build:** 报告区默认只给卷级；选中一卷可以**展开逐页**，
追查是哪一页把整卷的档位拉下来。展开时左栏收起，主区吃满宽度——
逐页那两行轻松过 100 列，宽度是稀缺资源。

**Blocked by:** 09 — 会话主区。

**Status:** ready-for-agent

- [ ] 报告区默认只给卷级
- [ ] 选中一卷可展开逐页：每页的尺寸、缩放、判定与各候选判据值都看得到
- [ ] 展开时左栏收起，主区吃满宽度；收起后能一键回到配置
- [ ] 逐页行不被折断；终端窄到放不下时横向可滚，页面不整体错位
- [ ] 失败页在逐页里标得出来，且说得出它的尺寸是**卷内统一尺寸**而非它自己的
- [ ] 走彩色分支的页标得出来（它不量化、不进上包络）
