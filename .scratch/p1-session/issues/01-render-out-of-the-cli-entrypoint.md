# 01 — 报告渲染搬出 CLI 主文件

**What to build:** 命令行的输出一个字节都不变，但「把 `Report` 渲染成文字」这件事挪成一个独立模块，
将来会话与命令行共用同一套措辞。

纯前置重构。为的是让后面加会话时不必在项目最大的那个文件里动手——它现在是全项目最大的一个，
而 spec 说 CLI 该是主入口之上的**薄层**。先把改动变容易，再做那个容易的改动。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 命令行输出与重构前逐字节相同
- [ ] 黄金回归全绿，且**未重录任何基线**
- [ ] 渲染只吃报告与模式，不再依赖 CLI 的参数类型
- [ ] CLI 主文件显著变小，只剩参数解析、分派与进度条
- [ ] 渲染模块留在界面层，不进库
