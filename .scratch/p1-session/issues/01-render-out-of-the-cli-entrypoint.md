# 01 — 报告渲染搬出 CLI 主文件

**What to build:** 命令行的输出一个字节都不变，但「把 `Report` 渲染成文字」这件事挪成一个独立模块，
将来会话与命令行共用同一套措辞。

纯前置重构。为的是让后面加会话时不必在项目最大的那个文件里动手——它现在是全项目最大的一个，
而 spec 说 CLI 该是主入口之上的**薄层**。先把改动变容易，再做那个容易的改动。

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] 命令行输出与重构前逐字节相同
- [x] 黄金回归全绿，且**未重录任何基线**
- [x] 渲染只吃报告与模式，不再依赖 CLI 的参数类型
- [x] CLI 主文件显著变小，只剩参数解析、分派与进度条
- [x] 渲染模块留在界面层，不进库

## 落地记录

渲染搬进新的 `src/render.rs`——**二进制 crate 内**的一个模块，不进库。
哪个 `src/*.rs` 属于哪一侧，规矩是现成的：`lib.rs` 顶上那张 `mod` 清单之内的是库，之外的是界面层。

### 形状：四段

渲染切成四个 `pub fn`，各自只吃报告的一块：

| 段 | 吃什么 | 什么时候要它 |
|---|---|---|
| `header` | `&Report` + `Mode` | 一趟一次：profile、判据聚合、dry-run 那一行 |
| `volume` | `&VolumeReport` | 逐卷：去处与页数、过期副本、判定、读取计划、缓存 |
| `pages` | `&VolumeReport` | 逐卷：那一卷的逐页两行 |
| `tail` | `&Report` | 收尾：部分救回与隔离两小结 |

`report` 把四段按序拼起来，命令行走的就是它。

四刀是照后面几张票的形状画的，不是随手切的：

- **02（事件流）**：卷级事件带着 `VolumeReport`，`volume` 与 `pages` 正好只吃这个。
  `header` 故意吃 `&Report` 而不是单独一个 `&Profile`——报告是逐卷攒出来的，
  攒到一半的那一份同样答得出抬头那三件事。
- **09（会话主区）**：报告区默认只给卷级、展开才逐页。那条分界线现在就是
  `volume` 与 `pages` 的函数边界，两侧共用同一个 `pub fn`，不是两套措辞。
- **`p0-hardening` 11（计时）**：渲染一个计时字段都不读，
  「计时不默认进渲染出的文字」与「黄金不因计时 flaky」因此自动成立。

新增一条用例 `drawing_the_four_parts_one_by_one_gives_the_same_bytes_as_one_shot`
钉住「逐段画 == 一次性画」：真有人往 `report` 里插一行四段里没有的东西，
会话与命令行的措辞就分了家，这条当场红。

### 一并搬走的：标定图那几行

`calibration_note` 也进了 `render`。它不从报告来，但同属界面文案——会话按键出图印的是同一套说法
（会话批的 13 号票）。主文件因此只剩参数解析、分派、退出码与进度条。

### 逐字节不变，是这么验的

**10 组命令行场景，重构前后的 stdout 逐字节比对，22250 字节完全相同。**
重构前那个二进制是拿 `git checkout` 把三个文件退回 HEAD 建出来的，两趟跑同一份脚本。

覆盖：干净卷带透传文件、隔离卷、幂等跳过、dry-run、`--per-page`、覆盖项裁到只剩一个候选、
几何门整卷不成立与混排、部分救回、`--no-metadata`、整卷全是坏页、一页都没有的卷、标定图那几行。
彩色分支那一条没有真夹具（手边造不出彩页），靠原样搬过来的
`the_report_tells_a_color_page_apart_from_a_gray_one` 覆盖。

全量 **273 通过 0 失败**（基线 272，多的是上面那条新用例；`smoke` 未设 `TONEFIT_SAMPLES`，
印一行跳过、贡献 0）。`tests/` 一行未动，黄金基线未重录。

### 数

`src/main.rs` 1577 → 647 行，不再是全项目最大的那个（`lib.rs` 1232）。
`src/render.rs` 1067 行，其中用例约六成——渲染那批用例跟着渲染一起搬，
命令行解析那批留在主文件。二进制 crate 的单元测由 20 变 21。

### 两处按自检收口

- **`pages` 里补回 `if volume.skipped()` 那道守卫。** 拆分前它与 `volume` 里那道是同一句
  `continue`；靠「跳过的卷 `pages` 恒空」把它省掉，就是给 `VolumeReport::skipped`
  那条「跳过只许有一个出处」的不变量添一个只写在注释里的依赖方。今天两种写法逐字节相同，
  但那条不变量将来若松动，省掉守卫的那一侧会静默地把跳过卷的逐页结果印出来。
- **新写的注释里那几个票号加了批次限定**（`会话批的 13 号票`）。同一个文件里
  `13 号票` 与 `02 号票` 已经各有主（分别是核心批的介质探测与加固批的判据分块），
  不加限定就撞车——`加固批 01 号票` 是文件里既有的正确写法。
