# 12 — 会话：预设的存与取

**What to build:** 会话里把当前的设备层 + 口味层存成命名**预设**，也能列出并套用已有的。
两侧同一份格式——会话里存出来的，命令行上 `--preset` 直接用得起来。

**Blocked by:** 07 — 预设（命令行侧）；08 — 会话骨架。

**Status:** resolved

- [x] 会话里能把当前设备层 + 口味层存成命名预设
- [x] 会话里能列出并套用已有预设
- [x] 套用预设**不动范围层**
- [x] 读不懂的预设在会话里明确报错，不静默套默认值
- [x] 会话里存出来的预设在命令行上用得起来，反之亦然

## 落地记录

**格式一个字都没新立。** 07 已经把盘上那份 TOML 定死（一份文件装多个命名预设，
各装 `device` 与 `taste` 两节，两层都 `deny_unknown_fields`），08 又把屏上那两层做成
**就是** `preset::DeviceLayer` 与 `TasteLayer`。本票要做的因此不是搬运，是三件事：
一个状态、一批键、以及**往用户自己的文件里写字节**这件事的分寸。

### 一个键 `p`，存与取都在它后面

`Mode::Picking(Picker)`。那一栏列着盘上有的那几份，**末尾一行是「＋ 把当前的设备层与
口味层存成一份预设」**——照范围层那一栏「＋ 再打一个卷进来」的样子（`Field::AddVolume`）。
列一份清单与往清单里添一条是同一栏上的两件事，分成两个键就要多记一个键。

```
Browsing --p--> Picking --p／Esc--> Browsing
                  ↑↓（kj）挪一行，两头绕回去
                  ⏎／空格 停在一份预设上 → 套用它
                  ⏎／空格 停在末尾那一行上 → 打个名字
                     ↳ Naming --⏎--> 存下（撞名先说一句，再按一次才覆盖）
                                --Esc--> 退回列表（再按一次才出这一栏）
```

`c` 留给 `13`，没动。跑着的时候 `p` **按不动**——套用一份预设就是把两层整个换掉，
而跑起来之后三层只读（与 `e` 在 Q72 上判的那一条同一个理由）；展开着时也按不动，
那一栏占的就是主区。

**打名字那一副与编辑左栏一行是同一副样子**（字进缓冲、`⏎` 收下、`Esc` 丢掉、
上下左右一个都不接），三处不同各有理由：`⇥` 没有意义（名字不是路径，没有下一层可补）；
一个字都没打就按回车是「算了」（与「再打一个卷进来」同一条）；`Esc` 退的是**一步**——
先回列表，再按一次才出这一栏。

### 碰盘的三支不进状态机

`Action::Pick`／`Take`／`Store` 三支落在 `session::press`，与 `Start`／`Expand`
同一条分法：状态机答「哪个键在哪个状态下做什么」，它读不到那一趟攒的报告，也碰不到盘。
press 读完盘再回调 `Session::pick`／`took`／`saved`／`name_is_taken`，
三支各走各的函数（`list_presets`／`take_preset`／`store_preset`）——合成一个收 `Action`
的分派就要留一支「到不了」的 `_`，而那正是往后新添一支动作会被静默吃掉的地方。
`Pick` 进 `Mode::Picking`，照 `Expand` 进 `Mode::Expanded` 那一对取名。

盘那一侧收成 `preset::Presets`——**位置在造出来那一刻定死**，于是用例拿得到一份指向
临时目录的它，不必去改进程的环境变量（`tests/preset.rs` 早说过为什么不改：edition 2024
里 `set_var` 是 `unsafe` 的，用例又并行跑）。找不到用户配置目录**不在造它那一刻报**：
会话不该因为一台机器没设 `APPDATA` 就进不去，那句话留到按下 `p` 那一刻说。

`preset::load`（命令行那一路）改成走同一个 `Presets::read`，措辞与行为一字未动。

### 存出去的只有「说了的那几项」（停车场 Q58）

`Session::preset()` 就是把两层原样装进 `Preset`——**每一格仍是 `Option`**，
而 `OnDisk` 那两节各项都写着 `skip_serializing_if = "Option::is_none"`。于是：

| 屏上 | 盘上 |
|---|---|
| `默认（height）`（没说） | `taste` 那一节里**没有** `fit` 这一行 |
| `height`（转了一格，恰好等于默认值） | `fit = "height"` |

**范围层进不去也不必靠自觉**：`Session::preset()` 拼得出来的只有那两个字段，
而盘上那两节都 `deny_unknown_fields`。套用则是**整个换**——它没说的那几项跟着回到「没说」，
否则「存出去再套回来」不是一次往返，而是与上一次配置的一次合并，合出来的东西没人说得清。

### 写盘：新的追加，同名重排，两下才覆盖

`preset::insert(text, name, preset)` 两条路：

- **名字还空着** → 那两节**追加**在末尾，原文一个字节都不改。注释、排版、连本版本读不懂的
  那几份预设全部原样留着。追加完还验一遍（点名的那份读得回来、别的几份一个没变），
  验不过才退回重排——`preset` 写成内联表时接不上一节。
- **名字已经有了** → 整份**重排**：那一份换掉，别的按不透明的 `toml::Value` 原样搬过去。
  丢掉的是注释与手写的排版（`toml` 1.1 没有保留格式的编辑端，停车场 Q73）。

**读不懂的整份文件当场报错、一个字节都不写**——拿一份自己都没读懂的文件去覆盖，
是这一路上最不该做的事。写到位走「先写 `.partial` 再改名」，与输出容器同一条规矩
（连那个远角上的代价也照它：临时名字是推得出来的，两个会话同一秒里各存一份会撞上，
换成随机名字则清不掉硬停留下的那一份）。

覆盖要**按两下**，与两级停同一个形状：`Presets::save` 撞上同名就是 `Saved::Taken`
（**撞名不是错误，是一个答案**），屏上说一句、闩上「再按一次」，第二下才走
`Presets::replace`。那一句里连代价一起说：「覆盖会把那份预设文件整个照标准格式重排，
手写的注释与排版留不下来」。**缓冲一改那一问就作废**——改成另一个已有的名字，
不该被上一次的确认捎带着盖掉（用例逐步走过这一条）。

### 屏上：那一栏占主区，左栏照旧在场

```
┌预设 · 装设备层与口味层，范围层不进───────────────┐
│ C:/Users/…/AppData/Roaming/tonefit/presets.toml  │
│                                                  │
│  漫画                                            │
│  画集                                            │
│  ＋ 把当前的设备层与口味层存成一份预设           │
└──────────────────────────────────────────────────┘
 预设名 新的▏   ⏎ 存下 · Esc 回列表
 存的是设备层与口味层。范围层（输出根与卷）不进预设，套用时因此写不到上一次的目录去
```

**那份文件在哪写在这一格里，不写在屏底那句话里**：屏底那一格不折行，一条 Windows 长路径
会被从行尾切掉，而这一格折得下来。存好之后那句话因此只说「存好了：「漫画」——命令行上
`--preset 漫画` 就是它」。

**名字多过这一格装得下的行数时，视口跟着光标走**（`opens_from`，算出来的、不是记着的）：
末尾那一行是唯一存得出去的入口，它掉出屏外就等于这一栏没有出路了。

与展开那一副**正好相反**：那一副要的是宽度（逐页那两行过 100 列），
这一副要的是**对照**——存出去的就是左栏上那两层，按下去之前得看得见。
左栏在场但**那一行不再反白**：反白说的是「就在这一行上动手」，而按键这时全归这一栏
（与跑着时不反白同一条理由；压暗仍只给跑着那一种，这一栏一个 `Esc` 就回来了）。

屏底那一行随光标停在哪一行改口（停在一份预设上时把**名字**摆进那句话里），
下一行说那一下会怎样——**套用把两层整个换掉、眼下配好的随之丢掉，而那一下不可撤销**，
因此与覆盖那一句同一条规矩：在按下去之前说。浏览时那一行添了「`p` 预设」，同时把「`e` 展开逐页」
缩成「`e` 展开」——那一行在窄终端上是从行尾切掉的，每多一个键尾巴上那个键就少露一截，
而尾巴上摆的是退出。64 列上因此仍旧一个字都没被切掉。

## 停车场结转

### Q58 — 会话里「没说」与「说了一个恰好等于默认值的值」是两个状态，命令行上它们没有分别

- **From:** 票 `p1-session/08`
- **Kind:** 票面没想到的第三种情形
- **Where:** `src/session/state.rs` 的 `ring` 与 `Session::shown`；`src/preset.rs` 的 `TasteLayer`
- **Why it did not block:** 两层的每一格都是 `Option`（预设只说它说到的那几项），会话照搬了这条：
  每一项的取值环上第一格是「没说」，屏上印成`默认（lanczos3）`，转一圈回得到它。
  于是屏上分得开「没说」与「说了 lanczos3」——**而这一趟的 `Request` 与参数哈希对两者完全一样**，
  差别只在存成预设（`12`）时才落地：前者不写进那份 TOML，后者写。
  不分开的话 `12` 就没法存出一份「只说了两项」的预设，只能把十一项全写满；
  分开的代价是屏上多一格、用户得多按一下才回得到默认。
- **What this ticket actually did:** **两个状态原样落到盘上，一句新代码都不必为它写。**
  `Session::preset()` 把两层原样交出去，`OnDisk` 那两节的 `skip_serializing_if` 就是分界：
  没说的那一项不写，说了的写（哪怕它恰好等于今天的默认值）。用例
  `what_was_never_said_is_not_written_and_a_default_that_was_said_is` 两头都钉：
  一项没碰过的会话存出去只有两个空节；把适配方式转到恰好等于默认值的那一档上，
  盘上就多一行 `fit = "height"`，而别的项一个都没跟着写出去。
  往返那一头由 `what_the_session_stores_is_what_it_takes_back` 钉住——套回来它仍是「说了」。
  **屏上没有再多说一句**：`08` 那一副（「没说」连同它落到的默认值一并印出来）够用，
  而两者的差别现在**在盘上看得见**，那才是它真正的去处。
  它还落进了 `CONTEXT.md` 的《会话》：往后默认值改了，「说了 height」仍是 height，
  「没说」跟着新的默认走——一份预设因此说得出「我只在乎这两项」。
- **Whose call:** `12`（会话里的预设存取）——它是第一个真要用到这个分别的地方，
  也是第一个要回答「屏上要不要把它说得更明白」的地方
- **处置：** 由本票了结。

### Q62 与 Q56 各留一半

两条都是派活时点名交给本票的，都**只收了说得清的那一半**，理由记在停车场各自的条目里：

- **Q62（会话里改了阈值，屏上却写「命令行指定」）**——判成 `Pinned`，**不加第三个变体**：
  `ThresholdSource` 分的是「这个数怎么定出来的」（盲测标定的内置值 vs 用户点名的界），
  不是「从哪个入口点的名」。本票还添了**第三个入口**（预设的设备层可以写 `threshold`，
  经 `Profile::with_threshold` 同样成 `Pinned`），三个入口一个来源。
  **措辞没改**：报告里那一行是命令行的输出，而本票的硬约束是命令行那一路一字不变。
  顺带更正了原条目的一处事实：黄金基线里没有这句话，改它不必重录黄金快照。
- **Q56（`calibrate` 读不到预设）**——没碰 `calibrate`：给它加一个 `--preset` 是往命令行
  添一条新语法。但缺口在**会话那一侧已经不存在**了：`p` 套一份预设就把设备层填齐，
  而 `13` 拿的是会话里那份设备层去调库的写出接口，根本不经过 `calibrate` 的命令行解析。
