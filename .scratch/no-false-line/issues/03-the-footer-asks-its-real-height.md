# 03: 屏底那一格问真实高度

**What to build:** 80 列上屏底那句说明**被截成半句**：印出来是「……与「说了一个恰好等」，
读起来像一句完整的话。

成因是一处自相矛盾：算「说明那一行分得到几行」时，代码拿屏底那一格的**高度下限**
当定数去减——而那个常量自己的文档第一句就是「**下限，不是定数**」，
而且真有一个函数会把这一格往下长。截断因此发生在长高之前，长高永远轮不到。

`CONTEXT.md`[《让位》](../../../CONTEXT.md)说的是：高度不够时屏底**照折行那一套按需长高**，
长到主区只剩总览那几行加表那一行为止。屏底那个模块自己的文档写的却是反的
（先丢说明那一行，让完仍摆不下才长）。**两处次序正相反，而词汇表是权威。**

改成：**先长高，长到顶了才丢说明那一行，而且整句丢。**
截出来的半句不是更少的信息，是另一句话。

那个环（要知道分得到几行才折得出行、要拿到行才算得出高度）用**上限**断开：
这一格最多分得到几行是一个纯算术，由主区无论如何要留下的那几行倒推，
**与那个高度函数的 clamp 用同一个数**。不必折两趟。

收停车场的 **Q191**。
