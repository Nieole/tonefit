# 02: 每一列说得出自己的字面出处

**What to build:** 「哪几格的字面要过宽度这一关」在仓库里有**两处出处**——
三个 `Column` 枚举，和措辞那一层用例里一份手抄的名单。往表里加一列，
那份名单不跟着加**也不会红**。

逐页表添了五格几何列之后，裁边与缩放两格进了对齐的列，而名单没跟着添——
**预言过的后果原样发生了**，而那两格的字形是歧义宽度，CJK 终端上此刻就在错位。

收拢：**每一个 `Column` 变体自己声明它的[字面出处](../../../CONTEXT.md)**——
[措辞](../../../CONTEXT.md)（界面层造的）、[原样](../../../CONTEXT.md)（用户数据）、
还是[记号](../../../CONTEXT.md)。加一个变体不写这一格，**编译就过不去**。
手抄那份名单改成从它导出，然后删掉。

**字形本身不在这一票查。** 三档各归一条已经存在的规矩：措辞 → 造字面的那一层管
（库出的归 `p4-parking-lot/30`，bin 造的归措辞那一层既有那条用例）；
原样 → 摆不下时从中间省略（[砍列](../../../CONTEXT.md)那条）；记号 → 表这一层那条。
`Column` 只负责**说出这一格该归谁管**。

收拢做得成的前提是一处事实：**`session::columns` 不在 `tui` 特性后面**，
只有画法与终端那两个模块在。挡住上一次的墙比记的窄——真正在特性后面的只有
「格到列」那份**映射**，而字面出处不必走那份映射。

列与格**不是一对一**（记号那一列压根不是一格字、页名那一列从另一行补上、
判定那一列对的是另一个名字的格），所以出处挂在**列**上，不挂在格上。

收停车场的 **Q187** 的 bin 那一半、**Q188**。

**Blocked by:** `p4-parking-lot/30` — 库认下字形约定。
名单一从字面出处导出，裁边与缩放就进了闸门，而它们的字形还是歧义宽度（在库里）——
**30 落地之前这一票跑不绿**。

**Status:** resolved

- [x] 裁边与缩放两列此刻在闸门里，且**绿**（靠的是 `30` 换过的字形）

## 落地记录

### 出处挂在列上，一处，而且是必答项

`Column` 那个 trait 上多了一个**没有默认实现**的项：

```rust
// src/session/columns.rs——`tui` 特性**外面**，三条闸门都跑得到
fn provenance(self) -> Provenance;
```

三张表各写一个**不留 `_` 的穷举 `match`**。加一个变体，那三处当场非穷尽，
`error[E0004]`——**编译就过不去**。这不是新发明的招数：同一副做法在
`crate::render::plain::line` 与那条用例问理由的地方各有一处先例。

`Provenance` 三档逐字取自 `CONTEXT.md`《格》：

| 档 | 谁写的 | 规矩在哪儿 | 哪几列 |
|---|---|---|---|
| **措辞 (Wording)** | 界面层自己造的字面 | 字形宽度必须稳——**由造字面的那一层查** | 卷数 · 分布 · 页数 · 基准档 · 耗时 · 尺寸 · 裁边 · 缩放 · 跨页 · 彩页 · 判定 · 理由 · 判据 |
| **原样 (Verbatim)** | 用户的字节 | 摆不下时从中间省略，**不进那一关** | 目录名 · 卷名 · 页名 · 定档页 · 去处 |
| **记号 (Mark)** | 一个字符说完一件事 | 归画它的那一层 | 三张表的行首记号 |

**规矩一条都没写在 `Provenance` 上**——这一维只答「这一格该归谁管」。

**挂在列上，不挂在格上**，因为列与格不是一对一：记号那一列压根不是一格字；
页名那一列的字从另一行补上；判定那一列对的是**另一个名字**的格（`Field::Candidate`）。
措辞那一档因此带着「出自哪一格」：`Wording(Some(field))`。

### 手抄的那份名单删掉了

`src/render.rs` 里那个八项的 `const LINED_UP: &[Field]` 整段删除，闸门改成从出处导出：

```rust
let lined_up = crate::session::columns::wording_cells();
```

导出来是**十二格**，比手抄那份多四格——`Crop`、`Scaling`、`Cut`、`ColorToGray`，
正是逐页表添了五格几何列时漏出去的那几列（停车场 Q188 预言过，而它原样发生了）。

`session::columns` 为此敞开成 `pub(crate)`（Q376）：摆法、砍列与三个 `Column` 仍是
`pub(super)`，真敞开给外面的只有 `Provenance` 与 `wording_cells` 两项。
`wording_cells` 挂 `cfg_attr(not(test), allow(dead_code))`——非测试那一趟没有一个调用方，
**那不是死代码，是那一关的前提**，与会话里那几处「只有画法读得到」同一副写法、逐处挂不挂整模块。

### 名单一导出，当场逮到一处：票面第 6 条为什么改写

`Field::Scaling` 一进名单，闸门当场红：

```
· 是东亚歧义宽度：PageGeometry 的 Scaling 那一格写着「失败页 · 卷内统一尺寸留白」
```

那个 `·` 是 U+00B7，东亚宽度表上标 **Ambiguous**，而它摆在逐页表**缩放那一列**上。
它是 **bin 自己造的字面**，不是库出的——`p4-parking-lot/30` 够不着它。
改成取 `render` 既有的 `SEPARATOR`（`⋅`，U+22C5——那个常量自己的文档写着为什么不取 `·`）：
**一格里装着两样，拿那个记号隔开**，与基准档分布、判据那一串同一条。

`wrap::width` 两个字形都算一格，**列宽与格数一格未动**，四处跟着换了那一个字符
（`draw::report` 两张快照、`draw::yielding` 一张、`draw::pages` 模块文档一处），
`tests/golden-snapshot.txt` 一个字节没动。

**票面第 6 条随之改写。** 原话是「屏上画出来的东西**一格不变**——这一票只加声明与导出，
不改渲染」，而它与本票的目的**自相矛盾**：这张票买的正是「名单导出之后，过不了那一关的
字面当场现形」，票面自己在《What to build》里预言了这个病，验收条却假设它不会发生。
改写成「列宽与格数一格不变」，经拍板；按 `docs/agents/issue-tracker.md`，
**更正一条写下时就已经站不住的验收条不算改写历史**。来龙去脉记在停车场 **Q373**。

### 会红的那两处

**编译先红**，用例是第二道：

- `session::columns::tests::every_column_says_where_its_text_comes_from`（新，**闸门 2 跑得到**）
  ——三张表逐列走一遍，问的是**答出来的那一档站不站得住**：记号那一档恰好一列且是行首那一列；
  砍无可砍时收窄的那一列必是原样（从中间省略正是那一档的规矩）；一格只进一列；
  报 `Wording(None)`（措辞档、而字面出自画法这一层）的**只放开耗时一列**，
  再来一列得存心加一行（同一副做法见 `tonefit::glyph` 那条用例的 `SENTENCES`，Q374）。
- `render::tests::every_glyph_this_layer_puts_in_a_lined_up_cell_is_the_same_width_on_any_terminal`
  （既有，改成从出处导出）——另加三道守卫：裁边与缩放**真在名单里**；
  **导出来的每一格夹具真摆得出来**（名单进得来、格不在场，那一列等于没问；
  只放开 `Field::Cut`，`tonefit::Cut` 在库外造不出来，它的 `Display` 由库那条穷举用例钉着，Q375）；
  **原样那一档逐格问反面**——`Field::Source` 与 `Field::Output` 两格都(a)不在名单里、
  (b)真带着一个过不了那一关的 `·`。夹具的头一卷因此叫 `库/第1话·上`，
  那一页叫 `序·卷首.jpg`、去处是 `out/第1话·上/序·卷首.png`——
  卷名、页名、去处路径、**定档页名**（定档页那一行读的就是这一页的源路径）四样一并喂到。

### 词汇表

`CONTEXT.md`《格》那一行补了四个英文名：**字面出处 (Provenance)** · **措辞 (Wording)** ·
**原样 (Verbatim)** · **记号 (Mark)**。**只补名，含义一字未改**——按《改 CONTEXT.md 的规矩》，
新词当场加得。头一版类型叫 `Origin`，那个名字被《来路 (Origin)》与公共类型
`tonefit::Origin` 占着（`src/metadata.rs`）；`Wording` 取自 ADR 0016 的文件名，不是新造（Q378）。
