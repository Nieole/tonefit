# 屏上没有一句假话

Status: ready-for-agent

## Problem Statement

屏上与文档里说的话，有八处与真相对不上。

最狠的一处**此刻就在咬人**：逐页表的裁边与缩放那两列，字面出自库的
`Crop` 与 `Scaling` 两个 `Display`，里面带着 `→`（U+2192）、`·`（U+00B7）、`×`（U+00D7）
三个**东亚歧义宽度**字形——CJK 配置的终端上各画两格，而列宽一律按一格算。
**那两列在真实终端上是错开的**，而三条闸门一条都不红。缩放那一列更宽：
分隔记号 `·` 在「预缩」与「未预缩」两个分支里都有，**每一页每一行都带着它**。

拦不住它的原因是一份**手抄的名单**：「哪几格的字面要过宽度这一关」在仓库里有两处出处——
`session::columns` 那三个 `Column` 枚举，和 `render` 那条用例里的 `LINED_UP`。
往表里加一列，`LINED_UP` 不跟着加**也不会红**。逐页表添了五格几何列之后，
裁边与缩放两格进了对齐的列，而 `LINED_UP` 没跟着添——预言过的后果原样发生了。

其余七处同一个性质，只是没这么显眼：

- **屏底那一句被截成半句。** `room` 拿屏底那一格的**高度下限**当定数去减，
  而那个常量自己的文档第一句就是「**下限，不是定数**」；`CONTEXT.md`《让位》说
  高度不够时屏底「按需长高」。80 列上按键那一行折成两行，说明那一行只分到一行，
  于是印出断在半路的话——**而屏上此刻还空着一截**。
- **总览块从头到收场都不说「隔离」。** 按 `t` 起的那一趟，哪怕在决策点上答过继续、
  真写了几卷出去、隔离了五卷，钉住的那一块一个「隔离」都不说，而退出码已经注定是 `2`。
- **点名一个盘根恒收在 `3` 上。** `System Volume Information`、`$RECYCLE.BIN` 这类
  **永远**读不动的目录进了**走不进去的地方**那一栏，而那一栏劝人做的三件事
  （文件还在不在、盘还挂着没有、权限变没变）对它们一件都做不了。重跑一百遍都一样。
- **同一件事有三个类型说得出。** 卷表那套记号、**语义色**、屏底那一句挂的那三档
  ——记号到语义色今天是四对四的双射。
- **屏上还有一处键是手抄的。** 「还没跑过」那两句里的 `t`／`x` 不出自按键表，
  而按键表里写着同样的字。
- **夹具与真会话说不同的话。** 那份「每一种卷都有一卷」的探针夹具里，带失败页的那一卷
  一条逐页失败事件都没报过——真会话里出得来的那一副，快照里从来没露过面。
- **三处模块文档指着不存在的东西。** 画法那一层三处指着一个改过名的模块、
  十来处 `super::press` 指的其实是 `terminal::press`，以及预设栏那句
  「**因为屏底那一格不折行**」——屏底早就折行了。bin crate 不进 `cargo doc`，
  一条告警都不会报。

## Solution

八处逐一改到说真话，**并且各留一处会红的地方**——这一批买的不是「这一次修好」，
是「下一次改错时有人当场喊停」。

**根子上的那一处**：每一个 `Column` 自己**说得出它的字面出处**（`CONTEXT.md`《格》新立的那一维）
——**措辞**、**原样**、还是**记号**。三档各归一条规矩：措辞那一档字形宽度必须稳；
原样那一档（页名、卷名、去处路径、定档页名）宽度永远稳不住、归**砍列**那条省略管；
记号那一档另有一条。加一列时说不出自己是哪一档，**编译就过不去**——那份手抄的名单从此消失。

字形本身回**造字面的那一层**去查：库出的归库的**字形约定**，bin 造的归 `render`
那条既有用例。两处都在 `tui` 特性外面，三条闸门都跑得到。

其余七处照各自的真相改，规矩逐条写在它该在的地方。

## User Stories

1. As a 在 CJK 终端上读报告的用户, I want 逐页表的裁边与缩放两列上下对齐, so that 我一眼扫得下来哪一页被裁得最狠
2. As a 在 CJK 终端上读报告的用户, I want 每一页的缩放那一格都不把后面的列挤歪, so that 一张两百页的表不是每一行都错位
3. As a 下一个往表里加一列的人, I want 加一列时编译器逼我说出这一列的字面出处, so that 我不会像上一次那样静默地把一列漏出闸门
4. As a 下一个往表里加一列的人, I want 「哪几格要过宽度这一关」只有一处出处, so that 我不必记得去改第二份名单
5. As a 读表的人, I want 页名与去处路径那几列摆不下时从中间省略而不是去争宽度那一关, so that 一个带 emoji 的文件名不会把整张表判红
6. As a 80 列终端上用会话的用户, I want 屏底那句说明要么整句在、要么整句不在, so that 我不会读到一句断在半路、看着像完整的话
7. As a 80 列终端上用会话的用户, I want 屏上还空着地方时屏底就先长高, so that 该说的话不在有地方摆的时候被丢掉
8. As a 打字补全卷名的用户, I want 窄屏上补全候选也吃得到长高之后那几行, so that 我少按几次就选得中
9. As a 按 `t` 起了一趟又答了继续的用户, I want 收场之后总览块告诉我完成几卷、跳过几卷、隔离几卷, so that 我不必自己去翻报告末尾才知道退出码为什么是 2
10. As a 正在决策点上要按 `x` 的用户, I want 我按下去那一帧钉住的那一块不换内容也不矮一行, so that 我据以拿主意的那一份不会在手底下变掉
11. As a 只按 `t` 跑了一趟纯试算的用户, I want 收场之后总览块照旧给判定分布, so that 我看到的不是一句「完成 0 卷」这种真话式的废话
12. As a 点名一个盘根的用户, I want 系统目录被默默绕过, so that 一趟卷卷都成的运行收在 `0` 上而不是恒收在 `3` 上
13. As a 点名一个盘根的用户, I want 报告里不出现我既不能也不该去管的那几个目录, so that **走不进去的地方**那一栏里每一条都是我真该去查的
14. As a 权限没配好的 NAS 用户, I want 那一栏照旧告诉我哪一层走不进去、退出码照旧变, so that 收窄不会把我真需要的那一半一起收掉
15. As a 写脚本的用户, I want 退出码只在真有东西没做成时才不是 `0`, so that 我的 CI 不会因为磁盘上有个回收站就一直红
16. As a 读会话代码的人, I want 「这一句有多重」只有一个类型说得出, so that 我不必先弄清屏底那三档与语义色四档谁管谁
17. As a 关掉终端库跑闸门 2 的人, I want 语义色那个类型照编不误, so that 状态机说得出「刚才那一下成没成」而不必绕一圈
18. As a 给屏上某一格上色的人, I want 有一条用例问得出「这一处配了记号没有」, so that 色盲与不上色的终端上一个字都不丢这条规矩执行得了
19. As a 用不上色终端的用户, I want 每一处上色的地方旁边都有一个字或一个行首记号, so that 我一个信息都不丢
20. As a 换按键位的人, I want 屏上每一处提到那个键的地方都从按键表取, so that 我改一处就够、不必去找「还没跑过」那两句
21. As a 读会话快照的人, I want 夹具喂的事件流与真会话一致, so that 快照里出现的那一副就是用户真会看到的那一副
22. As a 读报告区快照的人, I want 「失败页（出现的当场）」那一段在快照里露过面, so that 它改坏了会有一张快照红
23. As a 读代码的人, I want 模块文档里的链接指得到真东西, so that 我照着它跳过去不会落空
24. As a 读预设栏代码的人, I want 那句「为什么摆在这一格」给的理由是真的, so that 我据它判断下一条长路径该摆哪儿时不会判错
25. As a 维护者, I want 这一批每一处改动都留下一处会红的地方, so that 「屏上没有一句假话」是被守着的、不是这一次碰巧成立

## Implementation Decisions

### 缝

**这一批一处 seam 都不新增。** 测试全部落在既有的缝上（见《Testing Decisions》）。
库的**字形约定**是这一族里唯一的新 seam，而它**不在这一批**——见《Out of Scope》。

### 一、字面出处：加一列就有一处会红

- **每一个 `Column` 变体自带它的字面出处**，三档取自 `CONTEXT.md`《格》：
  **措辞** · **原样** · **记号**。三个 `Column` 类型各自逐变体给出——
  **加一个变体不写这一格，编译不过**。
- **`render` 那条用例里的手抄名单从它导出，原来那一份删掉。**
- 三档各归一条规矩，而规矩本身**不写在 `Column` 上**，写在它该在的地方：
  措辞 → 字形宽度稳（见下）；原样 → 摆不下时从中间省略（`CONTEXT.md`《砍列》既有那条）；
  记号 → 表这一层造的字形一个都不许是歧义宽度（既有那条，原样不动）。
- **字形本身的检查回造字面的那一层**：bin 造的由 `render` 那条既有用例管，
  库出的由库的**字形约定**管。`Column` 只负责**说出这一格该归谁管**。
- 这样收拢的前提是**一处事实**：`session::columns` 不在 `tui` 特性后面，
  只有画法与终端那两个模块在。挡住上一次的墙比记的窄——真正在特性后面的只有
  「格到列」那份**映射**，而字面出处不必走那份映射。
- 列与格**不是一对一**，因此出处不挂在格上：记号那一列压根不是一格字；
  页名那一列从另一行补上；判定那一列对的是另一个名字的格。

### 二、屏底那一格问真实高度

- **`room` 改问上限，不再问下限。** 上限是一个纯算术（这一格最多分得到几行，
  由主区无论如何要留下的那几行倒推），与那个高度函数的 clamp **用同一个数**——
  「要知道 `room` 才折得出行、要拿到行才算得出高度」那个环因此消失，不必折两趟。
- **让位次序以 `CONTEXT.md`《让位》为准**：高度不够时屏底**先按需长高**，
  长到主区只剩总览那几行加表那一行为止；**长到顶了才丢说明那一行，而且整句丢**。
  屏底那个模块的文档写的是反的（先丢再长），**改口的是文档，不是词条**。
- 说明那一行摆不下时**整句让位**，不再截前缀——截出来的半句不是更少的信息，是另一句话。
- 补全候选那一格用的是同一个 `room`，因此窄屏上会列得多一些；同一个 clamp 拦着它。

### 三、总览块答「此刻」，一直答到收场

- 总览块后两行的分岔谓词换成**「这一趟到此刻为止真写出过东西没有」**。
  它记在会话那一侧攒报告的那个状态上，**一格布尔、只升不降**——形状与闩相同。
- 置真的那一刻是**第一卷真写完**，不是决策点答继续那一帧：
  那一帧用户正要按下 `x`，把他据以拿主意的那一份换掉，正是既有那条验收要治的病。
- 纯试算（一卷都没答继续）收场时**照旧给判定分布**——那时「完成 0 卷」是真话却是废话。
- 抬头照旧跟着「此刻在写没写」改口，一处不少。

### 四、语义色收成一个类型

- **语义色那个类型搬到 `tui` 特性前面**，屏底那一句原先挂的那三档并进它。
  依据在词汇表：`CONTEXT.md` 把《语义色》放在《会话》那一节、写着「只在会话里」——
  它本来就是会话层的词，住在画法层是放错了地方。
- **它不带记号。** 《语义色》那句「颜色不是唯一载体」是**对每一处的要求**，
  不是这个类型的一个属性：语义色在页那一级是**多对一**（「注意」一档收着六样），
  一个方法答不出那六样各配什么记号。卷表那四对四是巧合，不是构造。
- 落成**一条闸门**：每一处上色的地方都配了一个字或一个行首记号。
- 卷表那套记号原样留着，它到语义色那个映射也原样留着——**方向只有一个**。
- 颜色**一格不许变**：这一件是搬家，不是改配色。

### 五、不看的地方

- 新词已在 `CONTEXT.md`《处理对象》：**不看的地方 (IgnoredPlace)**。
  **走不进去的地方**同时收窄成「本该走得进去、**这一趟**走不进去」。
- **两份名单并成一份。** 打包环境留下的目录与操作系统留下的目录**行为逐字相同**
  （默默跳过、不进退出码、不进任何一栏），分成两份只是历史。
  那份名单的判据从「打包环境留下的目录」改成「本来就不看的地方」，
  `System Volume Information`、`$RECYCLE.BIN`、`lost+found`、`.Trash-1000` 一并收进去。
- **按名字认。** 这几个名字在各自平台上是固定的，不随语言变。
- 绕过发生在**发现**那一层：它们根本不成为候选，因此预扫看不见、那一栏收不到、
  退出码一格不动。
- **报告上一个字都没有**——这与「东西不该无声消失」那条线不冲突：那条线针对的是
  **本该处理而没处理**，而这一类本来就不处理。

### 六、剩下三处

- **键出自按键表**：「还没跑过」时总览块与报告区各说的那一句，
  里面的键与写法都从按键表取，不再手抄。屏底那几句说明里的键至少把**写法**取自它。
- **夹具喂全事件流那一半**：那份探针夹具里带失败页的那一卷补上逐页失败事件。
  这会牵动报告区、上色、让位三个模块十几张快照——**这一件排在这一批最前面**，
  后面每一张动画法的都 rebase 到新快照上。
- **三处文档订正**：画法那三处指着改过名的模块 → 指对；`super::press`／`super::expand`
  → `terminal::press`／`terminal::expand`（十来处）；预设栏那句理由改写成真的
  （屏底折得下来，但它是三样争一格的地方）。**代码一行不动，闸门数一格不变**——
  与前面几件分开落，不把一次订正混进一次结构改动的 diff。

## Testing Decisions

好的用例只问**外部行为**：屏上出来的是什么、退出码是几、报告里有没有那一行。
不问某个函数被调过没有、某个字段是什么值。这一批还多一条：
**几条用例问的是「有没有第二份」**——那正是本批买的东西，而它只有断言才守得住。

**一处 seam 都不新增。** 逐条落点：

- **字面出处穷举** — `session::columns` 的 `mod tests`。它在 `tui` 特性**外面**，
  三条闸门都跑得到。穷举那三个 `Column` 的全部变体，问每一个说不说得出自己的出处。
  加一个变体不写出处时编译就过不去，用例是第二道。
- **措辞那一档的字形** — `render` 那条既有用例继续管 bin 造的字面，改成从字面出处导出、
  不再手抄。**先例就是它自己**：它已经在逐格问那个宽度判据，
  且已经为判定与理由那两列的枚举取值逐个再问一遍。
- **原样那一档不进那一关** — 同一条用例的反面：页名、去处路径、定档页名那几列
  **不许**被拉进宽度那一关。喂一个带宽字符的名字，用例照旧绿。
- **屏底高度 · 总览块收场 · 语义色搬家** — `session::draw` 各模块的 `mod tests`
  与 TestBackend 快照。先例是既有那批窄终端快照（80×24、52 列、34 列、20×6 各一档）。
  语义色搬家**颜色一格不许变**：既有那条「同一屏上色与不上色文字逐格相同」的恒等式
  用例照旧钉着。
- **每一处上色的地方都配了记号** — 新添一条，落在上色那一层的 `mod tests`。
  先例是既有那条「卷表四个字形逐个过得了宽度那一关」。
- **键出自按键表 · 文档里没有第二份** — `tests/single_source.rs`。
  先例是 `the_refusal_list_lives_in_one_place`（扫 `CONTEXT.md` 加 `src/` 加 `docs/`，
  问三件事：别处没有第二份、家里真住着那张单子、路标还在）。
- **不看的地方** — `tests/discovery.rs`（那几个目录一个都不成为候选）
  与 `tests/exit_code.rs`（一棵含系统目录、卷卷都成的树收在 `0` 上）。
  同时留一条**反向**用例：权限真的没配好的目录**照旧**进那一栏、照旧进退出码——
  收窄不许把那一半一起收掉。
- **夹具** — 那份探针夹具补上逐页失败事件；受牵动的快照**逐张核对后重录**，
  不是顺手覆盖。报告区那一段「失败页（出现的当场）」从此在快照里露面。

**这一批不碰黄金快照。** 已经验过：`tests/golden.rs` 链的是 lib、自己拼快照行，
够不着界面层——裁边那个词在快照文件里只出现在头部注释的格式说明里。
这是第四次撞见同一个形状，**不要再把黄金快照写进这一批任何一条验收**。

## Out of Scope

- **库的字形约定**——把「不许断的那个空格」与「字形宽度稳」两条提成库的公共 API、
  并换掉库里 `Crop`／`Scaling`／`SplitRule` 三个 `Display` 的字形。
  那是 `p4-parking-lot` 那一批的活（19 号票拆出来的第二张），**这一批依赖它**：
  逐页表那两列真正对齐要等它落地。这一批出的是**闸门**，它出的是**字形**。
- **闩的编码收成一处**、**命令行接两级停**——`p4-parking-lot/19`、`18`。
- **`CONTEXT.md` 那批还没改的词条**——《折行》补三条判据、《失败》那段退出码说明、
  《卷表》《下钻》《行》《焦点》那几条，都在 `p4-parking-lot/28`。

## Further Notes

这一批的名字按**它建的是什么**起，不按它从哪个抽屉出来。它出自一轮 `/settle`——
停车场 `Q34–Q205`（90 条）清空之后，47 条落在已有的票上，剩下这八件没有一张在册的票要。
但**不要把它读成「清停车场」**：那个名字读起来像一笔要在别的活开工之前先还掉的债，
而这八件该跟其余的活按价值比一比。

八件的共同线是**说出来的话与真相对不上**——逐页表那两列错位、屏底那句被截成半句、
总览块不说隔离、盘根恒收在 `3`、三个类型说同一件事、夹具与真会话说不同的话、
模块文档指着不存在的模块。名字说的就是这一条。

**落地次序有两处硬的**：夹具那一件排最前（它动十几张快照，后面每一张动画法的都要 rebase）；
逐页表那两列真正对齐要等库的字形约定落地，这一批只保证**下一次漏掉时有一处会红**。

**这一批的判据出自一轮 grill**，其中六处事实比停车场原记录更重，写在这里免得再查一遍：

1. 缩放那一列的分隔记号在**两个分支里都有**（含「未预缩」）——每一页每一行都错位，
   不是停车场原记的「预缩过的那几页」；
2. `session::columns` **不在** `tui` 特性后面，只有画法与终端那两个模块在；
3. 卷表记号到语义色是**四对四的双射**，而页那一级「注意」一档收着六样——双射是巧合；
4. `CONTEXT.md`《让位》与屏底那个模块的文档**次序正相反**，而代码连后者都没照做：
   它拿那个高度下限当定数，而那个常量自己的文档第一句就是「下限，不是定数」；
5. 措辞那份名单（八格）**从来就不该等于**列的名单——它漏掉页名、路径、定档页名
   是**故意的**，那三格是原样那一档；
6. 换字形不动黄金快照（第四次撞见 golden 够不着界面层）。

**这一批不动库。** 三条闸门全绿是每一张票的收尾条件；本批不改库对外形状，
`p4-parking-lot/19` 与它拆出来的那一张才改。
