# 11 — 展开的逐页表：默认只列要紧的页

**What to build:** 报告区里选中一卷按 `⏎` 展开它的逐页。逐页也是一张表，与卷表同一套
视口、砍列与上色。

**默认只列要紧的页**：特例页、失败页、部分救回页、几何门不成立的页、宽溢出的页、
兜底上界改过的页，以及**定档页**（它是这一卷的答案，非在不可）。`a` 切到**全部页**。
展开一卷的目的通常只有一个——**哪一页把整卷拉下来**——而两百页的卷里那八页
不该由用户自己在四百行里找。

抬头钉住这一卷的：基准档、定档页、要紧的页有几张、它是第几卷。

**跑着与等答话时都展得开**——这是 `p2-loose-ends/08` 搬进本批的那件事。它票面那条
硬约束原样成立：正在跑的那一卷要么展得开、要么明说它还没收摊，**不许摊开上一卷冒充它**。
做法是把展开的索引从「报告上第几卷」改成一个认得出「收摊了的那几卷」与
「还在攒着的那一卷」两处的东西。

**左栏照旧收起**：展开与左栏收起是同一件事，80 列的终端上那 52 列让不出来。

**Blocked by:** 02, 10

**Status:** resolved

- [x] `⏎` 展开选中那一卷，`Esc` 收起且光标停在原处、三层一格没动
- [x] 默认只列要紧的页，`a` 切到全部页，切换状态屏上看得出
- [x] 一张要紧的页都没有的卷：说清「这一卷没有要紧的页」，不给一张空表
- [x] 跑着的时候展得开，报告边跑边长、展开的那一副跟着更新
- [x] 正在跑／正在等答话的那一卷：要么展得开、要么明说它还没收摊——
      **不许摊开上一卷冒充它**，用例钉着
- [x] 展开着时按停仍按得动，两级语义不变（一次收尾、再一次中止）
- [x] `⇥`／`⇧⇥` 换下一卷／上一卷，视口对到那一卷的抬头上
- [x] 左栏收起，主区吃满宽度
- [x] 快照：只列要紧的页、全部页、跑着时展开、等答话时展开，各一张
- [x] 停车场 Q64 与 Q72 记上处置；`p2-loose-ends/08` 的落地指到本票
- [x] 三条闸门全绿

> **十一条都勾了。三处「勾得足，但读法要写明」：**
>
> - **第七条的「视口对到那一卷的抬头上」变成了另一个形状。** 从前展开那一副画的是
>   **整份报告**，换一卷要在里面数出那一卷落在第几行（`draw::opens_at`）；现在这一副
>   只画**那一卷**，抬头钉在这一格顶上——换一卷之后光标回到头一页，屏上第一眼看到的
>   因此恒是那一卷的抬头。那个行号连同 `opens_at` 一起没了。
> - **第一条的「三层一格没动」与从前逐字相同**（`Esc` 只把焦点换回报告区），
>   而「光标停在原处」现在有**两个**光标：报告区那个（跟随，`p3/10` 的）一格没动，
>   逐页表上那个是展开这一下现造的、收起就没了——它不该活过一次展开。
> - **第二条的「切换状态屏上看得出」摆在两处**：抬头末一格说**状态**
>   （`要紧的页 6/8` ⇄ `全部 8 页（要紧的 6 页）`），屏底那一行摆**键**
>   （`a 列全部页` ⇄ `a 只列要紧的页`）——与展开那一副「第几卷在抬头上、键在屏底」
>   同一条分法。
>
> 另有一处**判断**（不是保留）：**等答话时 `a` 归答话，「列全部页」那一下按不动**。
> 票面第二条要 `a` 切全部页，而 ADR 0017 决定第 4 条写着答话那三个键在哪一块上都按得动，
> 两者撞在同一个字母上——让的是「列全部页」（换一副列法等得起，一条停在决策点上的线程
> 等不起），屏底那一行跟着不摆它。记在 **Q161**。
>
> 本票**不了结任何一条**（Q64 与 Q72 早由 `p3/10` 了结，本票只把索引表那两行的去处改对），
> 新增 **Q161**、**Q162**、**Q163**，逐条写在《停车场结转》里。

## 落地记录

### 「要紧的页」的判据在 `render`，屏上那个词在画法

判据落在 `src/render.rs`——**从 `render` 取的，不是另写一套**：

```rust
pub enum Notable { Failed, Salvaged, Outlier, OutsideTheGate, Overflowed, Backstopped, Driver }
pub fn notable(volume: &VolumeReport, panel: Panel) -> Vec<Vec<Notable>>
```

出的是**与 `volume.pages` 等长同序**的一列，一页一格，空的那一格就是「这一页不要紧」——
**一页可以同时要紧在好几处**（以高为准的跨页卷里，定档页多半也是一张宽溢出的页）。
七种各自问的是：

| 要紧法 | 判据 | 来自 |
|---|---|---|
| 失败页 | `page.failure().is_some()` | `PageOutcome::Failed` |
| 部分救回 | `page.salvage().is_some()` | `PageOutcome::Salvaged` |
| 特例页 | `page.verdict().reason == Reason::Outlier` | `decide::Reason` |
| 几何门不成立 | `page.gate() == Some(GeometryGate::Broken)` | 与 `VolumeReport::outside_the_gate` 同一条 |
| 宽溢出 | `page.size.width > panel.resolution.width` | 与 `Report::wider_than_the_panel` 同一条 |
| 兜底上界 | `page.backstopped()` | 与 `Report::backstopped` 同一条 |
| 定档页 | `Envelope::driver == at` | 卷级判定那一格 |

前六种逐条对上 `CONTEXT.md` 的《语义色》在**页**这一级上分出的那几样；末一种一档都不占，
它是**这一卷的答案**。判据**一处出处**：屏上默认列哪几页、行首挂什么记号、抬头上
「要紧的页有几张」那个数，三处问的都是它（`render::tests::which_pages_matter_is_judged_in_exactly_one_place`）。

屏上那个**词**与那个**记号**在画法那一层配（`src/session/draw/pages.rs` 的 `says`），
与卷表那一头同一个形状（停车场 Q153）：一种要紧法配一个词加一个记号，
**添一种不配记号根本编不过去**，「颜色不是唯一载体」因此不靠人记着。

**两种不给词**，理由同一条：屏上本来就跟着 `render` 出的那一格，而它自己就说得出这件事——
失败页行尾是那一句原因（以「失败」开头），部分救回页行尾是 `Field::Salvage` 那一格
（`救回 62.0%`）。后者比一个词**多说了救回多少**：救回 5% 与救回 95% 是两回事，
一个「部分救回」把那个数抹平了。

### 逐页也是一张表：砍列、视口、上色三样一样都没另造

**砍列**——`src/session/columns.rs` 从「卷表的列」升成「报告区那两张表的列」：
摆法写在一个 trait 上（`Column`：`ALL` · `DROPPED_IN_TURN` · `NARROWED` · `head` ·
`to_the_right`），两张表各实现一份（`VolumeColumn`、`PageColumn`）。
`Widths` 跟着带上类型参数，`fit`／`line_width`／`elide` 一个字没改，
另添两个共用的：`plan`（砍列 + 收窄名字那一列，两步一处出处）与 `lay`
（一行怎么摆出来，从 `draw/table.rs` 搬进来——它一个终端都不碰，搬过来两张表就共用一份）。

逐页那六列与它的砍列次序：

```
 记号  页名  尺寸  判定  理由  判据          砍：判据 → 尺寸 → 理由
```

记号、页名与**判定**恒在——判成哪一档就是这一副要答的那件事。

**视口**——`src/session/viewport.rs` **一格没改**（只动了文档那张表）。展开那一副从前有
横竖两个滚动量记在 `Expansion` 上；竖的那一个换成了**光标停在第几页上**（`Expansion::at`），
视口照旧由光标算出来。`CONTEXT.md` 的《视口》那句「滚动量是算出来的，不是记着的」
因此第一次在这一副上也成立，而这一格顺带多了一条滚动条（画它的地方仍只有 `draw::scrollbar` 一处）。

**上色**——`src/session/draw/paint.rs` **一个字节都没动**。一行的语义由行首那个记号说了算，
四种记号（`✓` 普通 · `*` 定档页 · `!` 要留神 · `✗` 失败）各挂一种 `Tone`；
一页要紧在好几处时取**最重的那一个**（`Mark` 按 `Ord` 从轻到重排，与 `Tone` 同一个做法）。

**顺带收掉的一档**：spec 的《语义色》把**兜底上界**列在「注意」里，而屏上从前一处都没上色
（停车场 Q155 记着）。它此刻是要紧的页之一：行首 `!`、整行黄、行尾另有「兜底上界」那个词。
Q155 上补了一句现状——**那一条剩下的那一半（末尾几小结整段一种色）原样成立**，不归本票。

### 那一副此刻长什么样

```
┌报告 · 展开 卷二（第 2/2 卷）──────────────────────────────────────────┐
│ 基准档 4bit · 定档页 003.jpg · 要紧的页 6/8                           │  ← 钉住，不滚
│ 记号  页名     尺寸       判定  理由              判据                │  ← 表，跟着视口滚
│ *     003.jpg  1182×1680  4bit  阈值内最低的一档  1bit+FS 32.000 …  定档页
│ !     004.jpg  1600×1680  8bit  特例页单独定档    …                 特例页  宽溢出
│ !     006.jpg  1182×1680  4bit  卷级上包络        …                 兜底上界
│ !     007.jpg  1182×1680  4bit  卷级上包络        …                 救回 62.0%
│ ✗     017.jpg  1182×1680                                            失败 解不出完整尺寸…
└───────────────────────────────────────────────────────────────────────┘
 ↑↓ 选一页 · a 列全部页 · ⇥／⇧⇥ 换下一卷／上一卷 · e／Esc 收起，左栏回来 · q 退出
 只列要紧的页：特例 · 失败 · 部分救回 · 几何门不成立 · 宽溢出 · 兜底上界，加上定档页
```

**抬头钉在这一格顶上**（`pages::heading`）：基准档与定档页两格与卷表那两列**同一个出处**
（`render::base_column` 与 `table::driver`）——展开着的时候卷表不在屏上，
而「这一卷判成哪一档、是哪一页定的」正是逐页那几行要比的东西。
「它是第几卷」不在这里，那个数在报告区那一格的抬头上（`报告 · 展开 卷二（第 2/2 卷）`）——
**一个数不摆两处**。

**一页都列不出来时给的是一句话，不是一张空表**（`pages::nothing_to_list`），两种各说各的：
跳过的卷「幂等命中，一页都没有重做：没有逐页结果可看」（不要紧那一档）；
一张要紧的页都没有的卷「没有一页出事、也没有一页被摘出去」——那是**一句好消息**，
空表说不出这件事，读起来像画坏了。

### `a` 与那几个键

`Expansion` 从三格变成三格，含义换了两格：

```rust
pub struct Expansion { pub volume: Volume, pub at: usize, pub listing: Listing }
pub enum Listing { Notable, All }          // `a` 在两档之间来回
```

`Listing` 是个枚举而不是 `bool`（与 `Resuming`、`Reach` 同一条：本仓库不爱看不出意思的裸值），
而 `Action::List(Listing)` **带着去哪一档**——屏底那一行要说出这一下按过去是什么样，
一个 toggle 说不出（与 `Action::Focus(Pane)` 同一个形状）。

按键表那一支（`expanded_action`）：

| 键 | 做什么 | 与从前的差 |
|---|---|---|
| `↑↓`／`kj` | 逐页表上挪一页（`Action::Move`） | 从前是滚一行（`Action::Scroll`） |
| `a` | 换一副列法（**等答话时归答话**，Q161） | 新的 |
| `←→` | **不派动作**——横向摆不下时砍列 | 从前是横着滚 `SIDEWAYS` 列 |
| `⇥`／`⇧⇥` | 换下一卷／上一卷 | 一格没动 |
| `e`／`Esc` | 收起，回报告区 | 一格没动 |
| 其余 | 交 `stage_action`（按停、答话那三个、退出） | 一格没动 |

`Toward` 那个枚举、`SIDEWAYS` 那个常量与 `Action::Scroll` 三样一起没了：
两根轴变成一根，而那一根是光标不是滚动量。

**两头不转圈**（`move_cursor` 那一支）：三层那几个取值环与预设栏是短列表，两头转一圈；
这一副是一张两百页的长表，从末一页一下转回头一页会让「翻到底了」在屏上没有落点。
往上收在零，往下由画法那一层每帧收一次（`Session::clamp_report`：只有它知道这一副
此刻列着几页）。

### 那两条硬约束

**「不许摊开上一卷冒充它」**——`p3/10` 已经把索引换成 `live::Volume`
（`Settled(usize)` / `Summarized { after }`），本票原样用它、一处都没重做。
钉它的用例是 **`the_volume_waiting_at_the_decision_point_expands_into_its_own_pages`**
（`src/session/draw/report.rs`）：两卷造得认得出来——收摊了的那一卷八页、要紧的六页，
决策点上攒着的那一卷一页——展开后者，屏上说得出 `展开 卷二`、`要紧的页 1/1`，
而前者那几页（`004.jpg`…`017.jpg`）**一页都不在**；那一卷收摊、下一卷停到它自己的决策点上
之后，这一格给的仍旧是它自己。快照那一张是
`the_volume_waiting_at_the_decision_point_expands_while_it_waits`。

**「展开着时按停仍按得动，两级语义不变」**——结构上成立，不靠自觉：
展开那一块自己的按键表一个改动键都没有，不认的键一律交给 `stage_action`，
而阶段那一维派得出的就是按停、答话那三个与退出（ADR 0017 决定第 2、4 条）。
`which_keys_do_what_in_which_state` 的第七之二段逐条问过（跑着时 `s` 是按停、
等答话时 `x`／`a`／`s` 是答话、`q` 按不动、`Ctrl-C` 照旧退得出去）。

### 评审

`/code-review high` 跑过一遍（**只读，没碰工作区，一条 cargo 都没跑**）。提了五条，**五条全收**：

- **逐页表把「救回了多少」那一格丢了**（`Field::Salvage`，`救回 62.0%`）：屏上只剩
  `says` 给的那个词「部分救回」，于是**救回 5% 与救回 95% 的两行逐字相同**——
  而那个数正是「这一页坏到什么程度」唯一的读数。它也不在 `pages.rs`
  《表有意不带的那几格》那张单子上，因此是漏，不是决定。**改法**：部分救回那一档
  与失败页同一个待遇——**不给词**，行尾跟着 `render` 出的那一格，它自己就以「救回」开头。
- **夹具那一页同时是「兜底上界」与「宽溢出」，而库那一侧写着两者不重叠**
  （`Report::backstopped`：「退回之后的页恒不超过面板宽，一页都不会同时落在两张清单里」）。
  「一页可以同时要紧在好几处」这件事因此钉在一个**到不了的状态**上，快照还把那一对
  摆给用户看。**改法**：`004` 改成**特例页加宽溢出**（可达），`006` 只留兜底且拿普通尺寸；
  `render` 那条用例换成同样可达的**宽溢出加定档页**（以高为准的跨页卷里，定档页多半就是宽的），
  `Notable` 与 `Mark` 两处文档里那个举例跟着改。
- **夹具那份 `Envelope` 的 `body_pages` 与它自己那八页对不上**：`4` 写成的其余页
  按 `Envelope::body_pages` 自己的定义只有 **3** 张（`001`、`003`、`006`——彩页、特例、
