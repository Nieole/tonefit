# 11 — 展开的逐页表：默认只列要紧的页

**What to build:** 报告区里选中一卷按 `⏎` 展开它的逐页。逐页也是一张表，与卷表同一套
视口、砍列与上色。

**默认只列要紧的页**：特例页、失败页、部分救回页、几何门不成立的页、宽溢出的页、
兜底上界改过的页，以及**定档页**（它是这一卷的答案，非在不可）。`a` 切到**全部页**。
展开一卷的目的通常只有一个——**哪一页把整卷拉下来**——而两百页的卷里那八页
不该由用户自己在四百行里找。

抬头钉住这一卷的：基准档、定档页、要紧的页有几张、它是第几卷。

**跑着与等答话时都展得开**——这是 `p2-loose-ends/08` 搬进本批的那件事。它票面那条
硬约束原样成立：正在跑的那一卷要么展得开、要么明说它还没收摊，**不许摊开上一卷冒充它**。
做法是把展开的索引从「报告上第几卷」改成一个认得出「收摊了的那几卷」与
「还在攒着的那一卷」两处的东西。

**左栏照旧收起**：展开与左栏收起是同一件事，80 列的终端上那 52 列让不出来。
