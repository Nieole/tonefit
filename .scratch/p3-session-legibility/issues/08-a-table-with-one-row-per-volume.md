# 08 — 卷表：一卷一行，列对齐，窄了砍列

**What to build:** 报告区从一整段纯文本变成**一卷一行的表**：

```
记号   卷名        页数   基准档     定档页    耗时
 ✓    棋魂 07      184   2bit+FS    087.png   1m12s
 !    哆啦 03      212   4bit+FS    011.png   2m03s   隔离
 –    名侦探 05    190   跳过                   3s
 ✗    消失的那卷    —    没做成：卷根不在了
```

要修的毛病是：今天一卷四到五行长句、`·` 串起来，120 列的屏上主区只剩 68 列于是行行回绕，
整屏一种字重、一处颜色都没有——跑二十卷就是一百多行长得一模一样的灰字。

**各种卷各有各的行**：跳过的卷在基准档那一列写「跳过」、定档页留空、**耗时照给**
（幂等那一道不是免费的，而「跳过一卷为什么也要等这么久」正问在这里）；卷级失败的卷
写「没做成」加理由；`--per-page` 与覆盖顶掉判定的照卷级判定说的写；停在决策点上等答话
的那一卷也占一行，标着「等你拿主意」。

**不重排**：卷按跑完的先后添上去，出事的靠记号跳出来、不靠位置——重排会让刚跑完的
那一卷在屏上跳位置，而「一卷跑完当场看得见」正是这一格存在的理由。

**窄了按固定次序砍列：耗时 → 定档页 → 页数**，卷名与行首记号恒在。这个次序**只有一处出处**。

抬头那几行（profile、适配方式、裁边、跨页拆分、判据构成与聚合）这一票**暂时摆在表上方、
跟着表滚**，12 号票把它们收进覆盖层。

## 落地记录

### 砍列摆在终端库外面

新模块 **`src/session/columns.rs`**，与 `state`、`live`、`run`、`complete`、`viewport`
同一层（`src/session.rs` 的《终端库在哪一半》与 `docs/agents/gate.md` 那张分界表**都补了**）。
它一个 `ratatui` 都不 `use`：

```rust
/// **砍列的次序：耗时 → 定档页 → 页数。**
const DROPPED_IN_TURN: [Column; 3] = [Column::Elapsed, Column::Driver, Column::Pages];

pub(super) fn fit(room: usize, widths: &Widths) -> Vec<Column>
pub(super) fn elide(text: &str, room: usize) -> String
pub(super) fn line_width(kept: &[Column], widths: &Widths) -> usize
```

**次序只有 `DROPPED_IN_TURN` 一处出处**，画法那一层一个字面量都没有——它只问 `fit`。
`Column::ALL` 是列的次序（记号 · 卷名 · 页数 · 基准档 · 定档页 · 耗时），
`Widths` 是「那一列上最长的一格（列头也算一格）」。

**行首记号也当成一列**：它与别的列一样要对齐、要量宽度，排除在外只会让画法自己再算一遍
它占几格。它与卷名一起是砍不掉的那两列——`DROPPED_IN_TURN` 里没有它们。

`elide` 从**中间**省略、两头留着：书名与第几卷都要认得出，从行尾切掉的话满屏的卷
长得一模一样。宽字符跨在边界上就不要它——画半个汉字是一格空白。

**七条用例全在这一侧**（闸门 2 照跑）：一列多宽、砍列那个次序、最窄那一档上记号与卷名
仍在、中间省略、窄到一两格不错位、行宽 = 各列加中间那几个空、收窄一列之后行摆得下。

### 卷表：同一批行的第二副排版

新模块 **`src/session/draw/table.rs`**（`p3/01` 的分法照旧：屏上一块一个模块），
吃的是 `render::volume(volume)` 出的那**同一批行**——不另取一份数据：

| 那一列 | 出处 |
|---|---|
| 行首记号 `✓ ! – ✗` | `Mark::of`（这一层；命令行上根本没有） |
| 卷名 | `render::volume_name`（与进度条、当前卷条同一个） |
| 页数 | 卷那一行的 `Field::PageCount` |
| 基准档 | **`render::base_column`**（新，措辞那一层） |
| 定档页 | `RowKind::Driver` 那一行的 `Field::Source`，只印最后一段（同样走 `volume_name`） |
| 耗时 | `VolumeTiming::elapsed`，写法走 `overview::spell`（与抬头那两个时长同一个） |

**六种卷各有各的行**（`six_kinds_of_volume_each_get_their_own_row` 逐条问）：

```
 记号  卷名        页数  基准档        定档页   耗时
 –     棋魂 07      184  跳过                   3s
 !     哆啦 03        2  4bit          001.jpg  1m12s  隔离
 ✓     名侦探 05      1  逐页                   1m12s
 ✓     浪客行 12      1  覆盖 2bit+FS           1m12s
 ✗     消失的那卷     —  没做成                        卷根不在了
 ✓     棋魂 08        1  4bit          001.jpg  1m12s  等你拿主意
```

- **跳过的卷**：基准档写「跳过」、定档页留空，**耗时照给**——幂等那一道不是免费的。
- **卷级失败的卷**：档位写「没做成」，那句原因**成句跟在行尾**，页数那一格不在场
  （只有页数留一个 `—`：它夹在卷名与档位中间，空着读起来像掉了一个数）。
- **逐页与覆盖**：档位照卷级判定说的写，不编第二套说法。
- **等答话那一卷**：记号与档位照它**到此刻为止**的那份报告画，行尾标着「等你拿主意」
  （措辞出处是 `overview::DECIDING`，与总览块抬头上那一句同一个）——
  **不许摊开上一卷冒充它**（`p2-loose-ends/08` 的硬约束）。

**不重排**：卷按跑完的先后添上去（`the_table_never_reorders_the_volumes_it_has_added`
钉的正是那个先后）。一处例外记在 **Q151**。

### 没做成的那一卷自成一种行（Q133）

`RowKind` 多一种 `FailedVolume`，`render::failed_volume(&VolumeFailure) -> Row` 出那一行
（两格：路径、那句原因）。**关键是让命令行那一路也读它**——
`failed_volume_tail` 里逐条那两行改成 `plain::line(&failed_volume(failure))`，
`plain::line` 因此提为 `pub(super)`，`plain` 那个 `match` 多一条（形状与从前逐字相同）。

那一句原因于是**只有一处出处**：卷表读的与末尾那一小结印的是同一行
（`a_volume_that_never_got_done_is_its_own_kind_of_row` 两头对着问：
`tail(&report).contains(&plain::line(&row))`）。不这么接还有一个硬理由——
不接的话那一行在关掉 `tui` 的构建里没有一个构造者，`dead_code` 当场红。

**命令行印出去的字节一个没变。**

### 视口接住了报告区

默认那一副的滚动量与滚动条**都由 `Viewport` 出**，不另造一套（票面：视口只有一份实现）：

```rust
let view = Viewport::new(rows.len(), usize::from(inside.height), rows.len().saturating_sub(1));

```

**光标恒停在末行**：算出来的起点因此恰好是从前那个 `past_the_top`（「滚到底」），

（那是 `p3/10` 的事）。`past_the_top` 连同它那段文档删掉了——出处只剩 `Viewport` 一处。

### 成句的那几段一句都没塞进格

报告区默认那一副的正文是 `collapsed()`：**抬头几行 · 卷表 · 失败页 · 末尾那几小结**。
表以外的三段照旧走 `crate::wrap` 折行，`src/wrap.rs` **一个字节没动**：

- **末尾那几小结**与**抬头里互锁那几行**：整段折行，折出来的每一行逐字对得上
  （`the_sentences_are_still_drawn_as_folded_prose`）。
- **没做成那一卷的那句原因**：它跟在表上那一行的**行尾**，摆不下时整行折下去。
  表上每一行行首恒留一格空白——那一格既让表离开框线，也是折下来那几行的**悬挂缩进**。
- **过期副本与部分救回那两句**：表上没有它们的列，报告别处也没有它们的位置
  （过期副本连末尾那几小结与总览块的出事行都没有它），因此**缩进摆在那一卷那一行底下**，
  整段折行（`table::under`）。几何门那几句注解**没有**跟着摆回来——表有意不带几何，
  追下去要展开那一卷，而把它们摆回来就是把这一票要消灭的那四五行长句原样搬回屏上。

**抬头那几行摆在表上方、跟着表滚**（12 号票才把它们收进覆盖层，本票没有提前收）。

### 评审

`/code-review high` 跑过一遍（**只读，没碰工作区**）。提了五条，**五条全收**：

- **过期副本与部分救回从默认那一副里掉了**（唯一一条 medium，也是唯一一条真丢东西的）。
  `render::volume` 出的这两种成句的行在表上没有列，而**过期副本连末尾那几小结与总览块的
  出事行都没有它**——落地前对一个被隔离过的库重跑，报告区当场印着「盘上还躺着上一趟那一份，
  删不删由你」；照第一版落地之后屏上只剩一行 `✓ 卷X`。**改法**：新加 `table::under`，
  把这两种句子缩进摆在那一卷那一行底下、整段折行；用例
  `the_sentences_the_table_has_no_column_for_sit_under_that_volume` 两头问
  （那一句逐字来自 `render`，没有过期副本的卷一行都不出）。
- **「不重排」那条用例挡不住它要挡的那次交换**：它按 `split_whitespace().nth(1)` 取名字，
  而 `棋魂 07` 与 `棋魂 08` 都取到 `棋魂`——那两卷恰是这条要钉的一对（一个来自收摊了的
  那一列，一个是决策点上那一份），对调了照样绿。**改成比整个卷名**，连卷号一起。
- **省略号两头的预算不互相找补**：一个汉字跨在头上那半的边界时白扔一格，
  `消失的那卷` 收进七格出的是 `消…卷`（宽 5），而 `消…那卷` 正好摆得下。
  **改成头上没用完的还给尾巴**，窄终端那张快照跟着重录（`消…卷` → `消…那卷`）。
  多认出一个字，而「书名与第几卷都认得出」正是这个函数存在的理由。
- **页数没走它自己文档说的那个出处**：模块文档写着「出自卷那一行的 `Field::PageCount`」，
  代码却直接读 `volume.page_count()`。今天两者同值，但 `render::volume` 的文档明写着
  源页数是另一个数、「两者眼下相等」——真分开说的那天两副会走散。**改成读那一格**。
- **四种记号里三种是东亚歧义宽度**（`✓ ✗ –`，连同 `—` 与 `…`），而 `wrap::width` 一律算
  一格；按 CJK 配置的终端上它们占两格，同一批里的 `!` 却恒占一格，整张表会逐行参差。
  这套约定是仓库既有的，本票没有引入；**新的是「对齐」头一次成了屏上那一格存在的理由**。
  **把这条限制写进 `columns` 的模块文档**，记号集一个字没换，账记在 **Q154**。

评审另点了两处「不算 finding」的：卷级失败那句原因收场后在表上与末尾小结里各印一遍
（有意为之：一套措辞、两副排版），以及窄终端上折下来的注只有一格悬挂缩进、
与正文首列同宽。两处都照原样留着。

### 停车场结转

**了结两条**：**Q133**（卷级失败的卷怎么进表——走「多一种 `RowKind`」那条，
措辞仍只有一处）、**Q130**（两张主区快照归了报告区；共用措辞那一半判定为不动）。

**新增四条**，一条都没了结：

- **Q151**（新，**待处理**）：没做成的那几卷排在收摊了的那几卷**后面**，
  不是按跑完的先后——`Report` 把两者分成两列存，跨列的先后没有一处记着。
  修它要动库那一侧的 `Report`，而本批「库这一侧一个 seam 都不动」。
- **Q152**（新，**待处理**）：`CONTEXT.md`《视口》那条列的三处里没有报告区，
  而本票把卷表接了进去。**词条一个字没改**；代码那一侧的名单（`Viewport` 上那张表，
  唯一出处）已经补了。
- **Q153**（新，**待处理**）：「隔离 / 跳过 / 没做成」那几个字与四种记号分在两处
  （措辞一处、排版一处，分法本身是对的），而**「这一卷属于哪一种语义」这个判断**
  眼下只活在 `Mark::of` 里——语义色那一票（`p3/09`）要接的就是它。
- **Q154**（新，**待处理**，评审揪出来的）：卷表的四种记号里三种是东亚歧义宽度，
  而 `wrap::width` 一律算一格；按 CJK 配置的终端上整张表会逐行参差。
  约定是既有的，本票只把这条限制写进 `columns` 的模块文档。

### Q130 — 按「屏上那几块」切开之后，仍有两样东西跨着两块

- **From:** 票 `p3-session-legibility/01`（评审揪出来的两条判断题）
- **Kind:** 票面没想到的第三种情形（分块之后才看得见的耦合）
- **Where:** 一、`src/session/draw.rs` 里的 `WITHOUT_A_FAILED_PAGE` 与
  `WITH_A_FAILED_PAGE` 两张快照；二、`src/session/draw/bars.rs` 头上那句
  `use super::footer::{START_KEYS, stopping_name};`
- **Why it did not block:** 两样都不是搬错了地方，是**那几块本来就在这两处搭着**：
  - 那两张快照钉的是 `main_pane` 画出来的**整个主区**（横条两条加报告区正文），
    因此跟着 `main_pane` 留在布局那一块。代价是：`render` 改一句措辞，就要回到布局
    模块重录这两张。
  - `START_KEYS` 与 `stopping_name` 是**两块共用的措辞**（全局条的抬头与屏底那一行
    说的是同一件事），措辞只有一处出处是对的，但「屏上那一块」的分法没给这种东西一个家，
    它眼下寄在屏底名下。
- **What this ticket actually did:** 两样都**照原样搬，没有动**。本票是纯搬家，
  拆快照或另立一处「两块共用的措辞」都是重新设计，而后面十二张票要往主区加总览与卷表
  （spec 的《Implementation Decisions》第一条），那时这两处的形状十有八九要重定。
- **Whose call:** 下一张动主区的票（把两条横条与摘要合并成「总览」的那一张）——
  它会重录这两张快照，届时顺手决定它们归谁
- **两样各怎么收的（`p3-session-legibility/08`）:**
  1. **两张快照归了报告区**（`src/session/draw/report.rs` 的 `mod tests`，改名成
     `the_report_pane_without_a_failed_page` 与 `the_report_pane_with_a_failed_page`）。
     判据是「它钉的是谁画出来的字」：那两张里逐行的字全部出自报告区那一格
     （抬头几行 + 卷表 + 失败页），总览块那五行自己另有四张快照在 `overview` 里。
     搬过去之后，改一句报告措辞只重录报告区那一块，布局模块一行不动——那正是这一条记的代价。
     `main_snapshot` 那个探针留在 `probe`（它画的是**主区整块**，本来就是跨块的探针）。
  2. **`START_KEYS` 与 `stopping_name` 照原样留在屏底名下，判定为不动。**
     它们是**两块共用的一份措辞**，而「一处出处」本来就要求它只有一个家；
     「屏上那一块」的分法分的是**画法**，不是措辞，给措辞另立一个模块只会让
     「这句话住在哪儿」多一层要猜的东西。谁引用谁在文档里写着，读得出来就够了。
- **处置：** 了结（`p3-session-legibility/08` 收的）。

### Q133 — 卷级失败的卷没有自己的一种「行」，而卷表要给它一行

- **From:** 票 `p3-session-legibility/02`（评审 Spec 轴揪出来的）
- **Kind:** 票面没想到的第三种情形
- **Where:** `src/render.rs` 的 `failed_volume_tail`（卷级失败那一小结）与 `RowKind`；
  P3 spec 的《Implementation Decisions》第六条那张卷表：
  「**卷级失败的卷**：记号红，档位那一列写「没做成」，理由跟在后面（成句，不拆格）」，
  示意图上那一行是 `✗ 消失的那卷  —  没做成：卷根不在了`
- **Why it did not block:** 本票降到字段级的是**卷级与逐页那两段**，而那两段吃的是
  `VolumeReport`。卷级失败的卷**连 `VolumeReport` 都没有**——它在 `Report::failed_volumes`
  里，只带着路径与一句原因，`render::volume` 够不着它。票面同时明写末尾那几小结
  「一个都不要动」，`failed_volume_tail` 因此原样留着。
- **What this ticket actually did:** `RowKind` 里**没有**卷级失败那一种。
  「失败的卷是哪一种行」这条验收按**有页失败、因此被隔离的卷**答的：那种卷的卷级那一段
  多出一行 `RowKind::Isolated`（用例
  `a_failed_page_and_the_volume_it_isolates_are_each_their_own_kind_of_row`）。
  两种「失败的卷」是两件事，`CONTEXT.md` 的《失败》分得很清楚。
- **Whose call:** 画卷表那一张票。它得决定卷级失败的卷怎么进表——多一种 `RowKind`
  并让某个函数吃 `Report::failed_volumes`，还是让卷表自己从 `Report` 那一列里取。
  前者措辞仍只有一处（那一句原因今天在 `failed_volume_tail` 里），后者会长出第二个出处。
- **走了哪条（`p3-session-legibility/08`）:** **第一条**。`RowKind` 多一种
  `FailedVolume`，`render::failed_volume(&VolumeFailure) -> Row` 出那一行（两格：
  路径与那句原因，成句不拆）。关键的一步是**让命令行那一路也读它**：
  `failed_volume_tail` 里逐条那两行改成 `plain::line(&failed_volume(failure))`，
  `plain::line` 因此提为 `pub(super)`，`RowKind::FailedVolume` 在那个 `match` 里多一条
  （形状与从前逐字相同，报告印出去的字节一个没变）。这一步不只是为了漂亮：
  不这么接，那一行在关掉 `tui` 的构建里就没有一个构造者，`dead_code` 当场红——
  而真正的收益是**那一句原因确实只有一处出处**，卷表与末尾那一小结读的是同一行。
- **档位那一列另立了一个函数，不是一格:** `render::base_column(rows) -> Option<String>`
  答「这一卷判成哪一档，或者它为什么没有一档」（基准档 / 覆盖 X / 逐页 / 跳过 / 没做成）。
  **没有走「给跳过的卷加一格 `Field::Base`」那条**：`CONTEXT.md` 的《格》明写着
  「跳过的卷没有基准档那一格」，加上去就是改一条已有词条的含义，而那要先拍板
  （`CLAUDE.md`《改 CONTEXT.md 的规矩》）。函数这条路把五种说法收在措辞那一层的一处，
  一格的在场与否照旧作数。
- **处置：** 了结（`p3-session-legibility/08` 收的）。
