# 12 — 两张覆盖层：`?` 键位表与「这一趟的前提」

**What to build:** 键位变多了，而屏底那一行摆不下全部——用户不知道有哪些键，只能试
（与取值那一处是同一个毛病：**看不见的东西等于不存在**）。

屏底瘦身成此刻最常用的四五个，**末尾恒是 `? 全部键`**；`?` 调出一张按**焦点**分组的
完整键位表（左栏 / 报告区 / 展开着 / 预设栏 / 任何时候），`Esc` 关。

同一副形状再用一次：08 号票暂时摆在卷表上方的**抬头那几行**（profile、适配方式、
裁边、跨页拆分、判据构成与聚合）收进第二张覆盖层。它们是「**这一趟的前提**」，
一趟只说一次，在长任务里没人会反复看，而它们占的正是卷表要的行。

「**屏上不摆按不动的键**」这条照旧：屏底那一行仍随状态变，`?` 那张表也只列此刻
这个阶段派得出的键。

## 落地记录

### 覆盖层是焦点那一维上的第七个取值，而它**盖住**一块、不替掉它

```rust
pub enum Focus { Config, Editing(Edit), Report, Expanded(Expansion), Picking(Picker),
                 Valuing(Values), Overlaid(Covered) }

pub struct Covered {
    pub overlay: Overlay,   // 掀开的是哪一张
    under: Box<Focus>,      // 盖住的那一块焦点：`Esc` 原样回到它
    from: usize,            // 从第几行画起
}

pub enum Overlay { Keys, Premises }
```

盖住的那一块**整份带着**（`Box<Focus>`）而不是记一个「回哪儿去」的小枚举：
展开的那一卷、摊着的那一列、预设那一栏各带着一份东西，而关掉覆盖层要的是**原样回去**。
`an_overlay_covers_one_block_and_gives_it_back` 钉的正是这一条——展开着那一块带着
「哪一卷、哪几页、光标停在第几页」三样，掀开又关掉之后三样都还在。

**掀着一张时按另一张那个键是换过去，不叠第二层**（`Session::reveal` 把上一张的
`under` 原样接过来）：`Esc` 因此恒是一下回到屏上那一块，要按几下不必用户自己数。

### 两张是**一张画法、两份内容**

`src/session/draw/overlay.rs` 一个函数把这一格画完——抬头、边框、折行、视口、滚动条
一处都不分岔。两张差的只有一句 `match`：

```rust
let body = match which {
    Overlay::Keys => keys(session),        // 问 Session::key_table
    Overlay::Premises => premises(live),   // crate::render::header
};
```

它盖的是**屏底之外的全部**（`draw::shell` 里那一道分岔）：`?` 那张表与这一趟的前提
都要一眼扫得完，而屏上此刻没有第二件要读的事。屏底那几行照旧在场——那一行说的正是
怎么关掉它。

### `?` 那张表是**问出来**的，不是抄出来的

`Session::key_table` 把**每一个键**（`every_key`）交给那一块的按键表问一遍，
`Action::Ignored` 的丢掉，剩下的就是这一组：

```rust
pub fn key_table(&self) -> Vec<(KeyGroup, Vec<(Key, Action)>)>
```

**分组就是按键表自己的头一层分岔**（ADR 0017 决定第 2 条：先按焦点分岔，落到哪一块
再按阶段分）——票面说的「按焦点分组」正是它。六组：左栏 · 取值栏 · 报告区 · 展开着 ·
预设栏 · **任何时候**。

**三道滤**，各答一条票面：

- **此刻进不去的那一组整组不列**（`KeyGroup::reachable`，两条都由阶段那一维说了算）：
  取值栏与预设栏**只从左栏进得去，而跑起来之后左栏一个改动键都不派**
  （ADR 0017 决定第 8 条《两维不是笛卡儿积》）；报告区与展开着在**一趟都没跑过**时
  进不去（那时 `⇥` 不派、展开也无从谈起）。屏上不摆按不动的键，
  而一张进不去的块的键位表是同一件事。
- `Action::Ignored` 的不列——同一条。
- **一个键只列一处**：[到处都是同一件事的](Session::means_the_same_everywhere)归
  「任何时候」（`Ctrl-C 退出会话` 照实列的话会在五组里各出现一次），
  **有一块另派的归各块自己**——`Esc` 在左栏上是退出会话、在展开着上是收起、
  在取值栏与预设栏上是退一步，摆进「任何时候」的话这张表就在几块上说了假话。

画法那一层**一个键都不列**，只把问出来的动作翻成屏上那句话（`overlay::says`），
再把**派得出同一件事的那几个键并成一行**（`↑ ↓ j k` 是一件事，不是四件）。
`the_key_table_is_the_key_table_itself` 两头对：按键表派得出的每一个动作都在屏上，
派不出的（`z`）一处都没有。

**只列此刻这个阶段派得出的键**：没跑过时按停不在这张表上，跑起来它就在了，
而且只在「任何时候」那一组里（`the_key_table_is_asked_of_the_key_table_itself`）。

### 「这一趟的前提」挑的是 `i`，两个键都在按键表里查过

**`?` 与 `i` 各在六块焦点、四个阶段上问了一遍，一处都不派动作**——这一条不是我读出来的，
是用例问出来的（`the_key_table_is_asked_of_the_key_table_itself` 里那个双重循环：
`session.acts(group, Key::Char(overlay.key())) == Action::Ignored`，六组各问两个键）。

各块此刻占着的字母，逐块列出来：

| 块 | 占着的字母 |
|---|---|
| 左栏（`browsing_action`） | `j k d t x e p c q` |
| 报告区（`report_action`） | `k j e g` |
| 展开着（`expanded_action`） | `k j a e` |
| 预设栏（`listing_action`） | `k j d p q` |
| 取值栏（`valuing_action`） | `k j q` |
| 阶段那一维（`stage_action`） | 跑着 `s`／等答话 `x a s`／没跑过与收场了 `q` |

`i` 与 `?` 一处都没有——`a` 那种撞车（**Q161**：展开着且等答话时 `a` 归答话）
在这两个键上因此不存在。挑 `i` 而不是 `h`：`h` 在 vim 手上是「往左」，而左栏上
`←` 正是「就地换一个取值」，撞的是习惯而不是表。

**它们归第三处，不进那六块**（`Session::action_in` 里那一道 `revealing`）：
与按停、答话那几个归 `stage_action` 一处同一个形状——两个键都与眼下在看什么无关，
摆进六块里就是六份措辞。

### 屏底瘦身成了什么样

左栏那一行从**十个键**（`←→ 换一个 · ⏎ 摊开 · c 出标定图 · ↑↓ 选 · ⇥ 报告区 ·
t 试算 · x 执行 · e 展开 · p 预设 · q 退出`，80 列上折三行）瘦成**五个**：

```
 ⏎ 摊开取值 · t 试算 · x 执行 · q 退出 · ? 全部键
```

留下的各有理由：**这一行上动手那一个**（随行状变：摊开／改／打一个路径／勾上）、
**试算与执行**（与光标停在哪儿无关，而「配好了之后按哪个键」最该一直看得见）、
**`q 退出`**（一行不让，停车场 Q75）、末尾那一句。收场之后多一个 `⇥ 报告区`。

`? 全部键` 那一句**由 `footer` 一处接上**，不在各状态那几个函数里各接一遍——
一处接完，「恒在末尾」才是结构上成立的。

`i 这一趟的前提` 摆在**报告区**那一行上：那几行从前就摆在卷表**上方**，
读报告的人正是在那一块上找它们的。**一趟都没跑过时不摆**（那时一个字都印不出来），
与展开那个键在左栏上的待遇同一条。

### 前提那几行真的走了

`report::collapsed` 的头一行从前是 `render::header(...)`，此刻直接是卷表——
`the_sentences_are_still_drawn_as_folded_prose` 的末一段反过来问：
`profile ` 与互锁那几行**都不在**那一格里，而 `said.starts_with(" 记号")`。
措辞照旧只有 `crate::render::header` 一处：覆盖层印的就是命令行报告顶上那一段字
（`the_premises_overlay_carries_the_header_the_volume_table_used_to_wear` 逐行比过）。

跟着变的还有一处**读法**：卷表从此从报告区那一格的头一行起，光标那个行号不必再
往下推一段（`collapsed` 里那个 `cursor.map(|row| row + rows.len())` 没了）。

### 装不下时滚得动，而这一处记的是**滚动量**

覆盖层是**读物**：一行上没有第二步可走，一个光标都停不上去，而「视口跟着光标走」
要先有个光标。`Covered::from` 因此记的是**从第几行画起**——屏上唯一记着滚动量的一处
（`CONTEXT.md` 的《视口》那句「滚动量是算出来的，不是记着的」在它身上是个例外，
记在 **Q163**）。

**`Viewport` 一格没改**：交给它的是「露出来的最后一行」（`from + height - 1`），
算出来的起点恰好是 `from`，而往下滚到哪儿为止由它收；往下按过了头由
`Session::clamp_overlay` 每帧收一次（与逐页表那一处同一条）。
`an_overlay_too_tall_for_its_box_scrolls` 四头都问了：↓ 动、↑ 回、到底不再动、按住 ↑ 回头。

### 屏上那两张长什么样

`?` 那张在 80×24 上摆得下一格覆盖层加屏底三行，右边那条滚动条说出「下面还有」

### 评审

`/code-review high` 跑过一遍（**只读，没碰工作区，一条 cargo 都没跑**——闸门那时正在
另一个进程里跑）。提了五条，**四条全收，一条记进停车场**：

- **「任何时候」那一组把 `Esc` 说成「退出会话」，而它在四块上不是这个意思**
  （展开着是收起，取值栏与预设栏是退一步，覆盖层是关掉）。那一道去重从前只在动作
  **相等**时才滤，于是同一张表上既有「取值栏 · `← Esc` 一格不改地回左栏」，
  又有「任何时候 · `Esc Ctrl-C q` 退出会话」。**改法**：那一道滤换成
  「**一个键只有在此刻进得去的每一块上都是同一件事时才归『任何时候』**」
  （`means_the_same_everywhere`）——`Esc` 因此归各块自己列，`Ctrl-C` 与 `q` 照旧只列一处。
- **取值栏与预设栏两组跑着时照列，而那两块那时根本进不去。** 它们只从左栏进得去，
  而跑起来之后左栏一个改动键都不派（ADR 0017 决定第 8 条）。**改法**：
  `KeyGroup::reachable` 按阶段撤组——顺带把「一趟都没跑过时报告区与展开着两组」也撤了
  （那时 `⇥` 不派、展开无从谈起），80×24 上那一张因此短了一截。
- **覆盖层屏底那一行无条件摆 `i 这一趟的前提`**，而一趟都没跑过时按下去只换来一句话。
  **改法**：`overlaid_prompt` 收 `live`，与 `report_prompt` 同一条挡法。
- **文档把「按停与答话在别的块上都按得动」的范围说大了**（写成「另外五块」）：
  真正把不认的键交给 `stage_action` 的只有左栏、报告区、展开着三块。**改法**：
  三处措辞（`overlay_action`、`Focus::Overlaid`、停车场 Q164）都改成「摆得下它们的三块」，
  并点明覆盖层是**跑着时进得去、却一个都不派**的唯一一块。
- **`?` 那张表滤不掉「派得出、而 `press` 那一层挡着」的键**（`e` 展开与 `i` 前提，
  一趟都没跑过时按下去只说一句话）。**没收**：挡它们要 `live`，而 `key_table` 是状态机上
  的纯函数——收 `live` 就等于让状态机读那一趟攒下来的东西。那两支**按下去有话说**，
  不是按了没反应。记在 **Q167**。

## 停车场结转

**一条都没了结。** 本票撞见但按票面不收的：Q136、Q154、Q159、Q161、Q162。

**按票面在 Q163 上补了三条**（同一类「词汇表与实现对不上」，不新开条目）：

- 《焦点》写着「焦点的取值**六个**」——覆盖层是第七个（ADR 0017 决定第 1 条早写着它会来）；
- 《视口》那句「滚动量是算出来的，不是记着的——屏上没有一处记着『滚到哪儿了』」
  此刻有**一处例外**（`Covered::from`）；
- 《卷表》写着「表**上面**跟着它一起滚的是这一趟的抬头」——那几行进了覆盖层。

**新增三条，一条都没了结**：

- **Q164**（新，`p4-parking-lot/06` **已了结**）：**覆盖层掀着时按停与答话那三个键
  按不动**，而 ADR 0017 决定第 4 条说它们「在焦点落在哪一块上都按得动」。
  本票照票面走的，ADR 一个字没改；后来判的是照 ADR 走（见上面那一条判断）。
- **Q165**（新，**待处理**）：**「屏底末尾恒是 `? 全部键`」在打字的那两块上摆不出来**。
