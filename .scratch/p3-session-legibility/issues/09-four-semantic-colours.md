# 09 — 一套语义色，四种，颜色不是唯一载体

**What to build:** 屏上眼下**一处颜色都没有**——出事的卷与正常的卷长得一模一样，
「一眼看出重点」最便宜的那个手段一直没用上。给它四种语义色，**一处出处**：

| 语义 | 用色 | 用在哪 |
|---|---|---|
| 平常 | 终端默认色 | 正常跑完的卷、普通的页 |
| 注意 | 黄 | 隔离、宽溢出、部分救回、兜底上界、几何门不成立、特例页 |
| 出事 | 红 | 失败页、卷级失败、拒绝执行 |
| 不要紧 | 暗 | 跳过的卷、只读时的左栏 |

**颜色不是唯一载体**：每一处上色的地方旁边都另有一个**字**（「隔离」「失败」「跳过」）
或一个行首记号。色盲、以及不上色的终端上一个字都不丢。

只用 16 色里的基本色，**不定背景色**——背景归用户自己的终端主题，深色浅色两边都得活。

## 落地记录

### Q153 怎么收的：语义挂在**记号**上，措辞那一层一个颜色都没长

Q153 记的是「『隔离 / 跳过 / 没做成』那几个字与四种记号分在两处，而语义色要按同一批分类上色」。
派活说明把它交给本票：**「一种语义 → 一个颜色 + 一个字/记号」这三者怎么绑在一处，
而不让措辞层跟着长出颜色。**

收法是**认下那个分法，并把颜色挂在两处里不属于措辞的那一处**——
`src/session/draw/table.rs` 的 `Mark` 多了一个读法：

```rust
fn tone(self) -> Tone {
    match self {
        Self::Done => Tone::Plain,       // 正常跑完
        Self::Isolated => Tone::Caution, // 隔离
        Self::Skipped => Tone::Muted,    // 跳过
        Self::Failed => Tone::Trouble,   // 没做成
    }
}
```

三者因此**出自同一个取值**：`Mark::of` 判一次，判出来的那一个既定了行首那个字符
（`glyph`）、也定了这一行的语义（`tone`）。「颜色不是唯一载体」这条**不靠人记着**——
添一种记号不配语义（或反过来）根本编不过去。

**为什么载体是记号、不是档位那一列上的那几个字：**

| | 出自 | 命令行读不读它 | 砍列砍不砍得掉 |
|---|---|---|---|
| 行首记号 `✓ ! – ✗` | 画法（`table::Mark`） | **不读**（那一路一个列都不分） | **砍不掉**（与卷名一起恒在） |
| 「跳过」「没做成」 | 措辞（`render::base_column`） | 读 | 砍得掉（档位是一列） |

两者说的恰好是同一件事，屏上一行因此常常有两个载体；但**靠得住的那一个是记号**。
`src/render.rs` 与 `src/render/plain.rs` 因此**一个字节都没动**——
措辞那一层没有长出任何颜色概念（spec 的《Out of Scope》：命令行那一份不加颜色）。

### 四种语义住在 `src/session/draw/paint.rs`

新模块，**画法那几块共用**，与 `probe` 一样不是「屏上那一块」——`draw` 的模块文档
那张表因此没有它，另加了一句指路。

```rust
pub(super) enum Tone { Muted, Plain, Caution, Trouble }  // 从轻到重
```

- **挑颜色的地方只有 `Tone::style` 一处**：屏上那几块（`table`、`overview`、`report`、
  `config`、`picker`、`footer`）一个终端颜色名都不写。`grep -rn 'Color::' src/session/`
  除 `paint.rs` 自己（出处，加上问它挑得对不对的那几条用例）之外还落两处，两处都不是挑颜色：
  `probe.rs` 的 `Color::Reset` 是**读回来**的那一头（认得出「终端默认色」才说得出
  「这一行没上色」），`live.rs` 那几处是 `PageColor::Gray` / `PageColor::Color`——
  领域里的「灰度页 / 彩页」，与终端颜色不是一回事。
- **`Ord` 是派生的，而且有用**：一行上摆着好几件事时取最重的那一种——
  总览块的出事行同时数着隔离（注意）与失败页（出事），而它只上得了一种色。
- **不定背景色**：背景归用户自己的终端主题，定了背景的那一格深色底与浅色底之间必坏掉一边。
  `the_four_tones_are_the_only_place_a_colour_is_named` 四种逐个问 `style().bg == None`。
- **「暗」取 `Modifier::DIM`，不取某一个灰**：灰是个**绝对**的颜色，深色底上的暗灰读不出来；
  DIM 压的是当前这个前景色，深色浅色两边都活。它照旧归 `NO_COLOR` 管——它是这四种之一。

`Painted { text, tone }` 是「一行字 + 它是哪一种语义」，卷表、总览块、报告区三处传的都是它。
**那一对不许拆开走**：折成终端库的几行（`folded`，报告区那几段）、不折直接画一行（`line`，
总览块那几行）、缩进一层摆在别人底下（`indented`，摆在一卷那一行底下的那几句）
都是它自己的读法——拆成 `(String, Tone)` 递进去，调用处就看不出哪一半是哪一半了。
折行的规矩仍只有 `crate::wrap` 那一处，`folded` 只交代折到多宽。

### `NO_COLOR` 一处生效，而两副样子在同一条用例里比得着

判断只有一处 `paint::colourful()`：环境变量**在不在场**（`NO_COLOR=` 与 `NO_COLOR=0`
一样算数），`OnceLock` 读一次记住——一趟会话里它不会变，而每一帧要问几十次。

用例要两副都问得到，而环境变量在一个进程里只有一份。做法是一个 **`#[cfg(test)]` 的
线程局部按住位**（`paint::forcing(colourful, body)`）：Rust 自带的那套 harness
每个用例各跑在自己的线程上，按住它不漏到别的用例上。它顺带挡掉另一件事——
**开发机上真设着 `NO_COLOR` 的人跑这几条用例照样绿**。
先例是 `Session::focus_on`（`#[cfg(test)]`，只给用例用）。

### 屏上按语义要色的地方（四块）

| 屏上那一块 | 上的是什么 | 接住颜色的那个字或记号 |
|---|---|---|
| 卷表那几行（`table`） | 一行一种，由行首记号说了算 | 行首 `✓ ! – ✗`，外加「跳过」「隔离」「没做成」 |
| 总览块的出事行（`overview`） | 列着的那几件里最重的一种 | 行首「出事」两个字 |
| 总览块的抬头（`overview`） | 没做成那一趟是「出事」 | 「这一趟**没做成**：……」 |
| 失败页那一段（`report`） | 整段「出事」 | 头一行就叫「失败页」，逐条原因行上有「失败」 |
| 只读时的左栏（`config`） | 「不要紧」 | 抬头「配置 · 跑着，三层都只读」 |

摆在一卷那一行**底下**的那两句各有各的语义、**不跟那一行走**：部分救回是「注意」
（spec 那张表列着它），过期副本四档里一档都不占——给它「平常」，不编第五档（**Q156**）。

**报告末尾那几小结整段给「平常」**：六小结分属三档语义，而一段文字只上得了一种色；
按小结分色要先把 `render::tail` 拆开，而拆它就是把措辞挪进画法这一层（ADR 0016）。
记在 **Q155**。

### 不是语义色的那三样

光标那一格**反白**、层抬头**加粗**、预设栏那条文件路径**压暗**——三样都**没有**收进 `Tone`，
`NO_COLOR` 也不抹掉它们。理由写在 `paint` 的模块文档里：它们说的不是「这一趟怎么样」。
**语义色抹掉了话还在**（每一处旁边都另有一个字或记号），这三样抹掉了话就没了——
反白抹掉之后屏上没有第二处说得出光标停在哪儿。两者因此不归同一个开关管。

预设栏那条路径是三样里唯一一处**看上去与 `Tone::Muted` 一模一样**的：它留在 `picker` 自己那一块里，
因为它压暗说的是「这是抬头下面那条次要信息」，不是「这件事不要紧」——
收进来就等于说这两件事是同一件。

### 「颜色不是唯一载体」怎么钉

五条用例，都在 `paint` 的 `mod tests` 里（画法那一层，读的是缓冲）：

- `the_row_that_went_wrong_is_red_and_says_so`——**票面第六条**。
  没做成那一行是红的、带着 `✗` 与「没做成」；隔离那一行是黄的、带着 `!` 与「隔离」；
  跳过那一行是暗的、带着 `–` 与「跳过」；而逐页与覆盖那两卷正常跑完，**一格都不上色**
  （四种里有一种是「不上色」，屏上多数行属于它——人人都是红的等于没有红的）。
- `every_painted_row_carries_a_word_or_a_mark_of_its_own`——逐行走一遍主区：
  凡上了色的行必带着四种记号或那几个词之一。**它挡的是「往后添一处上色却忘了配一个字」。**
- `the_same_screen_reads_the_same_with_or_without_colour`——**票面第五条**。
  两头各再问一句「确实上了色／确实没上色」：少了它，这一条在两边都没上色时照样绿。
- `the_read_only_left_column_is_muted_and_the_title_says_why`——左栏那几行自己没有一个字
  说得出「只读」，接住颜色的是**那一格的抬头**；`NO_COLOR` 那一趟左栏一格不压暗，
  而抬头那句话还在。
- `the_failing_pages_block_goes_red_under_a_heading_that_says_so`——**整段上色时载体是那一段**：
  头一行「失败页（出现的当场……」与逐条的「失败 ……」都是红的，中间那几行是页的路径。
  同一屏顺带问出事行：它同时数着隔离（注意）与失败页（出事），而它是红的——取重的那一个。

读缓冲的探针是 `probe::painted`（新增），交出的是逐行的 `OnScreen`——
一行的字、这一行上出现过的前景色，加上逐格的压暗（`dim()` 问整行，`dim_before()`
只问左栏那几列，与 `reversed_rows` 同一条道理）。快照那一路只比得了字，
而这一条要问的是「**既是红的、也带着那个字**」，两半得在同一行上一起读得到。

**没有把同一屏抄成两份常量**：两份会一起被改掉，而直接比两次画出来的那两张，
改了任何一处都当场红。

> ### Q153 — 「隔离 / 跳过 / 没做成」那几个字与四种记号分在两处，而语义色要按同一批分类上色
>
> - **From:** 票 `p3-session-legibility/08`
> - **Kind:** 下一张票会撞上的耦合
> - **Where:** `src/session/draw/table.rs` 的 `Mark`（`✓ ! – ✗` 四种记号，
>   以及行尾那个「隔离」）与 `src/render.rs` 的 `base_column`（档位那一列上的
>   「跳过」「逐页」「覆盖 X」「没做成」）
> - **背景:** spec 的《语义色》要「四种语义（平常 / 注意 / 出事 / 不要紧）**一处出处**」，
>   并且写着「**颜色不是唯一载体**：每一处上色的地方旁边都另有一个字（「隔离」「失败」
>   「跳过」）或一个行首记号」。本票把那个「字」摆成了两处：短标签在
>   `render::base_column`（它是措辞，与卷级那几句成句的说法同源），
>   记号与行尾那个词在画法这一层（它们命令行上根本没有）。
>   **这一分法本身是对的**——一处是措辞、一处是排版；问题在于**「这一卷属于哪一种语义」
>   这个判断**眼下只活在 `Mark::of` 里，而上色那一票要的正是同一个判断。
> - **Why it did not block:** 本票一个颜色都不加（票面明写上色归 `p3/09`，一处出处），
>   `Mark::of` 眼下是屏上唯一读它的地方，没有第二处可对不上。
> - **What this ticket actually did:** 把判断集中在 `Mark::of` 一个函数里、
>   四种记号写成一个 `enum` 而不是四个散着的字符常量——上色那一票要接的就是它
>   （给 `Mark` 加一个「哪一种语义」即可，不必再认一遍字符串）。
> - **Whose call:** `p3-session-legibility/09`（语义色那一张）
> - **处置：** **本票了结。**08 把「这一卷属于哪一种」收进了 `Mark::of` 一个函数里，
>   而本票要的正是同一个判断——`Mark` 因此多一个 `tone()`：**记号与语义出自同一个取值**，
>   添一种记号不配语义（或反过来）根本编不过去。08 留的那个悬念「那个『字』摆成了两处」
>   的答案是：**接住颜色的是记号，不是那几个字**。记号在画法这一层、命令行根本不读它、
>   砍列也砍不掉它（与卷名一起恒在）；档位那一列上的「跳过」「没做成」出自
>   `render::base_column`，是**措辞**，命令行读的也是它——它们说的恰好是同一件事，
>   屏上因此常有两个载体，但**靠得住的那一个是记号**。
>   `src/render.rs` 与 `src/render/plain.rs` 一个字节都没改：措辞那一层没有长出任何颜色概念。
>   `the_row_that_went_wrong_is_red_and_says_so` 与
>   `every_painted_row_carries_a_word_or_a_mark_of_its_own` 两条钉着。
