# 09 — 一套语义色，四种，颜色不是唯一载体

**What to build:** 屏上眼下**一处颜色都没有**——出事的卷与正常的卷长得一模一样，
「一眼看出重点」最便宜的那个手段一直没用上。给它四种语义色，**一处出处**：

| 语义 | 用色 | 用在哪 |
|---|---|---|
| 平常 | 终端默认色 | 正常跑完的卷、普通的页 |
| 注意 | 黄 | 隔离、宽溢出、部分救回、兜底上界、几何门不成立、特例页 |
| 出事 | 红 | 失败页、卷级失败、拒绝执行 |
| 不要紧 | 暗 | 跳过的卷、只读时的左栏 |

**颜色不是唯一载体**：每一处上色的地方旁边都另有一个**字**（「隔离」「失败」「跳过」）
或一个行首记号。色盲、以及不上色的终端上一个字都不丢。

只用 16 色里的基本色，**不定背景色**——背景归用户自己的终端主题，深色浅色两边都得活。
