# 03 — 换词：驱动页、主体、离群页

**What to build:** 报告里三个要查文档才懂的词换成人话，`CONTEXT.md`、报告文字、
代码文档一起换：

| 今天 | 换成 | 英文标识符 |
|---|---|---|
| 驱动页 | **定档页** | `driver`（不动） |
| 主体 / 主体页 | **其余页** | `body_pages`（不动） |
| 离群页 | **特例页** | `outlier_pages`（不动） |
| 基准档 | **不换** | — |

换的是**中文说法**。英文标识符**不动**：它们对这三个概念仍是准确的英文，而改名要动
二十来个文件、二百六十余处，风险与收益不成比例。词条里把英文名带上，两边对得起来。

**命令行报告与会话同时换**——同一件事不许有两个名字。

《判据》里「上包络 = 卷内**主体**页判定的 p95 聚合」**不直译**，改写成
「**不含特例页的那些页**判定的 p95 聚合」：直译成「其余页」会读成
「相对特例页剩下的那些」，定义绕回自己。

## 落地记录

### 换掉的是哪几个词

| 从前 | 现在 | 英文（一个都没动） |
|---|---|---|
| 驱动页 | **定档页** | `Envelope::driver` |
| 主体 / 主体页 | **其余页**（数页时省作「其余 N 页」） | `Envelope::body_pages` |
| 离群页 / 离群判据 / 离群侧 / 离群检验 | **特例页 / 特例判据 / 特例侧 / 特例检验** | `Envelope::outlier_pages`、`outlying`、`OUTLIER_FACTOR` |
| 基准档 | **不换** | — |

**复合词跟着一起换**（票面没说，本票拿的主意，记在 **Q134**）：只换「离群页」这一条走不通——
「特例页由离群判据判出来」正是这张票要消灭的那种句子。

**计数那一格省一个字**：报告里那一串是 `基准档 … · 其余 N 页 · 特例 N 页（x%）· 迟滞升档 N 页`。
词条叫「其余页」「特例页」，数页时写「其余 N 页」「特例 N 页」——今天「离群 N 页」就是这么写的，
换成「其余页 N 页」会多出一个字、也与旁边那两格排不齐。

**本票动过的那些文件里**（`src`、`tests`、`docs`、`CONTEXT.md`、`README.md`）唯一留着
「离群」两个字的是 `CONTEXT.md`《尚未确立》那句「换一批双页片源之后它是常态还是离群」：
那里说的是一个残差比读数算不算异常值，不是页那个概念（**Q134**）。

**已经收掉的票据与 spec 里那三个词原样留着**：票面第六条点名要跟着改的只有停车场，
而收掉的票是当时那一刻的记录，改它等于改变更史（`CLAUDE.md`《文档写作》第 1 条）。

### 「就是主体」那个句形不直译

票面的「不直译」只点了《判据》里上包络那一句，但同一个坑在代码文档里有十一处：
「一页不剩地落在这一侧时，那些页**就是主体**」——直译成「就是其余页」是同义反复
（其余页的定义正是「摘完剩下的」），而原句里「主体＝大多数」那层意思也丢了。
十一处一律改成「**就当其余页**」：说的是「那一侧顶上其余页那个位置」，是条兜底规矩，
不是一句定义（「就当」是本仓库现成的说法，见 `source.rs` 那句「就当 UTF-8」）。
落在 `src/envelope.rs`、`src/decide.rs`、`src/lib.rs`、`src/report.rs`、`src/render.rs`、
`docs/adr/0007`、`CONTEXT.md` 各一处，`tests/golden.rs` 三处、`tests/pipeline.rs` 一处。

同一条道理，「十八页主体」这种数页的说法不写成「其余那十八页」（「其余」在本仓库是
六十多处普通中文，摆在术语旁边分不开），写成「**剩下那十八页**」。
