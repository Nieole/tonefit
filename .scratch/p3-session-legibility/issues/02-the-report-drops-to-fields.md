# 02 — 报告的措辞降到字段级

**What to build:** 报告的**卷级**与**逐页**那两段，从「返回一段文字」改成「返回一组**行**，
每行带着它是什么行、以及若干**格**」。命令行那一侧把它拼回今天那段文字，逐字不变——
**黄金快照零变化就是这张票的验收**。

这一步在屏上看不出任何变化，它是**卷表与逐页表的地基**：那两样吃的就是它出的格。
列对不齐、字段取不出来、状态标不上颜色，全卡在今天那个「拼死的字符串」上。

**已经成句的那几段不拆成格**：报告末尾那五小结、互锁那几行、失败原因那一句——
它们本来就是句子，拆开没有意义，会话把它们当整段文字折行画。

这一条推翻了 `p1-session` spec 里「渲染共用一套」的读法：**措辞仍只有一处出处，
排版从此两处**。理由与代价落成 `docs/adr/0016-…`。

**Blocked by:** None — can start immediately。与 03 都大改同一个模块，两张票别同时开工。

**Status:** resolved

## 落地记录

### 卷级与逐页从「一段文字」变成「一摞行」

`render::volume` 与 `render::pages` 的返回值从 `String` 改成 `Vec<Row>`。三个新类型都在
`src/render.rs` 里，一个都不出二进制 crate：

| 类型 | 是什么 |
|---|---|
| `Row` | 一行：`kind` 加 `cells`。`Row::cell(field)` 取一格，**不在场就是 `None`** |
| `RowKind` | 这是什么行，18 种，一种对应报告上的一种行 |
| `Cell` | 一格：`field` 加 `text`。装的是**值**，不装摆法 |
| `Field` | 这是哪一格，22 种 |

一行对应印出来的一行——`Envelope` 与 `Driver` 因此是两行（从前是一个 `format!` 里两个
`\n`），`--per-page`、覆盖顶掉判定、上包络是**三种行**而不是一种行的三种写法：
卷表要照它们各自的说法填基准档那一列，分不开就得回头去认字符串。

**挑值靠 `Field`，不靠位置**：一行上哪几格在场随这一卷、这一页而变（彩页零张就没有彩页
那一格，没裁过的页就没有裁边那一格），按位置数格早晚数错。

### 哪些成了格，哪些仍是一句整话

分界线画在**「这几个字换一副排版还成不成立」**上：

- **成格的**是「表要拿去填一列」的那几样：卷那一行（源 / 去处 / 页数 / 彩页数）、
  几何门那一行（判定范围 / 不成立几页 / 本卷抖不抖）、一页的几何那一行
  （尺寸 / 裁边 / 缩放 / 跨页 / 兜底 / 去处）、一页的判定那一行
  （部分救回 / 彩页转灰 / 候选 / 理由 / 判据）、驱动页、读取计划、缓存用量。
- **仍是一句整话的**有八种行，一行只有一格（`Field::Sentence`）：跳过、隔离、部分救回、
  过期副本、摊开、几何门底下那几句注解、`--per-page` 那一种卷级判定、一页失败。
  它们本来就是句子；拆的那一刀会把措辞挪到排版那一层去，而措辞只许有一处出处。
- **唯一的例外**是覆盖顶掉判定那一行：成句那一格之外另占一格候选——卷表要照它写
  基准档那一列（spec 第六条的「覆盖 4bit」）。上包络那一行同理，`Field::Base` 与
  成句的 `Field::Envelope` 里是同一个数。**只在表真要那一个值时才这么做**。
- **票面点名不许动的一个都没动**：`tail` 底下那六小结、`interlock_lines`、`failure_line`
  原样留着，抬头与末尾那两段仍返回 `String`（它们不进卷表：一趟只说一次、要看完整趟）。

### 拼装那一副：`src/render/plain.rs`

新模块 `render::plain`，模块文档头一句就写着它是纯文本那一副、措辞不在里面。
`plain::line` 那个 `match` 就是「拼装的规矩」的全部——一种行一条、**不留 `_`**，
缺一格当场恐慌。缩进、前缀、单位、格与格之间的分隔全在这里，一句解释都没有。

三个调用方改的只是路径：`main.rs`（`render::plain::report`）、
`session::run` 的 `Running::report`、`session::draw::report` 的 `report_text`
（`plain::volume` / `plain::pages`）。**会话那一侧的排版一格没动**，它拿到的仍是与今天
逐字相同的那段文字——排一版表是 P3 后面几张票的事。

**它为什么没搬进 `src/main.rs`**：`render::report` 有两个调用方，其中一个是会话
（退出会话时 stdout 上那份报告照命令行那一路的原格式），而会话的报告区眼下也在读它。
按文件位置讲，spec 那句「不住在 `render` 里」眼下做不到；做到的是**两副排版各占一处，
而这一处不是措辞那一处**。所有者在派活说明里把这一处留给实现者拿主意并列出了这条路——
选择、理由与那句原话的出入记在 **Q131**。

### 用例

新增四条（`src/render.rs` 的 `mod tests`），问的都是**行与格**，不问那段文字：

- `the_volume_and_page_lines_are_rows_that_each_say_what_they_are`——一摞行的次序与种类，
  卷那一行三格、几何门那一行三格，基准档单占一格。
- `a_skipped_volume_is_short_of_the_cells_it_never_computed`——跳过的卷少哪几格：
  基准档、几何门那三个数、缓存用量一格都取不出来；页数照旧在场。
- `a_failed_page_and_the_volume_it_isolates_are_each_their_own_kind_of_row`——
  失败的卷是哪一种行（`RowKind::Isolated`，成句、一格），失败的页是哪一种行
  （`RowKind::PageFailure`，原因整句不拆）。
- `a_cell_carries_a_value_and_never_an_indent_or_a_line_break`——格里没有换行、没有首尾空白。
  它挡的是把排版偷偷搬回措辞那一层的改动：那种改动纯文本这一副看不出异样。

**那段文字仍由老的钉着，一条都没改写**：`render` 的 `mod tests` 里二十多条
`plain::report(..).contains(..)`、`drawing_the_four_parts_one_by_one_gives_the_same_bytes_as_one_shot`
（四段逐段拼起来与一次性渲染逐字节比对），以及 `session::draw` 那六张 `TestBackend` 快照。
**黄金快照不在这条链上**——它由集成测试算出、链的是库那一侧，够不着 `render`（**Q132**）。

### 停车场

- **Q131**（了结）：「拼装的规矩住在命令行那一头」落在哪个文件——选了 `render::plain`
  单独成文件，三条理由（拼装器不是命令行私有的、会话报告区眼下也在读它、`main.rs`
  那一件事不是这个）。同时记下 spec 那句「不住在 `render` 里」按文件位置讲没有做到。
- **Q132**（待处理）：票面把黄金快照当成本票唯一的验收，而 `tests/golden.rs` 是集成测试、
  链的是库，`src/render.rs` 在 bin crate 里，`tests/` 一个符号都够不着它——
  本票就算把报告改得面目全非，黄金快照也一个字节不会动。真正钉住它的是另外两处。
  **这条影响下一张票**：换词若只动 `src/render.rs`，黄金快照同样不会动。
- **Q133**（待处理）：卷级失败的卷没有自己的一种行——它连 `VolumeReport` 都没有，
  至今只活在 `failed_volume_tail` 里，而 spec 第六条要卷表给它一行。
  「失败的卷是哪一种行」这条验收按**被隔离的卷**答的。
- **Q115** 补了一句现状：「列前几条，剩下的说个数」五处一处没动，只有几何门那一处
  现在住在一个 `GateNote` 行的成句格里。

### 评审

两轴各跑了一遍（只读）。**Spec 轴**三条、**Standards 轴**四条硬项加四条判断题，收下的：

- 「失败的**卷**是哪一种行」原先只答了失败的**页**——用例改名并补上卷那一侧的断言，
  真正的缺口（卷级失败的卷）落成 Q133。
- 「摊开 …（开工前整卷解到临时目录，跑完就收）」那句解释原先落在 `plain.rs`——
  搬回 `render`，`RowKind::Extraction` 改成成句的行，`Field::Extracted` 删掉
  （卷表不要那个数）。分界线（列头/单位/连接词 vs 解释）写进 `plain` 的模块文档。
- ADR 决定第 2 条补一句「一格的值本身是一串东西时，怎么串起来仍是措辞」（判据那一串、
  点名的头几页）；决定第 4 条订正——覆盖那一行是两格不是一格；《后果》里「黄金快照钉住
  逐字不变」按 Q132 改成指真正钉住它的那两处。
- `CONTEXT.md`《行》原先把种类列错（「卷级判定」写成一种、漏了两种），改成给例子并
  **以 `RowKind` 为准**。
- `plain.rs` 裁边那一格改用现成的 `marked`；`render.rs` 七处成句的行收进 `sentence_row`，
  `gate_note` 变成它的调用者。

**没收的两条判断题**：`failure_line` / `score_line` 名字里的 `_line`（前者票面点名不许动，
后者的输出确实是「排成一串」，改的是文档不是名字）；`gate_rows(volume, verdict)` 那处
弱 Data Clumps（签名与 `gate_line` 时代一模一样，本票没动它）。
