# P3：会话读得出来（取值看得见 · 装得下 · 有重点）

Status: ready-for-agent

## Problem Statement

P1 交付的会话把整条回路摆上了屏，但按实际试用，它有三处让人读不下去：

- **取值只转不列。** 左栏十四行里每一行都是一个「环」，`←→` 一次转一格。型号那一行背后是
  **31 个内置型号**，最坏要按 30 下；而更根本的是，环让「**这一项有哪几个取值**」在屏上
  根本不存在——用户只有把它轮询过一整圈，才知道自己有哪些选择。取值只有两三个的那几行
  同样吃这个亏，只是按得少一点。

- **装不下的东西无声消失。** 横向那一刀 `p2-loose-ends/07` 已经解决（按显示宽度折行，
  三处共用）。**纵向一刀都没有**：左栏根本没有滚动，打进几个卷之后光标能走到屏外；
  报告区只会滚到底、翻不回去；补全候选只列 12 条，第 13 条起没有任何交代；
  预设栏的视口跟着光标走，但屏上看不出上面还有、下面还有。四处各是各的成因，
  一处系统性的处理都没有。

- **报告堆砌，没有重点。** 报告区是一整段纯文本：抬头几行加每卷四到五行长句，`·` 串起来。
  120 列的屏上主区只剩 68 列，行行回绕；整屏只有一种字重、**一处颜色都没有**。
  跑二十卷就是一百多行长得一模一样的灰字——判成了哪一档、哪一卷进了隔离、哪一页失败了，
  全埋在里面。「一眼看出这一屏想说什么」是做不到的。

三处不是三件事：它们是同一个毛病的三个面——**屏上每一样东西的份量都一样重**，
于是既选不出、也翻不着、更读不出。

## Solution

三条对策，一条对一处：

**取值摊开来看。** 光标那一行按 `⏎` 就在它下面摊开一列取值，选中的那一格前面一个记号，
`↑↓` 选、`⏎` 定、`Esc` 一格不改地回去。型号那一行摊开的是**面板**（八块，每一行带着
分辨率、PPI、灰阶数、彩色与否），`→` 再下钻到那块面板下的型号——领域上早就写着
「设备只是面板的别名，多对一」，挑替身本来就该从面板挑起。

**一套视口，四处共用。** 列表有多少行、格子有多高、光标在哪儿 → 从第几行画起、
滚动条画成什么样。左栏、卷表、预设栏、补全候选走同一份实现，四处都说得出「还有多少没露面」。

**报告分成钉住的与滚动的两截。** 顶上一块**总览**（两条横条与摘要合并，整块钉住），
下面一张**卷表**（一卷一行、列对齐、窄屏按固定次序砍列）。总览的下两行随这一趟是什么而变：
试算给判定，执行给出事。出事的卷靠颜色、行首记号与一个**字**同时标出来——颜色不是唯一载体。
展开一卷时逐页也是表，**默认只列要紧的页**，`a` 切到全部。

报告区从此有自己的光标，`⇥` 在左栏与它之间切焦点；跑着的时候一样能选、能展开、能翻回去。

一屏大致长这样：

```
┌ 配置 ────────────────────┐┌ 执行 · 第 5/20 卷 · 还剩约 14m ──────┐
│ 设备层 · 判定的依据       ││ 总体 [=========>        ] 5/20 卷     │
│   型号   boox-poke6       ││ 本卷 [=====>            ] 第二遍      │
│   ● 1264x1680·300PPI·16级 ││ 完成 4 卷   跳过 1 卷                 │
│   ○ 1404x1872·227PPI·16级 ││ 出事 隔离 1 卷 · 失败 3 页            │
│   ○ …                     ││ ───────────────────────────────────  │
│ 口味层 · 这一趟的立场     ││ ✓ 棋魂 07 184 2bit+FS 087 1m12s    ▓ │
│   适配方式 默认（以高为准 ││ ✓ 棋魂 08 190 2bit+FS 003 1m20s    █ │
└───────────────────────────┘│ ! 哆啦 03 212 4bit+FS 011 2m03s    ░ │
 ↑↓ 选 · ⏎ 摊开 · ⇥ 报告区 · t 试算 · x 执行 · ? 全部键
```

顺带把报告里三个要查文档才懂的词换成人话：**驱动页 → 定档页**、**主体 → 其余页**、
**离群页 → 特例页**。换的是中文说法，命令行那一份跟着一起换——同一件事不许有两个名字。

命令行那一路除这三个词外**一字不改**。

## User Stories

### 取值看得见

1. 作为读者，我想在挑型号时一眼看到有哪些型号，这样我不必把方向键按满一圈才知道自己有哪些选择。
2. 作为读者，我想让型号按**面板**分组列出来，这样面板相同的那几个型号我一眼看得出是同一块屏。
3. 作为读者，我想在挑型号时看到每块面板的分辨率、PPI、灰阶数与彩色与否，这样内置表里没有我的设备时我挑得出一个替身。
4. 作为读者，我想先挑面板、再挑型号，这样三十来个名字不必摊成一片。
5. 作为读者，我想在挑完之后回到左栏原来那一行，这样我不会丢失位置感。
6. 作为读者，我想让取值只有两三个的那几行也摊得开，这样「有哪几个值」对每一行都是看得见的。
7. 作为读者，我想在摊开的取值里看到「默认」占着第一格，这样我分得清「没说」与「说了一个恰好等于默认的值」。
8. 作为读者，我想用 `Esc` 从摊开的取值里退出来且**一格不改**，这样看一眼有哪些值不必付出改掉它的代价。
9. 作为读者，我想让摊开的取值里当前选中的那一格有记号，这样我不必对照上面那一行才知道选的是哪个。
10. 作为读者，我想让摊开取值时左栏其余各行还在场，这样我改一个值时看得见它在整份配置里的位置。

### 装得下

11. 作为读者，我想在左栏行数超过屏高时仍看得见光标，这样打进十几个卷之后我不会不知道自己停在哪一行。
12. 作为读者，我想在任何一处列表滚动时看得出上面还有、下面还有，这样我不会把一屏当成全部。
13. 作为读者，我想让补全候选在超过一屏时说得出还有多少条，这样我不会以为这一层只有十二个东西。
14. 作为读者，我想让预设栏在预设变多时也说得出还有多少份，这样末尾那一行「存成新的」掉不出我的视野。
15. 作为读者，我想在 80×24 的终端上仍旧用得下去，这样我在小窗口里也开得起会话。
16. 作为读者，我想让窄终端上被砍掉的是次要的列而不是卷名，这样我永远认得出屏上这一行说的是哪一卷。
17. 作为读者，我想让被砍掉的那几列在展开一卷时看得到，这样砍列不等于信息消失。

### 报告有重点

18. 作为读者，我想在报告区顶上一眼看到这一趟是什么、走到哪儿、还剩多久，这样我不必自己拼三个数。
19. 作为读者，我想在试算之后一眼看到各卷判成了哪一档，这样我确认得了参数对不对。
20. 作为读者，我想在执行之后一眼看到有没有出事，这样我不必逐卷读才发现有一卷进了隔离。
21. 作为读者，我想让顶上那一块在我往下翻表时留在屏上，这样「这一趟到底怎么样」不必翻回顶部才看得到。
22. 作为读者，我想让卷表一卷一行、列对齐，这样几十卷我扫得下来。
23. 作为读者，我想让出事的卷在表里跳出来，这样我不必逐行找。
24. 作为读者，我想在色盲、或者终端不上色时也分得出出事的卷，这样颜色坏掉不等于信息坏掉。
25. 作为读者，我想让跳过的卷在表上看得出是跳过的，这样我知道它不是没跑。
26. 作为读者，我想让卷级失败的卷也在表上占一行并说清为什么，这样它不会因为「没打开过」而从屏上消失。
27. 作为读者，我想让报告里的词是人话，这样我不必去翻文档才知道「驱动页」是什么。
28. 作为读者，我想让屏上的词与命令行报告里的词完全一样，这样把报告重定向到文件之后我不必重新认一遍。

### 翻得动、点得开

29. 作为读者，我想在卷表里用上下键选一卷，这样「我在看哪一卷」在屏上是看得见的。
30. 作为读者，我想按一下就展开选中那一卷的逐页，这样追查「哪一页把整卷拉下来」是一步的事。
31. 作为读者，我想让展开默认只列要紧的页，这样两百页的卷里那八页不必我自己找。
32. 作为读者，我想按一个键切到全部页，这样要通读的时候也读得到。
33. 作为读者，我想在**跑着的时候**也能选卷、展开、翻回去看第一卷，这样几十分钟的一趟里我不必干等。
34. 作为读者，我想让卷表在跑着时默认跟着最新跑完的那一卷走，这样我什么都不按也看得到最新的进展。
35. 作为读者，我想在我一动光标时跟随就停下来，这样我看着的那一行不会被新卷顶走。
36. 作为读者，我想让屏上说得出跟随停了，这样我不会以为它卡住了。
37. 作为读者，我想按一个键回到跟随，这样看完之后我回得去。
38. 作为读者，我想在决策点上等答话时，正在等的那一卷也在表上占一行并说得出它还没收摊，这样我看的是眼前这一卷、不是上一卷。
39. 作为读者，我想让展开着的时候按停仍旧按得动、两级语义不变，这样翻报告不会让我停不下来。
40. 作为读者，我想让三层在跑起来之后仍旧只读，哪怕我的焦点在报告区，这样一趟里不会出现卷与卷之间参数不同。
41. 作为读者，我想按 `?` 看到此刻能按的全部键，这样我不必靠试。
42. 作为读者，我想让屏底只摆最常用的几个键，这样提示条不会把一屏刷满。

### 开发者

43. 作为开发者，我想让 `render` 出「一组字段」而不是「一段文字」，这样命令行与会话各排各的版，而措辞仍只有一处出处。
44. 作为开发者，我想让命令行印出来的文字在这一批里除换词外一字不变，这样黄金快照只重录一次。
45. 作为开发者，我想让换词那一次重录逐条确认，这样判定的变动不会混在措辞里溜过去。
46. 作为开发者，我想让会话的模式拆成两维之后，「哪些键在哪个状态下有效」仍旧一处答完，这样按键规则仍有一张表可问。
47. 作为开发者，我想让滚动视口只有一套实现，这样四处的行为不会各走各的。
48. 作为开发者，我想让砍列的次序只有一处出处，这样「窄屏上先砍谁」不会有第二份说法。
49. 作为开发者，我想让语义色只有一处出处、`NO_COLOR` 一处生效，这样上色规则不散在画法各处。
50. 作为开发者，我想让新画法有快照用例覆盖宽窄两档、试算与执行两副、收起与展开两态，这样布局改动是可见的。
51. 作为开发者，我想让取值栏与卷表的状态机脱离终端可测，这样按键与状态的规则有断言。
52. 作为开发者，我想让 `--no-default-features` 那一趟不受影响，这样闸门第二条照旧绿。

## Implementation Decisions

### Seam

**库这一侧一个 seam 都不新增、也不改动。** `run(Request) -> Report`、判据那个数值 seam、
标定图写出那一个照旧；观察者那条双向回路（事件 + 指令）一格不动。本批的全部改动落在
**二进制 crate 内**：`render`、`session` 那几个模块、外加新的视口与配色两小块。

库那一侧唯一的动静是把 `Profile` 上「按面板分组列出内置型号」那个读法**从私有提为公开**——
它今天只服务于未知型号那条错误消息，而取值栏要的是同一份分组。分组的规矩因此仍只有一处。

测试挂的 seam 三个，全是现成的：

1. **`render` 那几个函数的返回值。** 它从「一段文字」变成一组带类型的行与格；命令行那一侧
   把它拼回文字，`tests/golden.rs` 照旧钉着**拼出来的那段文字**。字段本身另有一小批用例。
2. **会话状态机的 `action`。** 纯函数，不开终端；两维之后它仍是「哪些键在哪个状态下有效」
   那张表的唯一出处。
3. **画法快照。** ratatui 的 `TestBackend`，`session::draw` 的 `mod tests` 已有一套。

### 一、报告的措辞降到字段级（ADR 0014）

`render` 的**卷级**与**逐页**那两段从「返回一段文字」改成「返回一组**行**，每行带着
它是什么行、以及若干**格**」。

- **命令行那一侧把它拼成今天那段文字，逐字不变**（换词那三处除外）。拼装的规矩住在
  命令行那一头，不住在 `render` 里。
- **会话那一侧按格排版**：列对齐、按宽度砍列、按行的类型上色。
- 「一个判定该怎么说」仍只有一处出处；变的只是「摆在哪儿」。
- **已经成句的那几段不拆成格**：报告末尾那五小结、互锁那几行、失败原因那一句，它们本来
  就是句子，拆开没有意义。会话把它们当整段文字折行画（走 `crate::wrap`）。
- 抬头那几行（profile、适配方式、裁边、跨页拆分、判据构成与聚合）**不进卷表**：它们是
  「这一趟的前提」，一趟只说一次。会话把它们收进一个按键调得出的地方（与 `?` 同一副形状），
  屏上不常驻——它们在长任务里没人会反复看，而它们占的正是卷表要的行。

这一条推翻了 `p1-session` spec 里「渲染共用一套」的读法，理由与代价写进 **ADR 0014**。

### 二、换词（三处，中文说法）

| 今天 | 换成 | 英文标识符 |
|---|---|---|
| 驱动页 | **定档页** | `driver`（不动） |
| 主体 / 主体页 | **其余页** | `body_pages`（不动） |
| 离群页 | **特例页** | `outlier_pages`（不动） |
| 基准档 | **不换** | — |

- 换的是**中文说法**：`CONTEXT.md` 的词条名、代码文档、报告文字、往后的 issue 与 spec。
- **英文标识符不动。** `driver` / `outlier` / `body` 对这三个概念仍是准确的英文，而改名要动
  二十来个文件、二百六十余处，风险与收益不成比例。词条里把英文名带上，两边对得起来。
- 命令行报告与会话**同时**换，同一件事不许有两个名字。
- **黄金快照重录一次**，逐条确认——判定一个数都不许动，变的只有那三个词。
- 《判据》里「上包络 = 卷内**主体**页判定的 p95 聚合」改写成「**不含特例页的那些页**判定的
  p95 聚合」：直译成「其余页」会读成「相对特例页剩下的那些」，而那正是它的定义在绕圈。

### 三、取值栏

左栏上**就地摊开**，不占主区（预设栏仍占主区，两者是两个状态、两个词）。

- 光标那一行按 `⏎`（或 `→`）在它**下面**摊开一列取值，`↑↓` 选、`⏎` 定、`Esc` 一格不改地回去。
- 摊开的第一格恒是「**默认（xxx）**」——两层的每一格都有一个「没说」的位置，而那正是
  存成预设时写不写进去的分别（`CONTEXT.md` 的《会话》）。当前选中的那一格前面一个记号。
- **型号那一行摊开的是面板**（八块，每行是那块面板的 `Display`：分辨率 · PPI · 灰阶数 ·
  黑白／彩色），`→` 下钻到那块面板下的型号（二到五个），`⏎` 定、回到型号那一行；
  在型号那一层按 `←`（或 `Esc`）退回面板那一层。**下钻只有这一处有两层**，别处一层。
- 型号一换，标定出来的灰阶数与阈值仍旧跟着清空（ADR 0002），与今天一致。
- 取值栏是「眼下在看什么」那一维上的一个取值，带着：摊的是哪一行、光标停在第几格、
  下钻到第几层。
- 摊开之后左栏纵向变长——由第四条那套视口接住。
- 环那一套（`←→` 就地转一格）**保留**：知道自己要什么的人不必先摊开再选。两条路改的是
  同一格；摊开时 `←→` 归摊开的那一层。

### 四、一套视口

一个纯函数的「视口」：**列表有多少行、格子有多高、光标停在第几行** → **从第几行画起**，
外加一条滚动条的位置与长度。四处共用：

| 用在哪 | 光标 | 从前 |
|---|---|---|
| 左栏（含摊开的取值） | 有 | **一点滚动都没有**，行数超过屏高就掉出去 |
| 卷表 / 逐页表 | 有 | 只滚到底，翻不回去 |
| 预设栏 | 有 | 视口跟着光标走，但屏上没有记号 |
| 补全候选 | 无 | 只列 12 条，第 13 条起无声消失 |

- 补全候选那一处改成「**列得下几条列几条，并说得出还有多少条**」，`take(12)` 那条硬上限撤掉。
- 滚动条走终端库自带的那个 widget；没有可滚的东西时不画。
- 「**滚动量是算出来的，不是记着的**」这条照旧（预设栏今天就是这么做的）：光标在哪儿，
  视口跟到哪儿。卷表是唯一的例外——它另有一个「跟随」的状态（见第七条）。

### 五、总览块

两条横条与摘要**合并成一块**，整块钉住，只有下面的表在滚。五行：

```
┌ 执行 · 第 5/20 卷 · 还剩约 14m ────────┐   ← 抬头：这一趟是什么 · 走到哪儿 · 还剩多久
│ 总体 [=========>        ] 5/20 卷      │   ← 全局条
│ 本卷 [=====>            ] 第二遍       │   ← 当前卷条：在走哪一遍
│ 完成 4 卷   跳过 1 卷                  │   ← 结论行
│ 出事 隔离 1 卷 · 失败 3 页              │   ← 出事行，没事就不出现
```

- **结论行与出事行的内容随这一趟是什么而变**，而「是什么」手上已经有（这一趟的 mode），
  不必多一个开关：
  - **试算**：结论行给判定分布（`6 卷 2bit+FS   2 卷 4bit+FS`），出事行给要注意的
    （特例页几张 · 宽溢出几页 · 几何门不成立几卷）。
  - **执行**：结论行给完成与跳过几卷，出事行给隔离几卷 · 失败几页 · 卷级失败几卷。
- **出事行一条都没有时整行不出现**，那一行让给表——与报告末尾那几小结同一条规矩。
- 抬头上仍旧挂着按停按到哪一级、以及等答话那一句（`p1-session/10`、`14` 立的那两条），
  措辞出处不变。
- 收场之后抬头改成收场那句话，「用了」那个数定住（库交出来的那一个，扣掉了在决策点上等人的时间）。
- 三段合成一格之后，`p1-session/09` 那条「三段各占一格，免得报告长起来把进度条顶出屏外」
  由**钉住**接住：整块不随表滚动。

### 六、卷表

一卷一行。列，从左到右：

```
记号   卷名        页数   基准档     定档页    耗时
✓     棋魂 07      184   2bit+FS    087.png   1m12s
!     哆啦 03      212   4bit+FS    011.png   2m03s     ← 隔离
–     名侦探 05    190   跳过                  3s
✗     消失的那卷    —    没做成：卷根不在了
```

- **卷名走 `render::volume_name`**，与命令行的进度条、会话的当前卷条印的是同一个。
- **跳过的卷**：基准档那一列写「跳过」，定档页留空；耗时**照给**——幂等那一道不是免费的，
  而「跳过一卷为什么也要等这么久」正问在这里。
- **卷级失败的卷**：记号红，档位那一列写「没做成」，理由跟在后面（成句，不拆格）。
- **`--per-page` 与覆盖顶掉判定**的那两种：基准档那一列照卷级判定说的写（「逐页」
  「覆盖 4bit」），不编第二套说法。
- **不重排。** 卷按跑完的先后添上去；重排会让刚跑完的那一卷在屏上跳位置，而「一卷跑完
  当场看得见」正是这一格存在的理由。出事的卷靠颜色与记号跳出来，不靠位置。
- **砍列次序：耗时 → 定档页 → 页数。** 卷名与行首记号恒在。这个次序**只有一处出处**。
- 卷名本身摆不下时从**中间**省略，两头留着：书名与第几卷都要认得出。

### 七、焦点与两维模式（ADR 0015）

会话的模式从一维拆成两维：

- **这一趟在哪个阶段**：没跑过 / 跑着 / 停在决策点上等答话 / 收场了。
- **眼下在看什么**：左栏浏览 / 左栏摊着取值 / 编辑一行 / 报告区 / 展开着 / 预设栏 / 键位表。

规矩：

- 「**哪些键在哪个状态下有效**」仍旧**一处答完**——那张表现在按两维查，它仍是本仓库
  唯一一处答这个问题的地方。
- **三层只读由第一维说了算**，与焦点在哪无关：跑着与等答话时左栏一个改动键都不派，
  抬头照旧改口、各行照旧压暗。
- `⇥` **按状态分派**，不冲突：左栏 ⇄ 报告区切焦点；编辑一行时是逐层补全；展开着时是换下一卷。
- **跟随**：跑着时卷表默认停在最后一行（跟着最新收摊的那一卷）；光标一动就停，
  屏上说一句「跟随停了」；`g` 回到跟随。跟随是卷表**独有**的状态，别处的视口仍是「算出来的」。
- **决策点上那一卷进表。** 它今天停在「攒着的那一份」上、不在收摊了的那几卷里，
  而 `p2-loose-ends/08` 票面记着「不许摊开上一卷冒充它」。做法：表上给它一行，
  记号与档位照它到此刻为止的那份报告画，末尾标着「等你拿主意」；**它展得开**。
  展开的索引因此从「报告上第几卷」改成一个认得出这两处的东西——这一改是 08 那条硬约束的解法。

`p1-session/10`、`11`、`14` 先后三次判过「模式不拆成两维」，依据都是「本票不需要」。
本批需要，推翻的理由与代价写进 **ADR 0015**。

### 八、展开的逐页表

- 逐页也是一张表，与卷表同一套视口、同一套砍列、同一套上色。
- **默认只列要紧的页**：特例页、失败页、部分救回页、几何门不成立的页、宽溢出的页、
  兜底上界改过的页，以及**定档页**（它是这一卷的答案，非在不可）。
- `a` 切到**全部页**；切换状态在屏上看得出来。
- 抬头钉住这一卷的：基准档、定档页、要紧的页有几张、它是第几卷。
- **左栏照旧收起**（`CONTEXT.md` 的《会话》：展开与左栏收起是同一件事）。80 列的终端上
  那 52 列让不出来，这一条不动。
- `⇥` ／ `⇧⇥` 换下一卷／上一卷，视口对到那一卷的抬头上，与今天一致。

### 九、语义色

四种语义，**一处出处**：

| 语义 | 用色 | 用在哪 |
|---|---|---|
| 平常 | 终端默认色 | 正常跑完的卷、普通的页 |
| 注意 | 黄 | 隔离、宽溢出、部分救回、兜底上界、几何门不成立、特例页 |
| 出事 | 红 | 失败页、卷级失败、拒绝执行 |
| 不要紧 | 暗 | 跳过的卷、只读时的左栏 |

- **颜色不是唯一载体**：每一处上色的地方旁边都另有一个**字**（「隔离」「失败」「跳过」）
  或一个行首记号。色盲、以及不上色的终端上一个字都不丢。
- **认 `NO_COLOR`**（环境变量在场即不上色），一处生效。
- 只用 16 色里的基本色，**不定背景色**——背景归用户自己的终端主题。

### 十、键位与 `?`

- 屏底那一行只摆此刻最常用的四五个键，**末尾恒是 `? 全部键`**。
- `?` 调出一张按**焦点**分组的完整键位表（左栏／报告区／展开着／预设栏／任何时候），
  `Esc` 关。它是第二维上的一个取值，进去之后别的键一律不派。
- 「屏上不摆按不动的键」这条**照旧**：屏底那一行仍随状态变，`?` 那张表也只列此刻这个阶段
  派得出的键。
- 屏底折行与按需长高照 `p2-loose-ends/07` 的规矩，不动。

### 十一、窄终端

- 最窄那一档按 **80×24** 设计与验收。
- 宽度不够时先把左栏让掉（今天就有的退化），再按第六条砍列。
- 高度不够时：总览块**不砍**（它是钉住的那一块，也是唯一答「这一趟怎么样」的地方），
  表压到最少一行，屏底照 07 的规矩折行并按需长高。
- 三者都让完仍摆不下时，宁可少画表，不少画总览。

## Testing Decisions

好的用例只断言**外部可观察的行为**：屏上有什么、命令行印出什么、哪个键在哪个状态下有效。
不断言私有结构，也不断言调用次数。

- **命令行输出不变**——`tests/golden.rs` 是主证。本批除换词那三个字外，黄金快照
  **一行都不该动**；换词那一票动它，且要逐条确认「变的只有那三个词」。
  措辞降到字段级那一票的验收标准就是**黄金快照零变化**。
- **字段本身**——`render` 新出的那组行与格另有一小批用例：一行是什么行、有几格、
  跳过的卷少哪几格、失败的卷是哪一种行。先例是 `src/render.rs` 已有的 `mod tests`。
- **状态机**——二进制 crate 内单元测，**不开终端**。两维之后逐条问那张表：
  跑着时左栏一个改动键都不派、焦点在报告区时上下键选卷、取值栏摊开时 `←→` 归它、
  `Esc` 回去且一格不改、`⇥` 在三种状态下各做什么。今天那条
  `which_keys_do_what_in_which_state` 是现成的家。
- **视口**——纯函数，单独一批：光标在头、在尾、列表短于格子、格子高度为零、
  光标跳到列表外。四处共用的那一个只测一次。
- **砍列**——纯函数：给一个宽度，出该留哪几列。断言最窄那一档上卷名与记号仍在。
- **快照矩阵**——`TestBackend`：
  - 宽（120×40）× 窄（80×24）
  - 试算副 × 执行副
  - 收起 × 展开（展开再分「只列要紧的页」与「全部页」）
  - 跑着且跟随 × 跑着且跟随停了
  - 等答话时那一卷在表上
  - 取值栏摊开（型号那一行的两层各一张）
  - `?` 那张键位表
  - 不上色（`NO_COLOR`）的一张
- **颜色**——快照那一路读的是缓冲，样式读得出来。断言「出事的那一行既是红的、也带着那个字」。
- **闸门**——三条命令都要绿。新东西全在 `tui` 后面，`--no-default-features` 那一趟
  不受影响；视口与砍列那两个纯函数若摆在 `tui` 之外，它们的用例那一趟也照跑。

## Out of Scope

- **鼠标交互。** 全键盘，与 P1 同一条。
- **库浏览器与全库索引。** 范围层仍只有输入框加逐层补全（ADR 0009）。
- **命令行那一份的排版。** 除换词那三个字外一字不改；不给它加表格、不加颜色、不加分组。
- **英文标识符改名。** `driver` ／ `outlier` ／ `body` 不动，理由见《换词》。
- **报告落成结构化文件**（JSON、CSV 之类）。字段级只在进程内用，不出一个新的对外格式。
- **配色可配置、主题可选。** 四种语义色写死，只认 `NO_COLOR`。
- **在报告区里改配置。** 跑起来之后三层仍旧只读；焦点在报告区时左栏也不派改动键。
- **多卷续做**、**试算抽样**、**最近使用过的范围列表**：与 P1 同一条，仍不做。
- **P0 之外的任何管线能力。** 本批只把已有的东西摆得读得出来，一个判定都不碰。
- **`p2-loose-ends/09`（预设可删且保留注释）**：它与本批轻度相邻，但仍留在 p2 里走完。
