## 设计树

### 01 生产与测试文件分离

已定：独立文件就近放置；测试函数、夹具、测试专用 impl 与辅助逻辑全部外置，生产文件仅保留必要测试装配声明，不放宽私有访问（Q1）。
已定：跨 crate 的公共夹具共享测试源码，仅在测试构建引入；私有实现夹具就近放置，不增加测试专用 crate（Q8）。
已定：深化 module 时同步迁移与替换测试，将内部细节测试改为 interface 行为测试；不是先保留全部旧测试再去重（Q11）。
验收约束：每个被删除或改写的旧断言，都说明由哪项新行为断言替代；独立列出新增、替换与删除，不以总通过数代替覆盖证明。不得通过删守卫、忽略新目录或弱化失败条件变绿。

### 02 领域能力与三个 crate

已定：领域能力优先、三个运行时 crate、不保留公共调用形式兼容。
已定：候选可行性、覆盖裁剪和覆盖顶死事实由 domain 拥有；processing 负责路径、拒绝时机与措辞（Q4）。
已确认方案：其余职责、跨 crate interface、依赖与 feature 验收见 design.md《02 三个运行时 crate 与领域能力》。
候选名称：tonefit 根程序、tonefit-processing、tonefit-domain；单向依赖，不引入第四个运行时 common crate。

### 03 页处理

已定：候选纯规则归 domain（Q4）；页处理 module 拥有解码、几何、参照与评估顺序，转换与样张按用途消费同一评估，不在调用端重新拼流程（Q5）。
已定：测试随 module 深化同步迁移与替换，逐条说明旧断言的新覆盖（Q11）。
已确认方案：结果生命周期、按用途物化和页事实／报告分工见 design.md《03 页处理：一个顺序，按用途消费》。
不重开：落格、单次解码、默认逐页判定、确认点前不写输出、样张与转换共用实现。

### 04 共用设置与结果规则

已定：设备设置与处理选项由独立于 CLI、预设和会话的共用 module 拥有，保留“没说”的语义；CLI 解释参数，预设负责读写，会话编辑，共用 module 统一解析有效设置（Q2）。
已定：共用设置 module 放 processing，接收不含 clap、TOML 或终端类型的设置，供 CLI、预设、会话及直接库调用者统一解析默认与校验（Q9）。
已确认方案：中立可选设置、按用途解析、错误先后及根程序退出规则见 design.md《04 共用设置与结果规则》。
不重开：未指定与显式指定默认值的区别；预设不收路径与输出。

### 05 会话交互

已定：起跑、停止、确认、预设操作、搜索和导航的完整非终端交互可用给定输入、时刻与窗口尺寸测试；关闭 tui 时仍编译并验证，真实终端进出、键码翻译与绘屏留在 tui 后面（Q3）。
已定：运行投影拥有清点、进度、确认和报告事实；交互 module 拥有视图、焦点、光标与输入，读取投影但不复制运行事实，终端不编排两者（Q7）。
已定：非终端交互 module 接收明确的运行与预设依赖，直接协调线程、预设读写与量具调用，不新增通用动作／结果协议；测试使用临时目录、给定时刻及受控运行（Q10）。
已确认方案：只读快照、写入口、锁外协调与测试组织见 design.md《05 会话：交互协调不在终端 adapter》。
不重开：阶段与焦点两维、两个视图、按键表与措辞单一出处、等待时不持锁。

### 06 幂等复用

已定：复用 module 同时拥有比较规则、跨页一族、留下页、旧输出访问与句柄生命周期；卷编排决定何时比较、写出与结束使用，不管理旧输出内部资源（Q6）。
已确认方案：拥有型复用结果、与记录／输出容器／缓存的分工、失败语义及验收见 design.md《06 幂等复用：规则和资源共同拥有》。
不重开：源哈希作用域互斥、跨页一族完整性、留下的页原样字节、混装目录与借住的卷语义。

## 已核实的实现约束

- 当前检查未见 tracked Place／CI 改动，不能继续把“等待旧脏改动”当作事实阻塞；仍遵守先设计、实施另行确认。
- 私有测试子模块可以外置文件，保持祖先私有访问；跨 sibling 使用的测试辅助需保留受限装配。
- 单一出处扫描有意扫描部分测试源码；不能一律排除新测试目录来规避误报，应按每条守卫的语义保留覆盖。
- 当前设置默认已由预设模型 getter 与领域类型共同供给；问题是拥有关系与请求组装耦合，不是三端各有一份全部默认。
- 候选可行性只依赖面板与尺寸贴合检查；覆盖裁剪也有纯集合运算。路径上下文、拒绝标记和建议文案属于处理编排，不能带进纯计算。
- 样张展示全部可行候选，覆盖只影响判定；单页候选恰剩一项不自动等于覆盖顶死。
- 完整输入分派的参数没有真实终端把手；放在 terminal module 才使其受 tui 控制。线程与预设读写仍是真实副作用，不应声称它是纯函数。
- 复用比较失败与留下页读取失败语义不同：旧输出无法打开或依据无法读取可不命中；写出时读取留下页失败是卷失败，不回退重算。
- 留下的页仅存路径、尺寸和字节数，不提前持有全部负载；旧输出句柄保持到写出需要时，最终改名前释放。重组不得改变该生命周期。

## to-spec 验收 seam 确认

用户确认采用既有高层 seam：处理与复用优先经 run；画质分、样张与灰阶测试图沿用各自既有入口；交互经完整非终端输入链、真实 CLI 和整屏验收；crate 依赖与测试隔离经构建和源码守卫验证。
