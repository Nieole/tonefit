# 17: 样张消费共用页结果

**What to build:** write_proof 与转换消费同一页求值和物化能力，样张真正展示转换会写出的页；样张仍是独立量具，显示全部可行候选，全部编好才开始落盘。

**Blocked by:** 15「共用页求值贯通逐页处理与纯 DryRun」。

**Status:** ready-for-agent

**规格覆盖：** task-ddd-reorganization；用户故事：26、27、28、32、33、34、36、78。

- [ ] 让样张消费共用页事实、评估和拥有型产物，删除样张独立拼解码、几何、参照、评估与物化的平行编排；不增加 Mode::Proof 或新产品 seam。
- [ ] 展示全部可行候选，覆盖只限制判定候选；自然只剩一个不自动算覆盖顶死，保持理由、画质门槛及标定来源。
- [ ] 保持一次源页解码、跨页阅读顺序、残缺页和提白关闭时的用途差异；彩色分支仍只有转换会写出的那张图，不强造候选或参照。
- [ ] 所有输出页的全部候选编码成功后，才创建目录和开始写出；前置拒绝与编码失败不得留下一叠新样张，不混入卷记录、缓存或幂等职责。
- [ ] 用 run 的对应 PNG 逐字节作神谕，并验证落格、全部候选、覆盖、页序与拒绝零副作用；不要求含不可复现时间戳的整个归档跨趟相同，不重录黄金产物。
- [ ] 同步外置／替换所属测试、辅助和夹具，按性质索引说明旧断言去向；更新源码守卫、路径消费者与实际量具／页处理 spec。
- [ ] 运行样张及转换字节对照聚焦检查、cargo xtask gate 与 cargo xtask polish；不以未迁移的整卷调用者为额外 blocker。

## 不做会怎样

样张即使复用几个 helper，仍可能以不同顺序评估或编码，失去“所见就是转换输出”的字节神谕；前置失败也可能留下半叠文件。
