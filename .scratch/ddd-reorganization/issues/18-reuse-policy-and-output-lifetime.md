# 18: 复用规则与旧输出资源共同拥有

**What to build:** 一个 processing 私有复用 module 同时拥有比较、跨页一族、留下页与旧输出访问。卷编排只消费整卷命中、按页复用或不命中及理由、重做位置和统计，不管理旧输出内部句柄；留下页在实际写出时才读负载。

**Blocked by:** 02「processing 接管编译拥有权，保留临时根门面」。

**Status:** ready-for-agent

**规格覆盖：** task-ddd-reorganization；用户故事：62、63、64、65、66、67、68、69、70、71、72、78。

- [ ] 集中比较、族完整性、重做位置、留下页尺寸／长度与旧输出资源，私有持有旧容器；对卷编排不交出容器句柄，不新增 Repository、通用文件系统 trait 或第四运行时包。
- [ ] 保持卷级与页级源哈希作用域互斥、整卷命中、按页复用及零留下页的合法计划；跨页按完整一族保留或重做，不复制记录格式／哈希规则。
- [ ] 比较时只读必要依据与长度，分析及确认等待期间保持所需资源；写出时才读取留下页负载并交给输出容器，保持原 PNG 字节、像素、判定和记录，不提前全量加载。
- [ ] 用消费式结束及析构保证旧输出在最终提交前释放，并覆盖失败、停止和取消；输出容器继续拥有临时产物、借住范围、陈旧／多余成员清理和提交，缓存继续拥有本趟预算与溢写。
- [ ] 保持旧输出打不开或依据不可读可以视为不命中；已决定留下的页在搬运时读写失败仍是卷失败，不回退重算。
- [ ] 经 run、真实产物和必要窄资源守卫覆盖整卷、按页、零留下页、完整一族、延迟负载、错误、取消、借住及多余成员；Windows 提交前释放由真实平台守卫证明，不用本机模拟替代。
- [ ] 同步外置／替换所属测试，逐项登记覆盖，更新相关源码／平台证明消费者及 owning spec；运行聚焦检查、cargo xtask gate 与 cargo xtask polish，未执行真实平台验证明确记录。

## 不做会怎样

命中结论、可读留下页和资源寿命仍分属多个调用者；正常路径手动释放容易漏掉错误或取消，Windows 最终替换也可能因旧句柄仍打开而失败。
