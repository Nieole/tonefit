# say-and-stop — 说得出发生了什么，停得下：摊开成为一个环节，命令行报告补上它漏说的那几件

**Status:** ready-for-agent

## Problem Statement

一趟跑完，命令行那份报告是用户手里唯一一份留得下来的东西（`tonefit … > 报告.txt`）；可它在几件事上一个字都不说，
而停止在一段路上根本按不下去：

1. **按停了，报告上看不出来。**命令行按 `Ctrl-C` 停下来的那一趟，「按到了哪一级」那一句走 stderr、而且对面不是终端时
   一个字节都不写；报告走 stdout，读的人只看得出卷比点名的少了几个，看不出是被按停的（停车场 Q260）。
2. **清点那一段按不停。**几十个归档卷在慢盘上列归档头要一阵，这一段里按停止、按中止都要等清点整个走完——
   库在清点时一条事件都不发，而观察者只在事件上答话（Q261）。
3. **停止的规则在 bin 里有两份。**「确认点上做完再停要让、立即停止不让」与那张升级表（继续 → 做完再停 → 立即停止），
   命令行与会话各抄了一份，名字逐字相同，没有东西逼它们一致（Q262、Q552）。
4. **摊开没有名分。**`.rar`／`.7z` 开工前要整卷摊到临时目录，大卷上是几分钟：它有步、有检查点，却不是一个**环节**——
   卷级计时里它落在「段外」那一截，事件流说不出「此刻在摊开」，屏上那几分钟写的是一个本该只闪一下的「开卷」（Q280、Q283）。
5. **报告漏说的几件事：**
   - 有卷的源在跑的过程中变过、那一卷因此退回串行读——那句话拼出来了，然后被丢掉（Q222）；
   - 一卷没被跳过、整卷重做了，报告说不出为什么——幂等命中那一句列着四项依据，它的反面一句都没有；
     升级之后整库重跑一次，用户不知道原因（Q528）；
   - 抬头列着适配方式、裁边、跨页拆分，却不说灰阶档位走的是逐页还是整卷统一——全卷都幂等命中的那一趟因此说不出自己是哪一条路（Q637）；
   - 没有一行说产物有多大，「装不装得下」只能转完再量（Q801，Q800 判不做的那一半）；
   - 没做成的卷没有卷级计时，会话只好自己量，屏上那个和因此可能差一截（Q808）；
   - 画质门槛的标定来源只写 boox-poke6，而把那个数收窄的是 kobo-libra-2 上的一轮真机——类型里只装得下一道窗口（Q472）；
   - 提白上限默认是 4，报告印「4 级」，一个字不提它是未标定的占位值——与 K、细节放宽那两个数的待遇不同（Q548）；
   - 默认路径上命令行目录那一行的「基准档分布」一律写「逐页 N」，与卷数那一格说的是同一件事（Q706）。

## Solution

- **命令行报告末尾说出这一趟怎么收的场**：跑完了不说；按停止（做完再停或立即停止）停下的、清点途中就停下的，说一句。
- **清点中也问一句**：清点每开一个归档头之前发一条「清点中」事件（不带卷数），观察者照常答话；答了停止，清点当场收手，一卷都不开工。
- **停止规则在 bin 里只剩一份**，命令行与会话共用。
- **摊开成为第一个环节**：要摊开的卷走四个环节——**摊开 → 查重 → 分析 → 写出**；不摊开的卷照旧三个。事件流报得出它，
  卷级计时多一段，步记在它名下。
- **报告补说那八件**：退回串行、为什么整卷重做、位深走的哪条路、产物体积、没做成的卷的计时、两道标定窗口、
  提白上限未标定、默认路径上目录行那一格不在。

命令行报告的字节因此变了，黄金快照由改到它的那几张票各自显式接受一次，每次只接受那一处的变动。会话屏上取自库的那几句（画质判定参数那一段）跟着变，设计稿同步改、重导。

## User Stories

1. 作为命令行用户，我想要按停止停下来的那一趟，报告末尾说出是按了哪一级停的，以便把报告存成文件之后仍看得出这一趟不完整、为什么不完整。
2. 作为命令行用户，我想要做完再停那一种说出剩下几卷没开工，以便知道下一趟还要补几卷。
3. 作为命令行用户，我想要立即停止那一种说出当前那一卷丢掉了、盘上没动过，以便不去找一份不存在的输出。
4. 作为命令行用户，我想要一趟正常跑完时报告不多出一行「收场」，以便正常的报告照旧干净。
5. 作为命令行用户，我想要清点那一段按 `Ctrl-C` 也停得下，以便点错了一个大库不必干等清点走完。
6. 作为命令行用户，我想要清点途中停下的那一趟，报告说出它在清点途中就停了、一卷都没开工，以便不误以为清点出错。
7. 作为会话用户，我想要清点中按停止也当场停，以便会话与命令行两条路按停的手感一样。
8. 作为会话用户，我想要清点中屏上照旧只说「清点中」、不报卷数，以便这一条新事件不改变清点那一屏（Q720）。
9. 作为维护者，我想要「确认点上做完再停要让、立即停止不让」与那张升级表在 bin 里只有一份，以便两条路不会各改各的。
10. 作为命令行用户，我想要一个要摊开的卷在摊开时进度那一侧知道自己在摊开，以便那几分钟不是一条没有名字的横条。
11. 作为会话用户，我想要要摊开的卷走四个环节、不摊开的卷走三个，以便屏上说的是这一卷真走的路（屏上那一半归 `design-parity/13`）。
12. 作为读报告的用户，我想要卷级计时里多出摊开那一段，以便知道一卷的时间花在摊开还是别处。
13. 作为维护者，我想要摊开那一段的步记在摊开这个环节名下，以便「步按环节划」这条规矩没有例外。
14. 作为维护者，我想要幂等命中而跳过的 `.rar` 卷照样报摊开，以便「查重要读源字节、源字节要先摊开」这件事在流上看得见。
15. 作为维护者，我想要「段外」那一截不再装着摊开的时间，以便它只剩真没有名字的那一点零头。
16. 作为读报告的用户，我想要某一卷的源在跑的过程中变过、退回了串行读时，那一卷说一句，以便知道它为什么慢、为什么这一趟没并发。
17. 作为读报告的用户，我想要一卷没被跳过、整卷重做时，报告说出上一趟的输出与这一趟差在工具版本、设备配置还是选项上，
    以便升级之后整库重跑一次时知道原因。
18. 作为读报告的用户，我想要只因为某几页的源变了而重做的那几页，照旧由「按页跳过 留下 N 页、重做 M 页」那一句说，
    以便「整卷重做的原因」与「按页重做」不混成一句。
19. 作为读报告的用户，我想要第一次转换（没有上一趟的输出）时不出这一句，以便报告不对着一件没发生的事解释。
20. 作为读报告的用户，我想要上一趟的输出在、却读不出记录时，报告说清是记录读不出，以便分得清「依据变了」与「依据丢了」。
21. 作为读报告的用户，我想要抬头说出这一趟灰阶档位走的是逐页判断还是整卷统一灰阶，以便全卷都跳过的那一趟也说得出自己是哪条路。
22. 作为读报告的用户，我想要报告末尾一行说出这一趟产物合计多大、每一卷各一行说出它多大，以便不必转完再去量盘。
23. 作为读报告的用户，我想要预览那一趟在默认路径上也说得出产物体积，以便先看一眼装不装得下再决定转不转。
24. 作为读报告的用户，我想要 `--envelope` 那条路上预览时这一行整个不出现，以便不看到一个会骗人的零或估值。
25. 作为读报告的用户，我想要预览与转换报的体积是同一种算法，以便两个数对得上。
26. 作为会话用户，我想要没做成的卷在卷列表上的耗时来自库的卷级计时，以便目录行那个和与报告一致。
27. 作为维护者，我想要会话自己量的那一份只在没有库那一份时才用（还在跑的卷、被立即停止掉的卷），以便一卷的耗时尽量只有一个出处。
28. 作为读报告的用户，我想要画质门槛那一句说出它是在 boox-poke6 与 kobo-libra-2 上实测的，以便自己判断它对手上那块屏成不成立。
29. 作为维护者，我想要标定来源的类型装得下不止一块面板，以便下一次再多一道窗口不必重写那句话。
30. 作为读报告的用户，我想要提白上限那一行在上限非 0 时注明是未标定占位值，以便知道默认的 4 不是测出来的。
31. 作为读报告的用户，我想要提白上限取 0 时那一行照旧说「0 级（没开）」、不挂占位的说明，以便关着的时候不多一句无关的话。
32. 作为命令行用户，我想要默认路径上 `--brief` 目录那一行不再写「逐页 N」，以便那一格只在它说得出新东西的 `--envelope` 那条路上出现。
33. 作为命令行用户，我想要 `--envelope` 那条路上目录那一行照旧有基准档分布，以便那条路的用户读得到它。
34. 作为会话用户，我想要配置视图里画质判定参数那一段跟着报告抬头一起说出两块面板、位深走哪条路，以便屏上与报告说同一句话。
35. 作为维护者，我想要这些措辞都只在措辞那一层写一次，命令行与会话读同一处，以便 ADR 0016「一套措辞」没有例外。
36. 作为维护者，我想要黄金快照由改到报告的那几张票各自显式接受一次、此后照旧逐字节钉住，以便每一处变动单独看得清。
37. 作为维护者，我想要事件流用例钉住摊开环节、清点中那一条、没做成的卷带计时，以便库的对外形状变动都有用例守着。
38. 作为维护者，我想要命令行按停之后 stdout 上的报告有收场那一句，有一条起真进程的用例钉着，以便这件事不再只靠 stderr。
39. 作为维护者，我想要 `CONTEXT.md` 的《环节》《卷级计时》《事件》之外的词条不因这一批改动，以便改动面收得住。
40. 作为维护者，我想要摊开成为环节这件事在 ADR 0015 里有一句，以便读格式决定的人知道摊开今天在流上长什么样。

## Implementation Decisions

### 收场那一行（Q260）

- `Report` 身上本来就带着这一趟怎么收的场（`RunOutcome`）；命令行报告末尾照它印一行，措辞只在措辞那一层写一次。
- 走到头不印；做完再停印「做完再停」与剩下几卷没开工；立即停止印「立即停止」、当前那一卷丢掉了、最终位置没动过；
  清点途中就停下的，印它在清点途中停下、一卷都没开工。
- 会话屏上的收场说法照设计稿，不读这一行（界面层的句子，ADR 0019）。

### 清点中也问一句（Q261）

- 事件多一种：**清点中**。清点每开一个归档头之前发一条，**不带卷数**（Q720：清点中只说正在清点）；观察者照常回指令。
- 答了做完再停或立即停止，清点在这一个归档之后收手：这一趟不发开工那一条，`run` 交回一份一卷都没有的报告，
  收场是按停止停下（两级在这一刻没有区别——还没有一卷在做）。
- 这是本批库的新契约之一；它符合《进度》那一句「观察者是双向的，取消不必另开一条信号通路」。命令行那条横条收到它什么都不画；
  会话收到它只答话，清点那一屏一格不变。
- 目录卷那一侧清点不开归档头，照旧不发；要清点很久的是归档卷。

### 停止规则收成一份（Q262、Q552）

- 「确认点上做完再停要让、立即停止不让」（`answer` 与 `at_the_decision_point`）与升级表（继续 → 做完再停 → 立即停止 → 立即停止）
  收进 bin 里一个模块，命令行与会话共用。库的对外形状一格不动——这是 bin 内部的收口，闩的编码早已在库里（`p4-parking-lot/19`）。
- 两路原先各自的用例搬进这个模块，两路各留一条「调的是它」的用例。

### 摊开成为第一个环节（Q280、Q283）

- `Pass` 多一个取值**摊开**。要摊开的卷，开卷之后、摊开开始之前报一条环节开始（摊开）；摊开途中那几步记在它名下；
  随后照旧查重 → 分析 → 写出。不摊开的卷不报它。幂等命中、整卷跳过的归档卷照样报摊开——查重要读源字节，源字节要先摊开。
- 卷级计时多一段**摊开**；「段外」那一截不再装着它。进度那一侧本来就是四段，从此计时与进度同一条分界线。
- `Pass` 是 `#[non_exhaustive]`，会话眼下有兜底那一支；屏上的名字与颜色归 `design-parity/13`，在那之前摊开期间屏上写兜底那一句。
- `CONTEXT.md` 随这张票改：《环节》四个（摊开只在要摊开的卷上出现）、《卷级计时》多一段；ADR 0015 补一句「摊开是一个环节」。

### 报告补说的八件

- **退回串行（Q222）**：`Independent::Replaced` 拼出来的那句话不再丢掉，随卷报告带出来；卷级一句「这一卷的源在跑的过程中变过，退回串行读」。
- **为什么整卷重做（Q528）**：幂等那一道比不上时，交出**差在哪一项**——工具版本、设备配置、选项（参数哈希）三项里的哪几项，
  或上一趟的输出在而记录读不出；随卷报告带出来，卷级一句说出它。源变了的那几页照旧由「按页跳过」那一句说，这一句只管共用那三项。
  没有上一趟的输出时不出。参数哈希是一个整体，只说得出「选项变了」，说不出哪一项（《尚未确立》「接着写出的粒度」照旧）。
- **位深走的哪条路（Q637）**：`Report` 带上这一趟是逐页判断还是整卷统一灰阶，抬头印一行，叫法与设置那一项同一个出处。
- **产物体积（Q801）**：卷级各一行、趟级末尾一行合计。口径是**这一趟交出去的输出页与透传文件的字节之和**，不含容器开销——
  预览与转换同一个口径。只在白捡的地方给：默认路径与覆盖顶死那一趟，分析环节就把字节编完了；`--envelope` 那条路预览时
  字节还没编，**整行不出现**（不印零、不印估值）；转换那一趟两条路都有。按页跳过留下的页，字节照算。
- **没做成的卷的计时（Q808）**：`VolumeFailure` 带上卷级计时，没做成那一条事件跟着带；会话对没做成的卷读它，
  自己量的那一份只留给还在跑的卷与被立即停止掉的卷。
- **两道标定窗口（Q472）**：标定来源的类型装得下几块面板；内置的那个印成「在 boox-poke6 与 kobo-libra-2 上实测，其他屏幕未验证」。
  点名的那一种不变。
- **提白上限未标定（Q548）**：上限非 0 时那一行印「N 级（未标定占位值）」，与 K、细节放宽同一个待遇；取 0 时照旧「0 级（没开）」。
- **目录行那一格（Q706）**：命令行目录那一行的基准档分布，默认路径上整格不在；`--envelope` 那条路照旧有。

### 会话屏上跟着变的那几句

- 配置视图里画质判定参数那一段取自报告抬头：标定来源那一句、位深那一行跟着变。照 ADR 0019 决定第 13 条先改设计稿、重导，
  再让实现跟上。这一批因此排在 `design-parity/01` 之后，与那一批串行改设计稿。

### 词条随票落地

- 《环节》四个、《卷级计时》多一段——摊开那一张；
- 《事件》多一种清点中——清点那一张；
- 其余几件是报告的措辞，词汇表不动。

## Testing Decisions

### 什么是好测试

只断言外部行为：**报告印出来的字节**、**事件流**、**进程的 stdout 与退出码**、**整屏**。不断言闩里存的是哪个数、
比依据时先比哪一项、计时在哪儿掐的表。

### 命令行报告的字节（主力）

- `render` 的用例：收场那一行（三种收场各一条、走到头不出）、抬头的位深那一行、两块面板的标定来源、提白上限的占位说明
  （0 与非 0 各一条）、退回串行那一句、整卷重做的原因（每一项各一条，没有上一趟时不出，记录读不出时那一句）、
  产物体积（默认路径预览与转换同数、`--envelope` 预览整行不在）、目录行那一格两条路各一条。
- 黄金快照由改到报告字节的那几张票各自显式接受一次，diff 里只有那一张的改动。先例：`tests/golden.rs` 与它那条「改了快照绝不会被静默接受」的用例。

### 事件流

- 与现有事件流用例同一个接缝（给 `run` 装一个观察者）：要摊开的卷先报摊开、摊开的步记在它名下、卷级计时那一段不为零；
  不摊开的卷不报它；幂等命中的归档卷照样报摊开；清点每开一个归档头之前一条清点中，答停止时不发开工、交回一卷都没有的报告；
  没做成的卷那一条带着卷级计时。先例：`tests/events.rs`，以及「报过开工就一定报得到结束」那几条。

### 进程级
