# 03: 展开一卷看得到各阶段花了多久

**What to build:** 展开一卷时，除了逐页那一副，另给这一卷**各阶段的耗时分布**——解码、转灰、裁边、缩放、判据、量化、编码、写出各占多少。数据今天已经在按阶段记着，屏上一处都不显示；这一票只是把它接出来，让「一趟跑得慢」答得出「慢在哪一步」。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 展开一卷看得到阶段耗时分布
- [ ] 一个具体秒数都不进快照用例——那是机器快慢，不是被测代码的性质
- [ ] 走过的阶段有数、没走过的阶段是零（试算没有编码与写出、跳过的卷两遍都没走）
- [ ] 阶段耗时是**各线程墙钟之和**，不是墙上过去的时间，措辞上不许混
- [ ] 卷表那一副不受影响，计时仍旧不进它渲染出的文字
