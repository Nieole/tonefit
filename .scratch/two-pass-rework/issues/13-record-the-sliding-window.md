# 13: 记下滑窗依据（expand）

**What to build:** 幂等的依据多出一份**滑窗**形态：一张输出页除了自己的源哈希，另记下「它连同前几页」这个窗口的哈希。新形态与既有的卷级那一份**并存**，谁都还没开始用它跳过——这一票只负责把它算出来、记下去、读得回来。

这是 expand–contract 的 expand 那一步：先把新形式摆在旧形式旁边，一个调用点都不改，14 号票才谈得上按页跳过。

段式迟滞的回看长度是有界常数，滑窗哈希因此成立——这正是卷级上包络做不到、而它做得到的那件事。

**Blocked by:** 11

**Status:** ready-for-agent

- [ ] 每张输出页记下滑窗哈希，与既有的卷级依据并存
- [ ] 窗口长度跟着迟滞的回看长度走，不写死第二份
- [ ] **跨页拆分下窗口定义得清楚**：一个源页产出多张，窗口数的是**输出页**的阅读顺序；`来路` 那一项正是为这件事留的
- [ ] 旧记录（只有卷级那一份）照旧读得懂，判为不命中而不是判为错
- [ ] 跳过与重做的行为这一票**一个字不变**——仍旧整卷跳、整卷重做
- [ ] 走 `--envelope` 那条路时不记滑窗依据：那条路上一页的档由全卷定，滑窗答不了
