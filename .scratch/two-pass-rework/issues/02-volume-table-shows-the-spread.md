# 02: 卷表那两列换成档位分布

**What to build:** 卷表一行说得出这一卷**用了哪几档、各多少页**（形如 `2bit+FS 229 · 1bit 1`），取代今天那个在默认路径上每行都写同一句话的 `基准档` 格。`定档页` 那一格只在卷级上包络真的参与了这一卷时在场——一格在不在场本身就是一句话。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 卷表给出档位分布，一卷一行
- [ ] 上包络那条路上它退化成「一档全包」，把「上包络这一卷买到了齐整」显示出来
- [ ] `定档页` 只在上包络参与时在场，否则整格不在
- [ ] 跳过的卷、没做成的卷、等答话的卷这三种行首记号与措辞不变
- [ ] 横向摆不下时的砍列次序仍然成立
- [ ] 表那一副与纯文本那一副共用同一份措辞，两处不各写一遍
