# 10: 段式迟滞——一页说了不算

**What to build:** `--per-page` 那条路从「纯逐页各判各的」变成「逐页判定 + 段式迟滞」：连续够长的一段要求同一档就整段统一，**够不上长度的孤立偏离压回邻居那一档**。

实测上这条规则要对付的正是孤立单页：八卷里逐页判定产生的换档，几乎全是「一页偏离对两次换档」的孤岛。

**默认值这一票一个字都不动**——上包络仍是默认，本票只改 `--per-page` 那条路。翻默认是 11 号票的事。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 迟滞取**段式**：一页的档只取决于它前后几页，回看长度是个有界常数
- [ ] **不取跑动式**：跑动式维护一个从卷首累积下来的当前档，回看长度是整卷，会直接推翻 13–15 号票的滑窗幂等
- [ ] 孤立偏离被压回邻居那一档；够长的一段整段统一到满足整段的最低一档
- [ ] 默认路径（上包络）一个字节都不变，黄金回归纹丝不动
- [ ] 卷级上包络那条路上的迟滞形态不受影响
- [ ] 迟滞页数仍是未标定占位值，本票不碰标定
