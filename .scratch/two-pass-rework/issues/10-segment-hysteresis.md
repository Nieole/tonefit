# 10: 段式迟滞——一页说了不算

**What to build:** `--per-page` 那条路从「纯逐页各判各的」变成「逐页判定 + 段式迟滞」：连续够长的一段要求同一档就整段统一，**够不上长度的孤立偏离压回邻居那一档**。

实测上这条规则要对付的正是孤立单页：八卷里逐页判定产生的换档，几乎全是「一页偏离对两次换档」的孤岛。

**默认值这一票一个字都不动**——上包络仍是默认，本票只改 `--per-page` 那条路。翻默认是 11 号票的事。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 迟滞取**段式**：一页的档只取决于它前后几页，回看长度是个有界常数
- [x] **不取跑动式**：跑动式维护一个从卷首累积下来的当前档，回看长度是整卷，会直接推翻 13–15 号票的滑窗幂等
- [x] 孤立偏离被压回邻居那一档；够长的一段整段统一到满足整段的最低一档
- [x] 默认路径（上包络）一个字节都不变，黄金回归纹丝不动
- [x] 卷级上包络那条路上的迟滞形态不受影响
- [x] 迟滞页数仍是未标定占位值，本票不碰标定

### 迟滞定成了什么形状

序列按逐页判定切成**极大同档段**。一段够不上 `PAGES`（=3）页时，看它两侧紧邻的段：

- **两侧都在、都要得更低** → 整段压回那两段里较高的那一档；
- **只有一侧**（这一段贴着序列的头或尾），那一侧要得更低、**而且它自己够 `PAGES` 页**
  → 整段压回它那一档；
- 其余一律不压。

**一趟算完，看的全是逐页判定**（不是压回途中的结果）；**只降不升**；一页的结果
只取决于它所在的那一段加两侧邻段，不出 `[i-2, i+2]` 这五页——**双向**的有界常数。
双向是规则本身要的：只往前看的话，一段够长的偏离里排在段首的那几页会被段前的邻居压回，
「整段留住」当场落空。spec 的 P-D 写的是「这一页 + 它前三页」，对不上，记在 Q349。

**三种不压，各挡一种误伤**（各有一条单元用例钉着）：

1. **只比一侧高**——阶梯的一级。落点要取两个邻居里较高的那一档，而那是更高的那一侧：
   压它会变成**抬**它。「只降不升」正是靠「两侧都要得更低」这一条成立的。
2. **比两侧都低**——`[4bit, 4bit, 1bit, 4bit, 4bit]` 里那个 `1bit`。不许让它把两侧的页
   拉下来：那两侧的页判据要的就是 4bit，它们不是孤立地高出邻居，spec 认下的那笔降配
   不含它们。撞得上的不是造出来的输入，卷首两页封面接一页纸白就是。
3. **只有一侧邻居、而那一侧自己也够不上长度**。一侧说了不算，除非那一侧本身够分量
   ——邻段够 3 页时卷首那一页孤岛照压。

**不再算子幂等**：跑第二趟还会动。`[1bit, 2bit, 8bit, 4bit, 1bit]` 上压完 `8bit` 之后
新冒出来的那个短段留在原地，有用例
`one_pass_over_the_original_verdicts_can_leave_a_new_short_run_behind` 钉着。
有界就是这么换来的——压回之后重新切段再压一趟，回看长度就成了链长而不是常数。
P-D 要的是「一页的档只取决于有界窗口」，不是算子幂等，两者不冲突。

### 哪些页编进同一条序列

**门那两组各数各的连续**（Q346）：两组的候选集不是同一套（ADR 0007），
而压回给出的那一档取自序列里某一页的判定，混着数会把抖动发给一页门不成立的页。
**部分救回页一条都不进**（Q347）：它的判据是在残缺像素上算的，不该去定邻居的档
（与上包络摘它同一个理由）。缺的页**不切断连续**，与上包络那一层数连续的方式一致。

由此，「回看有界」这个界数的是**序列上的位置，不是卷内的页序**——序列滤掉了彩页、
失败页、部分救回页与另一门组的页，序列上紧挨着的两页在卷里可能隔着几页。
P-D 的滑窗要照序列算，记在 Q351。

### 报告与措辞

新加 `Reason::RunHysteresis`，**不与 `Hysteresis` 并成一格**：一个降档、一个升档，
并成一格之后「这一页为什么不是它自己判出来的那一档」就有两种读法，而两种方向正好相反。
报告里写「段式迟滞压回邻居那一档」，tEXt 里写 `hysteresis pull-back`。

`--per-page` 关掉的只是上包络那一层，迟滞不跟着关。**说这句话的地方有六处**，
`--help`、`Request`、`Preset`、`VolumeVerdict::PerPage`、会话夹具，
以及**真正印给用户看的那一行**（`render.rs` 的 `RowKind::PerPage`）——最后那一处
是审查抓出来的，改的是定义、漏的是出口。六处措辞现在一致，且都说准了方向：
压回的是**孤立地高出邻居**的页，不是笼统的「孤立偏离」（要得更低的那一页不动）。

`envelope` 里那个私有的 `fn hysteresis` 改叫 `raise`，与模块 `crate::hysteresis` 分得开：
那一层问「够不够得着基准档」，这一层问「这一段孤不孤立」。

`CONTEXT.md` 新增词条《段式迟滞 (Run hysteresis)》。原先的 `HYSTERESIS_PAGES` 提成
两条路共用的 `hysteresis::PAGES`，值仍是 3、仍标未标定——**共用是眼下的取法，不是一条决定**，
标定那一趟要不要给两条路各标一个数记在 Q352。

**ADR 0006 一个字没改**：《决定》第 6 条与《后果》末条那两句在本票之后都不再准确，
但改 ADR 0005 与 0006 原篇是 11 号票点名的验收条，两张票改同一篇会撞。记在 Q345。
