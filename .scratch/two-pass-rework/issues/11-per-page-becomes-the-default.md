# 11: 逐页 + 迟滞成为默认

**What to build:** 位深默认**逐页选最低可用档、加段式迟滞**，不再默认走卷级上包络。要卷级齐整的人显式打开 `--envelope`。

用户看得见的变化：不再为一卷里少数几页的需要付**全卷**的体积；代价是那批孤立偏离页拿不到自己要的那一档（9 号票已经用眼睛验过）。

`--per-page` 这个开关**报错并指路**，不留成不做事的别名——留着最坏：脚本里那一行看着还在、行为已经反过来，而且它现在是默认，写不写都一样，用户永远不会发现。

**Blocked by:** 08, 09, 10

**Status:** ready-for-agent

- [ ] 默认路径 = 逐页判定 + 段式迟滞
- [ ] `--envelope` 显式打开卷级上包络与迟滞的旧形态，行为与今天的默认逐字节相同
- [ ] `--per-page` 当场报错并指路，不静默、不当别名
- [ ] 预设里那一项跟着翻，且命令行显式点到的那一项仍旧赢
- [ ] **认下全库重跑**：逐页与否是参数哈希的输入项，默认一翻，从没点过这个开关的用户全部不命中。这一条写进 ADR 的《后果》
- [ ] ADR 0005 与 ADR 0006 **改原篇**：状态行加修订记录，被推翻的那条决定就地改写，另开一节说清原来那条理由为什么不成立
- [ ] `CONTEXT.md` 里 `上包络` `基准档` `其余页` `定档页` `特例页` **保留原义**，只标注它们描述的是 `--envelope` 那条路；要改的是「默认走哪条路」那一句
- [ ] 报告说得出这一趟走的是哪条路，两趟的结果不会被混着比
- [ ] 黄金回归会动：判定与输出体积都变，快照**显式接受**，不许顺手覆盖
