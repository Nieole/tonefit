# 07: 两处没有消费者的白造

**What to build:** 两处算了但一个读者都没有的东西，去掉。

其一：命令行那一路每跑完一卷都拼一份**卷报告**交给观察者，而命令行一侧一个字节都不读——它只认六条事件，决策点那一条落在「其余的当下没有去处」那一支。判空的谓词选错了一层：该问「有没有人会读它」，问成了「有没有观察者」。

其二：关掉记录的那一趟仍旧为每张输出页造**来路**，而它的读者在那一趟全断了。

**Blocked by:** 04

**Status:** resolved

- [x] 命令行那一路每卷少拼一份卷报告；会话那一路一个字不变——它是真消费者
- [x] 关掉记录的那一趟不再造来路
- [x] 会话里决策点上画出来的那一卷报告逐字不变
- [x] 关掉记录那一趟的输出字节不变
- [x] 这两处都没有外部信号，用例只能钉「行为不变」加分配量——**如果找不到站得住的断言，就在票里说清并留一条注释，不要为了有用例而测实现细节**

## 落地记录

### 这一处拍过两次板，方向相反

**结论：留。** `Progress` 上那个带默认实现的方法留着；《已了结》里 `Q77` 那一行补了半句
指过来，它的**原文一个字没动**。

**为什么是覆盖，不是推翻。** `Q77`（`State: settled`，`Whose call: 拍板的人`）
**自己就认下了「没有读者」**——它逐字写着「`Bar` 是一个真观察者，`sink.is_some()` 那道短路
挡不住它，而它的 `match` 根本不接 `PassStarted`」。它否掉的只是「**为速度**值不值得收」，
依据是那组量不动的秒数。而这一票买到的**不是速度**（见下面那一节）：一条编译期逼着的
不变量、三句假话下线、以及「那个谓词从来没省过东西」被写在了代码旁边。
**成本收益变了，所以覆盖它，而不是推翻它。**

**两份文件对着说，而两份都没提对方。** `Q77` 判「不收」，还提过同一个做法
（`fn wants_the_summary(&self) -> bool { false }`）；`spec.md` 的《白付（P-B）》
把同一处列进要收的五处，07 号票面照抄。记在 **Q492**。

**这条停线本该在动手之前就停。** `settled` ＋ `Whose call: 拍板的人` ＋ 与票面反向，
三样齐了——那是停线第 ① 条的典型例（票面的指示与一条**仍然生效的决定**相抵触）。
落地的人当时只驳倒了 ① 的后半（撤销不出票），而前半（会不会写出错的东西）恰恰取决于
那次拍板还算不算数，**那不是落地的人答得了的**。做完才停，晚了一步；代价降到几乎为零
只因为三件事：提交之前说了、两边的依据摆全了、`Q77` 原文一个字没动。
**下一次撞到 `settled` ＋ `Whose call: 拍板的人` 与票面反向，直接停，别先做完。**

**默认方向与 `Q77` 的提法相反，是故意的。** 它写 `-> bool { false }`（默认**不要**），
本票取默认**要**：答错方向的代价两边不对称——默认「不要」会让库外已经写好的实现方
在决策点上**静默**少一格 `so_far`。这一条不管去留怎么定都成立，也写进了 trait 文档。

### 删的是**工**，不是东西

票面写「去掉」，落地是**改成条件式**。`Origin` 这个类型、`Event::PassStarted` 那一条事件、
`so_far` 那一格，**一个都没删**——删掉的是「没人读的时候还要造它们」的那份工。
两处于是同一个形状：判空的谓词从「这一趟有没有那个上下文」，换成
「**这一份有没有读者**」。票面第一段自己写的就是这句话（「该问『有没有人会读它』」）。

### 其一：命令行那一路每卷白拼的卷报告

`Events::ask_before_the_second_pass` 从前挂在 `self.sink.is_none()` 上。
**那个谓词在真实的命令行路径上一格都没省过**——`main::execute` 无条件装一个 `Bar`
（`request.progress = Some(ProgressSink::new(bar))`，那一句没有分支）。
而 `Bar::observe` 认六条事件，`PassStarted` 落在 `_ => {}` 那一支；
这一层唯一从那条事件取的东西是「这一条是不是决策点」，读的是**遍名**，不是报告。
票面那句「一个字节都不读」照票面要求自己验过，成立。

`Progress` 因此多一个**带默认实现**的方法 `reads_the_report_at_the_decision_point`，
默认**读**（答错方向的代价两边不对称：答「读」最多白拼一份，答「不读」会让真要用它的
实现方拿到一格 `None`）。`Bar` 答不读。换上这个谓词之后：

- **命令行**：每一卷少拼一份 `VolumeReport`——少一趟逐页结果遍历、一次缓存用量读数、
  一份报告的构造与丢弃。
- **会话**：`src/session/` **一个字没动**，它走默认的「读」，决策点上画出来的那一份逐字不变。
- **决策点这一问一句话都没少**：事件照发、答复照样当场作数、`answer` 那条
  「决策点上的收尾要让、中止不让」照旧在遍名上分岔，只是 `so_far` 那一格是 `None`。

### 其二：关掉记录的那一趟白造的来路

来路只有一个消费者：`Recorder`（连同彩色分支那一支 `Record::color`），而它要一份**指纹**
才在场；`--no-metadata` 那一趟连指纹都不算（`process_volume` 里那个 `if request.metadata`）。
造出来的每一份来路因此一个读者都没有——一张输出页一个转义过的 `String`。

`Placement::new` 于是多收一个 `Option<&Fingerprint>`，`Placement::origin` /
`OutputPage::origin` / `Seat::origin` 三格跟着成 `Option<Origin>`。

**三处消费点改成 `zip`**：`self.fingerprint.zip(placement.origin.as_ref())`、
`recorder.zip(page.origin.as_ref())`、`recorder.zip(origin)`。
「记录器与来路一起在、一起不在」从一条**约定**变成**编译器逼着的不变量**——
读一份不在场的来路写不出来。删掉解决今天，钉住解决将来。

### 顺手改掉的三句假话（不记停车场）

`src/progress.rs` 两处、`src/lib.rs` 一处（那条哨兵用例的文档）写着
「命令行不带进度条的那条路走的正是那一支」，而命令行**恒装**一个进度条
（`main::execute` 那一句没有分支）。三句描述的正是本票换掉的那个谓词，留着就是让下一个人
照假话理解新代码，因此**就地改掉**——`no-false-line` 那一批治的正是这一类。
`LockSentinel` 那条注释里同一句一并改了。

全库扫过一遍（`*.rs` 与 `*.md`）：`src/` 里**零残留**。其余四处都在 `.scratch/` 的票面与
《落地记录》里，**一处没动**——那是历史记录，`docs/agents/issue-tracker.md` 写死它们
不因后来的工作被重写，`Q482` 有同型的先例。

**落地途中差点留下第四句，而且是写在这份记录里的。** 收尾时一度在票面与 `Q492` 里写下
一条「订正」，说 `Q77` 引的「占比一律读作 0.0%」在 `measurements.md` 上只是四样合占一格
的**上界**。**那条订正本身是假的**：`grep` 用的模式是「拼报告」，而 `measurements.md` 上
那一句写的是「卷报告每卷**拼两次**」——模式没命中，于是拿一处部分匹配当成了全部，
`Q77` 的引用从头到尾没错。`/code-review` 的 Standards 轴抓出来，**提交之前撤掉了**。
同一张票里、同一个毛病、犯在写票的人自己身上；而它本可以不发生——
`CLAUDE.md`《写代码前》写死「需要实测数字时，来源只有 `docs/measurements.md`」，
当时引的却是一条停车场处置。

### 这一票买到的不是速度

**省下来的墙钟量不动，而且早就量过。** 出处只有一个——`docs/measurements.md` 的
《分阶段耗时剖面》，那一节末尾有专讲这一处的一句：

> **卷报告每卷拼两次的代价可以忽略**（停车场 Q77）：四卷分别是
> 0.000 / 0.000 / 0.001 / 0.003 秒，占比一律读作 0.0%。

来路那一半同级——一张输出页一个 `String`。本票**没有**测速，
也没往 `docs/measurements.md` 加一个字节（那是 `q2-mr07` 的地界）。

买到的是另外三样：

1. **一条编译期逼着的不变量**——那三处 `zip`。读一份不在场的来路写不出来。
2. **三句假话下线**（上一节）。
3. **「那个谓词从来没省过东西」这件事被写下来了。** `Events::ask_before_the_second_pass`
   挂在 `sink.is_none()` 上，而命令行恒装观察者——那道短路在真实的命令行路径上一格都没
   省过，却有三处文档照它写了假话。票面一个字没提这件事；它是本票路过挖出来的，
   也是本票真正的产出。

**这一处收不收，拍过两次板，方向相反**（记 **Q492**）：`Q77` 判过「不值得收」，
连做法都提过同一个（`fn wants_the_summary(&self) -> bool { false }`），依据正是上面那组
0.0%；`State: settled`。而 spec 的《白付（P-B）》把它列进要收的五处，本票据此落地——
spec 是后写的、层级更高的那一份。**默认方向本票与 `Q77` 的提法相反**：它写默认「不要」，
本票取默认「要」，理由是答错方向的代价两边不对称。

### 用例：先钉住「没人读」，再删；然后照 spec 把脚手架换掉

**红过才绿。** 三处谓词各按回本票之前的样子跑过一趟，各自带着自己那句话红：

| 按回去的那一处 | 红的时候说什么 |
|---|---|
| `ask_before_the_second_pass` 的判空 | 「没人读那份报告，库还是拼了一份」 |
| `Bar::reads_the_report_at_the_decision_point` 回 `true` | 「命令行答了『读』，库于是每一卷白拼一份没人看的卷报告」 |
| `Placement::new` 恒造来路 | 「关掉记录的那一趟照旧造了来路，而那一趟一个读者都没有」 |

**然后那三条脚手架**照 `/code-review` 的 Spec 轴撤掉了。它引的是 spec
《Testing Decisions》：「好的用例只测**外部行为**……**不测私有函数、不测调用次数**」，
而那三条恰恰是——数闭包调用次数、断言私有函数与私有字段、以及一条同义反复
（断言一个函数体写死 `false` 的方法回 `false`）。撤是对的：**它们是证明用的脚手架，
不是套件该长期背的东西**，而红过那一趟已经把它们证到的东西写进了上面那张表。

**留下的是一条，全用公开 API**，在 spec 点名的 `run(Request) -> Report` 接缝上：

`tests/events.rs` 的
`the_decision_point_carries_the_volume_report_only_for_an_observer_that_reads_it`
——两位观察者（`Progress` 是公开 trait），一位说读、一位说不读，各真跑一趟两页的小卷，
断言决策点那条事件的 `so_far`（公开字段）一位拿到 `Some`、一位拿到 `None`，
而**两趟的遍序一格不差**。它自己也红过：把库那一侧的谓词按回去，
它说「说自己不读的那一位照旧收到了一份白拼的报告」。

**来路那一半交付后没有自己的用例**，靠的是 `tests/golden.rs`——黄金回归本来就按
`--no-metadata` 跑，输出字节一个没动就是它的担保（见下一节）。

### 票面第 5 条：钉得住的与钉不住的

票面预告的两个数（`resizes`、`cached_references`）**一个都用不上**，04 号票自己的《落地记录》
早写着这一句。本票也**没有**添第三个窄计数器：两处白造都不经过缩放与缓存，而为它们各加一个
报告字段要在十四处夹具字面量上补行（Q387），换回来的是一个只有一条用例读的数。

钉得住的那一件在 `tests/events.rs`，全用公开 API：**决策点交出去的那一格，
读它的人拿到 `Some`、不读的人拿到 `None`，而遍序一格不差**。

**钉不住的两半照票面要求说清**，各留一条注释、各记一条：

- **「库有没有白拼一份」在外面一个信号都没有**（**Q495**）。库先拼一份、再传个 `None`
  出去，那条用例照样绿。它落地时是钉过的——红过那一趟就是——只是那条用例数的是**闭包
  调用次数**，spec 明令不测，因此钉子留在上面那张表里，不留在套件里。
  spec 唯一许可的补法是**窄计数器**，而它要在十四处夹具字面量上各补一行（`Q387`）；
  04 号票留的那句「那要等 07 自己说得出要量什么」，答案是「这一卷拼了几份决策点报告」。
- **「命令行答的是不读」交付后一条用例都没有**（**Q491**）。`Event` 非穷尽让二进制这一侧
  造不出事件，而 `tests/` 那一侧装得上的是用例自己的观察者、不是 `Bar`。
  真相由 `observe` 那个 `match` 的形状兜着：里面根本没有取得到 `so_far` 的那一支。

### 后两条复选框各由什么担保

- **「会话里决策点上画出来的那一卷报告逐字不变」**：会话走默认的「读」，
  `Events::ask_before_the_second_pass` 交给它的仍是同一份 `so_far`；
  `src/session/` 一个字节没改，会话那几副逐字符快照（闸门 1 与闸门 2 各跑一遍）照旧全绿。
