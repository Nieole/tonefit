# 07: 两处没有消费者的白造

**What to build:** 两处算了但一个读者都没有的东西，去掉。

其一：命令行那一路每跑完一卷都拼一份**卷报告**交给观察者，而命令行一侧一个字节都不读——它只认六条事件，决策点那一条落在「其余的当下没有去处」那一支。判空的谓词选错了一层：该问「有没有人会读它」，问成了「有没有观察者」。

其二：关掉记录的那一趟仍旧为每张输出页造**来路**，而它的读者在那一趟全断了。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 命令行那一路每卷少拼一份卷报告；会话那一路一个字不变——它是真消费者
- [ ] 关掉记录的那一趟不再造来路
- [ ] 会话里决策点上画出来的那一卷报告逐字不变
- [ ] 关掉记录那一趟的输出字节不变
