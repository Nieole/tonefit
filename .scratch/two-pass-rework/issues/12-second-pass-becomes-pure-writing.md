# 12: 第二遍退化成纯写出

**What to build:** 逐页 + 段式迟滞之后，一页的档只要再看几页就定得下来——参照因此不必攒一整卷。缓存改成**滚动窗口 + 编好的字节**：参照只留迟滞回看长度那么几页，出了窗口当场量化编码，缓存里此后装的是**编好的 PNG 字节**而不是全尺寸灰度参照。第二遍退化成把字节按阅读顺序写出去。

峰值内存从「整卷参照」掉到「几页参照 + 整卷编好的字节」。彩色分支今天已经是这条路，本票让灰度路径也走上去。

**写出仍旧等全卷，这一票不碰**：一页失败整卷进隔离目录，而哪页失败要解过才知道；拆分加序号的成员名可能撞上卷里本来就有的成员，那一撞要在写出第一个字节之前拦下。更要紧的是「第二遍开始之前一个字节都没写」这条不变式被中止与决策点同时依赖着。

**Blocked by:** 10

**Status:** resolved

- [x] 出了窗口当场量化、编码；缓存此后装编好的字节
- [ ] 峰值内存在长卷上显著下降，且不再随卷长线性涨到撑不住
- [x] 输出字节与本票之前逐字节相同
- [x] 溢写那条路仍在：缓存预算照旧管得住，越过预算的照旧溢写、结束即收
- [x] **「第二遍开始之前一个字节都没写」仍旧成立**——中止停在第一遍时输出目录纹丝不动，决策点答收尾等价于一次干净的试算
- [x] 试算那一趟仍旧只记账、不留页

## 落地记录

**滚动窗口落在第一遍里，第二遍在逐页那条路上退化成纯写出。** 缓存那一格从此先后装两样：
第一遍存进来的参照，与这一页的档定下来之后换上去的编好的 PNG 字节
（`cache::Kind`、`PageCache::replace`）。**序号不换**——它第一遍就交给了这一页的输出页，
而换字节的是另一条计算线程，够不着那张输出页。

**窗口长度不另取一个数。** `hysteresis::PAGES`（=3）推出来的 `2·PAGES-2` 就是它，
而这个上界不是推的：`pull_back` 改写成一个滚动形态 `hysteresis::Rolling`，
`pull_back` 自己变成「把整条序列交给它再收一次尾」——**规则一处出处**，
既有那十一条用例一条没改、一条没红。新加的两条穷举到七页长的**每一条**序列
（4 档 × 至多 7 页）：一条问滚动与整卷逐格相同，一条问窗口押着的页数从不超过 `2·PAGES-2`，
且**顶得满**（`widest == 4`）。

**票面「参照只留迟滞回看长度那么几页」那个数，`tpr/10` 的文档写小了。** 那里写的
`[i-PAGES+1, i+PAGES-1]`（`2·PAGES-1` 页）只对序列**内部**成立；「只有一侧」那一条
要问那一侧自己够不够 `PAGES` 页，序列头尾那几页因此够得到 `2·PAGES-2` 之外
（`[4bit, 4bit, 2bit, 2bit, 2bit]` 的头一页要看到第五页）。`src/hysteresis.rs`
**那两处代码文档**都补上了；停车场 **Q349** 与 10 号票的《落地记录》一个字没动
——前者是别人的条目，后者是一份 `resolved` 票的历史记录。一并收 **Q423**。

**「第二遍开始之前一个字节都没写」一格没动。** 编好的字节进的是**缓存**，不是输出容器；
`Sink::create` 仍旧只在第二遍那一段里,决策点、四个页边界检查点、`partial` 的建与丢
一处没改。逐页那条路上新加一条用例钉它（`tests/resume.rs` 的
`finishing_at_the_decision_point_writes_nothing_on_the_per_page_path_either`）：
决策点到来那一眼输出根是空的，跑完输出根根本没被建出来。

**输出字节逐字节相同，靠的是三件互相独立的事。** ①量化与编码调的是同一对函数
（`quantize::quantize` / `encode::png`），喂进去的参照经 LZ4 无损往返（既有用例钉着）；
②那一档由 `summarize_volume` 与窗口各算一遍，`process_volume` 里一条 `debug_assert!`
逐格比对——两处一旦分家，整套用例当场红；③盖进 tEXt 的那七项换了盖章的人，
新加一条用例逐字段问（`tests/idempotency.rs` 的
`the_record_on_the_per_page_path_still_names_the_verdict_and_its_reason`），
并钉住逐页那条路上理由不带 `driven by page`——定档页在那条路上恒不在场，
`driver()` 两边都回 `None`。**没有建一份基线二进制去做逐字节对拷**：
那要在这台机器上再冷建一整棵树，而三个兄弟 worktree 正同时在跑。

**溢写那条路原样在。** 编好的字节照旧过 `--cache-budget` 这道闸，装不下照旧溢写；
换掉的那一段参照从账上撤下来，临时文件不缩——那一段死字节占的是盘，不占内存。
`CacheUsage` 那几格因此说的是「这一卷**为缓存留下过**多少」：换字节时旧那一段撤账，
而写出那一遍取走一页**不**撤——报告在决策点上与收摊时各拼一次，两次要说同一个数。
收 **Q425**。
`tests/pipeline.rs` 新加一条：同一卷在 512M 与 0 两种预算下走逐页那条路，
写出的字节逐字节相同、判定逐格相同。

**覆盖项那一档答不出来时窗口让位。** `pinned` 问的是「其余页那一组」的候选集，
而哪一组是其余页要等整卷判完几何门才知道。两组答案相同时碰卷之前就答得出；
`--bit-depth 2` 这种一组剩两个、另一组剩一个的参数上答不出，那一卷**不开窗口**，
照旧攒整卷参照——与本票落地之前逐字节相同。收 **Q424**。

**验收第 1 条勾了，而界只有一半是严格的。** 「窗口长度跟着迟滞的回看长度走」严格成立
——`2·PAGES-2` 由 `hysteresis::PAGES` 推出，有用例顶满地钉着，代码里没有第二份常数。
「参照只在一个有界窗口内存活」在**序列**上成立，在卷内页序上打折：抢跑到的源页要等
排头那张算完才编得进序列，其间它的参照还是参照，那一批有多大由计算层的进度差定。
没有降级成不勾，是因为本票**没有新增**一条随卷长涨的路径——最坏情形退化成落地之前
「攒一卷参照」的样子。收 **Q432**（另见 **Q428**）。

**验收第 3 条没勾。**「峰值内存显著下降」是个量，而 `_samples` 语料不在这台机器上，
这一轮量不出来；`docs/measurements.md` 是实测数字唯一的出处，推一个数写进去就是造假出处。
结构那一半钉得住（参照只在有界窗口里活着），数那一半留给 `two-pass-rework/16` 那趟重跑。
收 **Q429**。
