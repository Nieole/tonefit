# 两遍管线：说清它在做什么，拆掉它白付的账

Status: ready-for-agent

## Problem Statement

跑起来之后屏上只说「第一遍」「第二遍」。用户看得见进度在走，看不出**在做什么**、
**为什么非做两遍不可**——而这正是一个真实用户问出来的第一个问题。

往下一层，这两遍本身有一大半是替**卷级上包络**付的账。上包络要看完整卷才定得下基准档，
所以第一遍解码完不能直接写出去，得把缩放后的参照攒在缓存里等汇总，第二遍再取回来量化编码。
ADR 0005 为这笔账列了三条理由，今天只剩一条成立（另两条一条从未实现、一条与实现对不上），
而那一条被 `--per-page` 一关就没了——那条路上参照缓存整趟白付。

再往下，实测说明上包络在真实素材上买到的东西比预想的少，付出的体积代价比预想的大。
（原先撑这一句的是八卷 1852 输出页那一趟，判据换了之后作废、已删，见《实测（作废，数字已删）》；
今天成立的读数是 `docs/measurements.md`
《逐页判定在 B 类素材上值 4.5%，而默认比一刀切 4bit 还贵 7.3%》，它同样早于改判据那一批。）

## Solution

四件事，互相独立，各自开票：

**P-A 语义化**——遍名从「第一遍/第二遍」换成说得出在做什么的名字，「为什么」下沉到 `?` 那张表；
词汇表里一词两名的 `段`/`遍` 并成一条；卷表那两列换成默认路径上真正有信息量的那一列。

**P-B 白付清理**——五处「开关关掉了消费者、生产者还在跑」，内存两处、墙钟三处。
与 P-A / P-C 都不耦合。

**P-C 默认翻成逐页**——卷级上包络从默认降为 `--envelope` 显式打开；
默认路径改走逐页判定，不做迟滞（ADR 0018）。带两道闸，闸不过不动代码。

**P-D 页级幂等**——P-C 之后，「跳过的单位只能是卷」那条推导失效，幂等单位降到
「这一页」。四件里最大的一件。

## User Stories

1. As a 用户, I want 横条上那个词说得出这一遍在做什么, so that 我不用去读源码才知道程序在忙什么
2. As a 用户, I want 按 `?` 能看到三遍各自为什么非做不可, so that 我明白为什么一卷要走两遍而不是一遍
3. As a 用户, I want 跑到一半按下 Ctrl-C 之前知道现在停下来会留下什么, so that 我能判断该不该现在停
4. As a 用户, I want 卷表那一列告诉我这一卷用了哪几档、各多少页, so that 我看得出这一卷的位深到底齐不齐
5. As a 用户, I want 展开一卷时看得到各阶段花了多少时间, so that 一趟跑得慢的时候我知道慢在哪一步
6. As a 用户, I want 位深默认逐页选最低可用档, so that 我不为整卷里少数几页的需要付全卷的体积
7. As a 用户, I want 一页孤立地要求更高的档时不把它旁边的页一起抬上去, so that 体积不被个别页绑架
8. As a 用户, I want 需要卷级齐整时能显式打开上包络, so that 翻页颗粒感一致这件事仍然要得到
9. As a 用户, I want `--per-page` 这个已经变成默认的开关在我用到时明确告诉我, so that 我的旧脚本不会静默地做了别的事
10. As a 用户, I want 试算那一趟不为它根本不会编码的彩页做整套缩放, so that 彩色面板上的试算不白等
11. As a 用户, I want 位深与抖动都点名之后不再为第二遍攒参照, so that 我完全指定参数的那一趟内存占用降下来
12. As a 用户, I want 默认路径上不再为第二遍攒参照, so that 峰值内存不再随卷长线性涨到撑不住
13. As a 用户, I want 改了卷里一页之后只重做那一页附近, so that 两百页的卷不因为一页重跑一整卷
14. As a 用户, I want 跑到一半崩掉之后接着从没做完的地方走, so that 我不必从头再来
15. As a 用户, I want 翻默认导致的全库重跑被明确告知, so that 我知道下一趟为什么全部不命中
16. As a 用户, I want 报告里的判定理由说得出这一档是怎么来的, so that 我能复盘一卷为什么是这个位深
17. As a 用户, I want 打开上包络那一趟仍旧指得出定档页, so that 「哪一页把整卷拉上去了」还答得出来
18. As a 用户, I want 默认路径上卷表不摆一列每行都写着同一句话的格, so that 窄屏上宽度让给真正有内容的列
19. As a 开发者, I want `段` 和 `遍` 在词汇表里只剩一个词, so that 我读文档时不必猜这两个是不是同一样东西
20. As a 开发者, I want ADR 0005 与 ADR 0006 里已经不成立的理由被就地改掉, so that 我照 ADR 做决定时不被过期陈述误导
21. As a 开发者, I want 那几处白付有用例钉着, so that 后来的改动不会把它们悄悄加回来
22. As a 开发者, I want 迟滞的规则在没有基准档时也定义得清清楚楚, so that 我实现得出来、也测得出来
23. As a 开发者, I want 一页的幂等依据只取决于这一页自己, so that 页级哈希算得出来（ADR 0018 之前这条写的是「回看长度是有界常数」，那时默认路径带迟滞）
24. As a 维护者, I want 翻默认之前有一次盲测兜底, so that 「尽量不影响阅读效果」这条前提不被悄悄破坏
25. As a 维护者, I want 实测数字与文档对不上的那一处查清楚, so that measurements 仍旧是实测数字的唯一出处
26. As a 维护者, I want 四件事各自开票, so that 一张票的失败不拖住其余三张
27. As a 用户, I want 试算停在决策点时那一卷仍旧一个字节都没写, so that 答收尾等价于一次干净的试算
28. As a 用户, I want 中止停在第一遍时输出目录纹丝不动, so that 中止不留半份产物
29. As a 用户, I want 打开上包络与默认逐页两条路的报告都说得出自己走的是哪条, so that 我不会把两趟的结果混着比
30. As a 用户, I want 关掉记录那一趟不为没人读的字段做功, so that 我要最快的那一趟真的最快

## Implementation Decisions

### 遍与它的名字（P-A）

- 屏上三个遍名换成**语义名**：`对指纹`（原「幂等这一道」）、`读图定档`（原「第一遍」）、
  `按档写出`（原「第二遍」）。开卷那一支不变。
- **不显示活的当前阶段**。第一遍是满核并行的，同一时刻不同计算线程在不同阶段，
  「现在在做哪一格」没有单一答案；显示一个会乱跳且说不清含义的数比现状更糟。
- 三个遍**各配一句为什么**，落在 `?` 那张表里，不进横条、不进屏底。
  横条在窄档上只有 30 列，只放得下骨架；屏底的单一职责是按键提示，不摆常驻散文。
  `?` 表因此从「键位表」扩成「键位 + 这一趟在做什么」。
- 词汇表里 `段 (Segment)` 与 `遍 (Pass)` 枚举的是同一批三样东西，**并成一条，留 `遍`**
  （代码里那个类型就叫 `Pass`），把「步按它划、卷级计时按它分」并进去。
- **展开一卷时另给阶段耗时分布**。`cost` 那一层今天已经在按阶段记纳秒，屏上一处都不显示；
  这一项只是把已经在算的东西接出来。
- 卷表的 `基准档` / `定档页` 两列换成**档位分布**（`2bit+FS 229 · 1bit 1`）。
  它在两条路上都说得出话：上包络那一路上退化成「一档全包」，正好把「上包络买到了齐整」显示出来。
  `定档页` 跟着 `--envelope` 走，只在它打开时在场——一格在不在场本身就是一句话。

### 白付（P-B）

按省下的是什么分两组。内存两处形状相同、开关不同：

- **默认路径上参照不再进缓存**。见下面 P-C 的「第二遍退化成纯写出」。
- **位深与抖动被覆盖裁到只剩一个候选时，参照同样不必进缓存**。那一档在开卷之前就定死了，
  判据说什么都不改结果，第二遍要用的东西第一遍当场就能做完。
  注意与既有的「覆盖了判定也照求判据曲线」分清：那一条是有意的（试算要说得出你点的那一档判据是多少），
  它只覆盖判据求值，**不覆盖缓存这一趟往返**。

墙钟三处：

- **试算 × 彩色面板：彩色缩放整套白付**。试算不编码，而编码是缩放结果的唯一消费者；
  缩放要的那个比例只靠两个尺寸做算术，不需要像素。现有注释只想到了省编码。
- **命令行那一路每卷白拼一份卷报告**。决策点交给观察者的那一份，命令行一侧一个字节都不读。
  判空的谓词选错了一层：该问「有没有人会读它」，问成了「有没有观察者」。
- **关掉记录时来路白造**。它的读者在那一趟全断了。量级很小，算卫生。

### 默认翻成逐页（P-C）

- 默认路径 = **逐页判定**，不做卷级聚合、**不做迟滞**（ADR 0018）。每一页拿到判据说它要的那一档。
- **段式迟滞曾在这里**（10 号票落地），09 号票真机之后去掉：它压回的那一档 74% 看得见色带，
  而它防的「翻页跳变」被判为不是问题——漫画页本来就是一页一个内容。理由与备选全在 ADR 0018，
  这里不复述。
- `--envelope` 显式打开卷级上包络与迟滞的旧形态。`--per-page` **报错并指路**，不留成不做事的别名——
  留着最坏：脚本里那一行看着还在，行为已经反过来，而且它现在是默认，写不写都一样。
- **认下全库重跑**：逐页与否是参数哈希的输入项，默认一翻，从没点过这个开关的用户全部不命中。
  这一条写进 ADR 的《后果》——不写下来，将来没人知道那次全库重跑是从哪来的。
- **第二遍退化成纯写出**：第一遍算完判据当场量化编码，缓存改存**编好的字节**而不是参照。
  彩色分支今天已经是这条路。
- **不做真单遍**。写出仍要等全卷：一页失败整卷进隔离目录，而哪页失败要解过才知道；
  拆分加序号的成员名可能撞上卷里本来就有的成员，那一撞要在写出第一个字节之前拦下。
  更要紧的是「第二遍开始之前一个字节都没写」这条不变式被中止与决策点同时依赖着——
  答收尾等价于一次干净的试算，正因为那时什么都没写。真单遍要把这些全部重新论证一遍。
- 词汇表里 `上包络` `基准档` `其余页` `定档页` `特例页` **保留原义**，只标注它们描述的是
  `--envelope` 那条路。这几个词说的是那条路内部的构造，那条路还在，改写反而把一套自洽的说法拆散。
  要改的是「默认走哪条路」那一句。
- ADR 0005 与 ADR 0006 **改原篇**，照 ADR 0012 的先例：状态行加修订记录，被推翻的那条决定就地改写，
  另开一节说清原来那条理由为什么不成立。新开一篇 supersede 会让这两个编号在几十处代码注释里指向过期内容。

### 页级幂等（P-D）

- 幂等单位从**卷**降到**「这一页」**。默认路径上一页的档只取决于它自己（ADR 0018），页级哈希因此成立。
- ADR 0006 那条「源哈希的作用域是卷」的推导**只对上包络成立**：它论证的是基准档由全卷定，
  而逐页判定根本不看别的页。
- 要认的复杂度：跨页拆分让输出页与源页不是一一对应——ADR 0006 里那个**来路**概念正是为这件事留的。
- 卷仍旧是**去处**（隔离目录）、**撞名**与**透传文件**的单位，这三样不跟着降级。

## Testing Decisions

好的用例只测**外部行为**：同一个输入下 `run` 交出来的报告、以及屏上画出来的那几行字。
不测私有函数、不测调用次数、不主张任何具体秒数（那是机器快慢，不是被测代码的性质）。

**接缝优先用已有的，新开只有一处。**

- **`run(Request) -> Report`**——P-C 与 P-D 全落这一条。既有的卷级档位一致性、
  离群页单独定档、幂等跳过与参数变更重做、隔离目录、试算不写输出都在这里，
  逐页判定、页级幂等是同一批断言的延伸。
- **draw 层的成屏文字**——P-A 全落这一条。既有那些逐字符快照就是先例：遍名、`?` 表多出来的那一节、
  卷表换列、展开那一副多出来的阶段耗时，都是「画出来的字变没变」。
- **`render` 的行与格**——卷表那一列的措辞落这里，纯文本与表两副排版共用一份措辞。
- **新开的那一处：窄计数器**。P-B 那几条的性质是「这件事不该发生」，报告上与屏上都没有信号。
  照 `VolumeReport::decodes` 的先例办——计数器不进渲染，只给用例钉不变量
  （既有用例形如「跳过的卷还是解码了」）。加的是缩放次数与参照进缓存次数两个数，
  **不把阶段耗时那张表整个公开**：那张表按它自己的文档是各线程墙钟之和，是记账，不是不变量。
- **黄金回归会动**。翻默认改变判定与输出体积，快照要显式接受，不能顺手覆盖。
- **真实素材冒烟**照旧 opt-in，不提交任何素材。
- `tests/timing.rs` 是「没走过的段该是零」这类结构断言的先例，P-B 的用例照它的路子写。

## Out of Scope

- **真单遍**（写出不再等全卷）。理由见 Implementation Decisions。
- **把去处、撞名、透传三样也降到页级**。P-D 只降判定与跳过的粒度。
- 上包络那条路自身的算法改动。它降为可选，形态不动。
- p95、迟滞页数、特例页那两个数的标定。四个数至今是未标定占位值，本 spec 不碰。
- 固定元素检测、单次仿射、32 页滞后窗口、编码器接口、SSIMULACRA2 仲裁——
  这些在 ADR 里被引用过但从未实现，本 spec 只把引用它们的**理由陈述**改掉，不实现它们。
- 会话层每帧重拼行表那一处。看着像白算，实际视口要的正是折行之后的总行数，不是白付。

## Further Notes

### 两道闸

P-C 动代码之前要过两道，闸不过就停在这里：

1. **卷级扫描表与本次实测对不上——查清了，闸开（`08`）。** 对不上的是**几何**，
   不是语料、不是判据：画集 Venus 那一格出在**裁边**，Bowing 那一格出在**适配方式**，
   两趟之间判据的数一位没动。Venus 那「三份形态」实际是同一个文件（硬链接）加它的摊开目录、
   逐字节相同——「用的是哪一份」没有答案，因为只有一份。经过与数落在
   `docs/measurements.md` 的《这张表有两格与今天的默认不同，差的是几何、不是素材》
   与《卷级扫描表：施测条件与八卷语料》。
   **但这一闸放行的不是下面那组数**：见《实测》那一节，那组数因为另一个原因作废了。
2. **那批降配页要做一次盲测**。既有流程现成：真实输出、盲标、逐组全排序。
   偏离页里画集占九页，而画集恰恰是连续渐变最多的素材——盲测里 4bit 不抖的色带就是在画集上露出来的。
   降配之后会不会看得见色带，判据答不了，只有眼睛答得了。
   这是整个改动里唯一一处质量可能真的下降的地方。

### 实测（作废，数字已删）

原先这里有一组 boox-poke6、八卷 1852 输出页的逐页／上包络对照，`08` 把它删了。
**删掉的理由不是闸 ① 那条对不上**（那一条查清了，差的是几何），而是它的**判据与阈值都不在了**：

- 颗粒可见度地板从绝对值改按格点间距收费之后，同一批八卷**一卷都不再落在 `2bit+FS` 上**
  （`docs/measurements.md`《卷级扫描：界在这条窗口里挪动，八卷基准档一卷都不动》），
  而那组数的头一行正是「1822 页（98.4%）落在 `2bit+FS`」；
- `DEFAULT_THRESHOLD` 已由 5.5 降到 5.123，单这一步就动了 1187 页里的 66 页逐页判定。

**实测数字只有一个出处，作废的那一份不留第二处。** 那一趟留下的、与判据无关的口径
（1852 输出页 ＝ 1187 源页 ＋ 665 切开页）已经落进
`docs/measurements.md`《这张表有两格与今天的默认不同，差的是几何、不是素材》。

> **P-C 的「三条路的账」现在没有实测撑着。** 上包络与逐页各自的代价，今天成立的读数是
> `docs/measurements.md`《逐页判定在 B 类素材上值 4.5%，而默认比一刀切 4bit 还贵 7.3%》
> ——那是另一批语料（`_samples/网络资源` 98 卷 2771 输出页、kobo-libra-2），
> 而且**它也是在改判据之前测的**（`dd72b0a`，2026-09-09，早于 `b6106fb` 与 `5784fff`）。
> 翻默认之前要不要按今天的判据重测一遍，是 `10`／`11` 自己的闸，不是 `08` 的
> （停车场 **Q497**：三张票各有一处还引着被删的数；**Q498**：顶上来这一节自己也过期）。

### 顺序

P-A → P-B → P-C → P-D。P-A 最小、风险最低，而且它直接答掉最初那个问题；
P-B 与其余三件不耦合；P-C 卡在两道闸后面；P-D 只有 P-C 落地之后才谈得上。
四期之间没有代码耦合，真要并行也行，但票必须分开——P-C 一期就要动两篇 ADR 加词汇表。

### ADR 漂移（顺带记下，不是本 spec 的交付目标）

审 ADR 时另外撞见几处「理由陈述与实现对不上」，与本 spec 的成本无关，单独记着：
ADR 0002 承诺的仲裁与 fast 档从未存在；ADR 0004 的编码器接口与「试编码」整段是空头；
ADR 0003 的「试编码开销一并减少」那半句因此也不成立；ADR 0001 后果里描述的三段流水线只有两段；
ADR 0008 说那笔模糊「靠边缘自适应 unsharp 找补」，而锐化不存在；
ADR 0009 的「重跑一个点名的子集是分钟级」被 ADR 0014 抽掉了前提（点名一个库就是几千个卷）。
