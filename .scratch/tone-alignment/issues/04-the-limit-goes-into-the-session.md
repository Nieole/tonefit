# 04: 会话的口味层调得动

**What to build:** 在会话里跑的用户按 `↑↓` 走到「纸白对齐上限」那一行、`⏎` 进去改成 4、再按一次试算，就看得出这一趟会对齐多少页——不必退出会话去敲命令行。改完存进预设也是同一条路。

它与「拆分阈值」同型（一个数值项，取值栏里编辑），**不需要新机制**；这一张的大头是口味层从十一项变十二项之后，那几幅写死的版面用例要跟着重画。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 口味层多出「纸白对齐上限」一项，位置与其余口味项同列
- [ ] 走 `焦点` 已有的那一套：`左栏` → `编辑一行` → `取值栏`，进出键与「拆分阈值」一致，不新造键
- [ ] 三层**只读那几个阶段**照旧只读（跑着、等答话时一个改动键都不派），与焦点在哪无关
- [ ] 取值改完之后**下一趟**生效，趟与趟之间改得动（会话的定义就是这个）
- [ ] 「存成预设」把这一项一并存进去（与 03 同一份取值写法）
- [ ] `让位` 那一套照旧管它：宽度不够时左栏先缩、缩不下整个让掉；高度不够时按既有次序让
- [ ] `视口` 与滚动条按多出来的这一行重算——滚动量是算出来的、不是记着的
- [ ] 那几幅写死的版面用例（`src/session/draw/` 下的）跟着重画，**差异审查后接受**
- [ ] 闸门三条绿（`cargo xtask gate`）
