# 05: 默认值抬到 4，黄金快照接受一次

**What to build:** 不加任何参数的用户，从这一张起也拿得到纸白对齐——全语料里 **43% 的页**纸白离格，其中 37.6% 离格 1 级、3.2% 离格 2 级，它们的白底从此不再撒点。上一趟的输出自动过期整卷重做，不会被幂等静默跳过。

这一张**只动一个默认值**，代码路径在 01 就已经全部到位。拆成两步是为了避开一个循环：`metric-recalibration/04` 那次真机标定要在**未对齐**的素材上做，而对齐会改变判据读数。

**Blocked by:** 01、02，以及 **`metric-recalibration/04`**（跨批：那次标定必须先在未对齐素材上跑完）

**Status:** ready-for-agent

- [ ] `--white-align-limit` 的默认值从 0 抬到 **4**
- [ ] 4 这个数是**数据给的断口不是拍的**：全语料 1202 页里钳制宽度 ≤4 覆盖 99.1%，而 **4 与 8 之间一页都没有**；超出的 11 页都是「另一批扫描」混进来的（measurements 的《全语料普查：四成三的页纸白不落在格点上》）
- [ ] **它仍然是未标定的占位值**，报告与 `CONTEXT.md` 的《尚未确立》照旧标着——本张不把它变成「测出来的数」
- [ ] **黄金快照的判定与体积变动，差异审查后显式接受一次。**那一篇存在的理由就是「防止调优在无人察觉时改变判定结果」，这次正是它该拦下的那种改动
- [ ] 旧输出**自动过期整卷重做**：默认值在参数哈希里（01 已落），幂等这一次拦得住。有一条用例钉住它
- [ ] 报告那一行（02 已落）在默认跑法上说得出「对齐了 N 页」，不再是「没开」
- [ ] 闸门三条绿（`cargo xtask gate`）

> **落地之后要回头看一件事**：spec 的《Further Notes》记着，真机 D 组是 2:2 平，而理由分成两半——判读者选抖动的两次是因为**文字**（2bit 不抖把 40~60 的笔画就近推到 85），选不抖的两次是因为**背景**。纸白对齐只治背景那一半。文字那一半归判据，在 `metric-recalibration` 那一批。**这一张不该被期待去修文字那一半。**
