## 落地之前要补一次真机

**这一张一落地，`metric-recalibration` 手上那批真机约束就悬空了**，而那批约束正是
`04` 全部结论的地基。原因是实测的，不是推的：

`04` 用的 B 组四页（武器原档，纸白 253）**真机判「2bit+FS 不可接受、4bit 不抖更干净」
——那是在未对齐的素材上判的**。对齐之后纸白钳到 255，FS 在白底上一个点都不撒，
**那个「不可接受」的原因当场消失**。把那四页按 `01` 的定义钳一遍再跑判据：

| B 组四页 | 对齐前 | 对齐后 |
|---|---|---|
| `2bit+FS` | 3.25 ~ 3.54 | **1.70 ~ 1.84** |
| `4bit 不抖` | **恒 2.000** | **0.66 ~ 0.70** |

第二行是好消息，正是本 spec 第 36 行要的那件事：**判据不再为「纸白不是 255」
向 4bit 不抖恒收《离格量》的费**（`.scratch/非阻塞问题.md` 的 Q433）。

**但第一行意味着 `04` 那条约束的前提没了。**「对齐后 B 组该判哪一档」**目前没有真机数据**，
而两种答案的后果差得很远（实测，脚本在 `.scratch/metric-recalibration/calibration/`）：

- 仍判 **≥4bit** → 判据的可行域倒挂 **3.10**，比对齐前（1.95）**还大**
- 改判 **2bit+FS** → 那批页的要求全变成同一档，判据在它们上面失去区分力
  （搜出来的「解」是颗粒地板 0.550、掩蔽不打折——**颗粒项恒零**，等于退回「只剩低通项」，
  正是 ADR 0002 立颗粒项要防的那件事）

**所以：抬默认值之前，把对齐后的那四页重判一遍。**四对，成本很小；不判就抬，
`04` 那批结论会在无人察觉时失去地基。材料照 `真机包04` 的先例造
（交错编、强制配平、页上无标注、逐页比字节自检）。

> **顺带一条要改的**：本 spec 的《Further Notes》写着「上限那个数……**已拍板并进
> `metric-recalibration/04` 那次上机一起看**」。**那一条没兑现**——04 上机时
> `--white-align-limit` 还没落地（`01` 是 `ready-for-agent`），造不出对齐版本的材料，
> 那个数因此**仍未标定**。依赖顺序是 `01` → 上机 → `05`，而实际是 04 先走了。
> 上限那个数要么随这次补测一起看，要么继续挂着占位值。

> **落地之后要回头看一件事**：spec 的《Further Notes》记着，真机 D 组是 2:2 平，而理由分成两半——判读者选抖动的两次是因为**文字**（2bit 不抖把 40~60 的笔画就近推到 85），选不抖的两次是因为**背景**。纸白对齐只治背景那一半。文字那一半归判据，在 `metric-recalibration` 那一批。**这一张不该被期待去修文字那一半。**

### 补测结果（第十轮，2026-09-09）

**四对，4/4 分不出。**对齐把第六轮 B 组那条「4/4 判 `4bit 不抖` 更干净」**溶掉了**
——它拿走的正是那次判读的理由：白底上撒着的 2.4% 抖动点。

| | 对齐前（第六轮 B 组） | 对齐后（第十轮） |
|---|---|---|
| 真机 | **4/4 判 `4bit 不抖` 更干净** | **4/4 分不出** |

| 判据 `4bit 不抖` | 恒 2.000 | **0.655 ~ 0.699** |
| 产品判定 | `4bit 不抖` | `2bit+FS` |

`tonefit --no-crop --no-split --per-page --dry-run` 复现过。

**所以本票上面那一问「对齐后 B 组该判哪一档」有答案了：两档在眼睛里没有分别。**
产品今天给 `2bit+FS`（升序里第一个进阈值的），体积更小，观感上不欠什么。
本节上面列的那两种后果（「仍判 ≥4bit 则可行域倒挂 3.10」「改判 2bit+FS 则失去区分力」）
**都不再是这一票要背的账**——`grain-floor-absolute/04` 已撤（wontfix），
那批可行域约束随它一起作废。

### 先钉后果，再改那个数

这一张只改一个默认值，**重量全在后果上**：先把「默认跑法上会变成什么」写成会红的断言，
再动那个数。改之前跑一趟，**六条红各红在自己那一句**：

| 红的那一条 | 红在哪一句 |
|---|---|
| `metadata::every_parameter_that_changes_the_output_changes_the_hash` | `改了纸白对齐上限，哈希没变`（左右同一串 `ae6acc51…`） |
| `idempotency::a_changed_parameter_redoes_the_volume` | `关掉纸白对齐之后这一卷仍然被跳过了：Some(Skipped { page_count: 2 })` |
| `main::…_defaults_to_four` | `默认值不是 4：… left: 0 right: 4` |
| `main::…_what_it_defaults_to_and_what_zero_means` | `--help` 里没有「默认 4」 |
| `render::the_default_limit_says_how_many_pages_it_aligned` | `默认那一趟屏上还说着「没开」：纸白对齐 上限 0 级（没开） · 对齐 1 页 …` |
| `pipeline::the_default_run_aligns_an_off_grid_page` | `left: Some(Off) right: Some(Aligned { paper_white: 253 })` |

头两条那个红**是这一票最要紧的一条证据**：那两格原本写的是「把上限改成 4」，
而默认值一旦就是 4，**它们会绿着而什么都没验到**。翻成「关回 0」之后红了出来。

### 默认值是一个会移动的锚

改一个默认值会让两族用例静默失效，本票撞见**四种走法，一种比一种难看出来**：
**空操作 · 断言漂了 · 主语没了 · 同一个数在一条用例里有两个出处**。
四种各是什么、各在哪一条上现形，**权威位置是停车场的 Q547**，本节不复述。

本票动的是那七处：问「取 0 的语义」的一律点名 `WhiteAlignLimit::OFF`，
问「默认那一趟」的一律点名 `WhiteAlignLimit::default()`，
四段拼合那一条改成**从同一份报告里拿**（`report.white_align_limit`）。
七处点名之后，**默认值再动一次，红的正是该红的那几条**。

> **我自己 Q547 记的那一族，却栽在自己手里。**本票新写的那条 `--help` 用例，断言写的是
> `help.contains("默认 4")`——**把那个数写死成了第二份**：默认值再动一次而帮助忘了跟着改，
> 它照样绿。从写下 Q547 到犯这一次，隔了几个小时。
>
> **那不是打脸，那是这一族最强的证据：知道一个坑在那儿，防不住掉进去；只有让它会红才防得住。**
> 改法正是让它会红——`format!("默认 {}", WhiteAlignLimit::default())` 拼出来比
> （`/code-review` 的 Spec 轴指出）。`--help` 里那一句实际没被折行，
> `**默认 4 级，即默认开着**。` 整句坐在一行上，断言没碰到折行边界。

### 黄金那一趟：**没有差异可审**，而那分两层

- **不是没做差异审查，是审查发现没有差异可审。**`cargo test --test golden` 直接绿，
  `TONEFIT_ACCEPT_GOLDEN` 一次都没设，`tests/golden-snapshot.txt` 全程在 `git status` 下是空的。
- **而「没有差异」不是因为判定没变，是因为这一篇看不见这条路。**

判据是 `clamp_width = 255 − 纸白`，上限 4 ⇒ **只有纸白落在 251~254 的页钳得动**。
逐页量过，**89 页里 `Aligned` 出现 0 次**：

> 量的是**合成夹具**不是语料。要复现，把那句挂回去跑 `cargo test --test golden -- --nocapture`。

纸白多半正好是 255」。记 **Q550**（同族 Q544 与 `two-pass-rework/06` 那句
「它没红，在这条路上不是证据，是它根本没看」）：推荐给黄金加一卷纸白 253 的页
（`fixtures::page_with_paper_white` 现成）——**加了之后，默认值下一次再动，它当场红**。

`tests/golden.rs` 里那句注释先写成了「经差异审查显式接受过一次」，**那是假话，在写下去之前
自己改成了真话**，并写上逐页量出来的那几个取值（Q532 说的正是这类假话会被写回来）。

### 票面《落地之前要补一次真机》里，哪几段是历史、哪几段还活着

**三段是历史，不是活的约束**：

- 「仍判 ≥4bit → 可行域倒挂 3.10」与「改判 2bit+FS → 判据失去区分力」这两条后果推演，
  站在 `grain-floor-absolute/04` 那批可行域约束上，而 **`gfa/04` 已 wontfix**
  （连同 `metric-recalibration/06`），那批约束随它作废。
- 「所以：抬默认值之前，把对齐后的那四页重判一遍」——**做完了**：第十轮 4/4 分不出，
  并已由 `01` 用产品重渲比字节核销掉那条 ⚠️ 限定。**「对齐后 B 组该判哪一档」这一问本身
  已经不成立**：两档在眼睛里没有分别。

**两条仍然活着**：

- **上限那个数仍未标定。**spec 说它「已拍板并进 `metric-recalibration/04` 那次上机一起看」
  ——那一条没兑现（04 上机时这个参数还没落地）。本票**照旧标着未标定**，

### 与票面对不上的两处
