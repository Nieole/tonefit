# 01: 纸白对齐落进管线，命令行调得动，默认关

**What to build:** 用户加上 `--white-align-limit 4` 之后，纸白离格的页在白底上**一个抖动点都不撒**——那正是真机上被判「明显影响观感」的那一类劣化（measurements 的《真机三组》B 组，四对全票）。不加这个参数时**一页都不改**：默认取 0，产物与今天逐字节相同。

这一张是整条路的 tracer bullet：量出纸白、按守卫决定改不改、改了之后参照与输出一起跟着走、参数在命令行上调得动、改了参数旧输出会过期。少任何一环这条路都跑不通。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] **纸白对齐是一个纯函数**：`GrayImage` 进、`GrayImage` 加「这一页做了什么」出。不碰文件系统、不碰全局状态，与 `score` 同型
- [x] **纸白的定义可执行**：页面上最大那块严格平坦区（3×3 邻域方差为 0 的像素里出现次数最多的灰度）。不取最亮像素，不取高百分位（理由见 spec）
      ⚠️ **这一条的括号外与括号内不是同一件事，落地照的是括号内。**现成那份实现（`survey_flat.paper_white`）取的是**全页零方差像素的众数**——`flat` 是一张散布全页的掩码，一次连通域分析都没有；「最大那一块里的众数」与它只在最大那块恰好也是最常见取值时才同解。口径一致才比得了字节（第十轮那四页就是拿它量的），因此**行为照实现走**，而本票自己那几处措辞（`CONTEXT.md` 的《纸白》、`src/white.rs`、`--help`、夹具）一律写成真的那一句。仍写着「最大那一块」的三处（本条、`survey_flat` 的文档字符串、measurements 那一节）**一个字没改**，记 **Q520**
- [x] **对齐的手段是钳制近白**：`[纸白, 255] → 255`，低于纸白的取值一个都不动。不做线性拉伸，不做整幅平移
- [x] **三条守卫各有一条用例**：《离格量》为 0 不动 · 离格量超过上限不动 · 平坦区不足（量不出纸白）不动。三种情形都**整页逐像素不变**
      三条各把守卫按反跑过一次，红都看见了。**其中头一条的红只在标签上**：离格量为 0 时钳 `[255,255]` 本来就是恒等，拆掉那条守卫像素一个都不会变——它管的是「这一页做了什么」，不是像素
- [x] **对齐之后那一页的纸白恰好是 255**，且该页在 `2bit+FS` 上的平坦白底**一个点都不撒**——这一条直接钉住整件事的目的
- [x] **上限取 0 时任何输入逐像素不变**（这是「关闭」的语义，不是另设开关）
      **是双保险**：`limit == 0` 那条短路拆掉之后，离格那条守卫照样把每一页拦下（`离格量 > 0` 恒成立），像素还是不动。短路挡的是白花的工夫，守卫挡的是像素——这一条写进了 `align_white` 的文档
- [x] 对齐发生在**缩放之后、构造参照之前**——**参照与其后一切量化用的都是对齐过的像素**，判据两侧因此同源，量化仍是唯一被隔离出来的变量（ADR 0002 决定第 1 条）。
      **不要把这一条写成「对齐过的图就是进缓存的那一份」**：`two-pass-rework/12` 之后缓存分两副——上包络那条路攒整卷参照，逐页那条路只在滚动窗口里留几页、出了窗口当场量化编码成字节。对齐在两副之前，因此两副都吃得到；说成「进缓存的那一份」在逐页那条路上是假话
- [x] **彩页不经这一步**（ADR 0010：那条路径既不量化也不抖动）；**几何门不成立的页照样对齐**（它只是没有抖动那一维）
- [x] `--white-align-limit <级数>` 在命令行上认得，默认 **0**，`--help` 说得出它是什么、取 0 是什么意思
- [x] **参数进 `metadata::params_hash`**。ADR 0002 的《后果》记过一次同型事故——「地板不在里面……旧输出会被静默跳过」。取值 0 也照样进
- [x] `tests/pipeline.rs` 上有一条：改了这个参数之后旧输出**过期重做**而不是被跳过（写法照 `tests/idempotency.rs`）
      ⚠️ **落点不是 `tests/pipeline.rs`，是 `tests/idempotency.rs`**：那条性质的穷尽数组（`a_changed_parameter_redoes_the_volume`）本来就在那里，往 `pipeline.rs` 里另写一条就是同一条性质的第二个出处。加的那一格是**从默认的 0 改到 4**——「取值 0 也照样进哈希」不成立时唯一漏得掉的正是它
- [x] **两张新夹具**：一张纸白离格的页（现有夹具全是合成图、纸白多半正好 255），一张满版无纸边的页
- [x] `CONTEXT.md` 加三个词条：**纸白**（进《图像内容》）、**纸白对齐**与它的**上限**（进《管线》）。《离格量》已经在《量化》里了
- [x] `CONTEXT.md` 的《尚未确立》记上：**上限那个数未标定**，占位值 4，与 `K`、`MASKING_FLOOR`、`MASKING_KNEE` 同一档待遇
- [x] **黄金快照逐字节不变**——默认 0 意味着一页都不改，这是这一张最强的验收
- [x] 闸门三条绿（`cargo xtask gate`）

### 「产物与今天逐字节相同」只在像素那一侧成立

上面那句话要带一条限定，它咬得到用户：**默认 0 那一趟写出的 PNG，tEXt 里的参数哈希变了**——
`--white-align-limit` 进了哈希文本，取值 0 也进（票面第 11 条要的正是这个，ADR 0002 的《后果》记过漏收的事故）。
于是**默认参数一个字没改的用户，升级后第一趟仍要整库重跑一次**。

**而他今天读不到原因**：报告上没有一个字说得出「哈希变了是因为多收了一个参数」，幂等那一道只答「对不上」、
不答「哪里对不上」。行为不改（那是票面要的），措辞与那一行报告记 **Q522**，落点指向 `02`。

黄金快照按 `--no-metadata` 跑，**验的正好只是像素那一侧**——记录那一侧今天没有任何用例在看。

### 两处被红逼出来的改动

- **`SHORT_HELP_INDENT` 31 → 35。**`--white-align-limit <级数>` 成了最长的开关，`-h` 那一列跟着变深，
  `the_help_folds_every_line_into_the_terminal` 当场红——**那个常量的文档预言的正是这一句**。
  顺带写下此前没人写过的一件事：**clap 排版按字符数算，而中文一个字占两格**，
  所以那个数不等于「最长开关的显示宽度」；落在屏上最深的那几行是**值名里中文最多的**
  （`<滤波器>`、`<字节数>`），不是撑开那一列的 `--white-align-limit` 自己。
- **满版无纸边那张夹具改了两次，两次都是因为「用例够不到它要验的东西」**（**Q521**，同一票内两例）：
  最亮 186 → 252（不然硬猜出来的纸白离格太远，被上限守卫拦下，逐像素那一半白测）；
  背景又补一块 68×68 的 253，内部 4356 个平坦像素——**照 measurements 里画集 Venus 实测那 4430 取的**
  （不然拆掉 `MIN_FLAT` 门限时众数落到 0、离格 255 级，**又**被上限守卫拦下）。
  两次拦下它的是同一条下游守卫，那条结论写在 Q521 里：**多重守卫串起来时，上游那道失效不会红。**
