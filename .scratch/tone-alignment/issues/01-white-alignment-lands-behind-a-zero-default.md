# 01: 纸白对齐落进管线，命令行调得动，默认关

**What to build:** 用户加上 `--white-align-limit 4` 之后，纸白离格的页在白底上**一个抖动点都不撒**——那正是真机上被判「明显影响观感」的那一类劣化（measurements 的《真机三组》B 组，四对全票）。不加这个参数时**一页都不改**：默认取 0，产物与今天逐字节相同。

这一张是整条路的 tracer bullet：量出纸白、按守卫决定改不改、改了之后参照与输出一起跟着走、参数在命令行上调得动、改了参数旧输出会过期。少任何一环这条路都跑不通。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] **纸白对齐是一个纯函数**：`GrayImage` 进、`GrayImage` 加「这一页做了什么」出。不碰文件系统、不碰全局状态，与 `score` 同型
- [ ] **纸白的定义可执行**：页面上最大那块严格平坦区（3×3 邻域方差为 0 的像素里出现次数最多的灰度）。不取最亮像素，不取高百分位（理由见 spec）
- [ ] **对齐的手段是钳制近白**：`[纸白, 255] → 255`，低于纸白的取值一个都不动。不做线性拉伸，不做整幅平移
- [ ] **三条守卫各有一条用例**：《离格量》为 0 不动 · 离格量超过上限不动 · 平坦区不足（量不出纸白）不动。三种情形都**整页逐像素不变**
- [ ] **对齐之后那一页的纸白恰好是 255**，且该页在 `2bit+FS` 上的平坦白底**一个点都不撒**——这一条直接钉住整件事的目的
- [ ] **上限取 0 时任何输入逐像素不变**（这是「关闭」的语义，不是另设开关）
- [ ] 对齐发生在**缩放之后、构造参照之前**；对齐过的图**既是参照也是进缓存的那一份**，第二遍量化因此用的就是它（判据两侧同源，量化仍是唯一被隔离出来的变量，ADR 0002 决定第 1 条）
- [ ] **彩页不经这一步**（ADR 0010：那条路径既不量化也不抖动）；**几何门不成立的页照样对齐**（它只是没有抖动那一维）
- [ ] `--white-align-limit <级数>` 在命令行上认得，默认 **0**，`--help` 说得出它是什么、取 0 是什么意思
- [ ] **参数进 `metadata::params_hash`**。ADR 0002 的《后果》记过一次同型事故——「地板不在里面……旧输出会被静默跳过」。取值 0 也照样进
- [ ] `tests/pipeline.rs` 上有一条：改了这个参数之后旧输出**过期重做**而不是被跳过（写法照 `tests/idempotency.rs`）
- [ ] **两张新夹具**：一张纸白离格的页（现有夹具全是合成图、纸白多半正好 255），一张满版无纸边的页
- [ ] `CONTEXT.md` 加三个词条：**纸白**（进《图像内容》）、**纸白对齐**与它的**上限**（进《管线》）。《离格量》已经在《量化》里了
- [ ] `CONTEXT.md` 的《尚未确立》记上：**上限那个数未标定**，占位值 4，与 `K`、`MASKING_FLOOR`、`MASKING_KNEE` 同一档待遇
- [ ] **黄金快照逐字节不变**——默认 0 意味着一页都不改，这是这一张最强的验收
- [ ] 闸门三条绿（`cargo xtask gate`）
