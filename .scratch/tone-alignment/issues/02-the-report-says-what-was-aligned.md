### 最该被记住的那一步：把 `01` 写下的那句区分落成了结构

票面第 3 条要「想自己判断上限该取多少的用户，用 `--dry-run` 看得到逐页的纸白与钳制宽度」。
**而那个用户，按定义，上限就是 0。**`align_white` 上限取 0 时有一道短路，连纸白都不量——
于是他每一页都读到「没开」，**一个数都拿不到**。这一条勾原本打得上，而交付物答不了票面那句话。

出路不是另调一次 `paper_white`（那会多一处量纸白的地方，spec 决定第 14 条正好禁它），
也不是让用户去传 `--white-align-limit 255` 这个反直觉的咒语（为了看清「对齐会做什么」，
先要求最大限度地对齐）。**出路是 `01` 自己写在 `align_white` 文档里的那句话：**

> 这条短路**不是**「0 不改像素」赖以成立的东西：拆掉它，离格那条守卫照样把每一页拦下……
> 两道各挡各的，**短路挡的是白花的工夫，守卫挡的是像素**。

那句区分只有在**有人能分别调用它们**的时候才算数。于是把三条守卫抽成
`white::judge(&GrayImage, WhiteAlignLimit) -> WhiteAlignment`（`pub(crate)`，**只判不改**），
`align_white` 判完只管钳、**短路一格没动**；`--dry-run` 那条路绕开短路直接问守卫。

上限取 0 时守卫答的是真话——`OverTheLimit { paper_white: 253 }`，
「离格 2 级，超过你这一趟的 0 级」，正是那个用户要的数。
**`WhiteAlignment` 五个变体一个没改，也没有第二处量纸白的地方。**

连带的结果比票面要的多一层：默认参数跑一次 `--dry-run`，卷级那一行于是**有数可报**——

```
  纸白对齐 上限 0 级（没开） · 对齐 0 页 · 超限 8 页 · 量不出纸白 1 页
    这一趟没开：上面那几个数说的是开了之后会怎样，逐页那几行各自说得出自己的纸白与钳制宽度
```

**story 14 要的那件事，不用任何咒语就成立了。**

### 三个数不恒在，而那不是漏

上限那一格恒在；**对齐／超限／量不出纸白那三个数只在真量过纸白时在场**。
照做那一趟上限取 0 时一页都没量，摆三个 0 上去是**编出来的字段**——
`CONTEXT.md` 的《格》写着「一格在不在场本身就是一句话」，这一处照它办。
试算那一趟三个数恒在，因为那一趟真判过。

同一条规矩下，**两种卷一行都不出**：一张灰度页都没有的卷（整卷彩页、整卷失败）
根本没经过这一步，跳过的卷一页都没算——与几何门那一段同一条界。

### `/code-review` 逼出来的四处改动

两轴各抓到一处**真的**，两处都不是风格问题：

- **spec 轴：屏上一句假话。**那一句注解原先写「上面那几个数说的是**开了之后会怎样**」，
  而上限取 0 时守卫把**任何**离格的页判成超限——那几个数说的是「照 0 级跑」的结果，
  不是「抬到 4 级会怎样」；真抬上去，超限那几页多半就被对齐了。
  改成「超限那个数在这里等于**离格的页有几张**」，并加一条用例**反着钉**：
  那一句里不许出现「开了之后会怎样」。
- **spec 轴：spec 决定第 10 条没兑现。**「**没能对齐的那几页必须点得出来**——那是
  「我对你的图没做成什么」」。原先只给了三个数，照做那一趟点不出是哪几页
  （逐页那一层只在试算出）。照几何门那句「不成立：…」补一句「没对上：…」，
  **两种模式下都在**，走同一个 `first_few_names`（头三页，其余报个数收口）。
  **上限取 0 时不说**：那时点名的是「离格的页」，是另一件事。
- **standards 轴：一处漏网的 94.6%。**`the_per_page_paper_white_is_a_dry_run_only_thing`
  的文档还引着它，而票面与 Q530 都写着「代码不引它」——那两句因此成了假话。改引两档。
- **standards 轴：`WhiteAlignment::paper_white()` 是我新开的公开方法而全仓没有第二个调用方。**
  收回模块内（那个数已经明摆在三个变体的字段上，读的那一端 `match` 一下就有）。
  顺带删掉脚本抄出来的 20 份逐字重复注释。

**Q529 那句「与几何门完全相同的待遇」也被订正了**，见下。

**那处漏网的 94.6% 是这两轴里最重的一条**，而重在哪儿值得写下来：破口不在那个数
算得对不对（它算得出来），在于**同一件事从此有两个地方各说各的**——其中一处一漏，
另一处（票面第 3 条与 Q530 那两句「代码不引它」）**当场变成假话，而没有任何东西会因此变红**。
这就是「单一出处」为什么是硬规矩，不是文风偏好。订正记进 Q530。

**那条反着钉的断言单记了一条（Q532）。**那一句假话读起来完全合理——落地人写下它、
坐标员背书过它，而正着写的断言拦不住它：`contains("开了之后会怎样")` 只证明
「这句话印出来了」，不证明「这句话是真的」，**措辞越顺口，那条绿越让人放心**。
改法是另加一条反着钉的：那一句里**不许**出现「开了之后会怎样」。
**正着断言一句话说得对很难；反着断言它别说某句已知的错话，很容易，
而且一旦有人写回去当场红。**屏上的措辞没有别的守卫，这正是它值得一条专门手法的理由。
