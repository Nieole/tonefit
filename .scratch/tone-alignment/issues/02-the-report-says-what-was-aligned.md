# 02: 报告说得出这一趟对齐了什么

**What to build:** 跑完之后用户看得出这一趟对每一卷做了什么——对齐了多少页、多少页因为超限没对、多少页量不出纸白。一卷完全没被对齐时，**一行就看得出是哪种原因**：是整卷本来就在格点上（好事），还是整卷量不出纸白（这条做法对它无效）。想自己判断上限该取多少的用户，用 `--dry-run` 看得到逐页的纸白与钳制宽度。

「我对你的图做了什么」属于屏上该说的实话，与《判据聚合》《判据构成》《阈值》连同标定来源一起印是同一条线。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] **卷级恒印一行**：本次上限 · 对齐了几页 · 超限几页 · 量不出纸白几页
- [ ] 一卷里**一页都没对齐**时那一行说得出是哪种原因——「本来就在格点上」与「量不出纸白」是两句不同的话，不是同一个 0
- [ ] **逐页那一层只在 `--dry-run` 出**：每页的纸白取值与钳制宽度。绝大多数页是 0 或 1（全语料 94.6%），恒印没有信息量
