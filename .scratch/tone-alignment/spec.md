# 纸白对齐：把纸白搬到格点上，抖动就不必在白底上撒点

Status: ready-for-agent

## Problem Statement

一整个库批量转出来，有些页的白底上蒙着一层细密麻点，有些页干干净净——同一套参数、同一块面板。
真机上看得一清二楚：武器種族傳說原档那四页文字与线稿，五个人里五个说「明显影响观感」、零接受；
而 B 类的八页几乎分辨不出。

分界线不在画风、不在题材，在一个可以逐页算出来的量上：**源的纸白落不落在输出格点上。**

2bit 的格点是 `0 / 85 / 170 / 255`。平坦白底上误差扩散**必须撒点**，密度就是《离格量》÷《格点间距》：

| | 纸白 | 离格量 | FS 在白底上撒的点 | 真机 |
|---|---|---|---|---|
| 武器原档四页 | **253** | 2 | `2/85` = **2.4%** | **一眼看得见**（4/4 判 4bit 不抖更干净） |
| B 类八页 | **255** | 0 | **0%** | 几乎分不出（6 平 2 偏，零个「不收」） |

而这**不是边角情形**：全语料抽样 1202 页，**43% 的页纸白不落在格点上**，其中 37.6% 离格 1 级、
3.2% 离格 2 级。两部原档与 Forget-me-not 整部都离格。

从纯黑掉 85 级的点撒在纸上，就是用户说的「麻子」。**它完全是量化格点与源纸白错位的产物**——
把纸白搬 1 到 2 级，它就不存在了。

判据现在也看不见它（低通项在那一撒上读零均值，颗粒项的 RMS 低于地板），
那一条由 `metric-recalibration` 那一批修；**本 spec 修的是上游那一半：让那一撒根本不发生。**

## Solution

在**参照构造的最后一步**加一道 **纸白对齐**：量出这一页的纸白，把 `[纸白, 255]` 这一段映到 255，其余不动。

三件事一次做完：

- **白底上的那一撒消失**——纸白落在 255 上，FS 一个点都不撒。
- **4bit 不抖那一档不再被误判**——判据现在为「纸白不是 255」向它恒收《离格量》的费
  （measurements 的《原档的 4bit 读数被纸白钉死在 2.000》），对齐之后那一笔归零。
- **2bit+FS 重新成为可用档**——省体积。

**255 是唯一在三档上都落在格点上的值**（`255 = 3×85 = 15×17`，格点是套嵌的），
所以对齐它等于对三个候选同时对齐，**不必先知道这一页会判哪一档**。

外部先例：Little-CMS 有一个机制完全同构的在产实现，源码注释逐字
`// Locate the node for the white point and fix it to pure white in order to avoid scum dot.`
（`cmsopt.c`）。它默认开，带一个显式关的标志，并有三条守卫——已对齐则不动、
点不落在节点上则放弃、差得太离谱（`> 0xf000`）则不修。本 spec 的三条守卫与它一一对应。
详见 `docs/research/paper-white-grid-alignment-prior-art.md`。

**落地分两步**（见《Implementation Decisions》第 11 条）：
第一步默认上限取 0，代码路径与参数做出来但**一页都不改**；第二步只抬默认值。

## User Stories

1. 作为一个批量转整库的用户，我希望白底上不要出现细密麻点，这样同一套参数在不同作品上的观感才一致。
2. 作为一个批量转整库的用户，我希望这件事**自动发生**，不必逐部作品去调，因为逐部调参正是我要避开的事。
3. 作为一个用扫描件的用户，我希望纸白 253 的源与纸白 255 的源转出来一样干净，因为那 2 级差别我肉眼根本看不出。
4. 作为一个在意体积的用户，我希望原本因白底撒点而被迫升到 4bit 的页能留在 2bit+FS，这样文件更小。
5. 作为一个用 Forget-me-not 这类整部离格素材的用户，我希望整部都受益，而不是零星几页。
6. 作为一个用满版画集（没有纸边）的用户，我希望程序**不要硬猜**一个纸白然后把我的图改坏，宁可原样不动。
7. 作为一个不放心的用户，我希望有一个开关能把这件事整个关掉，且关掉之后的产物与不带这个功能时**逐字节相同**。
8. 作为一个想微调的用户，我希望上限可以调，因为「愿意为对齐牺牲多少色调」是我的取舍不是程序的。
9. 作为一个在会话里跑的用户，我希望这个参数在 TUI 的口味层里改得到，与「拆分阈值」一样，不必退出去敲命令行。
10. 作为一个用预设的用户，我希望这个参数能写进预设的口味层，与其余口味项同列。
11. 作为一个改了这个参数的用户，我希望旧输出**自动过期重做**，而不是被幂等静默跳过——不然我改了没效果还找不出原因。
12. 作为一个跑完想知道发生了什么的用户，我希望报告里说得出这一趟对齐了多少页、多少页超限没对、多少页量不出纸白。
13. 作为一个看到某一卷完全没被对齐的用户，我希望**一行就看得出原因**（是整卷本来就在格点上，还是整卷量不出纸白）。
14. 作为一个跑 `--dry-run` 的用户，我希望逐页那一层说得出每一页的纸白与钳制宽度，这样我能自己判断上限该取多少。
15. 作为一个转彩页的用户，我希望这一步**不碰彩页**——那条路径既不量化也不抖动，对齐对它没有意义。
16. 作为一个页贴不住面板（几何门不成立）的用户，我希望这一页照样对齐——它只是没有抖动那一维，纸白该在格点上还是要在。
17. 作为一个用整卷素材的用户，我希望一页量不出纸白不会连累别的页，因为逐页判定本来就是逐页的。
18. 作为一个对比新旧产物的用户，我希望默认值从 0 抬到 4 的那一次是**一次显式接受**，而不是悄悄变了。
19. 作为一个维护者，我希望这一步是一个**纯函数**，好在不碰文件系统的前提下把它的性质钉死。
20. 作为一个维护者，我希望「纸白」有一个**可执行的定义**，而不是「页面的背景色」这种落不成代码的说法。
21. 作为一个读文档的人，我希望 `CONTEXT.md` 里查得到「纸白」「纸白对齐」「离格量」三个词，因为它们已经散在 measurements 与两篇调研里了。
22. 作为一个日后要标定的人，我希望上限那个数**明确标着未标定**，与判据里其余几个占位值一样，不被误当成测出来的。
23. 作为一个日后要标定的人，我希望第一步落地之后 `04` 号票那次真机标定**不受影响**，这样两件事不必挤在同一次上机里。

## Implementation Decisions

1. **落点只有一处**：灰度路径上，缩放之后、构造参照之前。对齐过的图**成为参照**，也**成为进缓存的那一份**
   ——第二遍量化用的就是它，输出因此跟着对齐。彩色分支不经这里（ADR 0010）。

2. **判据取对齐后的参照。**参照的定义不变（仍是「缩放到目标尺寸后、未经目标位深量化的图」，
   ADR 0002 决定第 1 条），只是它上游多了一步；参照与候选都从对齐过的图来，
   **量化仍然是唯一被隔离出来的变量**。取对齐前的参照等于把自己的修正当成误差收费。

3. **纸白的定义是可执行的**：页面上**最大那块严格平坦区**（3×3 邻域方差为 0 的像素里出现次数最多的灰度）。
   不取「最亮像素」——那是 KCC 的做法，一个亮斑就带偏，且有用户侧报告；
   不取高百分位——大片纯黑页上会取到错的值。

4. **对齐的手段是钳制近白那一段**：`[纸白, 255] → 255`，其余色调不动。
   不做线性拉伸（那会改动整条色调曲线，也是数字档案规范反对得最凶的一类），
   不做整幅平移（那会把纯黑推离格点，在另一头制造同一个病）。

5. **钳制宽度就是《离格量》**（`255 − 纸白`），它同时是这一步的**代价**：被压平的色调有多宽。

6. **三条守卫**，与 Little-CMS 的三条一一对应：
   - **离格量为 0 → 不动**（全语料 57% 的页落在这里）。
   - **离格量 > 上限 → 不对齐**，整页原样。全语料的分布在这里有一个天然断口：
     ≤4 覆盖 99.1%，而 4 与 8 之间**一页都没有**；超出的 11 页都是「另一批扫描」混进来的。
   - **量不出纸白（平坦区不足）→ 不对齐**，整页原样。满版无纸边的页本来就没有大片平坦白底，
     治不到也就没有不治的代价。业界五个工具在这一情形上一律是放弃，本 spec 照做。

7. **一个参数，不是两个**：上限即开关。取 **0** 时只有「本来就在格点上」的页满足条件，
   即一页都不会被改动——**`0` 就是关闭**。
   不另做布尔开关：`--no-crop`、`--no-split`、`--per-page` 三个「关掉什么」的开关在预设里的覆盖是**单向的**
   （命令行没有再开回来的写法），再加一个就是第四个带这条毛病的开关；数值参数没有这个问题。

8. **参数属于口味层**（这一趟愿意为对齐付多少色调，不是面板的物理事实）。三个去处同时到位：
   命令行一个 flag、预设的 `[preset."名字".taste]` 一个键、**会话 TUI 的口味层一项**
   （与「拆分阈值」同型，走 `焦点` 已有的 `编辑一行`／`取值栏` 那一套，不需要新机制；
   口味层从十一项变十二项，`让位` 那一套照旧管它）。

9. **参数进参数哈希。**它改变输出像素，与裁边、拆分同类。ADR 0002 的《后果》里已经记过一次同型事故
   ——「参数哈希收的是……**地板不在里面**……旧输出会被静默跳过」。取值 `0` 也一样进：
   从「关」改到「开」与从 4 改到 2 是同一类改动。

10. **报告出两级**：卷级恒印一行——本次上限 · 对齐了几页 · 超限几页 · 量不出纸白几页；
    逐页那一层（每页的纸白与钳制宽度）**只在 `--dry-run` 出**。
    绝大多数页的钳制宽度是 0 或 1（94.6%），逐页恒印没有信息量；但**没能对齐的那几页必须点得出来**
    ——那是「我对你的图没做成什么」，属于屏上该说的实话。措辞只有一处出处（ADR 0016）。

11. **落地分两步，中间隔着一次真机标定**：
    - **第一步**：代码路径、参数、报告、哈希全部到位，**默认上限取 0**。这一步**一页都不改**，
      黄金快照应当逐字节不变。`metric-recalibration/04` 那次真机标定照常在未对齐的素材上做，不受影响。
    - **第二步**：只把默认值抬到 4，**当作一次全库重跑处理**。因为默认值在哈希里，
      旧输出自动过期、整卷重做——**幂等这一次拦得住**。
    这样拆是为了避开一个循环：04 的标定要在未对齐素材上做，而对齐会改变判据读数。

12. **上限的默认值 4 是未标定的占位值**，与 `K`、`MASKING_FLOOR`、`MASKING_KNEE` 同一档待遇：
    报告里连同来源一并标出，记进 `CONTEXT.md` 的《尚未确立》。它该取多少要在真机上看
    ——「钳掉 N 级之后最淡的网点还在不在」。

13. **新词三个**，实现落地时一并加进 `CONTEXT.md`：**纸白**（进《图像内容》，与网点、灰调、线稿同列）、
    **纸白对齐**与它的**上限**（进《管线》）。《离格量》已经在《量化》里了。

14. **不新增第二个 seam。**「估计纸白」只有一个调用方，拆成公共 API 只会多一处要维护的东西；
    它的性质（满版页量不出来）在对齐那个 seam 上一样测得到。

## Testing Decisions

好的测试**只断言外部看得见的事实**：函数的输入输出、`Report` 里的内容、写出的文件有什么性质。
不断言中间状态、不断言私有结构、不为了可测而把私有的东西暴露出去。

**新 seam 一个**：纸白对齐那个纯函数，`GrayImage → (GrayImage, 这一页做了什么)`。
不碰文件系统、不碰全局状态，与 `score` 同型。在它上面测**性质**，不测具体数值
（上限还没标定，数值会动；而这几条性质正是这一步存在的理由，动了就是它错了）。
写法照 `tests/metric.rs` 的先例——那一篇的模块文档把「断言性质不是数值」的理由写清楚了。

要钉住的性质：

- 离格量为 0 的图**逐像素不变**。
- 离格量超过上限的图**逐像素不变**。
- 平坦区不足的图（满版无纸边）**逐像素不变**。
- 对齐之后，那一页的纸白**恰好是 255**。
- **只有 `[纸白, 255]` 那一段变了**：低于纸白的取值一个都没动。
- 上限取 0 时，任何输入都**逐像素不变**。
- 对齐之后，同一页在 2bit+FS 上的平坦白底**一个点都不撒**（这是整件事的目的，要有一条直接钉它的）。

**既有 seam 两个，都不新增**：

- **`run(Request) -> Report`**（`tests/pipeline.rs`）：外部可见的行为——报告那一行说的话；
  改了参数之后旧输出过期而不是被跳过（`tests/idempotency.rs` 有现成的写法）；
  彩页不受影响；几何门不成立的页照样对齐。
- **黄金快照**（`tests/golden.rs`）：**第一步落地时快照必须逐字节不变**——那是「一页都不改」这条最强的验收。
  第二步抬默认值时快照动一次，**显式接受**。那一篇的模块文档写着它存在的理由就是
  「防止调优在无人察觉时改变判定结果」，这次正是它该拦下的那种改动。

夹具上要补的：一张**离格的**页（纸白 253）与一张**满版无纸边**的页，
让上面那几条性质在管线这一级也走得到。现有夹具全是合成图，纸白多半正好是 255。

## Out of Scope

- **判据那一半不在这里。**低通项加地板、颗粒项地板的新窗口、四个数的重标——那些是
  `metric-recalibration` 那一批的事（`04`、`05`），本 spec 一个字都不改判据。
  两者互补不重叠：对齐治的是**纸白那一个实例**，地板治的是**任何看不见的差异**。
- **不改抖动算法。**边缘门控、阈值调制、换扩散核都不在这里；
  measurements 的《边缘门控抖动救不了那三页》已经量过，那条路管的是另一类劣化。
- **不做逐卷统一的纸白估计。**逐页即可——目标恒为 255，输出的纸白不随页变，
  FFmpeg 那条「逐帧独立算范围会闪烁」的先例对不上（它闪是因为拉到逐帧变化的范围）。
- **不做黑点对齐。**纯黑那一头同样可能离格，但本轮一格数据都没有；要做另开。
- **不碰彩色分支。**
- **不管有损编码。**tonefit 输出 PNG。「拉白点之后再有损编码会不会把白底重新推离格点」
  只在「拿成品再转一遍」时才成立，而那不是目标工况。
- **不为满版无纸边页发明兜底。**「用整卷补一页」在文档图像领域零先例，
  真要做也该等到有证据说它有收益。

## Further Notes

- **数据出处**：43% 离格与钳制宽度的分布见 `docs/measurements.md` 的
  《全语料普查：四成三的页纸白不落在格点上》；真机那四组见《真机三组：4bit 上的抖动分不出，
  白底上的抖动分得出，分界线是纸白落不落在格点上》与《D 组》；
  逐对原始数据在 `.scratch/metric-recalibration/judgements/第六轮真机四组.json`。
- **外部先例**：`docs/research/paper-white-grid-alignment-prior-art.md`。三条最该读的：
  Little-CMS 的 scum dot 修正（机制同构、在产、注释写了理由）；
  ImageMagick 官方明说「white-point only 的算子至今没有实现」，且这个现象在它的文档里
  有名字叫 **E-Dither Pixel Speckling**；数字档案规范（FADGI）把这个操作写成缺陷，
  但 Metamorfoze 自己划了界——**那些规范管的是归档母版，并明说为输出目的做 clipping 可以有用**。
- **文献方向相反**：多级半色调那一支研究过同一个物理事实，但只从**渐变区**那一侧——
  他们把「落在格点上不撒点」当成 banding 病，解法是**往那一档注入点**；
  我们在**平坦纸底**上把同一件事当药。**这个方向没人单独写过**，因此没有现成的参数可抄。
- **一条要留意的观察，不在本 spec 的范围里**：D 组真机判读是 2:2 平，而理由分成两半——
  判读者选抖动的两次都是因为**文字**（2bit 不抖把 40~60 的笔画就近推到 85，浓度掉一档），
  选不抖的两次是因为**背景**。纸白对齐只治背景那一半；文字那一半归判据（低通项本来就看得见它）。
- **上限那个数与真机的关系**：它是本 spec 唯一一个未标定的数，
  已拍板并进 `metric-recalibration/04` 那次上机一起看。
